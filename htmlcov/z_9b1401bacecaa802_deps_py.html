1"""Kernel-construction orchestration. 

2 

3`build_kernel` builds the process-wide `Kernel` from `Settings`, 

4called once from the FastAPI lifespan. The authorize-port factory 

5is INJECTED via the `authorize_factory` callable so this module 

6has zero BC imports (Phase-8d hardening: the prior version lazy- 

7imported `cora.trust` for `_build_authorize`, which tach correctly 

8flagged as a layer violation even though Python tolerated it). 

9 

10Composition root (`cora.api.main`) injects 

11`cora.trust.authorize_factory.build_authorize`; tests inject any 

12`Authorize` factory they want (typically 

13`lambda *a, **kw: AllowAllAuthorize()`). 

14 

15Adapter selection is driven by `Settings.app_env`: 

16 - `test` -> in-memory adapters (no Postgres needed; used by 

17 contract tests of API surface that don't care about 

18 persistence semantics) 

19 - anything else -> Postgres-backed adapters over an asyncpg pool 

20 

21`build_kernel` returns the kernel and a `teardown` callable so the 

22lifespan can release pool resources without `Kernel` having to 

23expose its private state. 

24 

25## Single-Kernel-construction-site invariant 

26 

27`Kernel(...)` is constructed in exactly two places: `make_postgres_kernel` 

28and `make_inmemory_kernel` below. Production's `build_kernel` calls 

29the appropriate primitive with `SystemClock` / `UUIDv7Generator` / 

30env-loaded `Settings`; tests call the same primitives via thin 

31wrappers in `tests/unit/_helpers.py` and `tests/integration/_helpers.py` 

32that supply `FrozenClock` / `FixedIdGenerator` / test `Settings`. 

33 

34The architecture fitness function 

35`tests/architecture/test_kernel_construction_single_site.py` enforces 

36this invariant: any direct `Kernel(...)` call outside this module 

37fails the build. Adding a required `Kernel` field then needs to land 

38in exactly two function bodies (the two primitives) instead of every 

39test file individually. 

40"""

104 """Postgres-backed Kernel primitive. 

105 

106 Single construction site for `Kernel(...)` with a Postgres pool. 

107 Production's `build_kernel` postgres branch calls this with 

108 `SystemClock` + `UUIDv7Generator` + env-loaded `Settings` + the 

109 `authorize` instance built around `event_store`. Integration tests 

110 call it via the `tests.integration._helpers.build_postgres_deps` 

111 wrapper, which supplies `FrozenClock` + `FixedIdGenerator` + test 

112 `Settings`. 

113 

114 `event_store` / `idempotency_store` default to fresh 

115 `PostgresEventStore(pool)` / `PostgresIdempotencyStore(pool)` for 

116 test convenience. Production passes the prebuilt instances so 

117 they're shared with the authorize_factory (chicken-and-egg: 

118 `authorize` needs `event_store` before the Kernel is constructed). 

119 

120 `clearance_lookup` defaults to `AlwaysCoveredClearanceLookup` (the 

121 test-bypass stub) so existing Run integration tests don't have to 

122 seed real clearances. Production's `build_kernel` injects the real 

123 `PostgresClearanceLookup` via the `clearance_lookup_factory` 

124 argument; gate-specific tests override here explicitly. 

125 

126 `caution_lookup` defaults to `AlwaysQuietCautionLookup` (returns 

127 `[]`) so existing Run integration tests don't have to seed 

128 cautions. Production's `build_kernel` injects the real 

129 `PostgresCautionLookup` via the `caution_lookup_factory` argument; 

130 snapshot-specific tests override here explicitly. NON-BLOCKING by 

131 construction (see `cora.infrastructure.ports.caution_lookup`). 

132 

133 `llm` defaults to `None` because most BCs and tests don't need 

134 an LLM; only Agent BC subscribers consume it. Production's 

135 `build_kernel` injects `AnthropicLLMAdapter` when 

136 `Settings.anthropic_api_key` is set; subscriber-level tests 

137 inject `FakeLLMAdapter` explicitly. 

138 

139 `logbook_mirror` defaults to `None`; no production implementor 

140 exists at 8f-b. Subscribers short-circuit on `None`. 

141 """

177 """In-memory Kernel primitive. 

178 

179 Single construction site for `Kernel(...)` with no Postgres pool. 

180 Production's `build_kernel` `app_env=test` branch calls this for 

181 contract tests of the API surface. Unit tests call it via the 

182 `tests.unit._helpers.build_deps` wrapper. 

183 

184 `pool` exists as an optional override exclusively for the 

185 idempotency-pruner tests, which need a non-None sentinel to 

186 exercise the "pool present" branch of the lifespan task without 

187 standing up a real Postgres connection. Production callers (and 

188 every other test) leave it as the default `None`. 

189 

190 `clearance_lookup` defaults to `AlwaysCoveredClearanceLookup` (the 

191 test-bypass stub) because the in-memory kernel has no projection 

192 worker running and no `proj_safety_clearance_summary` table. Gate- 

193 specific tests can override with a custom adapter built around an 

194 InMemory event store walk. 

195 

196 `caution_lookup` defaults to `AlwaysQuietCautionLookup` (returns 

197 `[]`) for the same reason: no projection worker, no 

198 `proj_caution_summary` table. Snapshot-specific tests can override 

199 with a custom adapter or a fake that returns seeded references. 

200 

201 `llm` defaults to `None`; the in-memory kernel is for unit / 

202 contract tests that don't exercise LLM subscribers. Subscriber 

203 tests that DO exercise the LLM path inject `FakeLLMAdapter` 

204 explicitly. 

205 

206 `logbook_mirror` defaults to `None`; no production implementor 

207 at 8f-b. Subscriber tests inject a `FakeLogbookMirror` (when 

208 they care) or leave `None`. 

209 """ 

210 return Kernel( 

211 settings=settings,

213 id_generator=id_generator,

298async def build_kernel( 

299 *, 

300 authorize_factory: AuthorizeFactory, 

301 clearance_lookup_factory: ClearanceLookupFactory | None = None, 

302 caution_lookup_factory: CautionLookupFactory | None = None, 

303 llm_factory: LLMPortFactory | None = None, 

304) -> tuple[Kernel, Teardown]: 

305 """Construct the kernel. Called once from the FastAPI lifespan. 

306 

307 `llm_factory` (Phase 8f-b iter 2a): when provided, called with 

308 `Settings` and the result wired into `kernel.llm`. When `None`, 

309 `kernel.llm` is `None` and Agent BC subscribers that depend on 

310 it fail-fast at registration. Test mode (`app_env=test`) does 

311 NOT call the factory; tests inject `FakeLLMAdapter` directly 

312 via `make_inmemory_kernel(..., llm=...)`. 

313 """ 

314 settings = Settings() # type: ignore[call-arg] # Pydantic loads from env 

315 configure_logging(settings.log_level) 

316 clock = SystemClock() 

317 id_generator = UUIDv7Generator() 

318 

319 if settings.app_env == "test": 

320 event_store: EventStore = InMemoryEventStore() 

321 idempotency_store: IdempotencyStore = InMemoryIdempotencyStore() 

322 authorize = authorize_factory( 

323 settings, 

324 event_store, 

325 pool=None, 

326 clock=clock, 

327 id_generator=id_generator, 

328 ) 

329 kernel = make_inmemory_kernel( 

330 settings=settings, 

331 clock=clock, 

332 id_generator=id_generator, 

333 authorize=authorize, 

334 event_store=event_store, 

335 idempotency_store=idempotency_store, 

336 ) 

337 return kernel, _noop_teardown 

338 

339 pool = await create_pool( 

340 settings.database_url, 

341 min_size=settings.db_pool_min_size, 

342 max_size=settings.db_pool_max_size, 

343 ) 

344 pg_event_store: EventStore = PostgresEventStore(pool) 

345 pg_idempotency_store: IdempotencyStore = PostgresIdempotencyStore(pool) 

346 authorize = authorize_factory( 

347 settings, 

348 pg_event_store, 

349 pool=pool, 

350 clock=clock, 

351 id_generator=id_generator, 

352 ) 

353 clearance_lookup: ClearanceLookup = ( 

354 clearance_lookup_factory(pool) 

355 if clearance_lookup_factory is not None 

356 else AlwaysCoveredClearanceLookup() 

357 ) 

358 caution_lookup: CautionLookup = ( 

359 caution_lookup_factory(pool) 

360 if caution_lookup_factory is not None 

361 else AlwaysQuietCautionLookup() 

362 ) 

363 llm: LLMPort | None = llm_factory(settings) if llm_factory is not None else None 

364 kernel = make_postgres_kernel( 

365 pool, 

366 settings=settings, 

367 clock=clock, 

368 id_generator=id_generator, 

369 authorize=authorize, 

370 event_store=pg_event_store, 

371 idempotency_store=pg_idempotency_store, 

372 clearance_lookup=clearance_lookup, 

373 caution_lookup=caution_lookup, 

374 llm=llm, 

375 ) 

376 return kernel, _compose_teardowns([_maybe_llm_teardown(llm), _make_pool_teardown(pool)])

390def _maybe_llm_teardown(llm: LLMPort | None) -> Teardown: 

391 """Build a teardown that closes the LLM client if it exposes `aclose()`. 

392 

393 Production `AnthropicLLMAdapter` has an `aclose()` method that 

394 releases the SDK's httpx connection pool. Test stubs 

395 (`FakeLLMAdapter`) typically don't; the teardown is a no-op 

396 in that case. When `llm is None` (no LLM configured), the 

397 returned teardown is also a no-op. 

398 """ 

399 

400 async def teardown() -> None: 

401 if llm is None: 

402 return 

403 close = getattr(llm, "aclose", None) 

404 if close is None: 

405 return 

406 await close() 

407 

408 return teardown

411def _compose_teardowns(teardowns: list[Teardown]) -> Teardown: 

412 """Run teardowns sequentially, swallowing per-teardown errors. 

413 

414 Ordering: pass `[a, b, c]` and they run a -> b -> c at shutdown. 

415 Errors from any one teardown are captured and re-raised AFTER 

416 the remaining teardowns run, so a misbehaving LLM client close 

417 doesn't leak the Postgres pool (or vice versa). The first 

418 raised exception wins; subsequent ones are suppressed per 

419 FastAPI shutdown convention. 

420 

421 Catches `Exception` (NOT `BaseException`) so `asyncio.CancelledError` 

422 + `KeyboardInterrupt` + `SystemExit` propagate through the 

423 teardown chain as intended (architecture gate-review P1#2 of 

424 8f-b iter 2b). 

425 """ 

426 

427 async def composed() -> None: 

428 first_exc: Exception | None = None 

429 for td in teardowns: 

430 try: 

431 await td() 

432 except Exception as exc: 

433 if first_exc is None: 433 ↛ 429line 433 didn't jump to line 429 because the condition on line 433 was always true

434 first_exc = exc 

435 if first_exc is not None: 

436 raise first_exc 

437 

438 return composed
