1"""Kernel-construction orchestration. 

2 

3`build_kernel` builds the process-wide `Kernel` from `Settings`, 

4called once from the FastAPI lifespan. The authorize-port factory 

5is INJECTED via the `authorize_factory` callable so this module 

6has zero BC imports (Phase-8d hardening: the prior version lazy- 

7imported `cora.trust` for `_build_authorize`, which tach correctly 

8flagged as a layer violation even though Python tolerated it). 

9 

10Composition root (`cora.api.main`) injects 

11`cora.trust.authorize_factory.build_authorize`; tests inject any 

12`Authorize` factory they want (typically 

13`lambda *a, **kw: AllowAllAuthorize()`). 

14 

15Adapter selection is driven by `Settings.app_env`: 

16 - `test` -> in-memory adapters (no Postgres needed; used by 

17 contract tests of API surface that don't care about 

18 persistence semantics) 

19 - anything else -> Postgres-backed adapters over an asyncpg pool 

20 

21`build_kernel` returns the kernel and a `teardown` callable so the 

22lifespan can release pool resources without `Kernel` having to 

23expose its private state. 

24 

25## Single-Kernel-construction-site invariant 

26 

27`Kernel(...)` is constructed in exactly two places: `make_postgres_kernel` 

28and `make_inmemory_kernel` below. Production's `build_kernel` calls 

29the appropriate primitive with `SystemClock` / `UUIDv7Generator` / 

30env-loaded `Settings`; tests call the same primitives via thin 

31wrappers in `tests/unit/_helpers.py` and `tests/integration/_helpers.py` 

32that supply `FrozenClock` / `FixedIdGenerator` / test `Settings`. 

33 

34The architecture fitness function 

35`tests/architecture/test_kernel_construction_single_site.py` enforces 

36this invariant: any direct `Kernel(...)` call outside this module 

37fails the build. Adding a required `Kernel` field then needs to land 

38in exactly two function bodies (the two primitives) instead of every 

39test file individually. 

40"""

97 """Postgres-backed Kernel primitive. 

98 

99 Single construction site for `Kernel(...)` with a Postgres pool. 

100 Production's `build_kernel` postgres branch calls this with 

101 `SystemClock` + `UUIDv7Generator` + env-loaded `Settings` + the 

102 `authorize` instance built around `event_store`. Integration tests 

103 call it via the `tests.integration._helpers.build_postgres_deps` 

104 wrapper, which supplies `FrozenClock` + `FixedIdGenerator` + test 

105 `Settings`. 

106 

107 `event_store` / `idempotency_store` default to fresh 

108 `PostgresEventStore(pool)` / `PostgresIdempotencyStore(pool)` for 

109 test convenience. Production passes the prebuilt instances so 

110 they're shared with the authorize_factory (chicken-and-egg: 

111 `authorize` needs `event_store` before the Kernel is constructed). 

112 

113 `clearance_lookup` defaults to `AlwaysCoveredClearanceLookup` (the 

114 test-bypass stub) so existing Run integration tests don't have to 

115 seed real clearances. Production's `build_kernel` injects the real 

116 `PostgresClearanceLookup` via the `clearance_lookup_factory` 

117 argument; gate-specific tests override here explicitly. 

118 """

120 settings=settings, 

121 clock=clock, 

122 id_generator=id_generator, 

123 authorize=authorize, 

124 event_store=event_store if event_store is not None else PostgresEventStore(pool),

145) -> Kernel: 

146 """In-memory Kernel primitive. 

147 

148 Single construction site for `Kernel(...)` with no Postgres pool. 

149 Production's `build_kernel` `app_env=test` branch calls this for 

150 contract tests of the API surface. Unit tests call it via the 

151 `tests.unit._helpers.build_deps` wrapper. 

152 

153 `pool` exists as an optional override exclusively for the 

154 idempotency-pruner tests, which need a non-None sentinel to 

155 exercise the "pool present" branch of the lifespan task without 

156 standing up a real Postgres connection. Production callers (and 

157 every other test) leave it as the default `None`. 

158 

159 `clearance_lookup` defaults to `AlwaysCoveredClearanceLookup` (the 

160 test-bypass stub) because the in-memory kernel has no projection 

161 worker running and no `proj_safety_clearance_summary` table. Gate- 

162 specific tests can override with a custom adapter built around an 

163 InMemory event store walk. 

164 """ 

165 return Kernel( 

166 settings=settings, 

167 clock=clock, 

168 id_generator=id_generator, 

169 authorize=authorize, 

170 event_store=event_store if event_store is not None else InMemoryEventStore(), 

171 idempotency_store=( 

172 idempotency_store if idempotency_store is not None else InMemoryIdempotencyStore() 

173 ), 

174 clearance_lookup=( 

175 clearance_lookup if clearance_lookup is not None else AlwaysCoveredClearanceLookup() 

176 ), 

177 pool=pool, # type: ignore[arg-type]

201async def build_kernel( 

202 *, 

203 authorize_factory: AuthorizeFactory, 

204 clearance_lookup_factory: ClearanceLookupFactory | None = None, 

205) -> tuple[Kernel, Teardown]: 

206 """Construct the kernel. Called once from the FastAPI lifespan.""" 

207 settings = Settings() # type: ignore[call-arg] # Pydantic loads from env 

208 configure_logging(settings.log_level) 

209 clock = SystemClock() 

210 id_generator = UUIDv7Generator() 

211 

212 if settings.app_env == "test": 

213 event_store: EventStore = InMemoryEventStore() 

214 idempotency_store: IdempotencyStore = InMemoryIdempotencyStore() 

215 authorize = authorize_factory( 

216 settings, 

217 event_store, 

218 pool=None, 

219 clock=clock, 

220 id_generator=id_generator, 

221 ) 

222 kernel = make_inmemory_kernel( 

223 settings=settings, 

224 clock=clock, 

225 id_generator=id_generator, 

226 authorize=authorize, 

227 event_store=event_store, 

228 idempotency_store=idempotency_store, 

229 ) 

230 return kernel, _noop_teardown 

231 

232 pool = await create_pool( 

233 settings.database_url, 

234 min_size=settings.db_pool_min_size, 

235 max_size=settings.db_pool_max_size, 

236 ) 

237 pg_event_store: EventStore = PostgresEventStore(pool) 

238 pg_idempotency_store: IdempotencyStore = PostgresIdempotencyStore(pool) 

239 authorize = authorize_factory( 

240 settings, 

241 pg_event_store, 

242 pool=pool, 

243 clock=clock, 

244 id_generator=id_generator, 

245 ) 

246 clearance_lookup: ClearanceLookup = ( 

247 clearance_lookup_factory(pool) 

248 if clearance_lookup_factory is not None 

249 else AlwaysCoveredClearanceLookup() 

250 ) 

251 kernel = make_postgres_kernel( 

252 pool, 

253 settings=settings, 

254 clock=clock, 

255 id_generator=id_generator, 

256 authorize=authorize, 

257 event_store=pg_event_store, 

258 idempotency_store=pg_idempotency_store, 

259 clearance_lookup=clearance_lookup, 

260 ) 

261 return kernel, _make_pool_teardown(pool)
