1"""BC-agnostic steering vocabulary: what good means + where to look. 

2 

3These value objects describe the INTENT of an autonomous-experiment search, 

4independent of any brain or beamline: the objective (what good means), the 

5feasible space (where the brain may look), and a proposed point within it. They 

6live here, not in the Operation BC's `DecidePort`, because more than one BC needs 

7them: the Operation `DecidePort` reuses them for the within-procedure steered 

8loop, and the Campaign aggregate declares a campaign's steering INTENT 

9(`steering_objective` / `steering_space`) so an across-Run steerer can derive the 

10next Run. tach forbids `cora.campaign` from importing `cora.operation.ports`, so 

11the shared value types move here (an allowed campaign dependency), exactly as 

12`DecisionConfidenceSource` moved to `cora.shared.decision_signals` for the same 

13reason. `DecidePort` re-exports the intent value types that MOVED out of it, so 

14existing Operation importers stay stable. Names that originated here, such as 

15`SteeringSubstrate` and `SteeringDesignSource`, are imported from this module 

16directly: there is no legacy importer to keep stable, and the substrate one must 

17not enter the port's public surface, which is deliberately blind to which brain 

18is behind the seam. 

19 

20`serialize_objective` / `deserialize_objective` / `serialize_space` / 

21`deserialize_space` live here for the same reason as the VOs themselves: both 

22`CampaignSteeringDeclared` and the Operation Procedure's `SteeringDesignRecorded` 

23carry `SteeringObjective` / `SteeringSpace`, and a shared VO must not carry two 

24payload shapes across the two streams. 

25 

26Deliberately narrow: only the value types two BCs genuinely share live here. The 

27ADVICE side of the seam (`SteeringAdvice`, `SteeringVerdict`, `SteeringEvidence`, 

28`SteeringObservation`, `SteeringBudget`, the `Decide*Error` families, the 

29`DecidePort` Protocol, and the `objective_is_satisfied` predicate that reads a 

30`Measurement`) stays in `cora.operation.ports.decide_port`: those depend on the 

31Operation BC's own value types (`Measurement`, `ArtifactRef`, `ActuationKind`) 

32and only the Operation BC consumes them. 

33"""

185

240SteeringBrain = InMemoryBrain | GridWalkBrain | SobolBrain | BoTorchBrain | StagedBrain | LlmBrain 

241"""The typed per-substrate steering-brain config space. 

242 

243One variant per `SteeringSubstrate` member, carrying exactly the values 

244that determine what that brain does and nothing a run of a DIFFERENT 

245substrate would have to declare irrelevant. `BRAIN_TYPE_BY_SUBSTRATE` 

246below is the totality of that pairing; the sibling fitness test asserts 

247its keys equal the full `SteeringSubstrate` enum, mirroring 

248`test_steering_substrate_matches_decide_substrate_literal`. 

249 

250Deliberately a true union of distinct classes (the `ControlAddress` 

251shape: `EpicsPvAddress | TangoAttributeAddress | InMemoryAddress`), not 

252one flat class with a kind field and every substrate's fields hoisted 

253onto it. A run recording `GridWalkBrain(points_per_axis=5)` carries no 

254`seed` slot to leave unset; the flat `DecidePortConfig` a run's config 

255comes from does, and a grid-walk run's recorded `seed` is a design fact 

256that had no effect on it. See [[project-per-kind-field-belongs-in-its-arm]]. 

257 

258`gen_record_dispositions._merge` folds a multi-variant union's field 

259dispositions into one rule covering every arm's keys, so this exports 

260correctly under `SteeringDesignRecorded` provided no two variants reuse a 

261field NAME for a different disposition; `BoTorchBrain.seed: int` and 

262`StagedBrain.handoff_brain.seed` (nested, not a naming collision) are the 

263only `seed`-named fields in this union, and both resolve identically. 

264 

265No emitter reads this yet: the type exists so both recording surfaces 

266(a Procedure segment's `SteeringDesignRecorded`, a future across-Run 

267steerer) can share one vocabulary, exactly as `SteeringObjective` / 

268`SteeringSpace` do. 

269"""

284enum member, or vice versa, is what that test exists to catch; the two

304@dataclass(frozen=True) 

305class DecidingBrainRef: 

306 """WHICH brain decided one steered iteration, typed rather than spelled. 

307 

308 The `Ref` suffix carries the axis that separates this from `SteeringBrain` 

309 above, matching `BrainRef` in the Agent BC, which is the same shape for 

310 the same question. `SteeringBrain` is design-time CONFIG: the dials a 

311 segment's brain was built with, pinned once on `SteeringDesignRecorded`. 

312 This is run-time IDENTITY: which brain answered one pass, recorded on every 

313 `ProcedureIterationEnded` a steered conduct writes. A `staged` segment is 

314 the case that makes them different facts rather than two spellings of 

315 one. Its design pins the composite; each iteration is decided by 

316 whichever child the composite had handed off to by then, which the design 

317 cannot say and only the iteration knows. 

318 

319 Carries exactly what the free-text `model_ref` it stands beside encodes, 

320 and nothing more: four substrates spell their own name, `llm` spells 

321 `provider:model`. `str()` renders that spelling back, so the two 

322 recorded forms are one fact rendered twice rather than two fields that 

323 can drift. `snapshot_pin` is deliberately absent even though `LlmBrain` 

324 carries it: a pin is a dial on the model, so it belongs to the design, 

325 and repeating it once per pass would re-record configuration as though it 

326 were an observation. 

327 

328 `STAGED` is rejected rather than representable. The composite returns its 

329 child's advice unchanged, so what reaches an iteration is `sobol` or 

330 `botorch`; a `DecidingBrainRef` naming the composite would mean the 

331 composite had grown an identity of its own, which `decider_replayability` 

332 already refuses to classify. Rejecting it at construction makes that 

333 state unwritable instead of merely unreadable. 

334 """ 

335 

336 substrate: SteeringSubstrate 

337 provider: str | None = None 

338 model: str | None = None

342 case SteeringSubstrate.LLM: 

343 if not self.provider or not self.model: 343 ↛ 344line 343 didn't jump to line 344 because the condition on line 343 was never true

344 raise InvalidDecidingBrainRefError( 

345 "an llm brain is named by a non-empty provider and model" 

346 ) 

347 case ( 

348 SteeringSubstrate.IN_MEMORY 

349 | SteeringSubstrate.GRID_WALK 

350 | SteeringSubstrate.SOBOL 

351 | SteeringSubstrate.BOTORCH 

352 ): 

353 if self.provider is not None or self.model is not None: 353 ↛ 354line 353 didn't jump to line 354 because the condition on line 353 was never true

354 raise InvalidDecidingBrainRefError( 

355 f"the {self.substrate.value!r} brain is named by its substrate " 

356 "alone and carries no provider or model" 

357 ) 

358 case SteeringSubstrate.STAGED: 

359 raise InvalidDecidingBrainRefError( 

360 "the staged composite decides no iteration itself; name the child " 

361 "brain it had handed off to" 

362 ) 

363 case _: # pragma: no cover - exhaustive over a closed enum 

364 assert_never(self.substrate)

366 def __str__(self) -> str: 

367 """Render the flat `model_ref` spelling the record still carries. 

368 

369 The single producer of that string, so the typed field and the legacy 

370 one on the same event are one fact rendered twice. Total over every 

371 constructible brain, and readable by `decider_replayability`, which 

372 still classifies the string form because a stream written before this 

373 type existed carries only that. 

374 

375 `__str__` rather than a named converter, following `ControlAddress` 

376 (the union shape this module's `SteeringBrain` already copies) and 

377 `FacilityCode`: both render a discriminated value object to the flat 

378 form the wire carries this way. A `to_model_ref` would read as 

379 returning `cora.infrastructure.ports.llm.ModelRef`, since every `to_X` 

380 in the tree returns the type it names, and this returns a string. 

381 No matching `parse` is offered: the fold deliberately does not 

382 reconstruct a brain from a legacy ref, and `decider_replayability` 

383 already reads that form. 

384 """ 

385 if self.substrate is SteeringSubstrate.LLM: 

386 return f"{self.provider}{LLM_REF_SEPARATOR}{self.model}" 

387 return self.substrate.value

493def serialize_brain(brain: SteeringBrain) -> dict[str, Any]: 

494 """Encode a SteeringBrain variant to a JSON-friendly dict. 

495 

496 No embedded type tag: the caller's own `substrate` field (already on 

497 every event this carries) is the discriminant `deserialize_brain` 

498 needs back, so one is not duplicated inside the payload. 

499 """ 

500 match brain: 

501 case InMemoryBrain(): 

502 return {} 

503 case GridWalkBrain(points_per_axis=points_per_axis): 

504 return {"points_per_axis": points_per_axis} 

505 case SobolBrain(): 

506 return {} 

507 case BoTorchBrain( 

508 min_observations=min_observations, 

509 num_restarts=num_restarts, 

510 raw_samples=raw_samples, 

511 seed=seed, 

512 ): 

513 return { 

514 "min_observations": min_observations, 

515 "num_restarts": num_restarts, 

516 "raw_samples": raw_samples, 

517 "seed": seed, 

518 } 

519 case StagedBrain(threshold=threshold, handoff_brain=child): 

520 return {"threshold": threshold, "handoff_brain": serialize_brain(child)} 

521 case LlmBrain(provider=provider, model=model, snapshot_pin=snapshot_pin): 

522 return {"provider": provider, "model": model, "snapshot_pin": snapshot_pin} 

523 case _: # pragma: no cover - exhaustive over SteeringBrain's closed union 

524 assert_never(brain)

537 return BoTorchBrain(

539 num_restarts=payload["num_restarts"], 

540 raw_samples=payload["raw_samples"], 

541 seed=payload["seed"], 

542 )

545def deserialize_brain(substrate: SteeringSubstrate, payload: Mapping[str, Any]) -> SteeringBrain: 

546 """Decode a JSON-friendly dict to the SteeringBrain variant for `substrate`. 

547 

548 Takes `substrate` as an explicit parameter rather than reading a tag out 

549 of `payload`, mirroring `parse_control_address(raw, substrate)`: the 

550 caller already knows the substrate from the same event's own 

551 `substrate` field, so a second embedded tag would be a duplicate a 

552 reader could read out of step with the first. 

553 """ 

554 match substrate: 

555 case SteeringSubstrate.IN_MEMORY: 

556 return InMemoryBrain() 

557 case SteeringSubstrate.GRID_WALK: 

558 return GridWalkBrain(points_per_axis=payload["points_per_axis"]) 

559 case SteeringSubstrate.SOBOL: 

560 return SobolBrain() 

561 case SteeringSubstrate.BOTORCH: 

562 return _deserialize_botorch_brain(payload) 

563 case SteeringSubstrate.STAGED: 

564 return StagedBrain( 

565 threshold=payload["threshold"], 

566 handoff_brain=_deserialize_botorch_brain(payload["handoff_brain"]), 

567 ) 

568 case SteeringSubstrate.LLM: 

569 return LlmBrain( 

570 provider=payload["provider"], 

571 model=payload["model"],
