1"""BC-agnostic steering vocabulary: what good means + where to look. 

2 

3These value objects describe the INTENT of an autonomous-experiment search, 

4independent of any brain or beamline: the objective (what good means), the 

5feasible space (where the brain may look), and a proposed point within it. They 

6live here, not in the Operation BC's `DecidePort`, because more than one BC needs 

7them: the Operation `DecidePort` reuses them for the within-procedure steered 

8loop, and the Campaign aggregate declares a campaign's steering INTENT 

9(`steering_objective` / `steering_space`) so an across-Run steerer can derive the 

10next Run. tach forbids `cora.campaign` from importing `cora.operation.ports`, so 

11the shared value types move here (an allowed campaign dependency), exactly as 

12`DecisionConfidenceSource` moved to `cora.shared.decision_signals` for the same 

13reason. `DecidePort` re-exports the intent value types that MOVED out of it, so 

14existing Operation importers stay stable. Names that originated here, such as 

15`SteeringSubstrate` and `SteeringDesignSource`, are imported from this module 

16directly: there is no legacy importer to keep stable, and the substrate one must 

17not enter the port's public surface, which is deliberately blind to which brain 

18is behind the seam. 

19 

20`serialize_objective` / `deserialize_objective` / `serialize_space` / 

21`deserialize_space` live here for the same reason as the VOs themselves: both 

22`CampaignSteeringDeclared` and the Operation Procedure's `SteeringDesignRecorded` 

23carry `SteeringObjective` / `SteeringSpace`, and a shared VO must not carry two 

24payload shapes across the two streams. 

25 

26Deliberately narrow: only the value types two BCs genuinely share live here. The 

27ADVICE side of the seam (`SteeringAdvice`, `SteeringVerdict`, `SteeringEvidence`, 

28`SteeringObservation`, `SteeringBudget`, the `Decide*Error` families, the 

29`DecidePort` Protocol, and the `objective_is_satisfied` predicate that reads a 

30`Measurement`) stays in `cora.operation.ports.decide_port`: those depend on the 

31Operation BC's own value types (`Measurement`, `ArtifactRef`, `ActuationKind`) 

32and only the Operation BC consumes them. 

33"""

41class SteeringObjectiveKind(StrEnum): 

42 """The optimization SENSE of an objective, without a search strategy. 

43 

44 The seam tells the brain what 'better' means; the brain owns how to get 

45 there. `Minimize` / `Maximize` drive a metric down / up; `Satisfy` hits 

46 a target value; `Explore` has no scalar target (the brain just covers 

47 the space, e.g. a grid). Anything richer (acquisition function, kernel, 

48 exploration weight) is the adapter's concern, deliberately not here. 

49 """ 

50 

51 MINIMIZE = "Minimize" 

52 MAXIMIZE = "Maximize" 

53 SATISFY = "Satisfy" 

54 EXPLORE = "Explore"

57class SteeringSubstrate(StrEnum): 

58 """Which brain materialised a steered run's `DecidePort`. 

59 

60 Mirrors, value for value, the `DecideSubstrate` Literal in 

61 `cora.operation.adapters.decide_port_config` (kept in sync by a 

62 fitness test, since tach forbids this shared module from importing 

63 that adapter-tier Literal directly). Lives here rather than being 

64 imported from there because it is recorded on a Procedure event, 

65 and events are typed with shared vocabulary, not adapter internals. 

66 

67 `IN_MEMORY` is the deterministic fake; `GRID_WALK` is the in-CORA 

68 grid/sweep decider; `SOBOL` is the Sobol initial-design seeder; 

69 `BOTORCH` is the GP Bayesian-optimization brain; `STAGED` is the 

70 two-phase sobol-then-botorch composite; `LLM` is the LLM steering 

71 brain. 

72 """ 

73 

74 IN_MEMORY = "in_memory" 

75 GRID_WALK = "grid_walk" 

76 SOBOL = "sobol" 

77 BOTORCH = "botorch" 

78 STAGED = "staged" 

79 LLM = "llm"

82class SteeringDesignSource(StrEnum): 

83 """Where a pinned steering design originated. 

84 

85 One value today: `REQUEST`, the operator- or agent-supplied wire 

86 request that started or resumed the conduct segment. Every design 

87 pin currently traces to that single origin, so a second value 

88 would have nothing to distinguish itself from and no reader ready 

89 to branch on it; this stays single-valued until an across-Run 

90 steerer can itself originate a design, at which point widening 

91 this enum is purely additive. 

92 """ 

93 

94 REQUEST = "Request"

97@dataclass(frozen=True) 

98class SteeringPoint: 

99 """A coordinate in the search space: axis name -> value. 

100 

101 The brain proposes it; the caller translates it into Conductor steps 

102 (the port never sees a Step, a PV, or the captures bus). Values are 

103 `Any` so a continuous axis carries a float, a discrete axis an int, and 

104 a categorical axis a label, all keyed by the `SteeringAxis.name` that 

105 is the bridge to the caller's actuation. 

106 """ 

107 

108 coordinates: Mapping[str, Any] 

109

111@dataclass(frozen=True) 

112class SteeringAxis: 

113 """One dimension of the feasible set: a name plus its legal range. 

114 

115 `name` is the substrate-neutral axis label the caller binds to an 

116 actuation slot; the brain only ever reasons about the name and its 

117 range. `lower` / `upper` bound a continuous axis; `choices` enumerates a 

118 discrete or categorical axis (empty for a pure continuous axis). The 

119 axis declarations are supplied by the caller, never invented by the 

120 brain, because the caller must translate a `next_point` back into steps. 

121 """ 

122 

123 name: str 

124 lower: float | None = None 

125 upper: float | None = None 

126 choices: tuple[Any, ...] = ()

129@dataclass(frozen=True) 

130class SteeringSpace: 

131 """The feasible set the brain may propose points within. 

132 

133 Required whenever the brain may return `Measure`: it is load-bearing for 

134 the caller's point-to-step translation (the caller cannot turn a 

135 `next_point` into actuation without the axis names and ranges), 

136 independent of which brain is behind the seam. 

137 """ 

138 

139 axes: tuple[SteeringAxis, ...]

142@dataclass(frozen=True) 

143class SteeringObjective: 

144 """What 'good' means, by a Measurement NAME, without a search strategy. 

145 

146 `target_measurement_name` names which `Measurement` in the observations 

147 is the objective scalar, so the brain ignores the rest. It is a NAME, 

148 origin-agnostic: the scalar may be a detector read (control) or a 

149 compute output (a derived quality metric), which is what keeps a 

150 compute-steering brain expressible with these same DTOs. `target_value` 

151 is the setpoint a `Satisfy` objective aims at; it is None for 

152 `Minimize` / `Maximize` / `Explore`. 

153 """ 

154 

155 kind: SteeringObjectiveKind 

156 target_measurement_name: str | None = None 

157 target_value: float | None = None

161# Serialize / deserialize (public; shared across every event stream that 

162# carries these VOs, so the same value object never carries two payload 

163# shapes -- Campaign's CampaignSteeringDeclared and Operation's 

164# SteeringDesignRecorded both call these rather than each hand-rolling 

165# their own encode/decode). 

166# ---------------------------------------------------------------------------

168 

169def serialize_objective(objective: SteeringObjective) -> dict[str, Any]: 

170 """Encode a SteeringObjective to a JSON-friendly dict.""" 

171 return { 

172 "kind": objective.kind.value, 

173 "target_measurement_name": objective.target_measurement_name, 

174 "target_value": objective.target_value, 

175 } 

176 

177 

178def deserialize_objective(payload: dict[str, Any]) -> SteeringObjective: 

179 """Decode a JSON-friendly dict to a SteeringObjective.""" 

180 return SteeringObjective( 

181 kind=SteeringObjectiveKind(payload["kind"]), 

182 target_measurement_name=payload.get("target_measurement_name"), 

183 target_value=payload.get("target_value"), 

184 ) 

185 

186 

187def serialize_space(space: SteeringSpace) -> dict[str, Any]: 

188 """Encode a SteeringSpace to a JSON-friendly dict (choices tuple -> list).""" 

189 return { 

190 "axes": [ 

191 { 

192 "name": axis.name, 

193 "lower": axis.lower, 

194 "upper": axis.upper, 

195 "choices": list(axis.choices), 

196 } 

197 for axis in space.axes 

198 ] 

199 } 

200 

201 

202def deserialize_space(payload: dict[str, Any]) -> SteeringSpace: 

203 """Decode a JSON-friendly dict to a SteeringSpace (choices list -> tuple).""" 

204 return SteeringSpace( 

205 axes=tuple( 

206 SteeringAxis( 

207 name=axis["name"], 

208 lower=axis.get("lower"), 

209 upper=axis.get("upper"), 

210 choices=tuple(axis.get("choices", [])), 

211 ) 

212 for axis in payload["axes"] 

213 ) 

214 )
