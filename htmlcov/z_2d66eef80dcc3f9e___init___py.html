1"""Data bounded context. 

2 

3Owns the "what came out" side of every Run. Per BC map, two 

4aggregates eventually (`Dataset`, `Transfer`); first cut is just 

5`Dataset`, the logical research data product, with bulk referenced 

6by URI + sha256 checksum. 

7 

8Independent track BC (no ISA analog). Cross-BC reads at registration 

9time: 

10 - `Run` (Track A): producing_run_id is the Run that produced the 

11 Dataset; existence-checked at registration (no status check). 

12 - `Subject` (Independent): subject_id is the Subject the Dataset 

13 is about; existence-checked at registration. 

14 - `Dataset` (recursive): each derived_from id is an upstream 

15 Dataset this one was derived from; each existence-checked. 

16 

17What `Dataset` is NOT: 

18 - Not the bytes (those live at the URI; S3 / Globus / POSIX / etc.) 

19 - Not a substream entry (per-projection rows live in a future Run 

20 samples logbook with the dataset URI as a column) 

21 - Not a Transfer (separate aggregate, deferred to its own phase) 

22 

23 

24Minimal Dataset: id + name + uri + checksum + byte_size + encoding 

25+ optional cross-refs + status (defaults `Registered`). 

26 

27Three slices: 

28 - `register_dataset` (create-style; idempotency-wrapped; full 

29 cross-aggregate validation via DatasetRegistrationContext; 

30 rejects Discarded sources in derived_from per 7b tightening) 

31 - `discard_dataset` (Registered → Discarded terminal; strict-not- 

32 idempotent; free-form `reason: str` 1-500 chars; GDPR-shaped) 

33 - `get_dataset` (read side; fold-on-read; mirrors get_subject) 

34 

35Archive / Verify / Move transitions defer until storage tiers / 

36re-checksum workflows ship. 

37 

38## Standards alignment (post-survey, gate-review L3 + deferred-with-trigger) 

39 

40 - PROV-O at API export boundary (deferred until first PROV 

41 consumer) 

42 - DataCite 4.7 metadata schema as export schema (deferred until 

43 cross-facility export ships) 

44 - RO-Crate 1.2 as packaging (deferred until cross-facility export) 

45 - FAIR Signposting at REST export (deferred-with-trigger: first 

46 license / citation / PROV graph endpoint) 

47 - In-domain `encoding` (schema.org / RO-Crate vocabulary) carries 

48 media_type + conforms_to: list of profile URIs; locked at L3 to 

49 avoid breaking change later. DataCite's export schema uses 

50 `format` which the export adapter would map to. 

51 - Croissant defer (ML-side; trigger = first ML-training export) 

52 - Zarr v3 defer (trigger = first cloud-native facility ingest) 

53 

54Layout (mirrors every other BC): 

55 aggregates/dataset/ -- aggregate state, events union, evolver, read 

56 features/<verb>_dataset/ -- vertical slice: command/query + decider? + handler + route + tool 

57 wire.py -- DataHandlers bundle + wire_data(deps) 

58 routes.py -- register_data_routes(app) 

59 tools.py -- register_data_tools(mcp, *, get_handlers) 

60"""
