1"""Dataset aggregate state, value objects, status enum, and domain errors. 

2 

3`Dataset` is the logical research data product, not the bytes 

4themselves. Bytes live wherever the URI points (S3 / Globus / 

5POSIX / etc.); the Data BC stores only the metadata: identity, 

6URI, checksum, byte_size, encoding, lineage, and the cross-aggregate 

7references back to whatever produced or describes the data. 

8 

9## What a Dataset is NOT 

10 

11 - Not the bytes (those live at the URI) 

12 - Not a substream entry (per-projection rows live in a future 

13 Run samples logbook with the dataset URI as a column; one 

14 Dataset = one logical product, not one Dataset per projection) 

15 - Not a Transfer record (Transfer is a separate aggregate, 

16 deferred to its own phase) 

17 

18 

19Minimal Dataset: id + name + uri + checksum + byte_size + encoding 

20+ optional cross-refs (producing_run_id, producing_procedure_id, 

21subject_id, derived_from) + status (defaults `Registered`). 

22 

237a shipped Registered as the genesis state. 7b adds the Discarded 

24terminal: a Registered Dataset can transition to Discarded with a 

25free-form reason (1-500 chars; mirrors stop_run / abort_run / 

26truncate_run shape). Discarded is GDPR-shaped: bytes at the URI 

27have been deleted from storage but the metadata record + reason are 

28retained for audit. Re-discarding raises (strict-not-idempotent). 

29 

307b also tightens the lineage invariant: registering a Dataset with 

31`derived_from` referencing any Discarded Dataset raises 

32`DerivedFromDatasetsDiscardedError` (we don't allow new lineage 

33edges into bytes that no longer exist). 

34 

35Archive / Verify / Move transitions defer until storage tiers / 

36re-checksum workflows ship. 

37 

38## Encoding as structured VO (gate-review L3 refinement, 2026-05-11) 

39 

40`encoding` is a small VO: `media_type: str` (loose MIME-type-ish 

41string) plus `conforms_to: frozenset[str]` (zero or more profile 

42URIs the Dataset claims to conform to, for example 

43`https://manual.nexusformat.org/...` or `https://ngff.openmicroscopy.org/0.4/`). 

44This matches schema.org's `encodingFormat` + `conformsTo` pair and 

45RO-Crate 1.2's pattern. The free-form-string-only alternative was 

46the original draft, but the standards survey showed real Datasets 

47can claim multiple profiles (NeXus + OME-Zarr is a documented 

48case), and retrofitting `conforms_to` later would be a breaking 

49change on the genesis event payload. 

50 

51Field name `encoding` rather than `format` deliberately avoids 

52shadowing the Python builtin `format()` and aligns with 

53schema.org's vocabulary; DataCite's export schema uses `format`, 

54which the export adapter maps to when one ships. 

55 

56## Cross-aggregate references 

57 

58Four optional refs: 

59 

60 - `producing_run_id: UUID | None`: the Run that produced this 

61 Dataset. None for externally-sourced data, uploaded reference 

62 sets, or pre-existing data being newly registered. 

63 - `producing_procedure_id: UUID | None`: the conducted Procedure 

64 that produced this Dataset (the secondary producer arm; most 

65 Datasets come from a Run). None for non-conducted / external 

66 Datasets. 

67 - `subject_id: UUID | None`: the Subject the Dataset is "about." 

68 None for calibration / dark-field / synthetic data with no 

69 sample. 

70 - `derived_from: frozenset[UUID]`: lineage edges to other 

71 Datasets this one was derived from (raw → reconstructed → 

72 segmented → ...). Empty for raw/captured data; multi-source 

73 for derivations that combine several inputs (multi-modal 

74 fusion, comparative analyses). 

75 

76Eventual-consistency stance: existence-only validation at the 

77handler load step, no status check (so Datasets can be registered 

78mid-Run, and derived from any non-Discarded Dataset). Re-validation 

79at fold time is NOT performed; same posture as Run-start's 

80Plan/Subject loading. 

81 

82The inverse query "what Datasets did Run X produce?" requires a 

83projection (deferred); it's never carried on the Run aggregate. 

84 

85## Lineage in domain vs PROV-O at API boundary 

86 

87In-domain lineage stays as the simple `derived_from` edge set on 

88each Dataset; query-time graph walks reconstruct the full 

89provenance chain. PROV-O export (using `prov:wasDerivedFrom`, 

90`prov:wasGeneratedBy`, `prov:Entity`/`Activity`/`Agent`) lives at 

91the API export adapter when a real consumer asks; we don't import 

92PROV-O vocabulary into the domain core. 

93 

94## Identifier scheme 

95 

96Dataset id is UUIDv7 (matches the cross-BC convention). Persistent 

97identifiers (DOIs via DataCite, including the IGSN-via-DataCite 

98flow for samples) land at the export layer when first needed; they 

99are not part of the in-domain Dataset identity. 

100 

101## Addition: Calibration BC AsShot citation (`used_calibration_ids`) 

102 

103`used_calibration_ids: frozenset[UUID]` records the CalibrationRevision 

104IDs the reconstruction (or any derivative) actually used. Symmetric 

105to Run.pinned_calibration_ids (AsShot anchor on the acquired-from Run); 

106the two sets are independent — reconstruction 

107may legitimately cite refined revisions not in the producing Run's 

108pin set (for example, a `tomopy.find_center_vo` refinement). NO write-time 

109cross-BC enforcement of derivative-source set equality per 

110[[project_calibration_design]] anti-hook #3 (revision-cited atomic 

111IDs make "partial override" a category error in this model). The 

112dual rule (anti-hook #13) is "no synthesis-by-omission" — every 

113value used MUST be a cited revision. 

114 

115## Twelfth bounded-name VO 

116 

117`DatasetName` calls the shared `validate_bounded_text` helper hoisted in 

1186e-1 (`cora.shared.bounded_text`). Twelfth occurrence of the 

119trimmed-bounded-name VO pattern (after Actor / Zone / Conduit / 

120Policy / Subject / Family / Asset / Method / Practice / Plan / 

121Run). 

122"""

193class Intent(StrEnum): 

194 """The Dataset's trust level / promotion state. 

195 

196 `Trial`: default on register. Working data: calibration scans, 

197 alignment runs, exposure tests, exploratory acquisitions. Not 

198 authoritative; no peer-reviewed claims attached. 

199 

200 `Production`: explicitly promoted via `promote_dataset`. 

201 Publication-grade, citable. Operator's intent is "this is the 

202 keeper"; the audit log captures WHY (PromotionReason) immutably. 

203 

204 `Retracted`: explicitly demoted from Production via 

205 `demote_dataset`. Terminal Intent value; no re-promote from 

206 Retracted (semantic: "this Dataset was authoritative, then 

207 retracted; if you want to re-publish a corrected version, 

208 register a NEW Dataset with `derived_from` pointing at this 

209 one"). The audit log captures WHY (DemotionReason) immutably. 

210 First concrete instantiation of the Q4 compensation-primitive 

211 pattern (per [[project-dataset-demote-design]]; mirrors the 

212 Crossref retraction model: additive notice, original 

213 preserved + marked). 

214 

215 Open enum: future values (Calibration, Superseded, Authoritative) 

216 land additively without breaking existing payloads (additive- 

217 state pattern). See [[project_dataset_lineage_design]]. 

218 

219 Distinct from `DatasetStatus` (Registered | Discarded) which 

220 captures lifecycle. Intent captures trust level: orthogonal to 

221 lifecycle, mutated by separate slices (`promote_dataset` / 

222 `demote_dataset`). 

223 """ 

224 

225 TRIAL = "Trial" 

226 PRODUCTION = "Production" 

227 RETRACTED = "Retracted"

737def _validate_storage_uri( 

738 value: str, 

739 *, 

740 max_length: int, 

741 error_factory: Callable[[str, str], Exception], 

742) -> str: 

743 """Validate a storage URI string per the shared Dataset/Distribution rules. 

744 

745 Returns the trimmed value or raises the caller's error class. The 

746 rules are: 

747 

748 - non-empty after `.strip()` 

749 - length <= ``max_length`` 

750 - `urllib.parse.urlparse(trimmed).scheme` non-empty 

751 - scheme (lower-cased) not in :data:`DATASET_URI_BLOCKED_SCHEMES` 

752 (defensive XSS blocklist; the same threat surface applies to a 

753 Distribution URI as to a Dataset URI) 

754 

755 Bytes resolution / existence check is out of scope at the BC layer 

756 (gate-review Q4 lock A: trust at registration; periodic re-checksum 

757 / verification is its own future workflow). 

758 """ 

759 trimmed = value.strip() 

760 if not trimmed: 

761 raise error_factory(value, "empty or whitespace-only") 

762 if len(trimmed) > max_length: 

763 raise error_factory(value, f"exceeds {max_length} chars") 

764 parsed = urlparse(trimmed) 

765 if not parsed.scheme: 

766 raise error_factory(value, "missing URI scheme") 

767 if parsed.scheme.lower() in DATASET_URI_BLOCKED_SCHEMES: 

768 raise error_factory( 

769 value, 

770 f"URI scheme {parsed.scheme!r} is blocked (XSS risk)", 

771 ) 

772 return trimmed

798@dataclass(frozen=True) 

799class DatasetChecksum: 

800 """Bulk-content integrity hash. Algorithm + canonical value. 

801 

802 Deviation from Identifier VO: strict 64-char lowercase-hex value 

803 invariant beyond Identifier's generic 1-200 bound. 

804 

805 Two algorithms accepted: `sha256` (a single file) and `sha256-tree` 

806 (a directory folded into a deterministic sha256 over its canonical 

807 manifest, the digest a directory-output compute artifact carries). 

808 Both produce a 64-char lowercase-hex value, so the value-format rules 

809 are identical; only the algorithm tag distinguishes them. The 

810 `(algorithm, value)` shape stays forward-compatible for adding 

811 BLAKE3 / SHA3 / etc. when a real consumer asks. 

812 """ 

813 

814 algorithm: str 

815 value: str 

816 

817 def __post_init__(self) -> None: 

818 if self.algorithm not in DATASET_CHECKSUM_ALGORITHMS: 

819 raise InvalidDatasetChecksumError( 

820 self.algorithm, 

821 self.value, 

822 f"algorithm must be one of {sorted(DATASET_CHECKSUM_ALGORITHMS)}", 

823 ) 

824 if len(self.value) != DATASET_CHECKSUM_SHA256_HEX_LENGTH: 

825 raise InvalidDatasetChecksumError( 

826 self.algorithm, 

827 self.value, 

828 f"checksum value must be {DATASET_CHECKSUM_SHA256_HEX_LENGTH} hex chars", 

829 ) 

830 if not all(c in "0123456789abcdef" for c in self.value): 

831 raise InvalidDatasetChecksumError( 

832 self.algorithm, 

833 self.value, 

834 "checksum value must be lowercase hex (0-9, a-f)", 

835 )

838@dataclass(frozen=True) 

839class DatasetEncoding: 

840 """Structured encoding descriptor: media_type + conforms_to profile URIs. 

841 

842 Per the gate-review L3 refinement (post-standards-survey), this 

843 is a small VO rather than a free-form string. `media_type` is 

844 a loose MIME-type-ish string ("application/x-hdf5", 

845 "application/x-zarr", "application/x-tiff", etc.); `conforms_to` 

846 is a possibly-empty set of profile URIs the Dataset claims 

847 (NeXus, OME-Zarr, CIF, etc.). Forward-compatible with RO-Crate 

848 1.2's pattern. 

849 

850 The on-the-wire payload representation sorts `conforms_to` 

851 deterministically (matches the Policy/permitted_principal_ids 

852 precedent) so two registrations of the same logical encoding 

853 produce byte-identical jsonb. 

854 """ 

855 

856 media_type: str 

857 conforms_to: frozenset[str] = field(default_factory=frozenset[str]) 

858 

859 def __post_init__(self) -> None: 

860 trimmed_media_type = self.media_type.strip() 

861 if not trimmed_media_type: 

862 raise InvalidDatasetEncodingError("media_type empty or whitespace-only") 

863 if len(trimmed_media_type) > DATASET_MEDIA_TYPE_MAX_LENGTH: 

864 raise InvalidDatasetEncodingError( 

865 f"media_type exceeds {DATASET_MEDIA_TYPE_MAX_LENGTH} chars" 

866 ) 

867 if len(self.conforms_to) > DATASET_CONFORMS_TO_MAX_ENTRIES: 

868 raise InvalidDatasetEncodingError( 

869 f"conforms_to has too many entries " 

870 f"(max {DATASET_CONFORMS_TO_MAX_ENTRIES}, got {len(self.conforms_to)})" 

871 ) 

872 trimmed_conforms_to: set[str] = set() 

873 for entry in self.conforms_to: 

874 entry_trimmed = entry.strip() 

875 if not entry_trimmed: 

876 raise InvalidDatasetEncodingError("conforms_to entry is empty or whitespace-only") 

877 if len(entry_trimmed) > DATASET_CONFORMS_TO_ENTRY_MAX_LENGTH: 

878 raise InvalidDatasetEncodingError( 

879 f"conforms_to entry exceeds " 

880 f"{DATASET_CONFORMS_TO_ENTRY_MAX_LENGTH} chars: {entry!r}" 

881 ) 

882 trimmed_conforms_to.add(entry_trimmed) 

883 object.__setattr__(self, "media_type", trimmed_media_type) 

884 object.__setattr__(self, "conforms_to", frozenset(trimmed_conforms_to))

926@dataclass(frozen=True) 

927class Dataset: 

928 """Aggregate root: one logical research data product. 

929 

930 `producing_run_id`, `subject_id`, `derived_from` are eventual- 

931 consistency refs (loaded at handler-load time; not re-verified 

932 at fold time). All three are optional (None / empty for the 

933 standalone-upload case). `derived_from` is the lineage edge set 

934 pointing at upstream Datasets this one was derived from. 

935 

936 `status` defaults to `Registered`; the lifecycle FSM expands in 

937 7b (Discarded terminal) and later phases. 

938 

939 `producing_run_end_state`: captures the producing 

940 Run's terminal status at the moment of Dataset registration 

941 (per non-determinism principle: capture, don't recompute). Null 

942 when there's no producing_run_id (standalone-upload Dataset) OR 

943 for legacy DatasetRegistered events without the field (they 

944 fold cleanly via payload.get default). Powers the 

945 `promote_dataset` Run-must-be-Completed guard. 

946 

947 `intent`: trust level / promotion state, orthogonal to 

948 `status` (lifecycle). Defaults to `Trial`; flipped to `Production` 

949 by an explicit `promote_dataset` call with audit reason. See 

950 [[project_dataset_lineage_design]]. 

951 """ 

952 

953 id: UUID 

954 name: DatasetName 

955 uri: DatasetUri 

956 checksum: DatasetChecksum 

957 byte_size: int 

958 encoding: DatasetEncoding 

959 producing_run_id: UUID | None = None 

960 # The conducted Procedure that produced this Dataset; the lineage edge the 

961 # actuation kind was derived from at registration. None for non-conducted 

962 # / external Datasets. Eventual-consistency ref (loaded at register time, 

963 # not re-verified at fold). Additive-state default None. 

964 producing_procedure_id: UUID | None = None 

965 subject_id: UUID | None = None 

966 derived_from: frozenset[UUID] = field(default_factory=frozenset[UUID]) 

967 status: DatasetStatus = DatasetStatus.REGISTERED 

968 # additions: 

969 producing_run_end_state: str | None = None 

970 # Raw ActuationKind value (Physical / Simulated / Hybrid) the producing 

971 # conduct observed, snapshotted at registration. None for standalone 

972 # uploads, conducts with no routing table, and legacy events. Powers the 

973 # promote_dataset simulator-origin guard (Simulated / Hybrid block). 

974 producing_actuation_kind: str | None = None 

975 intent: Intent = Intent.TRIAL 

976 # Calibration BC AsShot citation (revision-cited 

977 # atomic-ID model per [[project_calibration_design]]). Each entry 

978 # is a `CalibrationRevision.id` the reconstruction (or any 

979 # derivative) actually used. Symmetric to Run.pinned_calibration_ids; 

980 # the two sets are independent — the Dataset cites whatever revisions it 

981 # used (often the same as the producing Run's pin set, sometimes 

982 # including post-acquisition refinements like a refined 

983 # rotation_center revision computed by `tomopy.find_center_vo`, 

984 # sometimes a fully different set). NO write-time cross-BC 

985 # enforcement of derivative-source set equality per anti-hook #3 

986 # (revision-cited atomic IDs make "partial override" a category 

987 # error in this model) + canonical DDD eventual-consistency 

988 # stance. Anti-hook #13 (no synthesis-by-omission) is the dual: 

989 # every calibration value the reconstruction used MUST appear as 

990 # a revision_id in this set; downstream code paths MUST NOT 

991 # silently inject fallback values. 

992 # IMMUTABLE after register_dataset by aggregate-level invariant 

993 # (mirrors Run.pinned_calibration_ids AsShot immutability) — every 

994 # transition arm in the evolver (DatasetDiscarded / 

995 # DatasetPromoted) preserves `prior.used_calibration_ids` verbatim. 

996 # Defaults to empty frozenset so legacy streams fold cleanly via 

997 # `payload.get("used_calibration_ids", [])` (additive-state pattern; 

998 # mirrors derived_from / producing_run_end_state / intent 

999 # precedent). 

1000 used_calibration_ids: frozenset[UUID] = field(default_factory=frozenset[UUID])
