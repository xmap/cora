1"""Cross-aggregate context the `add_run_to_campaign` decider validates against. 

2 

3`CampaignMembershipContext` is built by the `add_run_to_campaign` 

4handler from a `load_campaign(...)` + `load_run(...)` + raw 

5`event_store.load(...)` calls before reaching the pure decider. The 

6decider treats the loaded aggregates as opaque domain data and 

7validates the membership preconditions without performing any I/O. 

8 

9Per the canonical cross-aggregate-validation pattern documented in 

10CONTRIBUTING.md and mirrored from Safety's `ClearanceAmendmentContext` 

11(11a-c-2). Same shape is reused by `remove_run_from_campaign` 

12(duplicated module per slice-independence; the Caution + Safety 

13precedent has separate contexts per slice). 

14 

15## Field semantics 

16 

17 - `campaign`: the Campaign being mutated. Decider rejects if not in 

18 `{Planned, Active, Held}` (`CampaignCannotAddRunError`). MUST not 

19 be None (handler raises `CampaignNotFoundError` before constructing 

20 the context). 

21 - `campaign_version`: the Campaign stream's current event-store 

22 version at load time. Passed straight through to 

23 `EventStore.append_streams` as the expected_version for the 

24 Campaign's `CampaignRunAdded` append. Optimistic-concurrency guard 

25 against a concurrent transition on the Campaign stream. 

26 - `run`: the Run being added. Decider rejects if not None and 

27 already-assigned-to-different-campaign 

28 (`RunAlreadyAssignedToCampaignError`). MUST not be None (handler 

29 raises `RunNotFoundError` before constructing). 

30 - `run_version`: the Run stream's current event-store version at 

31 load time. Used as the expected_version for the Run's 

32 `RunAddedToCampaign` append. 

33""" 

34 

35from dataclasses import dataclass 

36 

37from cora.campaign.aggregates.campaign import Campaign 

38from cora.run.aggregates.run import Run 

39 

40 

41@dataclass(frozen=True) 

42class CampaignMembershipContext: 

43 """Snapshot of both aggregates + their stream versions at membership-mutation time.""" 

44 

45 campaign: Campaign 

46 campaign_version: int 

47 run: Run 

48 run_version: int
