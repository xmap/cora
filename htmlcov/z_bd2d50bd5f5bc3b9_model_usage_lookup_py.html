1"""ModelUsageLookup port: which Decisions' recorded LLM calls touched a model? 

2 

3Consumed by the Agent BC's `list_at_risk_results` read slice, the 

4catalog's flagship question: when a vendor announces a model's 

5retirement, enumerate every Decision whose recorded LLM calls used 

6that model, so the slice can grade each result by whether the model 

7stays invocable (the entry's `ArchivabilityTier` axis, which grades 

8availability and not reproducibility). 

9 

10The `ModelUsage` prefix (not `LanguageModelUsage`) is deliberate: the 

11columns this port reads are the OTel `request_model` / 

12`response_model` provenance strings on inference rows, not 

13LanguageModel catalog entries. 

14 

15## Convention 

16 

17Same shape as the `SpendLookup` / `LanguageModelLookup` family: a 

18consumer-shaped Protocol + frozen result VO + an always-empty test 

19stub, living in `cora.infrastructure.ports` for neutral access. The 

20Decision BC ships the production adapter 

21(`cora.decision.adapters.PostgresModelUsageLookup`) because it owns 

22the durable usage fact: `entries_decision_inferences`, where each LLM 

23call's provenance row carries `decision_id`, `occurred_at`, 

24`provider_name`, `request_model`, `response_model`, and `agent_id`. 

25The Agent BC may not read that table directly (the 

26port-mediated-integration rule `test_no_cross_bc_projection_sql_reads` 

27pins at the SQL layer), so this port is how the catalog reaches the 

28usage facts. 

29 

30## Match semantics 

31 

32A row touches the model identity `(provider, model)` when 

33`provider_name = provider` AND (`request_model = model` OR 

34`response_model = model` OR `response_model` is `model` plus a dated 

35snapshot suffix, exactly `-YYYYMMDD`). The snapshot arm exists because 

36providers resolve an alias onto dated snapshots: a request for 

37`claude-sonnet-4-5` answers as `claude-sonnet-4-5-20250929`, and those 

38calls are equally at risk when the alias retires; the caller never 

39pinned the snapshot, so the alias's retirement takes the identity they 

40recorded out of service. The suffix is exactly eight characters so a 

41sibling minor version (`claude-sonnet-4` vs `claude-sonnet-4-5`) never 

42counts as a touch. 

43 

44The result carries ONE row per Decision (the newest touching call), 

45because the consumer enumerates affected Decisions, not raw calls. 

46"""
