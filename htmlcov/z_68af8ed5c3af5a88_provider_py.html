1"""TracerProvider configuration and per-app FastAPI instrumentation. 

2 

3Two public entrypoints: 

4 

5- `build_tracing(settings)` is pure: builds a `TracerProvider` and a 

6 `teardown` callable per `settings.otel_exporter`, mutates no global 

7 state. Used by tests so unit-level coverage of exporter selection 

8 doesn't flip the process-wide global (OTel's `set_tracer_provider` 

9 is one-shot per process). 

10- `configure_tracing(settings)` calls `build_tracing` and additionally 

11 installs the provider as the global, plus instruments process-wide 

12 libraries (asyncpg). Returns the same `teardown` callable. 

13 

14`instrument_app(app, settings)` attaches `FastAPIInstrumentor` to a 

15specific FastAPI instance with `excluded_urls` matching CORA's 

16operational endpoints (probes + scrape + docs) so they don't flood 

17the trace exporter under normal traffic. 

18 

19Exporter selection (`settings.otel_exporter`): 

20 

21- `none` — no provider installed; the global default no-op tracer 

22 stays active. Default for `app_env=test` so spans don't 

23 accumulate across many `create_app()` instances in the 

24 test process. Also the package-level default (Settings 

25 field) so unconfigured deployments are observable-when- 

26 chosen rather than observable-by-accident. 

27- `console` — `ConsoleSpanExporter` with `SimpleSpanProcessor`. Spans 

28 print to stdout immediately. Recommended for local dev. 

29- `otlp` — `OTLPSpanExporter` (HTTP/protobuf) with 

30 `BatchSpanProcessor`. Recommended for production. The 

31 endpoint is read from the standard `OTEL_EXPORTER_OTLP_*` 

32 env vars (we do NOT shadow them with a custom setting, 

33 so existing OTel deployment tooling Just Works). 

34 

35Sampler is `ParentBased(AlwaysOn)` for `console` (development is 

36loud by design), and `ParentBased(TraceIdRatioBased(ratio))` for 

37`otlp` so root spans are sampled at the configured ratio while child 

38spans inherit the root's sampling decision. 

39 

40Resource attributes follow OTel semantic conventions: 

41`service.name`, `service.version`, `service.namespace`, 

42`deployment.environment`. Set once on the provider; every span 

43inherits them. 

44"""

94def build_tracing(settings: "Settings") -> tuple[TracerProvider | None, Teardown]: 

95 """Build a TracerProvider per `settings.otel_exporter` without installing it. 

96 

97 Returns `(provider, teardown)`. `provider` is `None` for `none` 

98 (no work to do); `teardown` is always callable. Pure: no global 

99 state mutated, safe to call repeatedly in tests. 

100 

101 For `otlp`, `OTLPSpanExporter()` is constructed without an explicit 

102 `endpoint` so it picks up `OTEL_EXPORTER_OTLP_TRACES_ENDPOINT` (or 

103 falls back to `OTEL_EXPORTER_OTLP_ENDPOINT`, with `/v1/traces` 

104 appended) from the environment per the OTel SDK convention. 

105 """ 

106 if settings.otel_exporter == "none": 

107 return None, _noop_teardown 

108 

109 resource = Resource.create( 

110 { 

111 SERVICE_NAME: settings.otel_service_name, 

112 SERVICE_VERSION: __version__, 

113 SERVICE_NAMESPACE: "cora", 

114 DEPLOYMENT_ENVIRONMENT: settings.app_env, 

115 } 

116 ) 

117 

118 sampler: Sampler 

119 if settings.otel_exporter == "console": 

120 sampler = ParentBased(root=ALWAYS_ON) 

121 else: # "otlp" 

122 sampler = ParentBased(root=TraceIdRatioBased(settings.otel_sampler_ratio)) 

123 

124 provider = TracerProvider(resource=resource, sampler=sampler) 

125 

126 if settings.otel_exporter == "console": 

127 # SimpleSpanProcessor exports synchronously per finished span — 

128 # acceptable for local dev where latency doesn't matter and 

129 # immediate visibility does. 

130 provider.add_span_processor(SimpleSpanProcessor(ConsoleSpanExporter())) 

131 else: # "otlp" 

132 # BatchSpanProcessor batches spans and flushes asynchronously to 

133 # the OTLP collector. force_flush() on shutdown drains the queue. 

134 # Endpoint resolved by the exporter from OTEL_EXPORTER_OTLP_* 

135 # env vars; our Settings doesn't shadow those. 

136 provider.add_span_processor(BatchSpanProcessor(OTLPSpanExporter())) 

137 

138 def teardown() -> None: 

139 # force_flush gives in-flight spans a chance to ship; shutdown 

140 # tears down processors and exporters cleanly. 

141 provider.force_flush() 

142 provider.shutdown() 

143 

144 return provider, teardown
