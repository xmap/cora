1"""Pure decider for the `RegisterEnclosure` command. 

2 

3Pure function: given the current Enclosure state (None for a fresh 

4stream) and a `RegisterEnclosure` command, returns the events to 

5append. No I/O, no awaits, no side effects. 

6 

7`now`, `new_id`, and `registered_by` are injected by the application 

8handler from the Clock and IdGenerator ports and from the route / 

9tool boundary (the non-determinism principle: capture, don't 

10recompute). Registration is operator-only today; `registered_by` is 

11typed `ActorId` directly, not the trigger-aware union, matching the 

12genesis-event payload shape in `cora.enclosure.aggregates.enclosure`. 

13 

14## Validation 

15 

16 - State must be None (genesis-only) -> `EnclosureAlreadyExistsError` 

17 - `facility_lookup_result` must be non-None 

18 -> `EnclosureFacilityNotFoundError` 

19 - `name` is wrapped via `EnclosureName(...)` which validates 1-200 

20 chars in `__post_init__` -> `InvalidEnclosureNameError`. 

21 

22## Facility binding 

23 

24`command.facility_code` is the cross-deployment convergent slug for the 

25containing Facility (the Site / Area the enclosure sits within). The 

26handler resolves it via `FacilityLookup.lookup_by_code` and threads the 

27resulting `FacilityLookupResult | None` into the decider. LOAD lives in 

28the handler; REJECTION lives in the decider: a `None` result means no 

29Facility with that code is visible in the Federation projection and the 

30registration is rejected with `EnclosureFacilityNotFoundError` 

31(HTTP 404). The lookup-result's `.code` field is folded onto the event 

32so the event's `facility_code` reflects the projection's canonical typed 

33VO, not a command-echo (mirrors the Asset / Supply handler/decider 

34split). The decider does NOT partition on Facility status: every status 

35(Active, Decommissioned) is a valid containing geography. 

36 

37Initial permit-status is implicit `Unknown` and initial lifecycle is 

38implicit `Active`; the evolver seeds both from the genesis event 

39type. Per the universal industrial + cloud-native consensus on 

40registration-time defaults (Tango UNKNOWN, EPICS UDF, Azure Resource 

41Health Unknown, k8s Pending). 

42 

43Cross-stream uniqueness of the `(facility_code, name)` address 

44tuple is NOT enforced here: the decider cannot see other Enclosure 

45streams without DCB. The projection's partial UNIQUE INDEX (active 

46rows only) is the cross-stream guard; this decider's pre-state-None 

47check is the genesis collision guard against same-stream double 

48registration. 

49""" 

50 

51from datetime import datetime 

52 

53from cora.enclosure.aggregates.enclosure import ( 

54 Enclosure, 

55 EnclosureAlreadyExistsError, 

56 EnclosureFacilityNotFoundError, 

57 EnclosureId, 

58 EnclosureName, 

59 EnclosureRegistered, 

60) 

61from cora.enclosure.features.register_enclosure.command import RegisterEnclosure 

62from cora.infrastructure.ports.facility_lookup import FacilityLookupResult 

63from cora.shared.identity import ActorId 

64 

65 

66def decide( 

67 state: Enclosure | None, 

68 command: RegisterEnclosure, 

69 *, 

70 now: datetime, 

71 new_id: EnclosureId, 

72 registered_by: ActorId, 

73 facility_lookup_result: FacilityLookupResult | None, 

74) -> list[EnclosureRegistered]: 

75 """Decide the events produced by registering a new Enclosure. 

76 

77 Invariants: 

78 - State must be None (genesis-only) 

79 -> EnclosureAlreadyExistsError 

80 - facility_lookup_result must be non-None 

81 -> EnclosureFacilityNotFoundError 

82 - Name must be valid -> InvalidEnclosureNameError 

83 (via EnclosureName VO) 

84 

85 `registered_by` is the operator's `ActorId` (registration is 

86 always operator-driven; no Monitor or Auto counterpart). Folded 

87 onto the event payload as the fold-symmetric genesis attribution 

88 per [[project_fold_symmetry_design]]. 

89 

90 `facility_lookup_result.code` is the canonical Facility slug 

91 threaded onto the event payload, replacing direct echo of 

92 `command.facility_code` so the cross-BC convergent identity is the 

93 single source of truth for the wire value. 

94 """ 

95 if state is not None: 

96 raise EnclosureAlreadyExistsError(state.id) 

97 

98 if facility_lookup_result is None: 

99 raise EnclosureFacilityNotFoundError(command.facility_code) 

100 

101 name = EnclosureName(command.name) 

102 

103 return [ 

104 EnclosureRegistered( 

105 enclosure_id=new_id, 

106 name=name.value, 

107 facility_code=facility_lookup_result.code, 

108 registered_by=registered_by, 

109 occurred_at=now, 

110 ) 

111 ] 

112 

113 

114__all__ = ["decide"]
