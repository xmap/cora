1"""The `RegisterEdition` command for the register_edition slice. 

2 

3Carries everything the caller controls to register a new Edition: 

4 - `kind`: which serialization-target this Edition uses (closed enum) 

5 - `title`: display title (1-500 chars) 

6 - `dataset_ids`: initial member set (>=1; sorted on wire) 

7 - `creators`: ordered tuple of (actor_id, affiliation) (1-100; order 

8 is publication-significant) 

9 - `license`: optional SPDX identifier (free-text, 1-100 chars; if 

10 supplied at register-time, locked in) 

11 - `publication_year`: optional explicit year (1900..current_year+5; 

12 if supplied, locked in; auto-derived at seal-time if not) 

13 - `publisher_facility_code`: optional publisher Facility code 

14 (FacilityLookup-validated at seal-time, NOT at register-time) 

15 

16The new Edition id is server-allocated by the handler from the
