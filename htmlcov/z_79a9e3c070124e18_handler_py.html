1"""Application handler for the `regenerate_run_debrief` slice. 

2 

3Pattern C from the design memo: operator-triggered on-demand 

4RunDebriefer. The handler is the HTTP-side equivalent of the 

5subscriber: load Run, build payload (reusing the same prompt 

6module), call LLM, compose `DecisionRegistered` via the slice's 

7pure `decide()`, append. 

8 

9## Differences from the subscriber 

10 

11 - `principal_id` is the operator's UUID (from HTTP header), NOT 

12 the agent's. The agent is the WHO of the Decision (`actor_id`); 

13 the operator is the WHO of the COMMAND (`principal_id`). 

14 - `decision_id` is a fresh UUIDv7 from the kernel's `IdGenerator` 

15 (NOT UUID5-derived). Idempotency lives at the HTTP envelope 

16 via `Idempotency-Key` (Brandur), wrapped at wire.py. 

17 - `parent_id` is operator-supplied (optional), forming a PROV-O 

18 `wasInformedBy` chain to the prior auto-fired Debrief. 

19 - Authorize port IS called (HTTP-handler convention). 

20 

21## Cross-aggregate validation 

22 

23The handler pre-loads cross-aggregate refs and reports failures 

24via aggregate-state errors hoisted from this slice 

25(cross-BC gate-review): 

26 

27 - Run aggregate must exist (`load_run` returns non-None); 

28 raises `cora.run.aggregates.run.state.RunNotFoundError` -> 

29 HTTP 404 (already-mapped by Run BC's routes). 

30 - RunDebriefer Agent's Actor must exist and be active; raises 

31 `AgentNotSeededError` / `AgentDeactivatedError` (both in 

32 `cora.agent.aggregates.agent.state`) -> HTTP 400. 

33 - When `parent_decision_id` is supplied: parent Decision must 

34 exist (`DecisionParentNotFoundError` from 

35 `cora.decision.aggregates.decision`; HTTP 409 per Decision 

36 BC's existing mapping), have `context == "RunDebrief"` 

37 (`DecisionParentAgentMismatchError`; HTTP 400), AND reference 

38 the same `run_id` in its `inputs` 

39 (`DecisionParentRunMismatchError`; HTTP 400). 

40 

41The parent-context check (PR-author note: architecture gate-review) 

42catches accidental cross-agent chains where the 

43operator passes a Decision id authored by a different agent 

44context (eg. a `PolicyGrant` Decision). 

45 

46## DebriefDeferred fallback 

47 

48Same as the subscriber: when the LLM call exhausts, the handler 

49composes a `DecisionRegistered` with `choice="DebriefDeferred"` 

50via the same `decide()` and writes it. Operator can retry by 

51re-issuing the MCP call with a different Idempotency-Key (a same- 

52key retry replays the cached DebriefDeferred; the operator must 

53mint a fresh key to bypass the cache). 

54"""

231 error_message=redact_secrets(str(exc)[:200]), 

232 )

235 choice="DebriefDeferred", 

236 confidence=None, 

237 reasoning=(

239 "debrief regeneration deferred. Operator may retry with a " 

240 "fresh Idempotency-Key to bypass the cached failure."

245 else:

252 else None 

253 ),

255 )

258 domain_events = decide( 

259 state=None, 

260 command=command, 

261 context=decider_context, 

262 now=now, 

263 new_id=new_id, 

264 )

267 # adds a second event. 

268 (domain_event,) = domain_events 

269 new_event = to_new_event( 

270 event_type=event_type_name(domain_event), 

271 payload=to_payload(domain_event), 

272 occurred_at=domain_event.occurred_at, 

273 # Derive event_id from decision_id so the (decision_id,

275 event_id=uuid5(new_id, "event:0"), 

276 command_name=_COMMAND_NAME, 

277 correlation_id=correlation_id, 

278 causation_id=causation_id, 

279 principal_id=principal_id, 

280 ) 

281 await deps.event_store.append( 

282 stream_type=_STREAM_TYPE, 

283 stream_id=new_id, 

284 expected_version=0, 

285 events=[new_event], 

286 ) 

287 

288 # Capture model provenance for the regenerated Decision, only when the 

289 # LLM actually ran (the DebriefDeferred path has no response). After 

290 # the append so the recorder's lazy logbook-open finds the Decision. 

291 if outcome == "success" and response is not None: 

292 await _record_inference( 

293 deps.inference_recorder, 

294 decision_id=new_id, 

295 request=request, 

296 response=response, 

297 occurred_at=now, 

298 principal_id=RUN_DEBRIEFER_AGENT_ID, 

299 correlation_id=correlation_id, 

300 causation_id=causation_id, 

301 log=log, 

302 ) 

303 

304 log.info("regenerate_run_debrief.success", outcome=outcome, decision_id=str(new_id))

322 """Best-effort capture of the on-demand LLM call's model provenance. 

323 

324 Mirrors the subscriber path: fire-and-forget (the recorder never raises 

325 per its port contract; the try/except is defense-in-depth), deterministic 

326 inference `event_id`, recorded only after the Decision append commits. 

327 The inference is attributed to the RunDebriefer agent principal (the WHO of 

328 the Decision), so the operator-initiated regenerate carries the same authz 

329 requirement as the auto-fired subscriber path. 

330 """ 

331 trace = AgentInferenceTrace( 

332 decision_id=decision_id, 

333 event_id=uuid5(decision_id, "inference:0"), 

334 occurred_at=occurred_at, 

335 operation_name=DECISION_REASONING_OPERATION_CHAT, 

336 provider_name=request.model_ref.provider, 

337 request_model=request.model_ref.model, 

338 response_model=response.model_id, 

339 finish_reasons=(response.stop_reason,) if response.stop_reason else (), 

340 input_tokens=response.usage.input_tokens, 

341 output_tokens=response.usage.output_tokens, 

342 request_max_tokens=request.max_output_tokens, 

343 agent_id=str(RUN_DEBRIEFER_AGENT_ID), 

344 agent_name=RUN_DEBRIEFER_AGENT_NAME, 

345 ) 

346 try: 

347 await recorder.record( 

348 trace, 

349 principal_id=principal_id, 

350 correlation_id=correlation_id, 

351 causation_id=causation_id, 

352 ) 

353 except Exception as exc: 

354 log.warning( 

355 "regenerate_run_debrief.inference_record_failed", 

356 error_class=type(exc).__name__, 

357 error_message=redact_secrets(str(exc)[:200]), 

358 )
