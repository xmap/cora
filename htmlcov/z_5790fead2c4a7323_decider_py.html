1"""Pure decider for the `re_debrief_run` slice (Phase 8f-c iter 1). 

2 

3Composes the `DecisionRegistered` event for an on-demand RunDebrief 

4invocation. Pure function: given the operator inputs + LLM response 

5+ pre-loaded Actor + chosen `decision_id`, returns the event to 

6append. No I/O, no awaits, no clock / id-generator calls. 

7 

8## Why a separate decider 

9 

10The cross-BC slice-contract test 

11(`tests/architecture/test_slice_contract.py`) requires `decider.py` 

12for every command slice. The cross-BC gate-review P1 (8f-c iter 1) 

13additionally noted that the LLM-response-to-`DecisionRegistered` 

14mapping is genuinely pure and benefits from extraction: a future 

15on-demand agent slice (8f-c iter 2 / 8f-c+) and a Pattern B 

16subscriber would both consume the same shape. 

17 

18The 8f-b iter 2b subscriber (`cora.agent.subscribers.run_debrief`) 

19currently inlines an equivalent composition. Rule-of-three trigger 

20to hoist this decider out of the slice and into a shared module 

21(eg. `cora.agent.deciders.run_debrief`) fires when EITHER a second 

22on-demand agent slice ships OR the subscriber's composition is 

23refactored to call through this decider. 

24 

25## Cross-aggregate validation 

26 

27The decider does NOT load aggregates -- the handler pre-loads 

28Run + Agent's Actor + parent Decision. The decider trusts the 

29handler: 

30 

31 - `actor` is non-None (handler raised AgentNotSeededError otherwise). 

32 - `actor.is_active` is True (handler raised AgentDeactivatedError 

33 otherwise). 

34 - `parent_decision_id` (when set) points at a real Decision in 

35 the same Run AND with `context = "RunDebrief"` (handler raised 

36 ParentDecisionMissingError / ParentDecisionRunMismatchError / 

37 ParentDecisionAgentMismatchError otherwise). 

38 

39## Field validation 

40 

41Decision BC's public VOs + helpers do the per-field check: 

42`DecisionChoice` / `DecisionContext` / `DecisionRule` raise their 

43own `Invalid<X>Error` on bad input. `validate_reasoning` / 

44`validate_confidence` / `validate_decision_inputs` likewise. 

45""" 

46 

47from datetime import datetime 

48from typing import Any 

49from uuid import UUID 

50 

51from cora.access.aggregates.actor import Actor 

52from cora.agent.prompts import RUN_DEBRIEF_PROMPT_TEMPLATE_ID 

53from cora.decision.aggregates.decision import ( 

54 DECISION_CONTEXT_RUN_DEBRIEF, 

55 DecisionChoice, 

56 DecisionConfidenceSource, 

57 DecisionContext, 

58 DecisionRegistered, 

59 DecisionRule, 

60 validate_confidence, 

61 validate_decision_inputs, 

62 validate_reasoning, 

63) 

64 

65_DECISION_RULE = "agent:RunDebrief:v1" 

66 

67 

68def decide( 

69 *, 

70 new_id: UUID, 

71 actor: Actor, 

72 run_id: UUID, 

73 parent_decision_id: UUID | None, 

74 choice: str, 

75 confidence: float | None, 

76 reasoning: str, 

77 occurred_at: datetime, 

78 extra_decision_inputs: dict[str, Any] | None = None, 

79) -> DecisionRegistered: 

80 """Compose the on-demand RunDebrief `DecisionRegistered` event. 

81 

82 `choice` is constrained at the projection layer (and by the 

83 LLM's structured output schema) to the closed 6-value set, but 

84 the Decision BC's open-string `DecisionChoice` VO is used here 

85 so the decider stays vocabulary-agnostic. 

86 

87 `extra_decision_inputs` merges into the base inputs after the 

88 base keys are set; collisions on `run_id` / `trigger` / 

89 `prompt_template_id` are silently overwritten by the extra dict 

90 (intentional: callers supplying these keys override on purpose, 

91 eg. the DebriefDeferred path's `failure_error_class`). 

92 """ 

93 decision_choice = DecisionChoice(choice) 

94 decision_context = DecisionContext(DECISION_CONTEXT_RUN_DEBRIEF) 

95 decision_rule = DecisionRule(_DECISION_RULE) 

96 base_inputs: dict[str, Any] = { 

97 "run_id": str(run_id), 

98 "trigger": "on-demand", 

99 "prompt_template_id": str(RUN_DEBRIEF_PROMPT_TEMPLATE_ID), 

100 } 

101 if extra_decision_inputs: 

102 base_inputs.update(extra_decision_inputs) 

103 decision_inputs = validate_decision_inputs(base_inputs) 

104 validated_reasoning = validate_reasoning(reasoning) 

105 validated_confidence = validate_confidence(confidence) 

106 

107 return DecisionRegistered( 

108 decision_id=new_id, 

109 actor_id=actor.id, 

110 context=decision_context.value, 

111 choice=decision_choice.value, 

112 parent_id=parent_decision_id, 

113 override_kind=None, 

114 decision_rule=decision_rule.value, 

115 reasoning=validated_reasoning, 

116 confidence=validated_confidence, 

117 confidence_source=DecisionConfidenceSource.SELF_REPORTED, 

118 alternatives=(), 

119 decision_inputs=decision_inputs, 

120 reasoning_signature=None, 

121 occurred_at=occurred_at, 

122 ) 

123 

124 

125__all__ = ["decide"]
