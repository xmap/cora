1"""The `ListCautions` query: intent dataclass for keyset-paginated 

2list of cautions from the `proj_caution_summary` projection. 

3 

4Seven optional filters in canonical form: 

5 

6 - target_kind / target_id / category / tag / authored_by 

7 (single-value, exact-match) 

8 - severities (list of acceptable severity values; None == no filter) 

9 - statuses (list of acceptable status values; None == no filter) 

10 

11User-facing UX (`min_severity` ladder, status default-to-Active, 

12`status='all'` opt-in) lives at the route/MCP-tool boundary, NOT 

13in this dataclass. The route translates user input into the 

14canonical list-typed `severities` / `statuses` fields before 

15constructing the query. 

16 

17The query dataclass is the canonical internal contract: anything 

18constructing `ListCautions(...)` directly (tests, internal code) 

19sees a uniform "None means no filter" semantic for every field, 

20matching every other list-query slice in the codebase. 

21 

22Cursor encodes `(registered_at, caution_id)`. `registered_at` is 

23set once at CautionRegistered (immutable), so it's a stable keyset 

24key. 

25""" 

26 

27from dataclasses import dataclass 

28from typing import Literal 

29from uuid import UUID 

30 

31CautionTargetKindFilter = Literal["Asset", "Procedure"] 

32 

33CautionCategoryFilter = Literal[ 

34 "Wear", 

35 "Calibration", 

36 "Wiring", 

37 "OperationalWindow", 

38 "InterlockQuirk", 

39 "ProcedureGotcha", 

40] 

41 

42CautionSeverityFilter = Literal["Notice", "Caution", "Warning"] 

43 

44CautionStatusFilter = Literal["Active", "Superseded", "Retired"] 

45 

46 

47@dataclass(frozen=True) 

48class ListCautions: 

49 """Read a keyset-paginated page of cautions from the projection.""" 

50 

51 cursor: str | None = None 

52 """Opaque base64 cursor from a previous page's `next_cursor`.""" 

53 

54 limit: int = 50 

55 """Page size cap. Default 50, max 100 (route enforces).""" 

56 

57 target_kind: CautionTargetKindFilter | None = None 

58 """Optional target-kind filter (Asset / Procedure).""" 

59 

60 target_id: UUID | None = None 

61 """Optional target-id filter (typically used with target_kind).""" 

62 

63 category: CautionCategoryFilter | None = None 

64 """Optional category filter (one of the 6 CautionCategory values).""" 

65 

66 severities: list[CautionSeverityFilter] | None = None 

67 """Optional set of acceptable severity values; None == no filter, 

68 empty list also treated as no filter by the factory. 

69 

70 Route translates user-facing `severity` (singleton) and 

71 `min_severity` (Notice<Caution<Warning ladder) into a single 

72 list, returning 422 on conflicting inputs.""" 

73 

74 statuses: list[CautionStatusFilter] | None = None 

75 """Optional set of acceptable status values; None == no filter, 

76 empty list also treated as no filter by the factory. 

77 

78 Route applies the operator-UX default ([Active]) when the 

79 request omits the status param; the user opts into the full 

80 history by passing every status explicitly OR by passing the 

81 route-level `?status=all` sentinel which the route translates 

82 to None here.""" 

83 

84 tag: str | None = None 

85 """Optional tag filter; matches any caution whose `tags` array contains this value.""" 

86 

87 authored_by: UUID | None = None 

88 """Optional author filter (operator dashboard 'cautions I authored')."""
