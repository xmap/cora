1"""Edition aggregate state, value objects, status / kind enums, and domain errors. 

2 

3An `Edition` is a citable publication-package: a frozen set of 

4Production-intent Datasets bundled into a sealed, optionally 

5DOI-minted, optionally tombstoned artifact. ISBD / FRBR / BIBFRAME 

6publication-tier; DCAT-3 has no direct primitive (Distribution 

7sits one tier below). 

8 

9## What an Edition is 

10 

11 - A publication-grade artifact that names a set of Datasets 

12 + a publisher Facility + a license + a citation year 

13 - Carries its own identity (`id`) distinct from member Datasets 

14 - Has a sealing `content_hash` set at the Sealed transition (sha256 

15 of the canonical serialized form via `EditionSerializer`) 

16 - Optionally carries an `external_pid` (DOI minted via PersistentIdentifierMinter) 

17 after the Published transition 

18 - Can be tombstoned (Withdrawn) without deleting the DOI 

19 

20## What an Edition is NOT 

21 

22 - Not the bytes (those live at member Distributions / Supplies) 

23 - Not a Dataset (Dataset is the content-identity tier) 

24 - Not a Distribution (Distribution is the materialization tier) 

25 - Not an Attestation (Attestation is the verify / bit-rot 

26 fact-chain on Distribution) 

27 

28## Closed kind enum (6 values day-one) 

29 

30`EditionKind` ships all 6 values day-one: {ROCrate, DataCite, 

31Croissant, OAIS_AIP, OAIS_DIP, NeXus}. Only `RoCrate12Adapter` 

32ships today at the serializer port; the other 5 are 

33adapter-deferred. Closed-StrEnum day-one avoids the additive-enum 

34migration trap on future serializer adapter slices. Member name 

35SCREAMING_SNAKE per Python `StrEnum` / PEP 8; string value mostly 

36PascalCase per CORA's BC-status-vocabulary fitness expectation 

37(OAIS_AIP / OAIS_DIP keep underscores due to OAIS ALL_CAPS norm). 

38 

39## Status FSM (4 states; Withdrawn terminal) 

40 

41 Registered -> Sealed -> Published -> Withdrawn 

42 

43All four StrEnum values declared day-one; transitions ship across 

44the 5 slices A-E with all nullable attribution columns present in 

45the projection migration from day one (additive-state pattern; 

46mirrors Distribution + Asset + Supply precedent). 

47 

48## Two-content-hash model 

49 

50`Edition.content_hash` is set ONCE at the Sealed transition (sha256 

51of the pre-DOI serializer output) and is immutable thereafter. 

52 

53The `EditionPublished` event payload carries a SEPARATE 

54`published_content_hash` (sha256 of the re-serialized post-DOI 

55bytes); the projection denormalizes both via separate columns. The 

56aggregate state does NOT carry `published_content_hash` (projection + 

57event payload only). Sealed hash anchors operator commit to shape + 

58membership; published hash anchors the cited artifact bytes. 

59 

60## License kind-gate (DataCite / Croissant only) 

61 

62`license: SpdxIdentifier | None` is optional for most kinds but 

63REQUIRED at the Sealed transition for kinds in `{DataCite, Croissant}`. 

64The serializer adapter for those kinds cannot produce a complete 

65record without it. RO-Crate also strongly recommends a license but 

66does not require it; the gate may widen as adapters ship. 

67"""

566@dataclass(frozen=True) 

567class SpdxIdentifier: 

568 """Free-text SPDX identifier. Trimmed; 1-100 chars; SPDX-character-class. 

569 

570 Free-text today per Lock 12. Closed-allowlist tightening 

571 is a Watch item triggered at the 3rd rejected operator-supplied 

572 id. The on-the-wire representation on event payloads is bare 

573 `str` (post-trim) per the wire-payload bare-str convention. 

574 """ 

575 

576 value: str 

577 

578 def __post_init__(self) -> None: 

579 trimmed = self.value.strip() 

580 if not trimmed: 

581 raise InvalidSpdxIdentifierError(self.value, "empty or whitespace-only") 

582 if len(trimmed) > EDITION_LICENSE_MAX_LENGTH: 

583 raise InvalidSpdxIdentifierError( 

584 self.value, f"exceeds {EDITION_LICENSE_MAX_LENGTH} chars" 

585 ) 

586 for ch in trimmed: 

587 if ch not in _SPDX_ALLOWED_CHARS: 

588 raise InvalidSpdxIdentifierError( 

589 self.value, 

590 f"character {ch!r} not in SPDX identifier character class", 

591 ) 

592 object.__setattr__(self, "value", trimmed)

615@dataclass(frozen=True) 

616class Creator: 

617 """A creator credited on the Edition. Ordered tuple semantics on the carrier. 

618 

619 `actor_id` is the internal-opaque Actor.id (NOT externalized to 

620 the public-facing record; the serializer adapter resolves it to a 

621 name / ORCID via ActorLookup port when that ships). 

622 

623 `affiliation` is optional free-text 1-200 chars when supplied. 

624 

625 Validation lives at the carrier aggregate (creators tuple-level 

626 invariants: 1-100 entries, no duplicate actor_id, affiliation 

627 bounded). This dataclass enforces only affiliation length so a 

628 bare construction fails fast on malformed input. 

629 """ 

630 

631 actor_id: ActorId 

632 affiliation: str | None = None 

633 

634 def __post_init__(self) -> None: 

635 if self.affiliation is not None: 

636 trimmed = self.affiliation.strip() 

637 if not trimmed: 

638 raise InvalidCreatorsError( 

639 f"affiliation empty or whitespace-only for actor_id {self.actor_id}" 

640 ) 

641 if len(trimmed) > EDITION_AFFILIATION_MAX_LENGTH: 

642 raise InvalidCreatorsError( 

643 f"affiliation exceeds {EDITION_AFFILIATION_MAX_LENGTH} chars " 

644 f"for actor_id {self.actor_id}" 

645 ) 

646 object.__setattr__(self, "affiliation", trimmed)

649def validate_publication_year(value: int, *, current_year: int) -> int: 

650 """Range-check a publication_year against [1900..current_year+5].""" 

651 upper = current_year + EDITION_PUBLICATION_YEAR_FUTURE_BUDGET 

652 if value < EDITION_PUBLICATION_YEAR_MIN or value > upper: 

653 raise InvalidPublicationYearError(value, current_year=current_year) 

654 return value

657def validate_creators(creators: tuple[Creator, ...]) -> tuple[Creator, ...]: 

658 """Tuple-level creators invariants: 1-100 entries; no duplicate actor_id.""" 

659 if len(creators) < EDITION_CREATORS_MIN: 

660 raise InvalidCreatorsError( 

661 f"creators must have at least {EDITION_CREATORS_MIN} entry (got: {len(creators)})" 

662 ) 

663 if len(creators) > EDITION_CREATORS_MAX: 

664 raise InvalidCreatorsError( 

665 f"creators must have at most {EDITION_CREATORS_MAX} entries (got: {len(creators)})" 

666 ) 

667 seen: set[ActorId] = set() 

668 for creator in creators: 

669 if creator.actor_id in seen: 

670 raise InvalidCreatorsError(f"duplicate actor_id in creators: {creator.actor_id}") 

671 seen.add(creator.actor_id) 

672 return creators

680@dataclass(frozen=True) 

681class Edition: 

682 """Aggregate root: one citable publication-package over a set of Datasets. 

683

692 

693 Two-content-hash model: `content_hash` set ONCE at Sealed and

696 """
