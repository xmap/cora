1"""Pure decider for the `MarkDistributionStale` command. 

2 

3Marking stale records a fact about the world that already happened (the 

4bytes at this location are gone or no longer trusted); it is not a 

5deliberate act CORA is entitled to refuse, unlike `discard_distribution`. 

6The decider therefore does NOT mirror discard's guards: no redundancy 

7check against sibling copies, no parent-Dataset-Discarded check, and no 

8cross-aggregate context. The only guards are structural. 

9 

10## Firing order 

11 

12 1. State must not be None -> DistributionNotFoundError. 

13 2. command.reason validated via DistributionMarkStaleReason VO 

14 (1-500 chars after trim) -> InvalidDistributionMarkStaleReasonError. 

15 Validated BEFORE the state guard, mirroring discard_distribution: a 

16 bad reason on an already-Discarded copy raises the reason error, not 

17 the cannot-mark-stale error. 

18 3. state.status is DISCARDED -> DistributionCannotMarkStaleError 

19 (Discarded is terminal; a Discarded copy cannot be marked Stale). 

20 4. Emit DistributionMarkedStale with trigger hardcoded to 

21 TriggerSource.OPERATOR. 

22 

23## Trigger source: hardcoded Operator 

24 

25Mirrors every operator-facing Supply decider. The value is NOT taken 

26from the command: this slice's only surfaces are the REST route and the 

27MCP tool, both operator-driven, and letting a caller supply the field 

28would let a principal assert its own claim came from a monitor. When a 

29reconciliation sweep lands, it emits the same event with 

30TriggerSource.MONITOR from its own slice, exactly as Supply's 

31observe_supply_status does. 

32 

33## Marking an already-Stale (or Verified, or Registered) copy succeeds 

34 

35Re-marking a copy that is already Stale is NOT strict-not-idempotent 

36like discard: a second storage-failure report, or a report that arrives 

37after an independent checksum-mismatch flip already moved the read 

38model to Stale, is still a true fact and is recorded again (a fresh 

39`marked_stale_at` / `marked_stale_by`). The only status this decider 

40refuses to transition out of is Discarded. 

41 

42## Deliberately no last-Verified-copy guard 

43 

44Discarding the last Verified copy of a Dataset is refused 

45(`DistributionCannotDiscardLastVerifiedError`) because CORA is entitled 

46to refuse a deliberate destructive act. Marking stale has no equivalent 

47guard: if the array holding the last Verified copy died, the array 

48died, and refusing to record that would make CORA assert something 

49false. This is the one design decision this slice is built around; do 

50not add a redundancy guard here. 

51""" 

52

68def decide( 

69 state: Distribution | None, 

70 command: MarkDistributionStale, 

71 *, 

72 now: datetime, 

73 marked_stale_by: ActorId, 

74) -> list[DistributionMarkedStale]: 

75 """Decide the events produced by marking a Distribution copy Stale. 

76 

77 Invariants: 

78 (Firing order per the module docstring above.) 

79 - State must not be None -> DistributionNotFoundError 

80 - command.reason must be 1-500 chars after trimming 

81 -> InvalidDistributionMarkStaleReasonError 

82 - State.status must not be Discarded (terminal) 

83 -> DistributionCannotMarkStaleError 

84 """ 

85 if state is None: 

86 raise DistributionNotFoundError(command.distribution_id) 

87 reason = DistributionMarkStaleReason(command.reason) 

88 if state.status is DistributionStatus.DISCARDED: 

89 raise DistributionCannotMarkStaleError(state.id, current_status=state.status) 

90 return [ 

91 DistributionMarkedStale( 

92 distribution_id=state.id, 

93 reason=reason.value, 

94 trigger=TriggerSource.OPERATOR.value, 

95 occurred_at=now, 

96 marked_stale_by=marked_stale_by, 

97 ) 

98 ]
