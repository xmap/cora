1"""PyTango-backed `ControlPort` adapter for Tango device attributes. 

2 

3Sits in the control-port arc per [[project_control_port_design]] + 

4[[project_control_port_generalization_research]] alongside the EPICS family 

5(`EpicsCaControlPort`, `EpicsPvaControlPort`). This adapter covers the Tango 

6substrate that the ESRF BLISS / Beacon deployments (ID19, ID16B, ID28, ID32) 

7and MAX IV (Tango / Sardana) run on. Value-IO only: Tango Commands (RPC) and 

8Tango typed events (`DATA_READY` / `INTERFACE_CHANGE`) are out of scope per 

9the port's anti-hooks and land in future sibling ports. 

10 

11PyTango (`tango`) binds the C++ Tango core plus omniORB, a heavy native stack 

12that only Tango-floor deployments need. It ships under the optional `tango` 

13dependency group and is NOT imported at module load; the adapter probes 

14importability in `__init__` via `_optional_tango.require_tango` (raising 

15`ValueError` at wiring, rather than an uncaught `ImportError` mid-loop) 

16and imports `tango.asyncio` lazily on first use. This keeps `import cora` 

17cheap on EPICS-only installs. 

18 

19## Address space 

20 

21The adapter takes a `TangoAttributeAddress` (already split into `.device` and 

22`.attribute` by `ControlPortRegistry` via `parse_control_address`). One 

23`DeviceProxy` is cached per `.device`; many attributes share a device proxy. 

24The registry does the TRL parsing once at route-match time, so a malformed TRL 

25fails as a `MalformedControlAddressError` at the boundary rather than here. 

26 

27## Connection model 

28 

29`tango.asyncio.DeviceProxy` runs in asyncio green mode: `read_attribute` / 

30`write_attribute` / `subscribe_event` are awaitable. The proxy constructor is 

31also awaitable (it pings the device), so it is built lazily inside the async 

32methods and cached. PyTango has no per-call `timeout=` kwarg on the asyncio 

33methods, so each call is wrapped in `asyncio.wait_for(..., timeout=...)`; a 

34`TimeoutError` becomes `ControlTimeoutError` (write) or 

35`ControlNotConnectedError` (read, where a never-exported device and a slow 

36device are indistinguishable at this tier, mirroring the p4p adapter). 

37 

38## ACL translation (Tango DeviceAttribute -> Measurement) 

39 

40`read_attribute` returns a `DeviceAttribute` carrying `.value`, `.quality` 

41(`AttrQuality`), `.data_format` (`AttrDataFormat`), `.type` (`CmdArgType`), 

42and `.time` (`TimeVal`; `.totime()` -> float epoch seconds). The adapter 

43unpacks: 

44 

45 - `kind`: `IMAGE` -> "Image"; `SPECTRUM` -> "Array"; 

46 `type == DevEnum` or a `DevState` value -> "Categorical"; else "Scalar". 

47 - `value`: numpy scalars via `.item()`; spectra via `tuple(...)`; images via 

48 tuple-of-tuples; `DevEnum` resolved to its label string via the attribute 

49 config's enum labels, cached per address and falling back to the 

50 stringified ordinal when the config is unreachable; `DevState` via its 

51 name (it arrives as a real IntEnum and reports no enum labels). `None` 

52 whenever the attribute carries no value, which is what an ATTR_INVALID 

53 read is. A `DevEnum` SPECTRUM stays an `Array` of ordinals: the label 

54 lookup covers the scalar case only, since a per-element label array has 

55 no consumer yet. 

56 - `quality` (`AttrQuality` -> `Quality`): `ATTR_VALID` -> Good; 

57 `ATTR_WARNING` / `ATTR_CHANGING` -> Uncertain; 

58 `ATTR_ALARM` / `ATTR_INVALID` -> Bad. 

59 - `quality_detail`: the raw `AttrQuality` name as a forensic breadcrumb when 

60 quality is not VALID; empty string when VALID (matches the EPICS adapters). 

61 - `produced_at`: `datetime.fromtimestamp(attr.time.totime(), tz=UTC)`, 

62 or None when the attribute carried no time (see `_produced_at_for`). 

63 

64## Error mapping 

65 

66PyTango raises `tango.DevFailed`, carrying a stack of `DevError` each with a 

67`.reason` string. The adapter maps the first reason: 

68 

69 - `API_DeviceTimedOut` / `API_CommandTimedOut` -> `ControlTimeoutError` 

70 - `API_CantConnectToDevice` / `API_CorbaException` / 

71 `API_DeviceNotExported` / `API_DeviceNotFound` -> `ControlNotConnectedError` 

72 - `API_AttrNotAllowed` / `API_WAttrOutsideLimit` -> `ControlWriteRejectedError` 

73 - `API_AttrNotWritable` and authorisation refusals -> `ControlAccessDeniedError` 

74 - any other reason -> `ControlWriteRejectedError` with the reason folded into 

75 the detail so the decider's event payload captures it per 

76 [[project_non_determinism_principle]] 

77 

78Client-side value-encode failures (`ValueError` / `TypeError` raised by 

79PyTango before the wire call) map to `ControlValueCoercionError`. 

80 

81## Subscribe lifecycle 

82 

83`subscribe` is a plain `def` returning an async generator directly; proxy 

84construction + `subscribe_event(attr, EventType.CHANGE_EVENT, cb)` run on the 

85generator's first `__anext__`. Tango pushes an initial synchronised event on 

86subscribe, then one per change. The callback receives an `EventData` with 

87`.attr_value` (a `DeviceAttribute`) and `.err` / `.errors`; it is pushed onto 

88an unbounded `asyncio.Queue`. An error event raises `ControlNotConnectedError` 

89through the iterator so a silent stream pause is impossible. The generator's 

90`finally` calls `unsubscribe_event(event_id)` (matching the EPICS adapters' 

91cleanup discipline). 

92"""

148def _quality_for(quality: Any) -> Quality: 

149 """Collapse a Tango `AttrQuality` to the domain `Quality` trichotomy.""" 

150 name = getattr(quality, "name", str(quality)) 

151 if name == "ATTR_VALID": 

152 return "Good" 

153 if name in ("ATTR_WARNING", "ATTR_CHANGING"): 

154 return "Uncertain" 

155 return "Bad"

170def _kind_for(attr: Any) -> MeasurementKind: 

171 """Map a `DeviceAttribute`'s data format + type to `MeasurementKind`.""" 

172 data_format = getattr(attr, "data_format", None) 

173 format_name = getattr(data_format, "name", str(data_format)) 

174 if format_name == "IMAGE": 

175 return "Image" 

176 if format_name == "SPECTRUM": 

177 return "Array" 

178 type_name = getattr(getattr(attr, "type", None), "name", "") 

179 if type_name in ("DevEnum", "DevState"): 

180 return "Categorical" 

181 return "Scalar"

184def _unpack_value(attr: Any, kind: MeasurementKind, enum_labels: tuple[str, ...] | None) -> Any: 

185 """Extract a Python-native value from a Tango `DeviceAttribute`. 

186 

187 Returns `None` when the attribute carries no value, whatever its kind. 

188 On ATTR_INVALID the Tango core discards the value but keeps 

189 `data_format`, so an invalid spectrum still classifies as `Array` while 

190 `attr.value` is `None`: unpacking it as a sequence would raise a bare 

191 `TypeError` that is not a `ControlPort` error family and so escapes the 

192 Conductor's closed catch tuple. `None` instead keeps an invalid read 

193 shaped like every other invalid read (an invalid scalar already reads 

194 back as `None`), and preserves the forensic pairing of `quality='Bad'` 

195 with `quality_detail=attr_quality=ATTR_INVALID` that the Conductor 

196 records against the failed step. Deciding whether a value is usable is 

197 the consumer's call, not this adapter's: `_require_finite_number` 

198 already turns a `None` capture into a structured step failure, and a 

199 check criterion already treats it as a clean mismatch. 

200 """ 

201 value: Any = getattr(attr, "value", None) 

202 if value is None: 

203 return None 

204 if kind == "Image": 

205 if hasattr(value, "tolist"): 

206 return tuple(tuple(row) for row in value.tolist()) 

207 return tuple(tuple(row) for row in value) 

208 if kind == "Array": 

209 if hasattr(value, "tolist"): 

210 return tuple(value.tolist()) 

211 return tuple(value) 

212 if kind == "Categorical": 

213 # DevState arrives as a real IntEnum carrying its own label, so it 

214 # needs no config lookup (and reports no enum_labels). DevEnum 

215 # arrives as a bare int and is resolved against the cached labels. 

216 if hasattr(value, "name"): 

217 return value.name 

218 index = int(value) 

219 if enum_labels is not None and 0 <= index < len(enum_labels): 

220 return enum_labels[index] 

221 return str(index) 

222 scalar: Any = value 

223 if hasattr(scalar, "item"): 

224 scalar = scalar.item() 

225 if isinstance(scalar, bytes): 

226 return scalar.decode("utf-8", errors="replace") 

227 return scalar

230def _produced_at_for(time_val: Any) -> datetime | None: 

231 """Substrate time from a Tango `TimeVal`, or None when absent. 

232 

233 Tango counts from the Unix epoch, not the EPICS one, so the 

234 impossible boundary sits at 1970 rather than 1990: an attribute 

235 that was never stamped reports zero, and `fromtimestamp(0)` would 

236 render that as 1970-01-01. Same failure as the EPICS adapters, one 

237 epoch apart. Missing `time` entirely is the same absence and 

238 answers the same way. 

239 

240 Unlike `epics_ca_control_port._produced_at_for` this rule has no 

241 live measurement behind it; it follows from Tango's epoch, and 

242 matching behaviour across substrates is what the shared unit test 

243 holds in place. 

244 """ 

245 if time_val is None: 

246 return None 

247 timestamp = float(time_val.totime()) 

248 if timestamp <= 0.0: 

249 return None 

250 return datetime.fromtimestamp(timestamp, tz=UTC)

253def _to_reading(attr: Any, enum_labels: tuple[str, ...] | None = None) -> Measurement: 

254 """Translate a Tango `DeviceAttribute` to `Measurement`. 

255 

256 `enum_labels` resolves a DevEnum ordinal to its label; None leaves the 

257 ordinal stringified, which is the right fallback for a non-enum or an 

258 unreachable attribute config. 

259 """ 

260 kind = _kind_for(attr) 

261 value = _unpack_value(attr, kind, enum_labels) 

262 quality = getattr(attr, "quality", None) 

263 time_val = getattr(attr, "time", None) 

264 produced_at = _produced_at_for(time_val) 

265 return Measurement( 

266 value=value, 

267 kind=kind, 

268 quality=_quality_for(quality), 

269 produced_at=produced_at, 

270 quality_detail=_quality_detail_for(quality), 

271 name=str(getattr(attr, "name", "")), 

272 )

283def _map_dev_failed(address: str, exc: Any, *, timeout_s: float) -> Exception: 

284 """Translate a `tango.DevFailed` to the appropriate Control*Error.""" 

285 reason = _first_reason(exc) 

286 if reason in _TIMEOUT_REASONS: 286 ↛ 287line 286 didn't jump to line 287 because the condition on line 286 was never true

287 return ControlTimeoutError(address, timeout_s) 

288 if reason in _NOT_CONNECTED_REASONS: 

289 return ControlNotConnectedError(address) 

290 if reason in _ACCESS_DENIED_REASONS: 

291 return ControlAccessDeniedError(address) 

292 if reason in _WRITE_REJECTED_REASONS: 292 ↛ 294line 292 didn't jump to line 294 because the condition on line 292 was always true

293 return ControlWriteRejectedError(address, reason) 

294 return ControlWriteRejectedError(address, reason or "DevFailed")

298 """PyTango-backed `ControlPort` implementation for Tango device attributes.

300 See module docstring for the connection model, ACL table, error 

301 mapping, and subscribe lifecycle. Probes PyTango importability at 

302 construction so a missing `tango` extra fails as a `ValueError` at

306 def __init__(self, *, default_timeout_s: float = _DEFAULT_TIMEOUT_S) -> None: 

307 require_tango("tango") 

308 self._default_timeout_s = default_timeout_s 

309 self._proxies: dict[str, Any] = {} 

310 self._enum_labels: dict[str, tuple[str, ...]] = {} 

311 self._closed = False

313 async def _resolve_enum_labels(self, address: TangoAttributeAddress) -> tuple[str, ...] | None: 

314 """Cache a DevEnum attribute's labels per address via its attribute config. 

315 

316 Mirrors `EpicsCaControlPort._resolve_enum_labels`. Labels live in the 

317 attribute CONFIG, never on the read value, so this costs one extra 

318 round trip at first encounter; caching keeps it off the conduct 

319 loop's per-read path, where on a real Tango network (unlike 

320 loopback) it would be a real CORBA call per read. 

321 

322 An empty tuple is cached and returned as None, meaning "not an enum". 

323 Caching that negative matters here in a way it does not for EPICS: 

324 `DevState` is a common Categorical that reports NO labels, so 

325 without it every DevState read would re-fetch the config forever. 

326 A config fetch that fails is not an error worth raising: the read 

327 itself already succeeded, so fall back to the ordinal rather than 

328 turn a readable attribute into a failed step. 

329 """ 

330 from tango import DevFailed 

331 

332 raw = str(address) 

333 cached = self._enum_labels.get(raw) 

334 if cached is not None: 

335 return cached or None 

336 try: 

337 proxy = await self._proxy_for(address.device) 

338 config = await asyncio.wait_for( 

339 proxy.get_attribute_config(address.attribute), 

340 timeout=self._default_timeout_s, 

341 ) 

342 except (TimeoutError, DevFailed): 

343 return None 

344 labels = tuple(str(label) for label in getattr(config, "enum_labels", ())) 

345 self._enum_labels[raw] = labels 

346 return labels or None

348 async def _proxy_for(self, device: str) -> Any: 

349 """Return a cached asyncio `DeviceProxy` for `device`, building it lazily. 

350 

351 The asyncio proxy constructor is awaitable (it pings the device on 

352 build), so a construction failure surfaces here as `DevFailed` and 

353 is mapped by the caller. 

354 """ 

355 proxy = self._proxies.get(device) 

356 if proxy is None: 

357 from tango.asyncio import DeviceProxy 

358 

359 # `tango.asyncio.DeviceProxy` is a partial over `get_device_proxy` 

360 # whose declared return does not vary with green mode, so it types 

361 # as a bare DeviceProxy. Under Asyncio it really returns an 

362 # awaitable, which the integration module proves: `wait_for` on a 

363 # non-awaitable would raise TypeError instead of passing. 

364 proxy = await asyncio.wait_for( 

365 DeviceProxy(device), # pyright: ignore[reportArgumentType] 

366 timeout=self._default_timeout_s, 

367 ) 

368 self._proxies[device] = proxy 

369 return proxy

371 async def read(self, address: TangoAttributeAddress) -> Measurement: 

372 from tango import DevFailed 

373 

374 raw = str(address) 

375 try: 

376 proxy = await self._proxy_for(address.device) 

377 attr = await asyncio.wait_for( 

378 proxy.read_attribute(address.attribute), timeout=self._default_timeout_s 

379 ) 

380 except TimeoutError as exc: 

381 raise ControlNotConnectedError(raw) from exc 

382 except DevFailed as exc: 

383 raise _map_dev_failed(raw, exc, timeout_s=self._default_timeout_s) from exc 

384 enum_labels: tuple[str, ...] | None = None 

385 if _kind_for(attr) == "Categorical": 

386 enum_labels = await self._resolve_enum_labels(address) 

387 return _to_reading(attr, enum_labels)

455 def subscribe(self, address: TangoAttributeAddress) -> AsyncGenerator[Measurement]: 

456 """Return type narrows the Protocol's `AsyncIterator` to `AsyncGenerator`. 

457 

458 Covariant return lets tests close subscriptions via the iterator's 

459 `aclose()`; same pattern as the EPICS adapters. Setup (proxy build + 

460 `subscribe_event`) runs on the generator's first `__anext__`. 

461 """ 

462 return self._drain(address)

464 async def _drain(self, address: TangoAttributeAddress) -> AsyncGenerator[Measurement]: 

465 from tango import DevFailed, EventType 

466 

467 raw = str(address) 

468 queue: asyncio.Queue[Any] = asyncio.Queue() 

469 

470 def _callback(event: Any) -> None: 

471 # Synchronous put_nowait keeps FIFO ordering across rapid events; 

472 # the queue is unbounded so it never raises QueueFull. 

473 queue.put_nowait(event) 

474 

475 try: 

476 proxy = await self._proxy_for(address.device) 

477 event_id = await asyncio.wait_for( 

478 proxy.subscribe_event(address.attribute, EventType.CHANGE_EVENT, _callback), 

479 timeout=self._default_timeout_s, 

480 ) 

481 except TimeoutError as exc: 

482 raise ControlNotConnectedError(raw) from exc 

483 except DevFailed as exc: 

484 raise _map_dev_failed(raw, exc, timeout_s=self._default_timeout_s) from exc 

485 

486 try: 

487 while True: 

488 event = await queue.get() 

489 if getattr(event, "err", False): 

490 raise ControlNotConnectedError(raw) 

491 attr = getattr(event, "attr_value", None) 

492 if attr is None: 

493 continue 

494 enum_labels: tuple[str, ...] | None = None 

495 if _kind_for(attr) == "Categorical": 495 ↛ 496line 495 didn't jump to line 496 because the condition on line 495 was never true

496 enum_labels = await self._resolve_enum_labels(address) 

497 yield _to_reading(attr, enum_labels) 

498 finally: 

499 with contextlib.suppress(Exception): 

500 await proxy.unsubscribe_event(event_id)

502 async def aclose(self) -> None: 

503 """Drop cached device proxies + enum labels; idempotent. 

504 

505 Tango `DeviceProxy` objects release their CORBA connection on 

506 garbage collection; dropping the cache is sufficient. The enum-label 

507 cache goes with them so a reopened port re-reads attribute config 

508 rather than trusting labels from before a device restart. Provided so 

509 production code paths can call `aclose()` polymorphically against any 

510 `ControlPort`. 

511 """ 

512 if self._closed: 

513 return 

514 self._closed = True 

515 self._proxies.clear() 

516 self._enum_labels.clear()
