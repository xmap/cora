1"""Closed catalog of `CalibrationQuantity` values + per-quantity schema registry. 

2 

3Each quantity in the closed StrEnum declares two JSON Schemas at module 

4import time: 

5 

6 - `OPERATING_POINT_SCHEMA` — what operating-conditions dict identifies 

7 this calibration (for example, rotation_center at `{energy: 25, 

8 optics_config: "5x"}` is distinct from the same quantity at 30 keV). 

9 - `VALUE_SCHEMA` — what value dict the revision carries (for example, 

10 `{center: 1024.5, uncertainty: 0.3}`). 

11 

12Both schemas are CLOSED (`additionalProperties: False`) and property- 

13type-restricted to primitives per Q1 lock (Round 2: NXcalibration's 

14free-form approach is a documented gap; RELION optics-group + DICOM 

15coded-content + CMS typed-metadata all converge on typed-at-contract). 

16 

17## Adding a quantity 

18 

191. Add the StrEnum value below. 

202. Add a sibling module `cora/calibration/quantities/<value>.py` exposing 

21 `OPERATING_POINT_SCHEMA` + `VALUE_SCHEMA`. 

223. Add the module to `_SCHEMAS_BY_QUANTITY` below. 

234. Add the affordance unit test pinning the count + the per-quantity 

24 schema round-trip. 

25 

26Closed-catalog growth via PR (matches Affordance enum precedent). 

27Runtime configuration is forbidden per the design memo anti-hook 

28on free-dict operating-point: every quantity must declare schemas 

29before being usable. 

30"""

46class CalibrationQuantity(StrEnum): 

47 """Closed catalog of supported calibration quantities. 

48 

49 Day-one set covers the 2-BM tomography pilot's load-bearing 

50 calibrations. Growth happens by PR per the Affordance enum precedent. 

51 

52 String values are stable-by-design (event payloads carry them 

53 verbatim); renaming a value would orphan stored events. The enum 

54 member name follows SCREAMING_SNAKE_CASE; the value follows 

55 snake_case to match jsonb-key conventions in operating_point and 

56 value dicts. 

57 """ 

58

101def get_operating_point_schema(quantity: CalibrationQuantity) -> dict[str, Any]: 

102 """Return the operating_point JSON Schema for the named quantity. 

103 

104 Raises KeyError if the quantity has no registered schema (which is 

105 a programmer error: the StrEnum + registry must move together). 

106 """ 

107 return _SCHEMAS_BY_QUANTITY[quantity][0] 

108 

109 

110def get_value_schema(quantity: CalibrationQuantity) -> dict[str, Any]: 

111 """Return the value JSON Schema for the named quantity.""" 

112 return _SCHEMAS_BY_QUANTITY[quantity][1]
