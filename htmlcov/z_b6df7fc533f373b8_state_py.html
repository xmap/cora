1"""Permit aggregate state, lifecycle status, directional terms VOs, and domain errors. 

2 

3A `Permit` authorizes a federation flow between this facility and a 

4named peer facility. The single aggregate carries both directions of 

5the publish-pull relationship through a discriminated `terms` field 

6(`OutboundTerms | InboundTerms`); the `direction` enum on the 

7aggregate root is a query-convenience discriminator that mirrors 

8`type(state.terms)` for read-side filters and projection indexing. 

9 

10Polymorphism precedent: `Observation` carries a tagged-union payload 

11discriminated by SOSA `sampling_procedure`. Permit follows the same 

12shape: identity and lifecycle fields live on the root, direction- 

13specific contractual fields ride on the `terms` arm. 

14 

15The 4-state FSM is shared across directions: 

16 

17 Defined -> Active -> Suspended (resumable) -> Revoked (terminal) 

18 

19with `Active <-> Suspended` reversible until `Revoked` closes the 

20lifecycle. 

21 

22## Direction-specific term shapes 

23 

24`OutboundTerms` (this facility publishes to the peer): 

25 

26 - `scopes` is the bounded set of publishable scopes the peer may 

27 pull under this permit. 

28 - `read_scope` and `onward_action_scope` are orthogonal axes. 

29 Combinations that collapse the matrix (for example onward 

30 `MayExportOffPlatform` with read `ListMetadataOnly` has no carrier 

31 to export) raise `PermitScopeCollapseError`. 

32 

33`InboundTerms` (this facility pulls from the peer): 

34 

35 - `accepted_canonicalization_versions` carries the canonicalization 

36 schemes this side will accept (default `frozenset({"cora/v1"})`). 

37 - `required_receipt_kinds` is the set of `ReceiptKind` values the 

38 inbound side demands; default `frozenset()` (no receipt required). 

39 - `publisher_grant_correlation_handle` is the opaque string the peer 

40 minted at publish-time for cross-facility audit linkage; NOT a 

41 UUID foreign key. 

42 - `inbound_allowed_artifact_kinds` is the free-form string set the 

43 peer is authorized to publish for this permit. The `inbound_*` 

44 prefix disambiguates from the Permit root's own 

45 `allowed_artifact_kinds` field; same instance carries both. 

46 

47The tagged-union shape of `terms` structurally enforces direction- 

48specific field ownership: an outbound payload cannot smuggle 

49`accepted_canonicalization_versions` because that field does not 

50exist on `OutboundTerms`. The prior 

51`AcceptedCanonicalizationVersionsForbiddenOnOutboundError` is DROPPED; 

52the type system enforces it now. 

53 

54## ABI tier floor 

55 

56`AbiTier` lives here as its canonical home: shared with the seal 

57aggregate (and any future federation symbol). Hoist to a federation- 

58level `_value_types.py` helper once a second symbol fires rule-of-three. 

59 

60## Path C lifecycle bookkeeping 

61 

62Per [[project_template_aggregate_timestamps]] the transition 

63lifecycle timestamps (`activated_at`, `suspended_at`, `resumed_at`, 

64`revoked_at`) do NOT live on aggregate state; they are derived at 

65projection-apply time from each event's envelope `occurred_at`. 

66`expires_at` STAYS on state: it is a contractual upper bound, 

67domain-meaningful, and not envelope-derivable. `defined_at` also 

68STAYS on state per the fold-symmetry rule 

69[[project_fold_symmetry_design]]: the `PermitDefined.occurred_at` 

70fold pairs with the `defined_by` attribution fold on the genesis 

71arm. `defined_by` is type-annotated as `ActorId` so the 

72fold-symmetry fitness test detects attribution fields structurally. 

73 

74## Errors 

75 

76Inlined per the unanimous instance-aggregate precedent 

77(Calibration / Caution / Supply / Clearance all keep error classes 

78alongside state). Per [[project_genesis_error_classes]] the 

79`*AlreadyExistsError` and `*NotFoundError` pair stays un-hoisted: each 

80BC routes its own per-class isinstance check in the BC exception 

81handler. 

82"""

143class ReceiptKind(StrEnum): 

144 """Receipt schemes an inbound permit requires for accepted artifacts. 

145 

146 - `scitt`: transparency-log receipt arm 

147 - `rekor_sct`: certificate-transparency receipt arm 

148 - `ts_authority`: timestamp-authority token arm

238@dataclass(frozen=True, slots=True) 

239class Permit: 

240 """Aggregate root: federation-flow authorization for one peer + direction. 

241 

242 `peer_facility_code` is the cross-deployment convergent 

243 `FacilityCode` for the peer facility. Federation peers are 

244 external entities; CORA does NOT mint their ids. The bare slug 

245 string remains the cross-deployment identity on the event log 

246 (disk JSON key stays `"peer_facility_id"` per anti-hook). 

247 

248 `direction` mirrors `type(terms)` and is the read-side query 

249 discriminator; the decider enforces the invariant on every 

250 transition. 

251 

252 `allowed_credential_ids`, `allowed_payload_types`, and 

253 `allowed_artifact_kinds` narrow the permit across both 

254 directions: only the named Credential ids, payload-type strings, 

255 and artifact kinds are valid under this permit. Each MUST be 

256 non-empty; the decider rejects empty frozensets with 

257 `InvalidPermitScopeError`. There is no wildcard or implicit 

258 "no restriction" fallback. (Distinct from 

259 `InboundTerms.inbound_allowed_artifact_kinds`, which scopes the 

260 inbound arm specifically.) 

261 

262 `abi_tier_floor` is the lowest tier the permit will honor on 

263 either side of the relationship. 

264 

265 `expires_at` is the contractual upper bound; not envelope- 

266 derivable, stays on state. `defined_by` denorms the genesis 

267 principal and pairs with `defined_at` (folded from the 

268 `PermitDefined` envelope) per fold-symmetry. 

269 """ 

270 

271 id: UUID 

272 peer_facility_code: FacilityCode 

273 direction: Direction 

274 allowed_credential_ids: frozenset[UUID] 

275 allowed_payload_types: frozenset[str] 

276 allowed_artifact_kinds: frozenset[str] 

277 abi_tier_floor: AbiTier 

278 expires_at: datetime 

279 defined_by: ActorId 

280 defined_at: datetime 

281 status: PermitStatus 

282 terms: OutboundTerms | InboundTerms

318class UnsupportedCanonicalizationVersionError(ValueError): 

319 """An accepted_canonicalization_versions member is not a recognized scheme. 

320 

321 The inbound side has to map each accepted version to a concrete 

322 canonicalization implementation; an unknown string would mean 

323 every artifact under that version is unverifiable. Recognized 

324 versions are owned by the canonicalization port; v1 (`cora/v1`) 

325 is the day-one default per 

326 [[project_canonicalization_port_design]]. 

327 """ 

328 

329 def __init__(self, version: str) -> None: 

330 super().__init__( 

331 f"Unsupported canonicalization version {version!r}; the inbound side has " 

332 f"no verifier registered for this version" 

333 ) 

334 self.version = version
