1"""Agent BC's `LLMFactory` for the composition root. 

2 

3Bound from `cora.api.main` into `build_kernel` the same way 

4`cora.trust.build_authorize.build_authorize` is bound. Lives in Agent BC 

5because the production implementors (`AnthropicLLM`, `ArgoLLM`, and the 

6in-house `LocalLLM`) live here too (cross-BC adapter-ownership convention; Safety 

7BC owns `PostgresClearanceLookup`, Caution BC owns `PostgresCautionLookup`). 

8 

9Returns `None` unless BOTH `Settings.llm_enabled` (the switch) and the 

10selected provider's own configuration are present, so the Kernel carries 

11`llm=None` and no model is called at all. 

12 

13The switch is checked before the provider, and it has no per-provider 

14exemption. An in-house `local` model sends nothing outside the facility 

15and buys no vendor tokens, which makes it tempting to let it run with the 

16switch off; that is the same mistake `is_simulated` exists to prevent on 

17the control side, where a soft IOC still speaks real Channel Access. A 

18local model still invokes an LLM, still debits the beamline envelope at 

19its catalog rate, and still writes inference rows to the experiment 

20record. The same holds for a gateway the facility already funds: `argo` 

21buys no tokens on the deployment's own account, and still does all three. 

22`LLM_ENABLED` is the deployment's one answer to "does this instance run 

23an LLM at all", so it gates every serving route. 

24 

25`llm=None` is a fully supported state, not a degraded one: every 

26consumer already handles it because the key-absent case always 

27produced it. The LLM-backed subscribers log-and-skip 

28(`cora.agent._subscribers`) and `regenerate_run_debrief` answers 

29unavailable. The `llm` decide substrate cannot be selected by a remote 

30caller at all (`WireDecideSubstrate` admits only `in_memory` and 

31`grid_walk`), so `build_decide_port`'s `llm is None` guard is an 

32internal-caller guard, not a request-reachable path. 

33 

34(An earlier version of this docstring claimed subscriber registration 

35"fail-fasts" on `kernel.llm is None`. It does not, and never did: 

36`register_agent_subscribers` logs a warning and skips, deliberately, 

37so a deployment may defer Agent rollout without refusing to boot.) 

38"""

70def llm_provider_configured(settings: Settings) -> bool: 

71 """Whether the SELECTED provider has its own configuration present. 

72 

73 Ignores `llm_enabled` on purpose; the switch is a separate, 

74 provider-independent gate that both callers below check for 

75 themselves. This is the one place that matches 

76 `settings.llm_provider` against the credential each provider 

77 actually reads, via the same `_anthropic_credential` / 

78 `_argo_identity` / `_local_endpoint` extractors `build_llm` uses to 

79 construct the adapter. `build_llm` and `derive_llm` (in 

80 `cora.api._readiness`) both consult this instead of restating the 

81 match, so they cannot drift on what "configured" means for a given 

82 provider. 

83 

84 They used to drift: `derive_llm` checked `anthropic_api_key` alone, 

85 so a deployment running the argo or local arm booted its own log 

86 line reporting the LLM as `off`, seconds before serving hundreds of 

87 calls through it. 

88 """ 

89 if settings.llm_provider == "argo": 

90 return _argo_identity(settings) is not None 

91 if settings.llm_provider == "local": 

92 return _local_endpoint(settings) is not None 

93 return _anthropic_credential(settings) is not None

96def build_llm(settings: Settings) -> LLM | None: 

97 """Construct the production LLM, or `None` when off or unconfigured. 

98 

99 Two independent reasons to return `None`, and the switch is checked 

100 first so an operator who turns the LLM off gets that answer even 

101 with a provider fully configured in the environment: 

102 

103 - `llm_enabled` is False (the default): this deployment runs no 

104 model on any serving route, so no experiment metadata leaves the 

105 facility, no tokens are bought, and no envelope is debited. 

106 - the selected provider is unconfigured: `anthropic` without 

107 `anthropic_api_key`, `argo` without `argo_username`, or `local` 

108 without a base URL and a served model name. Nothing to call it 

109 with in any of the three cases. 

110 

111 `settings.llm_provider` chooses the adapter: `anthropic` buys an 

112 external, token-billed call; `argo` buys the same vendor models 

113 through Argonne's internal gateway, on facility-funded 

114 infrastructure rather than the deployment's own account; `local` 

115 serves a facility-hosted model over an OpenAI-compatible endpoint 

116 and meters the GPU time it holds. All three debit the same beamline 

117 envelope through the catalog's price for the entry, which is what 

118 makes the envelope source-agnostic, and reaching it by one route is 

119 the design rather than a coincidence. 

120 

121 The `get_secret_value()` calls below are the only places the 

122 Anthropic key and the Argo username are unwrapped; passing the raw 

123 string to an adapter constructor is the boundary at which "secret 

124 material" becomes "live credential". Adapter scope is responsible 

125 for not re-exposing it. 

126 """ 

127 if not settings.llm_enabled: 

128 return None 

129 if settings.llm_provider == "argo": 

130 return _build_argo_llm(settings) 

131 if settings.llm_provider == "local": 

132 return _build_local_llm(settings) 

133 credential = _anthropic_credential(settings) 

134 if credential is None: 

135 return None 

136 return AnthropicLLM(api_key=credential.get_secret_value())

139def _build_argo_llm(settings: Settings) -> LLM | None: 

140 """Build `ArgoLLM`, or None when no gateway identity is configured. 

141 

142 The gateway takes an ANL domain username where a vendor takes an 

143 API key, so the absent-identity case looks the same as the 

144 absent-key case and returns None the same way. 

145 """ 

146 identity = _argo_identity(settings) 

147 if identity is None: 

148 return None 

149 return ArgoLLM(username=identity.get_secret_value(), base_url=settings.argo_base_url)

152def _build_local_llm(settings: Settings) -> LLM | None: 

153 """Build the in-house `LocalLLM`, or None when its endpoint is unset. 

154 

155 The GPU time each call consumes is metered to the shadow-cost 

156 observability signal at `settings.local_llm_gpu_usd_per_hour`; it 

157 never debits the budget (in-house serving is metered-free by default, 

158 and what debits is the catalog's per-token rate for the entry). A real 

159 serving engine is stood up out of band; this only needs its base URL 

160 and served model name. 

161 """ 

162 endpoint = _local_endpoint(settings) 

163 if endpoint is None: 

164 return None 

165 base_url, model = endpoint 

166 return LocalLLM( 

167 backend=OpenAICompatibleBackend(base_url=base_url, model=model), 

168 monotonic_clock=SystemMonotonicClock(), 

169 on_measure=make_gpu_usage_sink(settings.local_llm_gpu_usd_per_hour), 

170 device_id=settings.local_llm_device_id, 

171 )

174def llm_unwired_reason(settings: Settings) -> str: 

175 """Say WHICH setting left `kernel.llm` unwired, per selected provider. 

176 

177 One source of truth for every surface that has to explain the 

178 unwired state: the subscriber-registration warning, the REST 503 

179 body, and the MCP tool's error. They must agree, and each must send 

180 the operator to the remedy that actually applies. Naming the 

181 credential when the switch is simply off is the more likely mistake 

182 now, because off is the default; naming the Anthropic key when the 

183 deployment selected `argo` or `local` would be worse, because it 

184 sends the operator to a credential that provider never reads. 

185 

186 Callers are expected to have already established that the LLM is 

187 unwired; this only explains why. 

188 """ 

189 if not settings.llm_enabled: 

190 return ( 

191 "LLM_ENABLED is false, so this deployment runs no model on any " 

192 "serving route. Set LLM_ENABLED=true (and configure the provider " 

193 "named by LLM_PROVIDER) to turn the LLM features on." 

194 ) 

195 if settings.llm_provider == "argo": 

196 return ( 

197 "LLM_ENABLED is true and LLM_PROVIDER is argo, but ARGO_USERNAME " 

198 "is not configured. Supply the ANL domain username the gateway " 

199 "authenticates: a service account for a long-lived deployment, " 

200 "so the gateway attributes these calls to the application rather " 

201 "than to an individual. Supply it and restart." 

202 ) 

203 if settings.llm_provider == "local": 

204 return ( 

205 "LLM_ENABLED is true and LLM_PROVIDER is local, but " 

206 "LOCAL_LLM_BASE_URL and LOCAL_LLM_MODEL are not both configured. " 

207 "Supply the served endpoint and model name and restart." 

208 ) 

209 return ( 

210 "LLM_ENABLED is true but ANTHROPIC_API_KEY is not configured. " 

211 "Supply the credential and restart." 

212 )
