1"""Authorize port: gate every command behind authz.authorize(principal, command, conduit, surface). 

2 

3`principal_id` (not `actor_id`) names the invoker because the Access BC 

4already owns an `Actor` aggregate; using `actor_id` for both the Actor 

5aggregate's id and the calling-party's id was a real bug vector at 

6handler call sites where commands target an Actor aggregate (for example, 

7DeactivateActor). 

8 

9`conduit_id: UUID` names the ISA-99/IEC-62443 inter-zone 

10channel — comms path between two trust zones — through which the 

11command would flow. Operationally inert at v1: every handler passes 

12`UUID(int=0)` nil-sentinel. Reactivation tracked as 

13project_conduit_injection_design.md WI10. 

14 

15`surface_id: UUID` names the process-level arrival point (HTTP / 

16MCP stdio / MCP streamable-http) through which the request entered 

17CORA. Closed-StrEnum kind sits on the 

18`cora.trust.aggregates.surface.Surface` aggregate; surface adapters 

19resolve concrete IDs per request, and edge-auth layers OAuth `aud` 

20validation on top. 

21 

22Defaults: both `conduit_id` and `surface_id` default to nil 

23`UUID(int=0)` so existing handler call sites work unchanged. As real 

24routing arrives at the HTTP / MCP / A2A boundaries, routes inject 

25concrete IDs and stop using the nil sentinel — the architecture 

26fitness test pins the no-nil-leak invariant. 

27 

28`AllowAllAuthorize` is the no-op stub used for dev/test and the 

29documented bootstrap workflow; `TrustAuthorize` 

30(in `cora.trust.authorize`) is the production adapter. 

31"""

41class Conjunct(StrEnum): 

42 """A named input an authorization decision consulted. 

43 

44 Stamped on every result as `evaluated`, so a decision reports which 

45 questions it actually answered instead of leaving that to the 

46 reader's assumption. A caller that consults fewer conjuncts than the 

47 gate produces a partial answer, and this set is what makes the 

48 partiality legible in a log, a test, or an API response rather than 

49 a convention someone has to remember. 

50 

51 - `Policy` -- the Policy aggregate's conduit, surface, 

52 permitted-principal, and permitted-command predicate 

53 - `Liveness` -- whether the calling principal is a registered 

54 Actor that an operator has not switched off. Reads 

55 `Actor.active`, one fact that describes a human and 

56 an agent identically because `Agent.id == Actor.id`. 

57 

58 Members are added as conjuncts land, never ahead of them. An 

59 unpopulated member would let a result claim it evaluated something 

60 no code checks, which is the one failure this vocabulary exists to 

61 make impossible. 

62 

63 A member appearing in `evaluated` means the decision CONSULTED it, 

64 not that the deployment has it wired. `Liveness` is absent when the 

65 posture is "off" or "shadow", when the command is exempt, or when 

66 the read failed, so an absence distinguishes "never asked" from 

67 "asked and passed". 

68 

69 That distinction lives on the RESULT and nowhere else today: the 

70 `Verdict` entry row has no conjunct column, so `evaluated` is not 

71 persisted. Do not describe the verdict logbook as recording which 

72 conjuncts ran until it carries them. 

73 """ 

74 

75 POLICY = "Policy" 

76 LIVENESS = "Liveness"

79@dataclass(frozen=True) 

80class Allow: 

81 """Authorization granted. 

82 

83 `evaluated` names the conjuncts the decision consulted to get here. 

84 It defaults to empty because a stand-in that decides on nothing 

85 (`AllowAllAuthorize`) should say so: an empty set is the honest 

86 report for a permissive fallback, and it is what distinguishes that 

87 fallback from a real grant in a verdict record. 

88 """ 

89 

90 evaluated: frozenset[Conjunct] = frozenset()

108class Authorize(Protocol): 

109 """Authorization gate: called before every command. 

110 

111 Named-method (not `__call__`) per Python typing-community guidance 

112 (PEP 544 + typing spec + mypy docs): `__call__` Protocols are for 

113 callback signatures `Callable[...]` can't express (variadic, 

114 overloaded, complex generic). A single-operation domain port uses 

115 a regular method, matching CORA's other ports (`Clock.now`, 

116 `EventStore.load`, `TokenVerifier.verify`, …) and the broader 

117 authorization-library corpus (Spring Security 6's 

118 `AuthorizationManager.authorize`, Pundit's `authorize`, Cedar's 

119 `is_authorized`, Casbin's `enforce`). 

120 

121 The seam: `Kernel.authz: Authorize` with call sites reading 

122 `await deps.authz.authorize(...)` — "use the authz port to 

123 authorize this command." Factory protocols (`AuthorizeFactory`, 

124 `LLMFactory`) DO use `__call__` because they ARE construction 

125 functions; this port is not. 

126 """
