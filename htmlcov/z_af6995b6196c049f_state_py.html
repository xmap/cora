1"""Visit aggregate state, value objects, enums, and domain errors. 

2 

3`Visit` is the operational-envelope counterpart to Trust's authz-topology 

4primitives (Conduit / Policy / Surface / Zone). It represents a team's 

5allocated time on a Surface for a Policy-scoped purpose: the 

6operational answer to "who is on this beamline today, doing what, until 

7when." Distinct from Campaign (scientific composition above Run) and 

8from Policy (stable authz rule); orthogonal axes, composition through 

9Surface + Run + Subject. 

10 

118-state FSM locked per `[[project_visit_aggregate_design]]`: 

12 

13 Planned -> Arrived (operator explicit gesture; presence 

14 tracking is separate per V6 lock) 

15 Arrived -> InProgress (operator explicit start) 

16 InProgress <-> OnHold (pause / resume cycle; OnHold reserved 

17 for genuine envelope pauses: beam dump, 

18 equipment fault, safety hold, extended 

19 user break -- NOT for nested-child 

20 commissioning, where parent stays 

21 InProgress and control concern lives on 

22 `proj_surface_active_visit`) 

23 InProgress | OnHold -> Completed (normal terminal) 

24 Planned | Arrived -> Cancelled (pre-work cancel; never started) 

25 InProgress | OnHold -> Aborted (work-started-then-stopped + reason) 

26 any non-terminal -> Voided (FHIR `entered-in-error` analog; 

27 "this Visit should never have 

28 existed", e.g. BSS double-sent) 

29 

30The aggregate is intentionally slim per `[[project_fold_cost_principles]]` 

31and the thin-shape lock in `[[project_visit_aggregate_research]]`: 6 

32owned scalar fields plus 2 collections (`presence_entries`, 

33`external_refs`) plus 1 self-FK (`parent_id`). 

34 

35## Two-tier period split 

36 

37`planned_start_at` + `planned_end_at` live on STATE (operator-supplied 

38at registration; decider reads them for invariants such as 

39`planned_end_at > now()`). `actual_start_at` + `actual_end_at` live on 

40PROJECTION per `[[project_template_aggregate_timestamps]]` Path C 

41(derivable from VisitArrived / VisitStarted / Visit{Completed, Cancelled, 

42Aborted, Voided} event `occurred_at`). 

43 

44## Lifecycle-via-explicit-gesture only 

45 

46Visit lifecycle changes via explicit gesture only -- never auto-derived 

47from Supply / Asset / Safety / Schedule state. Subscriber may emit an 

48explicit command in response to those BCs' events, but the command is 

49audit-trail-visible. Direct application of 

50`[[project_non_determinism_principle]]` V6 lock. 

51 

52## Bootstrap stance 

53 

54Visit commands (`RegisterVisit`, `RecordVisitArrival`, ..., `VoidVisit`) are NOT 

55in the System Bootstrap Policy seed. The bootstrap seed stays at 

56`{DefinePolicy, RegisterActor}`; first real admin Policy grants Visit 

57commands post-bootstrap. See AuthZ matrix in design memo. 

58 

59## VisitType closed enum 

60 

61`VisitType` is a closed StrEnum (`user` / `commissioning` / `maintenance` 

62/ `calibration` / `staff`) following the `Affordance` precedent. Replaces 

63the sentinel-value anti-pattern (DMagic `--gup 0`, NICOS demo=0). 

64Adding a 6th type uses CORA's forward-only migration pattern (drop + 

65re-add CHECK constraint). 

66 

67## No `Period` VO 

68 

69CORA has no `Period` VO today; uses separate `*_at` fields per existing 

70convention. First rule-of-three on `(start_at, end_at)` pairs would hoist 

71a `Period` VO; not yet. 

72 

73## Reason fields carry no PII 

74 

75Free-text `reason` on Held / Cancelled / Aborted / Voided sits in the 

76immutable event log forever. Operator UI MUST display a "no PII" 

77placeholder warning. Cannot be grep-enforced (free-text); enforced by 

78review + UI affordance. Promote to a `VisitTransitionReason` VO with 

79structured fields at rule-of-three on PII-leakage incidents. 

80"""

92 """The Visit's lifecycle state. 

93 

94 Eight values locked day one per `[[project_visit_aggregate_design]]`. 

95 

96 - `Planned` -- registered; not yet arrived; presence collection empty 

97 - `Arrived` -- operator declared team on-site (or remote-checked-in);

190@dataclass(frozen=True) 

191class PresenceEntry: 

192 """One actor's presence record on a Visit. 

193 

194 Fully-immutable frozen dataclass with default `__hash__`/`__eq__` over 

195 ALL FOUR fields (per Identifier / Wire / AssetPort precedent). When 

196 `VisitCheckedOut` flips `check_out_at` from None to a timestamp, the 

197 evolver removes the open entry and inserts a NEW entry with the same 

198 `(actor_id, mode, check_in_at)` plus the populated `check_out_at` -- 

199 the frozen-replace pattern. Old and new entries are distinct frozenset 

200 members because the hash differs on the 4th field. 

201 

202 Composite uniqueness on `(actor_id, check_in_at)` is enforced by the 

203 decider (iterate `state.presence_entries` for an open entry before 

204 accepting a new check-in), not by the frozenset itself. The frozenset 

205 naturally dedups full 4-tuple duplicates (e.g., replay of the same 

206 VisitCheckedIn event after a closed entry already exists). 

207 

208 Same actor may check in / out multiple times in one Visit (multi-shift 

209 presence: shift 1 closed, shift 2 open, both retained on state). 

210 """ 

211 

212 actor_id: UUID 

213 mode: PresenceMode 

214 check_in_at: datetime 

215 check_out_at: datetime | None = None

532@dataclass(frozen=True) 

533class Visit: 

534 """Aggregate root: a team's operational envelope on a Surface. 

535 

536 Slim aggregate per `[[project_visit_aggregate_design]]` thin-shape 

537 lock. Identity is a stable opaque `id: UUID`. 

538 

539 `policy_id: UUID` is REQUIRED -- the authz envelope the Visit 

540 operates under. Trust BC's `Authorize` port already gates commands 

541 by Policy; Visit references the same Policy so a single source of 

542 truth answers "is this actor allowed to act in this Visit's 

543 context." 

544 

545 `surface_id: UUID` is REQUIRED -- Visit is Surface-scoped (NOT 

546 Policy-scoped). One Policy may have many Visits (S8 multi-instrument 

547 case). Each Visit binds to exactly one Surface. Invariant enforced 

548 at register_visit. 

549 

550 `type: VisitType` is REQUIRED -- closed enum classifying the 

551 operational nature. Replaces sentinel-value anti-pattern. 

552 

553 `planned_start_at` + `planned_end_at` live on STATE (operator- 

554 supplied at registration; decider may read them for invariants). 

555 Actual periods live on projection per Path C. 

556 

557 `parent_id: UUID | None` is the self-FK for commissioning- 

558 during-user nesting. Constraint at register_visit: child Visit must 

559 reference parent on the SAME Surface (`VisitParentMismatchedSurfaceError`). 

560 

561 `external_refs: frozenset[Identifier]` is the open-scheme anti- 

562 corruption ref to upstream-deferred concepts (`proposal` / `btr` / 

563 `visit` / `cycle`). Reuses cross-BC infrastructure. 

564 

565 `last_status_reason: str | None` is populated by Held / Cancelled / 

566 Aborted / Voided events. Carries the audit breadcrumb. Resume 

567 preserves the prior value. 

568 

569 `presence_entries: frozenset[PresenceEntry]` tracks 

570 who actually checked in / out, in which mode (physical | remote), 

571 and when. The Visit lifecycle FSM operates independently of 

572 presence per V6 explicit-gesture lock: the operator can drive the 

573 full FSM without ever calling check_in_visit (and conversely, 

574 check_in_visit requires Visit.status in {Arrived, InProgress, 

575 OnHold} -- never auto-transitions Planned -> Arrived). 

576 

577 No actor field on the aggregate beyond inherited 

578 `StoredEvent.principal_id` envelope. Audit truth ("who started / 

579 held / completed / aborted") lives on the event envelope. Presence 

580 actor_id on PresenceEntry IS aggregate state because the decider 

581 reads it (the open-entry guard for VisitAlreadyCheckedInError). 

582 """ 

583 

584 id: UUID 

585 policy_id: UUID 

586 surface_id: UUID 

587 type: VisitType 

588 planned_start_at: datetime 

589 planned_end_at: datetime 

590 parent_id: UUID | None = None 

591 external_refs: frozenset[Identifier] = field(default_factory=frozenset[Identifier]) 

592 presence_entries: frozenset[PresenceEntry] = field(default_factory=frozenset[PresenceEntry]) 

593 status: VisitStatus = VisitStatus.PLANNED 

594 last_status_reason: str | None = None
