1"""The `ConductUntilAdvisedFrom` command + result, the steered-RESUME entry. 

2 

3The DECIDE-axis twin of `ReconductProcedure`: where that resumes a flat pinned 

4step list, this resumes an iterating GP-steered loop. It re-seeds the brain from 

5the recorded closed passes and consults it only at the open frontier, so the 

6already-measured passes are neither re-driven nor re-measured (strategy A per 

7[[project_resumable_conduct_design]]: recorded results replayed, side effects 

8not re-run). 

9 

10Carries the same steering config as `ConductUntilAdvised` (objective, space, 

11objective_capture_name, decide, budget): the resumed frontier passes evaluate 

12against the rebuilt brain, so the request re-supplies what good means + the 

13search space + the brain selection. The re-establishment boundary is NOT a 

14request field: it is DERIVED from the count of recorded closed passes, so the 

15operator cannot mis-declare it. 

16"""
