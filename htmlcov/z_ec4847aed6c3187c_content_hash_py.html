1"""SHA-256 content-addressed identity for CORA template aggregates. 

2 

3Hoisted at design-lock time per `project_content_addressed_identity_design` 

4(2026-05-23). Used by: 

5 

6 - Method / Plan / CalibrationRevision / Trajectory VO (per the 

7 design lock; per-aggregate implementation lands when each 

8 next-touch happens). 

9 - Candidate F signed events (`signing.py`): the `pae_bytes` output is 

10 the byte sequence the Ed25519 signer signs. Sharing one 

11 canonicalization profile across hashing and signing means one 

12 canonicalization audit, one test corpus, and one failure mode. 

13 

14## Why this exact pipeline 

15 

16The corpus survey (`project_canonicalization_research`) ruled out: 

17 

18 - JCS via `rfc8785` library (1-year silence, bus-factor risk) 

19 - Binary canonicalization (CBOR / msgpack / protobuf): 10% win on a 

20 32-byte hash, not worth migration cost 

21 - Postgres jsonb internal bytes (version-unstable across PG) 

22 - Pydantic `model_dump_json()` directly (dict-key insertion order 

23 preserved, not canonical) 

24 

25Locked: stdlib json sort-keys recipe + DSSE PAE wrap + SHA-256. 

26 

27## The non-obvious safeguards 

28 

29Three implementation details that are NOT obvious from the design lock 

30alone, surfaced by implementation research: 

31 

32 1. NFC normalization MUST recurse into keys and values. The only 

33 defense against composed-vs-decomposed Unicode drift (Latin 

34 umlauts, Turkish dotless-i, Czech caron). Without it, a 

35 copy-paste between editors silently produces two distinct hashes 

36 for "the same" identifier. 

37 2. `set` and `frozenset` MUST be coerced to sorted lists before 

38 `json.dumps`, recursively. `sort_keys=True` sorts dict keys but 

39 does NOT sort list contents. A `frozenset[AssetPort]` field 

40 serialized through Pydantic + `json.dumps(sort_keys=True)` would 

41 produce a different hash on every Python process restart 

42 (PYTHONHASHSEED varies). 

43 3. DSSE PAE length is BYTE length, not character length. Use 

44 `len(s.encode("utf-8"))` for non-ASCII payload types, never 

45 `len(s)`. Most common DSSE port bug. 

46 

47## What this helper does NOT do 

48 

49 - Does NOT validate `payload_type` against a closed catalog. Callers 

50 pick from the documented scheme 

51 `application/vnd.cora.<event-type>+json`. 

52 - Does NOT handle Decimal or float fields. Per design lock anti-hook 

53 #8, hashed aggregates may not introduce these without revisiting 

54 the lock. `json.dumps` raises `TypeError` on Decimal and 

55 `ValueError` on NaN/Infinity (with `allow_nan=False`); failing 

56 loudly is the correct signal. 

57 - Does NOT sign anything. Signing is `cora.infrastructure.signing` 

58 layered on top. 

59 

60## Stability across Python versions 

61 

62Output stability depends on the Unicode Character Database version 

63shipped with the Python interpreter (UCD 15.1 in CPython 3.13, UCD 16.0 

64in 3.14). Upgrading the interpreter major version is a 

65historical-hash-recomputation event; pin Python via `uv` and treat 

66upgrades as a deliberate migration. 

67"""

79def _canonicalize(value: Any) -> Any: 

80 """Recursively normalize a value into a JSON-stable Python structure. 

81 

82 Handles, in order: 

83 - str: NFC normalization 

84 - Pydantic BaseModel: `model_dump(mode="json")` then recurse 

85 - dataclass instance: `asdict` then recurse 

86 - Mapping: NFC-normalize keys, recurse values 

87 - set / frozenset: recurse into each element, then sort by 

88 canonical-JSON serialization of the element (sorts 

89 deterministically across sets-of-dicts, not only sets of 

90 primitives) 

91 - list / tuple: recurse 

92 - other (int / bool / None): pass through 

93 

94 Unsupported types (Decimal, float NaN, bytes, datetime, UUID) flow 

95 through unchanged and trigger `TypeError`/`ValueError` from the 

96 eventual `json.dumps`. Per design lock anti-hook #8 this is the 

97 correct signal. 

98 """ 

99 if isinstance(value, str): 

100 return unicodedata.normalize("NFC", value) 

101 if hasattr(value, "model_dump") and callable(value.model_dump): 101 ↛ 102line 101 didn't jump to line 102 because the condition on line 101 was never true

102 return _canonicalize(value.model_dump(mode="json")) 

103 if is_dataclass(value) and not isinstance(value, type): 

104 return _canonicalize(asdict(value)) 

105 if isinstance(value, Mapping): 

106 return {unicodedata.normalize("NFC", str(k)): _canonicalize(v) for k, v in value.items()} 

107 if isinstance(value, set | frozenset): 

108 canonicalized = [_canonicalize(item) for item in value] 

109 return sorted( 

110 canonicalized, 

111 key=lambda x: json.dumps( 

112 x, 

113 sort_keys=True, 

114 ensure_ascii=False, 

115 separators=(",", ":"), 

116 ), 

117 ) 

118 if isinstance(value, list | tuple): 

119 return [_canonicalize(item) for item in value] 

120 return value

123def canonical_body_bytes(body: Any) -> bytes: 

124 """Produce canonical UTF-8 JSON bytes for a payload. 

125 

126 Pipeline: `_canonicalize` (NFC + set-to-sorted-list + dataclass / 

127 Pydantic dispatch, recursive) then `json.dumps` with `sort_keys=True`, 

128 compact separators, `ensure_ascii=False`, `allow_nan=False`. Output 

129 is the byte sequence wrapped by `pae_bytes` for hashing or signing. 

130 

131 Raises `TypeError` on unsupported types (Decimal, bytes, datetime, 

132 UUID); `ValueError` on NaN/Infinity. Pydantic at the API boundary 

133 must convert datetime/UUID/Decimal to strings before payloads 

134 reach this helper. Per design lock these are the correct signals, 

135 not silent coercion. 

136 

137 Pydantic `by_alias` is NOT applied: `model_dump(mode="json")` uses 

138 field names, not aliases. Callers that need by-alias hashing must 

139 dump the dict themselves before passing it in. The motivation is 

140 to keep the hash stable when an alias is added or removed without 

141 a schema-meaning change. 

142 

143 `bool` and `int` alias inside Python sets (`True == 1` collapses 

144 set membership). The hash mirrors what the input actually contains 

145 after Python deduplicates; this is not a defect, it is set 

146 semantics. Aggregates whose hash-bearing fields care about the 

147 distinction must use lists, not sets. 

148 """ 

149 canonical = _canonicalize(body) 

150 return json.dumps( 

151 canonical, 

152 sort_keys=True, 

153 separators=(",", ":"), 

154 ensure_ascii=False, 

155 allow_nan=False, 

156 ).encode("utf-8")

159def pae_bytes(payload_type: str, body: bytes) -> bytes: 

160 """DSSE Pre-Authentication Encoding. 

161 

162 Format per `github.com/secure-systems-lab/dsse/blob/master/protocol.md`: 

163 `"DSSEv1" SP LEN(type) SP type SP LEN(body) SP body`. 

164 

165 LEN is ASCII decimal, no leading zeros. LEN is BYTE length under 

166 UTF-8 encoding (matters for non-ASCII `payload_type`). Single 0x20 

167 separators. No trailing newline. 

168 

169 Reference test vector from `securesystemslib/tests/test_dsse.py`: 

170 pae_bytes("http://example.com/HelloWorld", b"hello world") 

171 == b"DSSEv1 29 http://example.com/HelloWorld 11 hello world" 

172 """ 

173 payload_type_bytes = payload_type.encode("utf-8") 

174 return b"DSSEv1 %d %b %d %b" % ( 

175 len(payload_type_bytes), 

176 payload_type_bytes, 

177 len(body), 

178 body, 

179 )

182def compute_content_hash(payload_type: str, body: Any) -> str: 

183 """Compute SHA-256 content hash for an event payload. 64-char lowercase hex. 

184 

185 Full pipeline: `body` -> `canonical_body_bytes` -> `pae_bytes` -> 

186 `sha256.hexdigest()`. Stable across processes, across Python 

187 interpreter restarts within one major version, across hosts. 

188 

189 `payload_type` follows the scheme 

190 `application/vnd.cora.<event-type>+json` per 

191 `project_content_addressed_identity_design`. The URI is bound into 

192 the hash via PAE so a `method-versioned` hash can never collide 

193 with a `plan-versioned` hash even when bodies happen to serialize 

194 identically. This helper does NOT validate the URI scheme; callers 

195 pick from the documented set. 

196 """ 

197 body_bytes = canonical_body_bytes(body) 

198 pae = pae_bytes(payload_type, body_bytes) 

199 return hashlib.sha256(pae).hexdigest()
