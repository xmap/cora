1"""ClearanceTemplate aggregate state, status enum, errors, and value objects. 

2 

3`ClearanceTemplate` defines reusable form templates for safety clearances. 

4Template-tier aggregate emits "Defined" genesis events (not "Registered"); 

5the genesis event type is `ClearanceTemplateDefined`. 

6 

7Status FSM: `Draft -> Active -> Deprecated -> Withdrawn`. 

8Four closed enum values locked day one per [[project_slice9_design]]. 

9 

10Facility-scoped uniqueness on `(facility_code, code)` via projection 

11PARTIAL UNIQUE INDEX `WHERE status != 'Withdrawn'`. 

12 

13Version field ships day-one in the dataclass (default 1) + supersedes_template_id 

14for version tracking; the version-bump event ships in 9B. 

15 

16## Status as enum-in-state, derived-from-event-type-in-evolver 

17 

18`ClearanceTemplateStatus` is a `StrEnum` (like FamilyStatus, SubjectStatus). 

19State holds the enum; evolver derives status from event type 

20(ClearanceTemplateDefined -> Draft). 

21 

22## Day-one field structure 

23 

24ClearanceTemplate carries version + supersedes_template_id fields day one 

25so the schema does not churn when 9B ships the version-bump event. 

26Both ship in the ClearanceTemplateDefined payload. 

27"""

43class ClearanceTemplateStatus(StrEnum): 

44 """The ClearanceTemplate's lifecycle state. 

45 

46 Four values locked day one per [[project_slice9_design]]: 

47 

48 - `Draft` -- newly defined, not yet activated 

49 - `Active` -- in use; can be referenced by new Clearances 

50 - `Deprecated` -- no longer recommended; existing Clearances unaffected 

51 - `Withdrawn` -- completely removed from the address space 

52 

53 Transitions: 

54 - Draft -> Active (activate_clearance_template; 9B) 

55 - Active -> Deprecated (deprecate_clearance_template; 9C) 

56 - (any non-terminal) -> Withdrawn (withdraw_clearance_template; 9C) 

57 

58 `Draft` is the genesis state set by `define_clearance_template`. The enum 

59 values are PascalCase strings (matching the BC-map status vocabulary) so 

60 log lines and DTOs read naturally without additional mapping. 

61 """ 

62 

63 DRAFT = "Draft" 

64 ACTIVE = "Active" 

65 DEPRECATED = "Deprecated" 

66 WITHDRAWN = "Withdrawn"

186class ClearanceTemplateNotBindableError(Exception): 

187 """A register_clearance or amend_clearance command referenced a non-Active template.

189 Only `Active` templates accept new Clearance bindings per 

190 [[project_slice9_design]] L11 (binding-gate semantics). Draft templates 

191 have not been activated yet; Deprecated and Withdrawn templates are 

192 tombstones for new-binding purposes (existing bindings continue to 

193 gate; the projection's UNIQUE INDEX on `(facility_code, code)

209@dataclass(frozen=True) 

210class ClearanceTemplate: 

211 """Aggregate root: a reusable clearance form template definition. 

212 

213 `id` is the stable opaque PK (UUID). 

214 `facility_code` is the facility this template belongs to. 

215 `code` is the machine-readable identifier (facility-scoped). 

216 `title` is the human-readable display name. 

217 `status` is the lifecycle state (Draft | Active | Deprecated | Withdrawn). 

218 `version` is the current version number (default 1). 

219 `supersedes_template_id` tracks version lineage (None until first version bump). 

220 `external_ref` is an optional external system reference. 

221 """ 

222 

223 id: UUID 

224 facility_code: FacilityCode 

225 code: ClearanceTemplateCode 

226 title: ClearanceTemplateTitle 

227 defined_at: datetime 

228 defined_by: ActorId 

229 status: ClearanceTemplateStatus = ClearanceTemplateStatus.DRAFT 

230 version: ClearanceTemplateVersion = field(default_factory=lambda: ClearanceTemplateVersion(1)) 

231 supersedes_template_id: UUID | None = None 

232 external_ref: str | None = None
