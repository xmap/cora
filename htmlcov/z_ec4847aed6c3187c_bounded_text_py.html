1"""Trimmed-bounded-text validation helper for value object `__post_init__`. 

2 

3Originally hoisted as `validate_name` after the 10th bounded-name VO 

4landed (`PlanName`). Renamed to `validate_bounded_text` once the 

5helper picked up non-name callers (Run / Subject / Dataset reason 

6VOs + Decision choice/context/rule VOs) — the 

7shared concept across all sites is "trimmed string with a bounded 

8length", not "name". 

9 

10Why hoist a function (not a class) 

11----------------------------------- 

12The duplicated body across the call sites was, originally, the 

13**trim + length-check + raise** logic, not the dataclass shape itself. 

14Hoisting only the validation function preserved what's worth keeping 

15per-VO: 

16 

17 - Distinct frozen dataclass type (`isinstance` checks stay 

18 aggregate-specific; pyright keeps `ActorName` and `MethodName` 

19 apart at type sites). 

20 - Distinct error class with aggregate-specific message text. 

21 - Per-VO `MAX_LENGTH` constant in the aggregate's state module 

22 (read by both the VO and the API-boundary Pydantic schema). 

23 

24A `BoundedText` base class would couple all aggregates to one type 

25and make per-VO documentation harder to navigate. A class factory 

26would weaken `isinstance` semantics. A free function avoids both. 

27 

28Why also hoist a decorator (not just the function) 

29-------------------------------------------------- 

30Once the function-helper count crossed the rule-of-three trigger for 

31homogeneous `value: str`-only *Name VOs, the duplicated body at the 

32call site stopped being just the validation call: it became the 

33three-line `__post_init__` ritual (call helper, `object.__setattr__` 

34the trimmed value, blank line). The decorator `bounded_name` removes 

35that ritual at every site while preserving everything the function 

36hoist already preserved (distinct type, distinct error class, 

37aggregate-local MAX_LENGTH constant, isinstance distinction). 

38 

39See `project_axes_foundation.md` for the underlying "thread the 

40needle: shared mechanism without shared identity" axis. The function 

41stays exported and continues to back the decorator internally; it 

42also remains the right tool for the non-decorator-eligible call sites 

43which fall into three buckets: 

44 

45 1. Composite multi-field VOs that validate per-field within one 

46 `__post_init__` (e.g. `AssetPort`, `Drawing`, `AssetOwner`, 

47 `AlternateIdentifier`). 

48 2. Bare-string validation embedded in deciders (e.g. reason text 

49 validation in `stop_run` / `truncate_run` / `abort_run` / 

50 `adjust_run` / `expire_clearance` / `reject_clearance` and the 

51 various `register_*` slices). 

52 3. VOs with non-standard rejection semantics (e.g. 

53 `CalibrationDescription` accepts empty-after-trim and rejects 

54 only on over-length, which `validate_bounded_text` does NOT 

55 express). 

56 

57Current per-VO `MAX_LENGTH` values across the codebase: {50, 100, 200, 

58255, 2000}. The 2000-char value (`CautionText`) is single-field but its 

59naming-of-symbol semantics differ from the *Name VOs; whether it 

60adopts the decorator is a per-VO call at refactor time. 

61 

62Operator free-text `reason` bounds (500) are NOT in that per-VO set: 

63a reason is a bare validated string, not a value object, and the same 

64bound applies across every aggregate, so it is shared as 

65`REASON_MAX_LENGTH` in `cora.shared.text_bounds` rather than declared 

66per aggregate. 

67 

68How VOs use the decorator 

69------------------------- 

70The decorator goes ABOVE `@dataclass(frozen=True)` at the call site. 

71Decorators apply bottom-up: `@dataclass` runs first and synthesizes 

72`__init__`, then `@bounded_name` wraps that synthesized `__init__` 

73to trim + length-check the incoming value before storing it. 

74 

75 @bounded_name(max_length=ACTOR_NAME_MAX_LENGTH, error_class=InvalidActorNameError) 

76 @dataclass(frozen=True) 

77 class ActorName: 

78 value: str 

79 

80The error class's constructor is called with the **original** 

81(untrimmed) value so its message can quote what the caller actually 

82sent. 

83 

84Why wrap `__init__` (and not install `__post_init__`) 

85----------------------------------------------------- 

86`dataclasses._process_class` decides at DECORATION time whether to 

87emit a `self.__post_init__()` call site in the synthesized `__init__`, 

88based on `hasattr(cls, '__post_init__')` at that moment. Installing 

89`__post_init__` later via `setattr` is a silent no-op for classes 

90that did not define one before `@dataclass` ran. Wrapping `__init__` 

91instead is always sound: the synthesized `__init__` is always present 

92after `@dataclass(frozen=True)` and is always called at construction. 

93A user-authored `__post_init__` (rare but supported) still chains 

94correctly because the synthesized `__init__` calls it AFTER the 

95wrapped original `__init__` has stored the trimmed value. 

96 

97Pyright invariants preserved (strict mode) 

98------------------------------------------ 

99With `Callable[[type[T]], type[T]]` as the decorator's return type: 

100 

101 - `PolicyName` is `type[PolicyName]` at every reference site. 

102 - `PolicyName('x')` is `PolicyName`. 

103 - `.value` is `str`. 

104 - isinstance narrowing inside `if isinstance(x, PolicyName):` works. 

105 - `__match_args__` lets `case PolicyName(value=v):` match. 

106 - Frozen `p.value = 'mut'` is flagged with 

107 `reportAttributeAccessIssue`. 

108 - `PolicyName()` flagged with `reportCallIssue` (missing argument). 

109 - `PolicyName('a', 'b')` flagged with `reportCallIssue` 

110 (extra argument). 

111 

112The trim transformation itself is not visible to pyright; that's a 

113runtime invariant the per-VO test files pin. 

114 

115Decoration-time guards 

116---------------------- 

117`bounded_name` raises `TypeError` at class-decoration time when: 

118 

119 - The class is not a dataclass (typically: `@dataclass` was placed 

120 BELOW `@bounded_name` by mistake, so the wrapped class isn't 

121 yet a dataclass when `bounded_name` sees it). 

122 - The class lacks a `value` field. 

123 

124Both errors fire at module import; neither can ship a silently-broken 

125VO into production. 

126""" 

127 

128from collections.abc import Callable 

129from dataclasses import is_dataclass 

130from typing import TypeVar 

131 

132T = TypeVar("T") 

133 

134 

135def validate_bounded_text( 

136 value: str, 

137 *, 

138 max_length: int, 

139 error_class: type[Exception], 

140) -> str: 

141 """Trim, length-check, return the trimmed value, or raise `error_class`. 

142 

143 Raises `error_class(value)` (the original untrimmed value) if the 

144 trimmed result is empty or exceeds `max_length`. Otherwise returns 

145 the trimmed string for the VO to install on itself. 

146 """ 

147 trimmed = value.strip() 

148 if not trimmed or len(trimmed) > max_length: 

149 raise error_class(value) 

150 return trimmed 

151 

152 

153def bounded_name( 

154 *, 

155 max_length: int, 

156 error_class: type[Exception], 

157) -> Callable[[type[T]], type[T]]: 

158 """Wrap a frozen-dataclass `value: str` VO with trim + length-check. 

159 

160 Apply ABOVE `@dataclass(frozen=True)`: 

161 

162 @bounded_name(max_length=POLICY_NAME_MAX_LENGTH, error_class=InvalidPolicyNameError) 

163 @dataclass(frozen=True) 

164 class PolicyName: 

165 value: str 

166 

167 The decorator wraps the dataclass-synthesized `__init__` so that 

168 every construction of `PolicyName(...)` trims the input, raises 

169 `error_class(value)` with the ORIGINAL untrimmed value on empty 

170 or over-length, and stores the trimmed value via the synthesized 

171 `__init__`'s normal `object.__setattr__('value', ...)` call site. 

172 The class object is returned in place (no subclass, no factory), 

173 so `isinstance`, `__match_args__`, `__eq__`, `__hash__`, and 

174 `__repr__` are all preserved. 

175 

176 Raises `TypeError` at decoration time if the decorated class is 

177 not a dataclass (`@dataclass` belongs ABOVE `@bounded_name` so 

178 that `@dataclass` runs first and `@bounded_name` sees a real 

179 dataclass) or if the class lacks a `value` field. 

180 """ 

181 

182 def decorate(cls: type[T]) -> type[T]: 

183 if not is_dataclass(cls): 

184 raise TypeError( 

185 f"@bounded_name must be applied above @dataclass on {cls.__name__}; " 

186 f"saw a non-dataclass class. Decorator order: " 

187 f"@bounded_name OUTER, @dataclass(frozen=True) INNER." 

188 ) 

189 if "value" not in cls.__dataclass_fields__: # pyright: ignore[reportAttributeAccessIssue] 

190 raise TypeError(f"@bounded_name requires a `value` field on {cls.__name__}") 

191 

192 original_init = cls.__init__ 

193 

194 def wrapped_init(self: T, value: str) -> None: 

195 trimmed = validate_bounded_text(value, max_length=max_length, error_class=error_class) 

196 original_init(self, trimmed) # pyright: ignore[reportCallIssue] 

197 

198 cls.__init__ = wrapped_init # pyright: ignore[reportAttributeAccessIssue] 

199 return cls 

200 

201 return decorate 

202 

203 

204__all__ = ["bounded_name", "validate_bounded_text"]
