1"""Mount aggregate state, status enum, slot-code VO, and domain errors. 

2 

3A `Mount` is the named slot in the beamline at which a single 

4specimen Asset sits at a time. The slot persists across installs 

5(SAP's "the slot outlives the device installed in it" lesson per 

6project_mount_frame_design.md); operators install / uninstall 

7Assets into the slot, and the Mount carries the slot's identity, 

8position (Placement against a Frame), and currently-installed 

9specimen. 

10 

11## Identity 

12 

13`id` is the opaque UUID (CORA's standard internal id), used for 

14event-store stream keying and cross-aggregate references. 

15`slot_code` is the external alias (e.g., APS 2-BM's `02-BM-A-K-01` 

16RSS tag); operators talk in slot codes, the system talks in UUIDs. 

17Slot-code uniqueness is a projection-precondition concern at register 

18time (not enforced at the DB level here), enabling a future 

19multi-facility deployment where slot codes are facility-scoped. 

20 

21## Composition (parent_mount_id) 

22 

23`parent_mount_id` is the immediate parent in the slot hierarchy 

24(an Assembly slot containing Device slots, ISA-88-derived). It is 

25NOT the coordinate-frame parent: coordinate framing lives entirely 

26on `Placement.parent_frame_id`, which references a Frame, not another 

27Mount. The two parent axes are deliberately separate (a Mount may 

28live in an Assembly that itself lives in a different Frame from the 

29Mount). 

30 

31## Placement 

32 

33`placement` is required for every Mount (no "root mount" carve-out 

34analogous to root Frames; every slot has a position). Refers to a 

35Frame via `placement.parent_frame_id`. Per the design memo, eventual- 

36consistency: the decider does NOT verify the Frame exists at write 

37time (matches Asset.parent_id eventual-consistency stance). 

38 

39## Drawing 

40 

41`drawing` is the optional engineering reference (ICMS document for 

42the slot itself: which assembly drawing shows where this slot lives 

43in the beamline). Distinct from the Asset's `drawing` (the 

44build-to drawing for the specimen) per the design memo's 

45anti-hook: do NOT collapse Mount.drawing and Asset.drawing. 

46 

47## Currently-installed Asset 

48 

49`installed_asset_id: AssetId | None` is the single source of truth 

50for "what's installed where" per the design memo. None means the 

51slot is vacant (post-uninstall, pre-install, or freshly registered). 

52The bidirectional back-lookup (asset_id -> mount_id) lives in the 

53`asset_location` projection; the Asset aggregate does NOT carry 

54`installed_at` per the anti-hook. 

55 

56## Lifecycle 

57 

58`MountStatus` is `Active | Decommissioned`, matching Supply's 

59lifecycle-terminal pattern. No operational sub-states (slots are 

60either in service or gone; runtime conditions like "misaligned" 

61live on the installed Asset's condition, not on the slot per the 

62Frame design rationale). 

63 

64Transitions: 

65 - register_mount -> Active (genesis) 

66 - decommission_mount -> Decommissioned (terminal; guarded by 

67 MountHasInstalledAsset if a specimen is 

68 still installed AND by MountHasActiveChildren 

69 if any child Mount is still Active) 

70 

71`update_mount_placement`, `install_asset`, `uninstall_asset` do NOT 

72change status; they mutate the Placement / `installed_asset_id` 

73fields respectively. `update_mount_placement` is no-op-on-equal via the 

74make_mount_update_handler factory; `install_asset` is strict-not- 

75idempotent (re-installing into an occupied slot raises 

76MountAlreadyOccupied per the design's no-implicit-eviction anti- 

77hook); `uninstall_asset` likewise raises MountIsEmpty when there is 

78nothing to uninstall. 

79 

80## Bounded VO 

81 

82`SlotCode` is a trimmed-bounded-text VO via validate_bounded_text; 

83200 chars to match other CORA name VOs. Slot codes tend to be much 

84shorter in practice (`02-BM-A-K-01`). 

85"""

256class AssetNotInstallableError(Exception): 

257 """Attempted to install an Asset whose lifecycle disallows installation.

259 Only `Active` Assets can be installed. `Commissioned` Assets are

310@dataclass(frozen=True) 

311class SlotCode: 

312 """External alias for a mount (e.g., APS 2-BM `02-BM-A-K-01`). 

313 

314 Trimmed; 1-200 chars. Uniqueness is enforced per-facility-scope 

315 at the handler layer (via the `mount_slot_code` projection 

316 precondition), NOT at the VO. Two facilities could legitimately 

317 share a slot code in different deployments. 

318 """ 

319 

320 value: str 

321 

322 def __post_init__(self) -> None: 

323 trimmed = validate_bounded_text( 

324 self.value, 

325 max_length=SLOT_CODE_MAX_LENGTH, 

326 error_class=InvalidSlotCodeError, 

327 ) 

328 object.__setattr__(self, "value", trimmed)

331@dataclass(frozen=True) 

332class Mount: 

333 """Aggregate root: a named slot in the beamline. 

334 

335 `id` is the opaque UUID stream key; `slot_code` is the external 

336 alias operators use. Slot-code uniqueness is enforced via 

337 projection precondition at register time, not by the VO. 

338 

339 `parent_mount_id` is the immediate parent in the slot hierarchy 

340 tree (Assembly slot containing Device slots). None for top-level 

341 slots. Distinct axis from `placement.parent_frame_id` (which names 

342 the coordinate frame, NOT a Mount). 

343 

344 `placement` is required (every slot has a position). `drawing` 

345 is optional (the engineering reference for the slot itself). 

346 

347 `installed_asset_id` is the AssetId of the specimen currently 

348 in the slot, or None for a vacant slot. Single source of truth 

349 for "what's installed where"; the asset_location projection 

350 provides the reverse lookup. 

351 

352 `status` transitions only `Active -> Decommissioned`. The 

353 install / uninstall / update_mount_placement slices do NOT change 

354 status. 

355 """ 

356 

357 id: UUID 

358 slot_code: SlotCode 

359 parent_mount_id: UUID | None 

360 placement: Placement 

361 drawing: Drawing | None 

362 installed_asset_id: UUID | None 

363 status: MountStatus = MountStatus.ACTIVE
