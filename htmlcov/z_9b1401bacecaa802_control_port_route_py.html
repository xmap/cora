1"""Settings-loadable shape for the Operation BC Conductor's per-prefix routing. 

2 

3The actual `ControlPort` adapter classes live in 

4`cora.operation.adapters.*` (substrate-specific code) and the 

5factory that materialises them lives in 

6`cora.operation.adapters.control_port_config`. This module ONLY 

7carries the typed config dataclass the `Settings` field uses, so 

8infrastructure can validate the env var at startup without 

9importing any BC-specific adapter. 

10 

11Mirrors the layering used for `IdentityProviderConfig` (the typed 

12config + validation lives in infrastructure; the auth-side 

13factories that consume it live in BC + composition-root code). 

14 

15## Env var shape 

16 

17The `Settings.control_port_routes` field reads from 

18`CONTROL_PORT_ROUTES` as a JSON list of objects. Example for a 2-BM 

19deployment where most PVs are CA but the area-detector image PVs 

20ride PVA: 

21 

22 CONTROL_PORT_ROUTES='[ 

23 {"prefix": "2bma:cam1:image", "substrate": "epics_pva"}, 

24 {"prefix": "2bma:", "substrate": "epics_ca"} 

25 ]' 

26 

27Empty / unset = the Operation BC's `wire_operation` uses 

28`InMemoryControlPort` (legacy + test convenience). 

29""" 

30 

31from typing import Literal 

32 

33from pydantic import BaseModel, Field 

34 

35Substrate = Literal["in_memory", "epics_ca", "epics_pva", "tango"] 

36"""The closed set of ControlPort substrates a deployment can select. 

37 

38`in_memory` is the test + opt-out default; `epics_ca` + `epics_pva` 

39are the production EPICS adapters; `tango` is the PyTango adapter for 

40Tango-floor deployments (ESRF BLISS, MAX IV). New substrates land here 

41as additive literal values plus a matching arm in the BC-side 

42`build_control_port` factory's `_build_substrate` switch. 

43""" 

44 

45 

46class ControlPortRoute(BaseModel): 

47 """One adapter binding in the per-prefix `ControlPortRegistry` routing table. 

48 

49 `prefix` is the address-string prefix the registry uses for 

50 longest-prefix-match dispatch. `substrate` selects which adapter 

51 class the factory will construct for this route. `is_simulated` 

52 declares that addresses on this route drive a simulator rather 

53 than real hardware, even when the transport substrate is a real 

54 one (a soft IOC speaks real Channel Access). It is a declared 

55 deployment fact, never inferred from `substrate`, and feeds the 

56 Dataset provenance gate that blocks promoting simulator-origin 

57 data to Production. 

58 

59 `read_only` declares that CORA may observe this route but must 

60 never drive it: `build_control_port` wraps the route's adapter in 

61 a `ReadOnlyControlPort`, so a write refuses before any substrate 

62 is contacted. Like `is_simulated` it is a declared deployment 

63 fact, never inferred from `substrate`. 

64 

65 `read_only` is per-route EXPRESSIVENESS, for a writable deployment 

66 that must pin specific prefixes ("CORA may drive the sample stage 

67 but must never touch the shutter"). It is NOT the safety mechanism 

68 for an observe-only deployment: it defaults to False, so a route 

69 that omits it is writable. The deployment-wide safety switch is 

70 `Settings.control_writes_enabled`, which cannot be partially 

71 applied. Reach for the switch to make a deployment observe-only; 

72 reach for this field only to carve a hole in a writable one. 

73 

74 `text_addresses` declares which addresses on this route carry text 

75 in an EPICS DBR_CHAR waveform. EPICS gives a char waveform holding 

76 a NUL-terminated string (tomoscan's `ScanStatus`, `FileName`, ...) 

77 and one holding raw bytes (an NTNDArray image) the same wire type, 

78 so the adapter cannot tell them apart and must be told. Meaningful 

79 only for `epics_ca` (`EpicsCaControlPort` is the sole reader of it; 

80 PVA's NTScalar and Tango's DevString already carry this distinction 

81 on the wire); a route on another substrate that sets it is inert 

82 rather than rejected, since the address list still describes a 

83 true fact about the deployment, just one this substrate's adapter 

84 has no ambiguity to resolve. 

85 """ 

86 

87 prefix: str = Field(..., min_length=1) 

88 substrate: Substrate 

89 is_simulated: bool = Field( 

90 default=False, 

91 description=( 

92 "True when this route drives a simulator (e.g. a soft IOC) rather " 

93 "than real hardware. Declared per deployment, not inferred from substrate." 

94 ), 

95 ) 

96 read_only: bool = Field( 

97 default=False, 

98 description=( 

99 "True when CORA may read and subscribe on this route but must never " 

100 "write to it. Refuses before contacting the substrate. Per-route " 

101 "expressiveness within a writable deployment; to make a whole " 

102 "deployment observe-only, set CONTROL_WRITES_ENABLED=false instead." 

103 ), 

104 ) 

105 text_addresses: tuple[str, ...] = Field( 

106 default=(), 

107 description=( 

108 "Addresses on this route whose EPICS DBR_CHAR waveform carries a " 

109 "NUL-terminated string rather than raw bytes. Declared per deployment, " 

110 "never inferred: EPICS gives a string-bearing char waveform and a " 

111 "byte-bearing one (e.g. NTNDArray image data) the same wire type. " 

112 "Applies to epics_ca routes only; a no-op on other substrates." 

113 ), 

114 ) 

115 

116 model_config = {"extra": "forbid"} 

117 

118 

119__all__ = ["ControlPortRoute", "Substrate"]
