1"""Cross-aggregate context the `register_distribution` decider validates against. 

2 

3`DistributionRegistrationContext` is built by the 

4`register_distribution` handler from `load_dataset` (same-BC) and 

5`SupplyLookup.lookup` (cross-BC) calls before reaching the pure 

6decider. Per [[project-data-distribution-design]] L15 + L17 the 

7handler pre-loads both refs; the decider treats them as injected 

8proof-of-existence + carries the loaded peers in so the Discarded 

9+ kind guards are O(1) closures over already-fetched data. 

10 

11Slice-local module by design: only `register_distribution` uses it 

12today. Mirrors the `DatasetRegistrationContext` precedent. 

13 

14## Field semantics 

15 

16 - `dataset`: the parent Dataset (always required). The handler 

17 raises `DatasetNotFoundError` upstream if `command.dataset_id` 

18 does not resolve, so the decider can assume this field is 

19 non-None. Used by the decider for the Discarded guard (L17 

20 step 6) and the byte-identical-copy checksum + byte_size 

21 equality guards (L17 steps 9, 10). 

22 - `supply`: the resolved Supply reference from the SupplyLookup 

23 port (always required). The handler raises 

24 `DistributionSupplyNotFoundError` upstream if the lookup 

25 returns None, so the decider can assume this field is 

26 non-None. Used by the decider for the storage-kind guard 

27 (L17 step 8). 

28""" 

29 

30from dataclasses import dataclass 

31 

32from cora.data.aggregates.dataset import Dataset 

33from cora.infrastructure.ports.supply_lookup import SupplyLookupResult 

34 

35 

36@dataclass(frozen=True) 

37class DistributionRegistrationContext:

39 

40 Both fields are required; the handler populates each before 

41 constructing the context. The decider treats both as proof of 

42 existence + as carriers of the data it needs for the byte- 

43 identical-copy and storage-kind guards. 

44 """ 

45 

46 dataset: Dataset
