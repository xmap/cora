1"""Measurement: the substrate-neutral value-plus-metadata produced by a conducted act. 

2 

3A `Measurement` is the typed value a conducted act yields, whatever edge 

4runtime produced it: a control read (ControlPort), a compute job output 

5(ComputePort), or a transfer observation (TransferPort). The value-types 

6here are domain-owned and shared across all three ports; concrete 

7adapters serve as ACLs translating substrate-native shapes (EPICS V4 NT 

8structures, Tango `DeviceAttribute`, OPC UA `DataValue`, a compute job's 

9result record, a transfer manifest) into this CORA-owned vocabulary. 

10 

11## Domain vocabulary (substrate-neutral) 

12 

13- **`Measurement`** is the typed value-plus-metadata a consumer sees. 

14 Fields are domain-owned: `value`, `kind: MeasurementKind`, 

15 `quality: Quality`, `produced_at: datetime`, `quality_detail: str`, 

16 plus the substrate-neutral `name` and `units` annotations. 

17- **`MeasurementKind`** is a closed 5-value enum (`Scalar | Array | 

18 Image | Categorical | Tabular`). Maps to EPICS V4 NT kinds + Tango 

19 `AttrDataFormat` + OPC UA Variant types via adapter-side ACL, and 

20 describes compute / transfer outputs by the same shape vocabulary. 

21- **`Quality`** is the closed 3-value enum (`Good | Uncertain | Bad`) 

22 matching OPC UA's spec-defined high-level severity grouping and the 

23 NAMUR / ISA-95 vocabulary. Adapters translate substrate-native 

24 quality enums INTO this domain enum; substrate sub-codes (EPICS 

25 `alarm_status`, Tango string detail, OPC UA's ~240 named sub-codes) 

26 land in `Measurement.quality_detail` as opaque forensic breadcrumbs. 

27""" 

28 

29from dataclasses import dataclass 

30from datetime import datetime 

31from typing import Any, Literal 

32 

33MeasurementKind = Literal["Scalar", "Array", "Image", "Categorical", "Tabular"] 

34"""Closed 5-value discriminator for `Measurement.value` shape. 

35 

36- `Scalar`: a single typed value (int / float / bool / str). 

37- `Array`: a 1-D sequence of scalars (tuple at the port boundary). 

38- `Image`: a 2-D pixel grid (NTNDArray / Tango IMAGE / OPC UA image 

39 variants); shape and dtype carried inside `value`. 

40- `Categorical`: a string label from a closed substrate-defined set 

41 (EPICS NTEnum / Tango DevEnum or DevState / OPC UA enum). 

42- `Tabular`: column-oriented record (NTTable / OPC UA table / Tango 

43 multi-attribute bundle). 

44 

45Adapter ACLs translate substrate-specific type taxonomies INTO this 

46enum. Extensible by tag addition when a future substrate justifies a 

47new shape (e.g., OPC UA `LocalizedText` may justify a new tag). 

48""" 

49 

50 

51Quality = Literal["Good", "Uncertain", "Bad"] 

52"""Closed 3-value quality enum matching OPC UA's spec-defined severity 

53grouping and the NAMUR / ISA-95 vocabulary. 

54 

55Per the OPC UA sanity check in 

56[[project_control_port_generalization_research]], `StatusCode`'s top 

572 bits are exactly this trichotomy: 

58`Good = 0b00 | Uncertain = 0b01 | Bad = 0b10`. EPICS CA's 4-value 

59severity collapses (`NONE -> Good`, `MINOR | MAJOR | INVALID -> Bad`). 

60Tango's 5-value `AttrQuality` collapses (`VALID -> Good`, 

61`WARNING | CHANGING -> Uncertain`, `ALARM | INVALID -> Bad`). 

62 

63Substrate-specific forensic detail (EPICS `alarm_status`, Tango 

64string detail, OPC UA's ~240 named sub-codes such as 

65`BadCommunicationError` / `UncertainDataSubNormal`) lands in 

66`Measurement.quality_detail` as an opaque string; the closed enum stays 

67tight. 

68""" 

69 

70 

71@dataclass(frozen=True) 

72class Measurement: 

73 """Domain-shaped value-plus-metadata a conducted act produces or observes. 

74 

75 Substrate-neutral: a `Measurement` is what a consumer sees from any 

76 edge runtime, whether the value was read off a control address, 

77 produced by a compute job, or observed during a transfer. Domain 

78 owns every field. Adapter ACLs translate substrate-native value 

79 types (EPICS V4 NT structures, Tango `DeviceAttribute`, OPC UA 

80 `DataValue`, a compute result record, a transfer manifest) into this 

81 shape; substrate vocabulary (NTNDArray fields, DevState labels, 

82 OPC UA Variant types) stays caged in the adapter. 

83 

84 `value` is `Any` because the runtime shape varies with `kind`: 

85 `Scalar` is `int | float | bool | str`, `Array` is a tuple, 

86 `Image` is a 2-D structure (typically `numpy.ndarray` at the 

87 adapter, normalised to a tuple-of-tuples or wrapped array at the 

88 port boundary), `Categorical` is a string label, `Tabular` is a 

89 dict of column names to tuples. Callers narrow per kind at the 

90 use site. 

91 

92 Substrate-specific presentation hints (NT `valueAlarm`, 

93 `displayLimit`, `controlLimit` structures; Tango display formats; 

94 OPC UA `DisplayName`) are intentionally NOT surfaced here. They 

95 are operator-UI metadata, not data-plane data; adapters drop 

96 them at unpacking time. 

97 

98 `produced_at` is the time the substrate produced or observed the 

99 value (EPICS source timestamp, Tango `time`, OPC UA 

100 `SourceTimestamp`, a compute job's completion time, a transfer's 

101 observation time). `quality_detail` is adapter-specific and opaque 

102 at the port layer; treat it as a forensic breadcrumb, not a value 

103 to branch on. 

104 

105 `name` is an optional substrate-neutral key naming the output or 

106 quantity the value carries (the channel / output / quantity label); 

107 it is empty when the consumer identifies the value by position or 

108 address instead. `units` is the optional unit string for the value, 

109 `None` when the value is dimensionless or units are unknown. 

110 """ 

111 

112 value: Any 

113 kind: MeasurementKind 

114 quality: Quality 

115 produced_at: datetime 

116 quality_detail: str = "" 

117 name: str = "" 

118 units: str | None = None
