1"""Deriving the claim id a concern holds a Procedure under. 

2 

3The claim SET itself is folded onto `Procedure.hold_claims` by the evolver, so 

4a decider that already has folded state needs no second read. This module holds 

5only the derivation, which both a holder and a releaser must agree on without 

6either storing the id. 

7 

8Deliberately smaller than Run's sibling module, which also folds claims straight 

9from the event store. Run needs that because concerns OUTSIDE its BC hold Runs 

10and cannot fold the aggregate. Every Procedure holder today is the Conductor or 

11an operator surface, all of which go through a decider that receives folded 

12state. Add the event-store fold when an out-of-BC holder actually appears. 

13""" 

14 

15from __future__ import annotations 

16 

17from uuid import UUID, uuid5 

18 

19# Stable namespace for deriving a concern's claim id on a Procedure. Distinct 

20# from Run's namespace so the two aggregates cannot collide, following the 

21# fixed-uuid5-namespace-per-derivation-family convention. 

22_CLAIM_NAMESPACE = UUID("01900000-0000-7000-8000-00000000c1a2") 

23 

24 

25def derive_claim_id(procedure_id: UUID, cause: str) -> UUID: 

26 """The claim id a concern holds a given Procedure under: one per cause. 

27 

28 Deterministic so a holder and a releaser agree without either storing it, 

29 and so a re-delivered hold re-derives the same claim and folds idempotently 

30 rather than stacking a second one. 

31 

32 ONE claim per (Procedure, cause) is a deliberate coarsening, and it is what 

33 the code already did: because every holder guarded `status is RUNNING`, a 

34 second request from the SAME concern on an already-held Procedure was 

35 refused outright. Keeping that collapse means this change fixes the 

36 cross-cause fault without silently altering same-cause behaviour. Scoping a 

37 claim more finely (per failing step, say) is a further refinement and would 

38 need the release path to know which of them are still outstanding. 

39 """ 

40 return uuid5(_CLAIM_NAMESPACE, f"{procedure_id}|{cause}") 

41 

42 

43__all__ = ["derive_claim_id"]
