1"""`DigestingDurableCopyRegistrar`: the composition root's own `DurableCopyRegistrar`. 

2 

3`_durable_distribution_driver.DurableCopyRegistrar` names two obligations 

4and leaves both unmet: idempotent on `(dataset_id, supply_id, locator)` 

5established from the WRITE model, checked BEFORE digesting. This module 

6closes that hole. 

7 

8## Composes the pure decider directly; does not call the shipped handler 

9 

10`register_distribution`'s own handler (`cora.data.features.register_distribution 

11.handler.bind`) allocates its own fresh UUIDv7 id 

12(`deps.id_generator.new_id()`) and relies on that freshness to justify 

13`decide(state=None, ...)`: a UUIDv7 nobody has used yet is guaranteed to 

14have an empty stream (`handler.py`'s own docstring). This registrar 

15needs the OPPOSITE: a caller-CHOSEN id (walked deterministically from 

16`dataset_id` / `supply_id` / `locator`) so a re-delivered call lands on 

17the same stream twice rather than minting a second Distribution for the 

18same durable copy. 

19 

20Widening the handler's `IdempotentHandler` to accept a caller-supplied id 

21does not typecheck: `with_idempotency`'s `wrapped` closure has a closed 

22keyword list (`command`, `principal_id`, `correlation_id`, `causation_id`, 

23`surface_id`, `idempotency_key`), so `wire.py`'s composition would break. 

24Narrowing to the bare `Handler` typechecks but repeals the handler's own 

25documented invariant that the fresh id IS what makes `decide(state=None)` 

26sound. So this module composes `decide()` + `event_store.append()` 

27directly, the same Pattern C every cross-BC write in this codebase 

28already uses (`data._ingest.decide_ingest`, `agent.subscribers 

29.caution_promoter._write_caution`). 

30 

31## The generation chain 

32 

33A single `uuid5(dataset_id, supply_id, locator)` id would be permanently 

34burned the first time this exact triple's Distribution is discarded: 

35`_durable_distribution_sweep`'s candidate query deliberately re-admits a 

36Dataset whose Distribution was discarded (mirroring the projection's own 

37partial unique index, which excludes `Discarded` rows so a re-register is 

38legal), and re-deriving the SAME id would collide with a non-empty 

39(discarded) stream forever. 

40 

41The fix is a chain: `uuid5(_DISTRIBUTION_ID_NAMESPACE, f"{dataset_id}:{supply_id}:{locator}#{n}")` 

42for `n = 0, 1, 2, 3`. Walked via `load_distribution` (the WRITE model, 

43never the lagging projection) BEFORE any digest: 

44 

45 - empty stream at generation `n` -> that is the target id; register there. 

46 - non-empty, not Discarded -> `DurableCopyAlreadyRegistered`. This is 

47 the expected answer while the projection is catching up, and 

48 answering it from a directory listing plus a handful of event-store 

49 reads is the entire reason a stalled projector costs nothing more 

50 than that instead of re-reading tens of gigabytes over SSH. 

51 - Discarded -> advance to `n + 1`; someone discarded THIS generation's 

52 copy on purpose, so the next generation is where a fresh register 

53 belongs. 

54 

55Bounded at 4 generations. Exhausting all four without landing on an 

56empty or non-Discarded stream means this exact triple has been 

57registered-then-discarded three times over, which has no operational 

58precedent; refusing (`DurableCopyRegisterRefused`) rather than walking 

59forever is the conservative choice. 

60 

61## What "idempotent" actually promises here 

62 

63Scoped honestly: `uuid5` gives idempotence against *this agent's own* 

64prior writes, because only this registrar derives ids this way. A human 

65calling `POST /distributions` at the very same `(dataset_id, supply_id, 

66uri)` triple allocates a fresh UUIDv7 through the ordinary handler, and 

67the write model has no uniqueness constraint on the triple at all -- only 

68`proj_data_distribution_summary`'s partial unique index does, at the 

69projection tier. That is exactly enough to solve the lagging-projection 

70problem this Protocol exists for (a sweep tick re-examining a Dataset it 

71already handled); it is not a claim that two DIFFERENT principals can 

72never race to register the same durable copy under two different ids. 

73Saying more here would let a reader infer a guarantee the write model 

74does not hold. 

75 

76## The independence trap: three fields, not one 

77 

78The decider (`register_distribution.decider.decide`) compares 

79`algorithm`, `value` and `byte_size` against the Dataset's OWN recorded 

80values. All three MUST be sourced from the digest this registrar just 

81computed, never from the `Dataset` it also loads for `encoding` -- 

82sourcing even one of them from `dataset` instead of `computed` makes 

83that comparison agree by construction, and the whole point of digesting 

84the durable copy is to prove independently that its bytes match. This 

85class never reads `dataset.checksum` or `dataset.byte_size` for exactly 

86that reason; `media_type` and `conforms_to` are the only two fields 

87carried from `dataset.encoding`, and that asymmetry is deliberate: the 

88decider does not check those two against anything, so there is no 

89independence property to protect there. 

90 

91## Refusal text 

92 

93`Unreachable` from the checksum computer collapses to ONE fixed literal, 

94never `error_detail` verbatim: some implementors' `error_detail` values 

95can embed a path (the discipline is enforced at each origin, not 

96provable from this module reading an abstract `ChecksumComputer`), and 

97a refusal string here is logged the same as every other refusal in this 

98sweep. Decider exceptions render `str(exc)` instead: none of them can 

99carry a filesystem path (they report dataset ids, checksums and byte 

100counts), and the extra detail is a genuine diagnostic an operator can 

101act on without it. 

102"""

189class DigestingDurableCopyRegistrar: 

190 """Production `DurableCopyRegistrar`: digests the durable copy and 

191 registers it by composing `register_distribution`'s own decider. 

192 

193 See the module docstring for why the handler is not called, how the 

194 generation chain solves the discard-and-reuse case, and the 

195 independence discipline the digest path must hold. 

196 """ 

197 

198 def __init__( 

199 self, 

200 *, 

201 event_store: EventStore, 

202 authz: Authorize, 

203 supply_lookup: SupplyLookup, 

204 checksum_computer: ChecksumComputer, 

205 clock: Clock, 

206 id_generator: IdGenerator, 

207 ) -> None: 

208 self._event_store = event_store 

209 self._authz = authz 

210 self._supply_lookup = supply_lookup 

211 self._checksum_computer = checksum_computer 

212 self._clock = clock 

213 self._id_generator = id_generator 

214 

215 async def register( 

216 self, 

217 *, 

218 dataset_id: UUID, 

219 supply_id: UUID, 

220 locator: str, 

221 durable_path: str, 

222 access_protocol: str, 

223 observed_modified_at: datetime, 

224 ) -> DurableCopyRegistration: 

225 resolution = await self._resolve_target_id( 

226 dataset_id=dataset_id, supply_id=supply_id, locator=locator 

227 ) 

228 if not isinstance(resolution, UUID): 

229 return resolution 

230 target_id = resolution 

231 

232 decision = await self._authz.authorize( 

233 principal_id=DURABLE_COPY_REGISTRAR_AGENT_ID, 

234 command_name=_COMMAND_NAME, 

235 conduit_id=NIL_SENTINEL_ID, 

236 surface_id=NIL_SENTINEL_ID, 

237 ) 

238 if isinstance(decision, Deny): 

239 return DurableCopyRegisterUnauthorized() 

240 

241 dataset = await load_dataset(self._event_store, dataset_id) 

242 if dataset is None: 

243 return DurableCopyRegisterRefused(detail="dataset not found") 

244 

245 supply = await self._supply_lookup.lookup(supply_id) 

246 if supply is None: 

247 return DurableCopyRegisterRefused(detail="supply not found") 

248 

249 # `file://` built from the raw durable_path: this is the URI the 

250 # digest actually reads, never the `locator` that gets stored 

251 # (the indirect cora-capture-path:// scheme the driver minted). 

252 computed = await self._checksum_computer.compute( 

253 locator_uri=f"file://{durable_path}", supply_id=supply_id 

254 ) 

255 if isinstance(computed, Unreachable): 

256 return DurableCopyRegisterRefused(detail="durable copy could not be digested") 

257 

258 # Whole-second comparison, not a direct float-vs-nanosecond 

259 # equality: `observed_modified_at` and `computed.mtime_ns` come 

260 # from two INDEPENDENT stat() calls (locate, then the digest 

261 # walk), each converted through its own floating-point 

262 # representation on the way here. Comparing at nanosecond 

263 # precision would flag an unchanged file as "moved" on nothing 

264 # more than float round-trip noise; a copy actually moving under 

265 # the read changes by real seconds, not fractions of one. 

266 if int(observed_modified_at.timestamp()) != computed.mtime_ns // 1_000_000_000: 

267 return DurableCopyRegisterRefused(detail="durable copy changed while being digested") 

268 

269 now = self._clock.now() 

270 command = RegisterDistribution( 

271 dataset_id=dataset_id, 

272 supply_id=supply_id, 

273 uri=locator, 

274 checksum_algorithm=computed.algorithm, 

275 checksum_value=computed.value, 

276 byte_size=computed.byte_size, 

277 media_type=dataset.encoding.media_type, 

278 access_protocol=access_protocol, 

279 conforms_to=dataset.encoding.conforms_to, 

280 ) 

281 context = DistributionRegistrationContext(dataset=dataset, supply=supply) 

282 try: 

283 domain_events = decide( 

284 state=None, 

285 command=command, 

286 context=context, 

287 now=now, 

288 new_id=target_id, 

289 registered_by=ActorId(DURABLE_COPY_REGISTRAR_AGENT_ID), 

290 ) 

291 except _DECIDER_ERRORS as exc: 

292 return DurableCopyRegisterRefused(detail=str(exc)) 

293 

294 new_events = [ 

295 to_new_event( 

296 event_type=event_type_name(event), 

297 payload=to_payload(event), 

298 occurred_at=event.occurred_at, 

299 event_id=uuid5(target_id, "event:0"), 

300 command_name=_COMMAND_NAME, 

301 correlation_id=self._id_generator.new_id(), 

302 causation_id=None, 

303 principal_id=DURABLE_COPY_REGISTRAR_AGENT_ID, 

304 ) 

305 for event in domain_events 

306 ] 

307 try: 

308 await self._event_store.append( 

309 stream_type=_STREAM_TYPE, 

310 stream_id=target_id, 

311 expected_version=0, 

312 events=new_events, 

313 ) 

314 except ConcurrencyError: 

315 return DurableCopyAlreadyRegistered(distribution_id=target_id) 

316 

317 return DurableCopyRegistered(distribution_id=target_id) 

318 

319 async def _resolve_target_id( 

320 self, *, dataset_id: UUID, supply_id: UUID, locator: str 

321 ) -> UUID | DurableCopyRegistration: 

322 """Walk the generation chain from the WRITE model; see the module docstring.""" 

323 for generation in range(_MAX_GENERATIONS): 

324 candidate_id = _derive_candidate_distribution_id( 

325 dataset_id=dataset_id, supply_id=supply_id, locator=locator, generation=generation 

326 ) 

327 state = await load_distribution(self._event_store, candidate_id) 

328 if state is None: 

329 return candidate_id 

330 if state.status is not DistributionStatus.DISCARDED: 

331 return DurableCopyAlreadyRegistered(distribution_id=candidate_id) 

332 return DurableCopyRegisterRefused( 

333 detail="every generation at this dataset/supply/locator triple is discarded" 

334 )
