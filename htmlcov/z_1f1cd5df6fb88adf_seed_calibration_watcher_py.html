1"""Bootstrap-time seed for the CalibrationWatcher Agent. 

2 

3The CalibrationWatcher runtime (CORA's 7th seeded agent, a composition-root 

4periodic loop, deterministic flag-only) needs an Agent record (and its 

5co-registered Actor) at the pinned `CALIBRATION_WATCHER_AGENT_ID` so it can 

6author CalibrationVerification Decisions 

7(`decided_by = ActorId(CALIBRATION_WATCHER_AGENT_ID)`) as an agent-kind 

8principal. Mirrors `cora.agent.seed_clearance_watcher` except for the per-agent 

9constants; the shared scaffolding lives in `cora.agent._agent_seed`. 

10 

11Per [[project-calibration-watcher-design]]: 

12 - Pinned UUID in the `ca11` block (seventh seeded identity, sibling to 

13 RunDebriefer `aaaa00XX`, CautionDrafter `bbbb00XX`, RunSupervisor 

14 `cccc00XX`, CautionPromoter `dddd00XX`, ClearanceExpirer `eeee00XX`, 

15 ClearanceWatcher `ffff00XX`); deployment-stable forever. 

16 - DETERMINISTIC agent (rule-based, NOT LLM): no prompt template and a sentinel 

17 `ModelRef` (`provider="deterministic"`), never used to build an LLM (the 

18 runtime is a periodic staleness comparison). 

19 - FLAG-ONLY: the runtime issues NO write command. It records one 

20 Decision(context=CalibrationVerification, choice=Stale) per stale-calibration 

21 episode for a human to act on. Permission to record Decisions is granted at 

22 agent-definition time (the RunDebriefer stance); there is no write-command leg 

23 and so no per-command Policy grant to seed, though it does issue an 

24 authz-gated ListCalibrations read each tick (under a real Authorize policy the 

25 agent principal needs that read grant or the drain is denied). 

26"""

40# --------------------------------------------------------------------------- 

41# CalibrationWatcher agent identity (deployment-stable constants) 

42# ---------------------------------------------------------------------------

44# Treat as FOREVER-STABLE. Same change-cost rationale as the other seeded 

45# agents: changing this orphans every prior CalibrationWatcher-authored Decision 

46# (their actor_id pointers go stale). UUID is in the deployment-controlled 

47# `ca11` block (seventh seeded identity). 

48CALIBRATION_WATCHER_AGENT_ID = UUID("01900000-0000-7000-8000-0000ca110010") 

49CALIBRATION_WATCHER_AGENT_NAME = "CalibrationWatcher" 

50CALIBRATION_WATCHER_AGENT_KIND = "CalibrationWatcher" 

51CALIBRATION_WATCHER_AGENT_VERSION = "1.0.0" 

52CALIBRATION_WATCHER_AGENT_DESCRIPTION = ( 

53 "Deterministic in-loop agent: watches the calibration-verification lifecycle " 

54 "and records one Decision(context=CalibrationVerification, choice=Stale) per " 

55 "Provisional calibration whose newest revision has sat unverified past the " 

56 "staleness window. Flag-only (advise a human); issues no command." 

57)

60# Sentinel model ref: CalibrationWatcher is rule-based, not an LLM agent. The 

61# Agent aggregate requires a ModelRef; this value is never used to build an LLM 

62# (the runtime is a periodic staleness comparison, no build_llm call). 

63_DETERMINISTIC_MODEL_REF = ModelRef( 

64 provider="deterministic", 

65 model="agent:CalibrationWatcher:v1", 

66 snapshot_pin=None, 

67)

72# ---------------------------------------------------------------------------

74_AGENT_EVENT_ID = UUID("01900000-0000-7000-8000-0000ca110012") 

75_ACTOR_EVENT_ID = UUID("01900000-0000-7000-8000-0000ca110013")
