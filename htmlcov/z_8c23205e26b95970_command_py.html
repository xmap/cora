1"""The `RegisterAsset` command, intent dataclass for this slice. 

2 

3Carries the caller-controlled fields: the asset's display name, 

4its operational tier, its parent_id (None only for facility-rooted 

5Assets, enforced by the decider), an optional Drawing reference, and 

6an optional `model_id` Model-binding ref. Server-side concerns (new 

7aggregate id, wall-clock timestamp, correlation id, per-event ids) 

8are injected by the handler from infrastructure ports, matching the 

9cross-BC create-style command shape locked in Access / Trust / 

10Subject / Equipment. 

11 

12`tier` is typed as `AssetTier` (the StrEnum) so callers cannot 

13pass an invalid value; the route's Pydantic body and the MCP 

14tool's argument schema both enforce this at the API boundary. 

15 

16`parent_id` is `UUID | None`. Per the `{parent_id, facility_code}` 

17XOR rule, a root Asset has `parent_id=None` and binds 

18`facility_code`; a non-root carries `parent_id` and no 

19`facility_code`. Eventual-consistency stance for the parent ref: 

20the decider does NOT verify the referenced parent Asset exists in 

21the event store (same precedent as Trust's Conduit zone refs). 

22 

23`model_id` is `UUID | None`, optional reference to the Model 

24catalog entry this Asset is an instance of. Set ONCE at 

25registration per the model-binding design memo (Lock A); rebind 

26path is decommission + re-register. The handler verifies the 

27referenced Model stream exists before invoking the decider 

28(`ModelNotFoundError` -> 404); the decider does NOT need a Model 

29snapshot because the genesis Asset's families set is empty so the 

30subset invariant is vacuously satisfied at registration (Lock B). 

31 

32`alternate_identifiers` is a `frozenset[AlternateIdentifier]`, 

33defaulted to empty. Seeds the Asset's initial set of PIDINST v1.0 

34Property 13 alternate identifiers (operator-supplied serial 

35numbers, inventory tags, vendor-specific schemes) in a single 

36registration transaction; the targeted-mutation slices 

37`add_asset_alternate_identifier` / 

38`remove_asset_alternate_identifier` mutate the set post-genesis. 

39Identifiers are operator-supplied opaque strings: the decider 

40does NOT cross-validate `(kind, value)` uniqueness across Assets 

41in v1 (per [[project-asset-alternate-identifiers-design]] Lock F); 

42no cross-BC IO either (per Lock I), so the handler does not load 

43any external stream on this field's behalf. 

44 

45`controller_id` is `UUID | None`, optional reference to the 

46controller Asset (a sibling Device carrying the MotionController 

47Family) that drives this Asset. Set ONCE at registration per 

48[[project-controller-as-asset-stage1-design]] (Lock A precedent 

49from model_id); rebind path is decommission + re-register. 

50Eventual-consistency: the decider does NOT verify the referenced 

51controller Asset exists (mirrors `parent_id`, `model_id`, 

52`fixture_id`). The handler does not load any external stream on 

53this field's behalf. 

54 

55`located_in_enclosure_id` is `UUID | None`, an optional bare 

56cross-BC opaque pointer to the Enclosure (the operational 

57access-gated volume) this Asset physically sits in. It is the 

58device's OPERATIONAL where (distinct from `facility_code`, its 

59INSTITUTIONAL where). Set ONCE at registration (Lock A precedent 

60from `controller_id`); rebind path is decommission + re-register. 

61Eventual-consistency: the decider does NOT verify the referenced 

62Enclosure exists (mirrors `controller_id`); the handler loads no 

63external stream on this field's behalf. Kept a bare `UUID` so the 

64Equipment BC takes on no module dependency on the Enclosure BC. 

65 

66`facility_code` is `str | None`, optional cross-BC reference to 

67the Federation Facility that owns this Asset, keyed on the 

68cross-deployment convergent slug (`FacilityCode`) per 

69[[project-slice8-design]] L1. Set ONCE at registration per the 

70Asset.model_id Lock A precedent; rebind path is decommission + 

71re-register. The handler resolves the slug via 

72`FacilityLookup.lookup_by_code` before invoking the decider; the 

73decider rejects unknown slugs with `AssetFacilityNotFoundError` 

74(HTTP 404) and skips validation entirely when the field is None. 

75Bare `str` on the command (matches the Permit / Credential / Seal 

76wire convention of bare-str slugs on commands + typed 

77`FacilityCode` VO on aggregate state); route + tool Pydantic 

78regex enforces the `[a-z0-9-]{1,32}` codepoint contract at the 

79API boundary. 

80"""
