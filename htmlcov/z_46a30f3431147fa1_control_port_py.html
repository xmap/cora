1"""ControlPort port: domain-shaped value-IO for the Operation BC executor. 

2 

3`ControlPort` is the async Protocol that Operation BC slice handlers 

4(and the future Procedure executor) use to read, write, and subscribe 

5to control-system values. Substrate details (EPICS CA via aioca, 

6EPICS PVA via p4p, Tango via PyTango, OPC UA via asyncua) live behind 

7concrete adapters; the executor never touches substrate-specific 

8symbols directly. 

9 

10Per [[project_control_port_generalization_research]] this supersedes 

11the earlier `PvDriver` design. The supersession was driven by 

12a three-substrate stress test (EPICS + Tango + OPC UA sanity check) 

13showing that value-IO genuinely generalises across all three when 

14the port owns its vocabulary; RPC and typed events do NOT generalise 

15and stay deferred to future sibling ports (`CommandPort`, `EventPort`) 

16per adapter-first discipline. 

17 

18## Domain vocabulary (substrate-neutral) 

19 

20- **`Reading`** is the typed value-plus-metadata the executor sees. 

21 Fields are domain-owned: `value`, `kind: ReadingKind`, 

22 `quality: Quality`, `sampled_at: datetime`, `quality_detail: str`. 

23- **`ReadingKind`** is a closed 5-value enum (`Scalar | Array | Image 

24 | Categorical | Tabular`). Maps to EPICS V4 NT kinds + Tango 

25 `AttrDataFormat` + OPC UA Variant types via adapter-side ACL. 

26- **`Quality`** is the closed 3-value enum (`Good | Uncertain | Bad`) 

27 matching OPC UA's spec-defined high-level severity grouping and 

28 the NAMUR / ISA-95 vocabulary. Adapters translate substrate-native 

29 quality enums INTO this domain enum; substrate sub-codes (EPICS 

30 `alarm_status`, Tango string detail, OPC UA's ~240 named sub-codes) 

31 land in `Reading.quality_detail` as opaque forensic breadcrumbs. 

32 

33## Address space 

34 

35`address: str` at v1. Adapters parse substrate-specific syntax: EPICS 

36PV name (`"2bm:rot:rbv"`), Tango TRL (`"sys/tg_test/1/double_scalar"`), 

37OPC UA NodeId string (`"ns=2;s=Demo.Static.Scalar.Double"`). At second- 

38substrate trigger, promote to a typed-sum `ControlAddress` 

39(`EpicsPvAddress | TangoAttributeAddress | OpcUaNodeAddress`) per 

40watch item 4; the change is BC-internal and non-breaking outside the 

41Operation BC. 

42 

43## Out of scope (deferred sibling ports) 

44 

45- **RPC** (Tango Commands, OPC UA Methods, EPICS V4 RPC): future 

46 `CommandPort` Protocol. Triggers at first concrete RPC consumer. 

47- **Typed events** (Tango `INTERFACE_CHANGE` / `DATA_READY`, OPC UA 

48 `EventNotificationList`): future `EventPort` Protocol. Triggers at 

49 first typed-event consumer. 

50 

51Per [[project_control_port_generalization_research]] anti-hooks: 

52do NOT widen `ControlPort` with `invoke` (RPC) or 

53`subscribe_events` (typed events). Add separate ports when triggered; 

54keep this one value-IO-only. 

55 

56## Exceptions 

57 

58Six exception families mirror CORA's standard shape. `ControlPort` is 

59not REST-accessible; the executor's decider captures these as 

60event-payload metadata per [[project_non_determinism_principle]]. 

61 

62## Subscribe shape 

63 

64`subscribe` is a plain `def` returning `AsyncIterator[Reading]` directly 

65(no surrounding coroutine). Caller iterates with 

66`async for reading in port.subscribe(address):`. Connect setup may 

67happen lazily on the first `__anext__`; the adapter still raises 

68`ControlNotConnectedError` through the iterator if the address is 

69never reachable. Adapters may coalesce intermediate values on 

70subscriber lag (p4p Qt keep-last; OPC UA MonitoredItem queue 

71semantics). Mid-stream disconnect raises `ControlNotConnectedError` 

72through the iterator so silent stream pause is impossible. 

73"""

80ReadingKind = Literal["Scalar", "Array", "Image", "Categorical", "Tabular"] 

81"""Closed 5-value discriminator for `Reading.value` shape. 

82 

83- `Scalar`: a single typed value (int / float / bool / str). 

84- `Array`: a 1-D sequence of scalars (tuple at the port boundary). 

85- `Image`: a 2-D pixel grid (NTNDArray / Tango IMAGE / OPC UA image 

86 variants); shape and dtype carried inside `value`. 

87- `Categorical`: a string label from a closed substrate-defined set 

88 (EPICS NTEnum / Tango DevEnum or DevState / OPC UA enum). 

89- `Tabular`: column-oriented record (NTTable / OPC UA table / Tango 

90 multi-attribute bundle). 

91 

92Adapter ACLs translate substrate-specific type taxonomies INTO this 

93enum. Extensible by tag addition when a future substrate justifies a 

94new shape (e.g., OPC UA `LocalizedText` may justify a new tag). 

95"""

98Quality = Literal["Good", "Uncertain", "Bad"] 

99"""Closed 3-value quality enum matching OPC UA's spec-defined severity 

100grouping and the NAMUR / ISA-95 vocabulary. 

101 

102Per the OPC UA sanity check in 

103[[project_control_port_generalization_research]], `StatusCode`'s top 

1042 bits are exactly this trichotomy: 

105`Good = 0b00 | Uncertain = 0b01 | Bad = 0b10`. EPICS CA's 4-value 

106severity collapses (`NONE -> Good`, `MINOR | MAJOR | INVALID -> Bad`). 

107Tango's 5-value `AttrQuality` collapses (`VALID -> Good`, 

108`WARNING | CHANGING -> Uncertain`, `ALARM | INVALID -> Bad`). 

109 

110Substrate-specific forensic detail (EPICS `alarm_status`, Tango 

111string detail, OPC UA's ~240 named sub-codes such as 

112`BadCommunicationError` / `UncertainDataSubNormal`) lands in 

113`Reading.quality_detail` as an opaque string; the closed enum stays 

114tight. 

115"""

118@dataclass(frozen=True) 

119class Reading: 

120 """Domain-shaped value-plus-metadata at the executor boundary. 

121 

122 Domain owns every field. Adapter ACLs translate substrate-native 

123 value types (EPICS V4 NT structures, Tango `DeviceAttribute`, 

124 OPC UA `DataValue`) into this shape; substrate vocabulary 

125 (NTNDArray fields, DevState labels, OPC UA Variant types) stays 

126 caged in the adapter. 

127 

128 `value` is `Any` because the runtime shape varies with `kind`: 

129 `Scalar` is `int | float | bool | str`, `Array` is a tuple, 

130 `Image` is a 2-D structure (typically `numpy.ndarray` at the 

131 adapter, normalised to a tuple-of-tuples or wrapped array at the 

132 port boundary), `Categorical` is a string label, `Tabular` is a 

133 dict of column names to tuples. Callers narrow per kind at the 

134 use site. 

135 

136 Substrate-specific presentation hints (NT `valueAlarm`, 

137 `displayLimit`, `controlLimit` structures; Tango display formats; 

138 OPC UA `DisplayName`) are intentionally NOT surfaced here. They 

139 are operator-UI metadata, not control-plane data; adapters drop 

140 them at unpacking time. 

141 

142 `sampled_at` is the time the substrate observed the value 

143 (EPICS source timestamp, Tango `time`, OPC UA `SourceTimestamp`). 

144 `quality_detail` is adapter-specific and opaque at the port 

145 layer; treat it as a forensic breadcrumb, not a value to branch 

146 on. 

147 """ 

148 

149 value: Any 

150 kind: ReadingKind 

151 quality: Quality 

152 sampled_at: datetime 

153 quality_detail: str = ""

156class ControlNotConnectedError(Exception): 

157 """No active channel / session for this address. 

158 

159 Triggered on pre-connect call OR mid-call / mid-stream 

160 disconnect. `subscribe` iterators raise this through the iterator 

161 (not via silent pause) so the caller decides to retry (re-call 

162 `subscribe`) or close. 

163 """ 

164 

165 def __init__(self, address: str) -> None: 

166 super().__init__(f"Control address {address!r} not connected") 

167 self.address = address

170class ControlTimeoutError(Exception):

172

255@runtime_checkable 

256class ControlPort(Protocol): 

257 """Domain-shaped value-IO port for control-system addresses. 

258 

259 Substrate-agnostic. Concrete adapters 

260 (`InMemoryControlPort`, `CaprotoControlPort`, `EpicsCaControlPort`, 

261 `EpicsPvaControlPort`, future `TangoControlPort` / 

262 `OpcUaControlPort`) implement the wire details. Per 

263 [[project_non_determinism_principle]], port-injected effects are 

264 captured in the executor's event payloads at decider time. 

265 

266 Port shape follows the ros2_control "keep port dumb, executor 

267 pluggable" lesson from [[project_control_port_research]]. Adapter 

268 internals may use asyncio (aioca, p4p asyncio, asyncua) or 

269 threading (p4p thread, caproto sync backend); the surface callers 

270 see is `async def read` / `async def write` / `async def subscribe`. 

271 

272 The executor that consumes this Protocol stays open at v1: 

273 `ControlPort` composes with fixed-rate-tick, async event-driven, 

274 and plain-async executor architectures. The executor arc picks 

275 an initial shape; `ControlPort` is not coupled to that pick. 

276 

277 RPC (Tango Commands, OPC UA Methods) and typed events (Tango 

278 `DATA_READY` / `INTERFACE_CHANGE`, OPC UA `EventNotificationList`) 

279 are intentionally OUT of scope. Future sibling ports 

280 (`CommandPort`, `EventPort`) land at first concrete consumer 

281 trigger per adapter-first discipline. 

282 """

315 def subscribe(self, address: str) -> AsyncIterator[Reading]: 

316 """Subscribe to value changes on `address`. Caller iterates the result. 

317 

318 Plain `def`, no surrounding coroutine: caller pattern is 

319 `async for reading in port.subscribe(address):`. Adapters may 

320 defer connect-and-register-as-subscriber to the first 

321 `__anext__`; a `ControlNotConnectedError` raised through the 

322 iterator (rather than from `subscribe()` itself) is the 

323 expected shape when the address never reaches a connected 

324 state. 

325 

326 On mid-stream disconnect the iterator raises 

327 `ControlNotConnectedError` so silent stream pause is 

328 impossible. The caller decides whether to re-subscribe or 

329 close. 

330 

331 Subscriber-responsible back-pressure. Adapters MAY coalesce 

332 intermediate values on lag (p4p Qt keep-last; OPC UA 

333 MonitoredItem queue policy); each adapter documents its 

334 coalescing policy in implementation notes. Cancellation is 

335 via the iterator's `aclose()`. 

336 """
