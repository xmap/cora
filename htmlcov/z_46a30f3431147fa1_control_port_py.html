1"""ControlPort: domain-shaped value-IO for the Operation BC executor. 

2 

3`ControlPort` is the async Protocol that Operation BC slice handlers 

4(and the future Procedure executor) use to read, write, and subscribe 

5to control-system values. Substrate details (EPICS CA via aioca, 

6EPICS PVA via p4p, Tango via PyTango, OPC UA via asyncua) live behind 

7concrete adapters; the executor never touches substrate-specific 

8symbols directly. 

9 

10Per [[project_control_port_generalization_research]] this supersedes 

11the earlier `PvDriver` design. The supersession was driven by 

12a three-substrate stress test (EPICS + Tango + OPC UA sanity check) 

13showing that value-IO genuinely generalises across all three when 

14the port owns its vocabulary; RPC and typed events do NOT generalise 

15and stay deferred to future sibling ports (`CommandPort`, `EventPort`) 

16per adapter-first discipline. 

17 

18## Domain vocabulary (substrate-neutral) 

19 

20The shared value types `Measurement`, `MeasurementKind`, and `Quality` 

21live in `cora.operation.ports.measurement` (they serve every edge-runtime 

22port, not just control). A `read` returns a `Measurement`; subscribe 

23yields `Measurement` values. See that module for field-by-field detail. 

24 

25## Address space 

26 

27`address: str` at v1. Adapters parse substrate-specific syntax: EPICS 

28PV name (`"2bm:rot:rbv"`), Tango TRL (`"sys/tg_test/1/double_scalar"`), 

29OPC UA NodeId string (`"ns=2;s=Demo.Static.Scalar.Double"`). At second- 

30substrate trigger, promote to a typed-sum `ControlAddress` 

31(`EpicsPvAddress | TangoAttributeAddress | OpcUaNodeAddress`) per 

32watch item 4; the change is BC-internal and non-breaking outside the 

33Operation BC. 

34 

35## Out of scope (deferred sibling ports) 

36 

37- **RPC** (Tango Commands, OPC UA Methods, EPICS V4 RPC): future 

38 `CommandPort` Protocol. Triggers at first concrete RPC consumer. 

39- **Typed events** (Tango `INTERFACE_CHANGE` / `DATA_READY`, OPC UA 

40 `EventNotificationList`): future `EventPort` Protocol. Triggers at 

41 first typed-event consumer. 

42 

43Per [[project_control_port_generalization_research]] anti-hooks: 

44do NOT widen `ControlPort` with `invoke` (RPC) or 

45`subscribe_events` (typed events). Add separate ports when triggered; 

46keep this one value-IO-only. 

47 

48## Exceptions 

49 

50Six exception families mirror CORA's standard shape. `ControlPort` is 

51not REST-accessible; the executor's decider captures these as 

52event-payload metadata per [[project_non_determinism_principle]]. 

53 

54## Subscribe shape 

55 

56`subscribe` is a plain `def` returning `AsyncIterator[Measurement]` directly 

57(no surrounding coroutine). Caller iterates with 

58`async for reading in port.subscribe(address):`. Connect setup may 

59happen lazily on the first `__anext__`; the adapter still raises 

60`ControlNotConnectedError` through the iterator if the address is 

61never reachable. Adapters may coalesce intermediate values on 

62subscriber lag (p4p Qt keep-last; OPC UA MonitoredItem queue 

63semantics). Mid-stream disconnect raises `ControlNotConnectedError` 

64through the iterator so silent stream pause is impossible. 

65"""

74class ActuationKind(StrEnum): 

75 """How a conducted episode drove its addresses: real hardware, a 

76 simulator, or both. 

77 

78 Derived by the Conductor from the per-route simulated flag the 

79 registry carries, and snapshotted (as a raw string) onto the 

80 producing Dataset so simulator-origin data can never be promoted 

81 to Production. Simulated-ness is a declared property of a route 

82 (ControlPortRoute.is_simulated), not the transport substrate: a 

83 soft IOC speaks real Channel Access yet is still a simulator. 

84 

85 Physical: every address routed to a non-simulated adapter. 

86 Simulated: every address routed to a simulated adapter. 

87 Hybrid: a single conduct drove both. The promotion gate treats 

88 Hybrid exactly as Simulated (any simulator touch disqualifies). 

89 """ 

90 

91 PHYSICAL = "Physical" 

92 SIMULATED = "Simulated" 

93 HYBRID = "Hybrid"

110class ControlTimeoutError(Exception): 

111 """Adapter timeout elapsed before the operation completed. 

112 

113 Triggered when a `write`'s put-callback / confirmation did not 

114 fire under `wait=True`, a `read` exceeded its timeout, or

143class ControlValueCoercionError(Exception): 

144 """A control value cannot be coerced to the kind a consumer requires. 

145 

146 `target_kind` names the kind the value could not satisfy; it is a 

147 free-form label, not constrained to `MeasurementKind`. Three live cases, 

148 all carrying the raw type label so the failure is debuggable rather 

149 than a silently dropped value: 

150 

151 - Adapter read-unpack: an adapter sees a structured type or a 

152 substrate primitive that does not fit the closed `MeasurementKind` 

153 set; `target_kind` is the `MeasurementKind` it was unpacking toward. 

154 - Adapter write-coercion: a write value cannot be encoded for the 

155 substrate; `target_kind` is an operation label (e.g. the PVA 

156 adapter's `"pva put"`), not a `MeasurementKind`. 

157 - Consumer-side: a `Measurement` unpacked cleanly but its `value` is 

158 the wrong type for a downstream consumer (e.g., an action body 

159 needs a numeric axis position but read a categorical leaf). Here 

160 `target_kind` is a LOGICAL kind the consumer names (e.g. 

161 `"number"`). Action bodies raise this so the Conductor records a 

162 structured step failure (it is a member of the Conductor's caught 

163 `_CONTROL_ERRORS`) instead of letting a bare `TypeError` escape. 

164 """ 

165 

166 def __init__(self, address: str, raw_type: str, target_kind: str) -> None: 

167 super().__init__( 

168 f"Control address {address!r} value of type {raw_type!r} " 

169 f"cannot coerce to kind {target_kind!r}" 

170 ) 

171 self.address = address 

172 self.raw_type = raw_type 

173 self.target_kind = target_kind

208@runtime_checkable 

209class ControlPort(Protocol): 

210 """Domain-shaped value-IO port for control-system addresses. 

211 

212 Substrate-agnostic. Concrete adapters 

213 (`InMemoryControlPort`, `CaprotoControlPort`, `EpicsCaControlPort`, 

214 `EpicsPvaControlPort`, future `TangoControlPort` / 

215 `OpcUaControlPort`) implement the wire details. Per 

216 [[project_non_determinism_principle]], port-injected effects are 

217 captured in the executor's event payloads at decider time. 

218 

219 Port shape follows the ros2_control "keep port dumb, executor 

220 pluggable" lesson from [[project_control_port_research]]. Adapter 

221 internals may use asyncio (aioca, p4p asyncio, asyncua) or 

222 threading (p4p thread, caproto sync backend); the surface callers 

223 see is `async def read` / `async def write` / `async def subscribe`. 

224 

225 The executor that consumes this Protocol stays open at v1: 

226 `ControlPort` composes with fixed-rate-tick, async event-driven, 

227 and plain-async executor architectures. The executor arc picks 

228 an initial shape; `ControlPort` is not coupled to that pick. 

229 

230 RPC (Tango Commands, OPC UA Methods) and typed events (Tango 

231 `DATA_READY` / `INTERFACE_CHANGE`, OPC UA `EventNotificationList`) 

232 are intentionally OUT of scope. Future sibling ports 

233 (`CommandPort`, `EventPort`) land at first concrete consumer 

234 trigger per adapter-first discipline. 

235 """

255

263 `ControlWriteRejectedError` (substrate rejected the write), 

264 or `ControlAccessDeniedError` (substrate denied access). 

265 """

268 def subscribe(self, address: str) -> AsyncIterator[Measurement]: 

269 """Subscribe to value changes on `address`. Caller iterates the result. 

270 

271 Plain `def`, no surrounding coroutine: caller pattern is 

272 `async for measurement in port.subscribe(address):`. Adapters may 

273 defer connect-and-register-as-subscriber to the first 

274 `__anext__`; a `ControlNotConnectedError` raised through the 

275 iterator (rather than from `subscribe()` itself) is the 

276 expected shape when the address never reaches a connected 

277 state. 

278 

279 On mid-stream disconnect the iterator raises 

280 `ControlNotConnectedError` so silent stream pause is 

281 impossible. The caller decides whether to re-subscribe or 

282 close. 

283 

284 Subscriber-responsible back-pressure. Adapters MAY coalesce 

285 intermediate values on lag (p4p Qt keep-last; OPC UA 

286 MonitoredItem queue policy); each adapter documents its 

287 coalescing policy in implementation notes. Cancellation is 

288 via the iterator's `aclose()`. 

289 """
