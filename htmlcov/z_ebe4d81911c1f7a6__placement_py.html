1"""Placement value object: where a Mount or Frame sits in space. 

2 

3A Placement is the complete answer to "where is this thing and how 

4is it oriented?" It is a flat 6-degrees-of-freedom pose (three 

5position axes + three rotation axes) plus three additional pieces 

6of information that make the pose interpretable across surveys and 

7re-installations: 

8 

9 - `parent_frame_id`: which coordinate frame the values are measured 

10 against (the 1.35 mrad standard beam centerline, an alternate 

11 centerline at the mirror, the optical-bench frame on a table, ...). 

12 - `reference_surface`: which physical feature of the part the 

13 position values were measured from (the upstream face of the 

14 thermal block, the center of the optic, the upstream face of the 

15 shielding). Without this, "z = 259313" is ambiguous. 

16 - `units`: the unit system the values are stored in. CORA stores 

17 canonically; conversion happens at the edge per 

18 `project_units_design.md`. 

19 

20Tolerances are bilateral (symmetric ±) per axis. Per-axis tolerance 

21must be non-negative; zero means "exact." Asymmetric, projected, 

22MMC/LMC, and zone-shaped tolerances per ISO 1101 / ASME Y14.5 are 

23deferred (Watch item in `project_mount_frame_design.md`). 

24 

25Flat 6-DoF is the v1 shape; the IFC `IfcLocalPlacement` is its 

26ancestor (parent-pointer + relative orientation). Promote to a 

27NeXus NXtransformations-style ordered axis-chain only when 

28articulated multi-DoF kinematics surface (Watch item). 

29 

30`ReferenceSurface` is a closed StrEnum of four values; escape hatch 

31fires when a second facility lands and a new convention surfaces, OR 

32when a new component-category cohort at the existing facility has no 

33plausible fit among current values AND no canonical term in the 

34modeling-refs corpus (ISO 1101, ASME Y14.5, NeXus, AAS Hierarchical 

35Structures, OPC UA DI/LADS) would be a better fit. NOT a GD&T datum 

36(which is the derived theoretical entity); these are "datum features" 

37in GD&T parlance. CORA uses the longer `ReferenceSurface` to avoid 

38the term collision. 

39 

40`UnitSystem` is a StrEnum with one v1 value (`SI_MM_RAD`): 

41millimetres for translation, radians for rotation. Extensible when 

42non-SI deployments land. 

43 

44`Placement` is a closed-shape typed frozen dataclass. NOT 

45`json_schema_validation` (that pattern is for declarer-owns-schema / 

46carrier-owns-dict); validation lives in field shape + enum 

47membership + `__post_init__` checks. 

48"""

56class InvalidPlacementError(ValueError): 

57 """A Placement failed VO-level domain validation. 

58 

59 Failure modes at the VO layer: 

60 - Any tolerance is negative (tolerances are bilateral; zero 

61 means "exact", negative is meaningless). 

62 

63 Cross-aggregate validations (parent_frame_id must reference an 

64 active Frame, etc.) happen at the handler / decider layer, not 

65 in the VO. Per the design memo: the VO is closed-shape; the 

66 handler is where cross-aggregate preconditions land. 

67 

68 `reason` names the offending axis for diagnostics; the route 

69 layer's `_handle_validation_error` reads `str(exc)` (which 

70 formats as "Invalid Placement: <reason>"), so the reason is 

71 embedded in the message that surfaces in the 400 body. 

72 

73 Lives in this module (an aggregate-scoped private VO module) so 

74 aggregate state.py / events.py can import without violating the 

75 aggregates-don't-depend-on-BC-root tach layering rule. The 

76 `test_no_domain_errors_outside_aggregate_or_errors_module` 

77 fitness exempts the entire `cora/<bc>/aggregates/...` subtree. 

78 """ 

79 

80 def __init__(self, reason: str) -> None: 

81 super().__init__(f"Invalid Placement: {reason}") 

82 self.reason = reason

85class ReferenceSurface(StrEnum): 

86 """The physical feature of a part that a Placement is measured FROM. 

87 

88 Closed enum; CORA precedent is the Affordance StrEnum. Widening 

89 rules and GD&T-term-collision rationale live in the module docstring. 

90 """ 

91 

92 THERMAL_FACE = "ThermalFace" 

93 """Upstream face of the thermal component (front-end masks, beam stops, 

94 photon stops, Be windows; OFHC Cu / Be sit between cooling water and beam).""" 

95 OPTIC_CENTER = "OpticCenter" 

96 """Center of the optic (mirror axis, monochromator crystal axis; 

97 the active surface, not a face).""" 

98 SHIELDING_FACE = "ShieldingFace" 

99 """Upstream face of the shielding material (collimators, baffles; 

100 the W or Pb absorbing surface).""" 

101 MOUNTING_FACE = "MountingFace" 

102 """Precision-machined surface used to attach a motorized asset to its 

103 parent (bolted flanges, kinematic ball-groove couplings, V-rails, 

104 tapped-hole patterns). Functional naming covers mounts that are not 

105 strictly flanged."""

108class UnitSystem(StrEnum): 

109 """The unit system a Placement's values are stored in. 

110 

111 v1 ships with one value (`SI_MM_RAD`): translation in millimetres, 

112 rotation in radians. CORA stores canonically; conversion to or 

113 from facility-local units happens at the adapter boundary per 

114 `project_units_design.md` (canonical-stored, convert-at-edge). 

115 

116 The single v1 value is what makes the design memo's 

117 "tolerance units MUST match value units per axis" invariant 

118 structurally satisfied: with one UnitSystem, a Placement's 

119 tolerances are by construction in the same units as its 

120 values. When a second UnitSystem lands (non-SI deployment), 

121 the per-axis coupling check must move from "trivially true" to 

122 an explicit `__post_init__` validation, OR Placement must widen 

123 to per-axis units fields. Capture this gate before widening 

124 the enum. 

125 """ 

126 

127 SI_MM_RAD = "SI_mm_rad"

130@dataclass(frozen=True) 

131class Placement: 

132 """The pose (position + orientation) of a Mount or Frame. 

133 

134 Flat 6 degrees of freedom: three translations (x, y, z) and 

135 three rotations (rx, ry, rz). Each value carries an independent 

136 `±` tolerance. All twelve numeric values are in the system named 

137 by `units` (v1: millimetres for translation, radians for rotation). 

138 

139 `parent_frame_id` names the coordinate frame the values are measured 

140 against. `reference_surface` names the physical feature on the 

141 part the position is measured FROM. 

142 

143 Equality and hash are structural across all 15 fields, so a 

144 Placement can live unambiguously in a frozenset. 

145 """ 

146 

147 x: float 

148 y: float 

149 z: float 

150 rx: float 

151 ry: float 

152 rz: float 

153 parent_frame_id: UUID 

154 reference_surface: ReferenceSurface 

155 tol_x: float 

156 tol_y: float 

157 tol_z: float 

158 tol_rx: float 

159 tol_ry: float 

160 tol_rz: float 

161 units: UnitSystem 

162 

163 def __post_init__(self) -> None: 

164 # Pure validation, no normalization (no trim or 

165 # `object.__setattr__` dance): all fields are typed 

166 # primitives or enums; only finiteness + tolerance non-negativity 

167 # are not encodable in the type itself. 

168 # 

169 # NaN/Inf rejection at the boundary: an unguarded NaN propagates 

170 # through the equality + comparison logic in update_mount_placement's 

171 # no-op-on-equal path (NaN != NaN, so every retry would re-emit 

172 # an event) and serializes as a JSON literal that asyncpg's 

173 # jsonb codec rejects at write time as a 500. Catch at the VO. 

174 for axis_name, value in ( 

175 ("x", self.x), 

176 ("y", self.y), 

177 ("z", self.z), 

178 ("rx", self.rx), 

179 ("ry", self.ry), 

180 ("rz", self.rz), 

181 ("tol_x", self.tol_x), 

182 ("tol_y", self.tol_y), 

183 ("tol_z", self.tol_z), 

184 ("tol_rx", self.tol_rx), 

185 ("tol_ry", self.tol_ry), 

186 ("tol_rz", self.tol_rz), 

187 ): 

188 if not math.isfinite(value): 

189 raise InvalidPlacementError(f"{axis_name!s} must be finite (got: {value!r})") 

190 for tol_name, tol_value in ( 

191 ("tol_x", self.tol_x), 

192 ("tol_y", self.tol_y), 

193 ("tol_z", self.tol_z), 

194 ("tol_rx", self.tol_rx), 

195 ("tol_ry", self.tol_ry), 

196 ("tol_rz", self.tol_rz), 

197 ): 

198 if tol_value < 0: 

199 raise InvalidPlacementError( 

200 f"tolerance {tol_name!s} must be non-negative (got: {tol_value!r})" 

201 )

204def placement_to_payload(placement: Placement) -> dict[str, object]: 

205 """Serialize a Placement VO to a JSON-friendly dict for jsonb storage. 

206 

207 Canonical codec shared by every aggregate event that carries a 

208 Placement (Mount, Frame, Assembly). Sibling rebuilder is 

209 `placement_from_payload`. Hoisted to the VO module to close the 

210 duplication anti-hook flagged in `project_mount_frame_design` 

211 Watch items. 

212 """ 

213 return { 

214 "x": placement.x, 

215 "y": placement.y, 

216 "z": placement.z, 

217 "rx": placement.rx, 

218 "ry": placement.ry, 

219 "rz": placement.rz, 

220 "parent_frame_id": str(placement.parent_frame_id), 

221 "reference_surface": placement.reference_surface.value, 

222 "tol_x": placement.tol_x, 

223 "tol_y": placement.tol_y, 

224 "tol_z": placement.tol_z, 

225 "tol_rx": placement.tol_rx, 

226 "tol_ry": placement.tol_ry, 

227 "tol_rz": placement.tol_rz, 

228 "units": placement.units.value, 

229 }

232def placement_from_payload(payload: dict[str, object]) -> Placement: 

233 """Reconstruct a Placement VO from its JSON payload. 

234 

235 Sibling of `placement_to_payload`. Round-trips losslessly with it. 

236 Re-runs Placement.__post_init__ validation so on-disk corruption 

237 (NaN, Inf, negative tolerance) surfaces at load time. 

238 """ 

239 return Placement( 

240 x=payload["x"], # type: ignore[arg-type] 

241 y=payload["y"], # type: ignore[arg-type] 

242 z=payload["z"], # type: ignore[arg-type] 

243 rx=payload["rx"], # type: ignore[arg-type] 

244 ry=payload["ry"], # type: ignore[arg-type] 

245 rz=payload["rz"], # type: ignore[arg-type] 

246 parent_frame_id=UUID(str(payload["parent_frame_id"])), 

247 reference_surface=ReferenceSurface(str(payload["reference_surface"])), 

248 tol_x=payload["tol_x"], # type: ignore[arg-type] 

249 tol_y=payload["tol_y"], # type: ignore[arg-type] 

250 tol_z=payload["tol_z"], # type: ignore[arg-type] 

251 tol_rx=payload["tol_rx"], # type: ignore[arg-type] 

252 tol_ry=payload["tol_ry"], # type: ignore[arg-type] 

253 tol_rz=payload["tol_rz"], # type: ignore[arg-type] 

254 units=UnitSystem(str(payload["units"])), 

255 )
