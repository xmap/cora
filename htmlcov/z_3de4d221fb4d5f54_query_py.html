1"""The `ListClearances` query -- intent dataclass for this read slice. 

2 

3Mirrors `ListProcedures`: cursor pagination + optional kind / status / 

4risk_band / facility_asset_id / binds_to_*_id filters. Each filter is 

5optional; passing None means "don't filter on this dimension". 

6 

7`limit` defaults to 50 (capped at 100 in the route layer per the

9`(registered_at, clearance_id)`. 

10 

11The 4 binds_to_* filters use UUID[] GIN indexes on the projection;
