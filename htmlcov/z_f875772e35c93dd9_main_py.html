1"""CORA FastAPI entrypoint. 

2 

3`create_app()` is the factory: each call builds a fresh FastMCP server, 

4fresh FastAPI app, fresh middleware stack. The module-level `app` is 

5the production singleton (uvicorn imports it). Tests call `create_app()` 

6to get isolated instances — necessary because FastMCP's 

7StreamableHTTPSessionManager raises if the same instance's `.run()` is 

8called twice (once per lifespan), so reusing the module-level app 

9across multiple TestClient context managers fails. 

10 

11Lifespan composition: the MCP session manager's lifespan must wrap our 

12shared-deps build so the manager initializes before any MCP request. 

13Without the wrap, mounted MCP requests silently fail 

14(modelcontextprotocol/python-sdk#1367). 

15 

16Observability stack: 

17- OpenTelemetry tracing is configured at app construction; the global 

18 TracerProvider is installed iff `settings.otel_exporter != "none"`. 

19 Per-app FastAPI instrumentation is attached after app creation. 

20 The W3C `traceparent` header is the source of truth for "this 

21 request" identity; the prior `asgi-correlation-id` middleware was 

22 removed because OTel's TraceContextTextMapPropagator handles inbound 

23 / outbound trace propagation per the W3C spec. 

24- Prometheus metrics are exposed on `/metrics` (operational endpoint, 

25 excluded from OpenAPI schema). 

26- structlog is configured in `build_kernel()`; an OTel processor 

27 injects `trace_id` and `span_id` into every log line emitted inside 

28 an active span. 

29"""

236# Production-tier app environments that must run the full hardened 

237# posture: a real authenticated principal, no permit-everyone AllowAll 

238# default, and HTTPS-only IdPs. `staging` is included deliberately: a 

239# pre-prod box typically handles realistic data and is network-reachable, 

240# so it should not silently run wide-open. Genuinely-casual staging can 

241# still opt out per-check (ALLOW_PERMISSIVE_AUTHZ, etc.). Dev / test / 

242# local and any other env name keep the permissive default. 

243_PROD_LIKE_APP_ENVS = frozenset({"prod", "production", "staging"})

246def _enforce_production_principal_policy(settings: Settings) -> None: 

247 """Refuse to boot deployments where the principal-fallback would 

248 silently grant admin to header-less callers. 

249 

250 THREE numbered conditions, plus the F11 transport-security check 

251 below, all producing the same fail-fast: 

252 

253 1. `app_env in {prod, production, staging}` without 

254 `require_authenticated_principal=True`. The legacy Phase-3e 

255 gate: header-less prod requests would otherwise run as 

256 SYSTEM_PRINCIPAL_ID under whichever Authorize port is wired. 

257 `staging` is treated as production-tier (see `_PROD_LIKE_APP_ENVS`). 

258 

259 2. `trust_policy_id is not None` without 

260 `require_authenticated_principal=True`, when `app_env` is 

261 NOT `test`. Post-Phase-A: the seeded bootstrap policy permits 

262 SYSTEM_PRINCIPAL_ID to call DefinePolicy + RegisterActor. 

263 Without the principal-header check, ANY caller spoofing 

264 `X-Principal-Id: 00000000-0000-0000-0000-000000000000` 

265 becomes SYSTEM and gets standing admin. Staging/local 

266 deployments with only TRUST_POLICY_ID set (forgetting the 

267 second flag) would ship a wide-open API — gate-review F1. 

268 

269 Test env (`app_env=test`) is exempt because legitimate test 

270 fixtures exercise "operator misconfigured" + "SYSTEM-fallback 

271 under real policy" scenarios that REQUIRE this combo to be 

272 constructible. The exemption is safe because `app_env=test` 

273 is never operator-set in deployment configs. 

274 

275 3. `app_env in {prod, production, staging}` with `trust_policy_id is 

276 None` and `allow_permissive_authz` not set. A None `trust_policy_id` 

277 wires `AllowAllAuthorize`, which permits every command; shipping 

278 that permit-everyone stub to production is almost always a 

279 misconfiguration. Refuse boot unless the operator consciously 

280 opts in via `ALLOW_PERMISSIVE_AUTHZ=true`, the same conscious- 

281 choice shape as the per-IdP `allow_insecure_*` opt-ins. 

282 

283 Bootstrap workflow stays clean: a fresh non-prod deploy wanting 

284 AllowAll leaves `trust_policy_id` unset (today's default); a prod 

285 deploy points `TRUST_POLICY_ID` at the seeded bootstrap policy (or 

286 sets `ALLOW_PERMISSIVE_AUTHZ=true` to stay permissive on purpose). 

287 A deploy wanting real authz sets `TRUST_POLICY_ID` + 

288 `REQUIRE_AUTHENTICATED_PRINCIPAL=true` together, and operates 

289 behind an auth proxy that strips/sets `X-Principal-Id` per the 

290 routing.py contract. 

291 """ 

292 # Normalize once so case or surrounding whitespace in APP_ENV cannot 

293 # silently bypass the prod gates: pydantic case-folds env-var NAMES, 

294 # not VALUES, so a raw "PROD" / "Production " would otherwise miss 

295 # `_PROD_LIKE_APP_ENVS` and ship AllowAllAuthorize. 

296 app_env = settings.app_env.strip().lower() 

297 if app_env in _PROD_LIKE_APP_ENVS and not settings.require_authenticated_principal: 

298 msg = ( 

299 f"app_env={settings.app_env!r} requires " 

300 "require_authenticated_principal=True (set " 

301 "REQUIRE_AUTHENTICATED_PRINCIPAL=true). The permissive " 

302 "SYSTEM_PRINCIPAL_ID fallback is not safe for a " 

303 "production-tier environment (prod / production / staging)." 

304 ) 

305 raise RuntimeError(msg) 

306 if ( 

307 app_env != "test" 

308 and settings.trust_policy_id is not None 

309 and not settings.require_authenticated_principal 

310 ): 

311 msg = ( 

312 f"trust_policy_id={settings.trust_policy_id!r} requires " 

313 "require_authenticated_principal=True (set " 

314 "REQUIRE_AUTHENTICATED_PRINCIPAL=true). Without the " 

315 "principal-header check, any caller can spoof " 

316 "X-Principal-Id and become SYSTEM under the configured " 

317 "Policy — bypassing the authz gate you just turned on. " 

318 "See memory/project_bootstrap_policy_design.md (F1)." 

319 ) 

320 raise RuntimeError(msg) 

321 # gate-review HIGH F11: per-IdP allow_insecure_* opt-ins 

322 # exist for localhost test fixtures. Under prod posture an operator 

323 # (or an attacker with env-var-write access) could flip one IdP to 

324 # plaintext HTTP, silently bypassing the per-adapter HTTPS gate. 

325 # The per-adapter check in `JwtTokenVerifier` / `IntrospectionTokenVerifier` 

326 # CAN'T see `app_env`; this Settings-level check refuses boot when 

327 # any IdP entry opts in to insecure URLs under prod. 

328 if app_env in _PROD_LIKE_APP_ENVS: 

329 for idp in settings.identity_providers: 

330 if idp.allow_insecure_jwks_url or idp.allow_insecure_introspection_url: 330 ↛ 329line 330 didn't jump to line 329 because the condition on line 330 was always true

331 msg = ( 

332 f"app_env={settings.app_env!r}: IdP issuer={idp.issuer!r} " 

333 "has allow_insecure_jwks_url or allow_insecure_introspection_url " 

334 "set to True. These opt-ins exist for localhost test fixtures; " 

335 "under prod posture, HTTP JWKS is MITM-exploitable and HTTP " 

336 "introspection leaks CORA's client_secret over plain Basic " 

337 "auth. Either remove the IdP entry, switch its URLs to " 

338 "https://, or disable the opt-ins. See " 

339 "memory/project_edge_auth_design.md gate-review F11." 

340 ) 

341 raise RuntimeError(msg) 

342 # Prod must not silently run the permit-everyone AllowAllAuthorize 

343 # stub. `trust_policy_id is None` wires AllowAllAuthorize (every 

344 # command permitted); shipping that to production is almost always a 

345 # misconfiguration, not an intent. Refuse boot unless the operator 

346 # consciously opts in via `allow_permissive_authz`, mirroring the 

347 # per-IdP `allow_insecure_*` opt-ins above. Placed last so the more 

348 # specific transport-security (F11) message wins when both apply; 

349 # non-prod envs keep the permissive default for dev / test. 

350 if ( 

351 app_env in _PROD_LIKE_APP_ENVS 

352 and settings.trust_policy_id is None 

353 and not settings.allow_permissive_authz 

354 ): 

355 msg = ( 

356 f"app_env={settings.app_env!r} has no trust_policy_id set, so the " 

357 "API would run AllowAllAuthorize and permit every command. Set " 

358 "TRUST_POLICY_ID to the seeded bootstrap policy " 

359 "(00000000-0000-0000-0000-000000000002) to enable real authz, or " 

360 "set ALLOW_PERMISSIVE_AUTHZ=true to consciously run permissive in " 

361 "production. See docs/stack/deployment.md." 

362 ) 

363 raise RuntimeError(msg)

376def _is_insecure_signing_stub(factory: object) -> bool: 

377 """True when `factory` is an in-memory signing stub. 

378 

379 Keyed on the `InMemory` name prefix, the project-wide convention for 

380 in-memory adapters (asserted by the facility-neutrality fitness 

381 test). The prefix catches every current stub 

382 (`InMemorySignaturePort` / `InMemorySigner` / `InMemoryPublishPort`) 

383 and any future `InMemory*` stub wired without updating this guard; 

384 real wire-tier adapters (`DsseStaticJwks...`, a KMS / Sigstore 

385 signer) do not carry the prefix and pass. 

386 """ 

387 return _signing_factory_display_name(factory).startswith("InMemory")

390def _enforce_production_signing_posture( 

391 settings: Settings, 

392 *, 

393 signature_port_factory: object, 

394 signer_factory: object, 

395 publish_port_factory: object, 

396) -> None: 

397 """Refuse to boot a production deployment wired to in-memory signing. 

398 

399 The signing seam ships with in-memory adapters by default (see 

400 `Settings.allow_insecure_inmemory_signing`): `InMemorySignaturePort` 

401 does NO cryptography and rubber-stamps every federation verify; 

402 `InMemorySigner` signs with an ephemeral per-process key whose 

403 signatures cannot be verified across a restart. Both are correct for 

404 dev / test and are the documented stubs kept until the rule-of-two 

405 wire-tier trigger fires, but under a production-tier `app_env` 

406 ({prod, production, staging}, see `_PROD_LIKE_APP_ENVS`) they would 

407 silently ship a false integrity guarantee. This is the 

408 in-memory-default footgun the `make_inmemory_kernel` fitness test 

409 guards for the Kernel; here it guards the signing factories. 

410 

411 Sibling to `_enforce_production_principal_policy`, and keyed on the 

412 same `_PROD_LIKE_APP_ENVS` set so staging runs the hardened posture 

413 too: fail at boot, which is cheaper than discovering crypto-free 

414 signing in production. `allow_insecure_inmemory_signing=True` is the 

415 explicit per-environment escape hatch. 

416 """ 

417 if settings.app_env not in _PROD_LIKE_APP_ENVS: 

418 return 

419 if settings.allow_insecure_inmemory_signing: 

420 return 

421 offenders = [ 

422 f"{label}={_signing_factory_display_name(factory)}" 

423 for label, factory in ( 

424 ("signature_port_factory", signature_port_factory), 

425 ("signer_factory", signer_factory), 

426 ("publish_port_factory", publish_port_factory), 

427 ) 

428 if _is_insecure_signing_stub(factory) 

429 ] 

430 if offenders: 

431 joined = ", ".join(offenders) 

432 msg = ( 

433 f"app_env={settings.app_env!r} is wired to in-memory signing " 

434 f"stubs: {joined}. InMemorySignaturePort does no cryptography " 

435 "and accepts every federation artifact; InMemorySigner uses an " 

436 "ephemeral key whose signatures do not verify across restarts. " 

437 "Wire the wire-tier adapters (DSSE / COSE / SCITT plus a durable " 

438 "KMS / Sigstore signer) before production, or set " 

439 "ALLOW_INSECURE_INMEMORY_SIGNING=true for a staging environment " 

440 "that is intentionally exercising the prod posture. See " 

441 "memory/project_federation_port_design.md (rule-of-two trigger)." 

442 ) 

443 raise RuntimeError(msg)

446def create_app(*, settings: Settings | None = None) -> FastAPI: 

447 """Build a fresh FastAPI app with its own FastMCP server instance. 

448 

449 Production calls this once at module import; tests call it per 

450 `TestClient` context to get isolation. 

451 

452 `settings` is an optional injection point for tests that need 

453 to override env-var-loaded config (for example contract tests for 

454 edge-auth that need a specific `identity_providers` list). 

455 Production callers pass nothing; `_settings_for_app()` reads 

456 from env / .env as usual. 

457 """ 

458 settings = settings if settings is not None else _settings_for_app() 

459 _enforce_production_principal_policy(settings) 

460 

461 # Signing factories: in-memory stubs by default until the rule-of-two 

462 # wire-tier trigger fires (see Settings.allow_insecure_inmemory_signing 

463 # and memory:project_federation_port_design.md). Production overrides 

464 # these with the DSSE+Sigstore + COSE+SCITT wire-tier adapters 

465 # (signature/publish) and a durable KMS / Sigstore signer. Selected 

466 # here, beside the sibling principal-policy guard, so the prod boot 

467 # refusal fires at construction; the lifespan closes over these and 

468 # hands them to build_kernel below. 

469 signature_port_factory = InMemorySignaturePort 

470 signer_factory = InMemorySigner 

471 publish_port_factory = InMemoryPublishPort 

472 _enforce_production_signing_posture( 

473 settings, 

474 signature_port_factory=signature_port_factory, 

475 signer_factory=signer_factory, 

476 publish_port_factory=publish_port_factory, 

477 ) 

478 # configure_tracing is a no-op when otel_exporter == "none" (the 

479 # default in tests), so calling it per create_app() is safe. In 

480 # production it runs once and installs the global TracerProvider. 

481 tracing_teardown = configure_tracing(settings) 

482 

483 # streamable_http_path="/" makes the inner MCP route the mount root, 

484 # so the full path under app.mount("/mcp", ...) is just "/mcp" 

485 # (otherwise the default "/mcp" inner path produces "/mcp/mcp"). 

486 # transport_security: FastMCP's DNS-rebinding protection rejects 

487 # unknown Host headers. We're embedded in FastAPI behind the host 

488 # security FastAPI / the deployment proxy already enforces, so we 

489 # relax MCP's check here. 

490 mcp = FastMCP( 

491 "cora", 

492 streamable_http_path="/", 

493 transport_security=TransportSecuritySettings( 

494 enable_dns_rebinding_protection=False, 

495 ), 

496 )
