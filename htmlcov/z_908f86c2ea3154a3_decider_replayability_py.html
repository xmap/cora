1"""Replayability classification of decider brains by their `model_ref`. 

2 

3The `conduct_until_advised` loop records, per iteration, the `model_ref` of the 

4brain that decided it (on `ProcedureIterationEnded`). The loop's replay- 

5determinism property holds only when that brain is a PURE FUNCTION of the 

6evidence: a replay re-asks the brain and must get the same answer. Some brains 

7satisfy this (the grid walker, the Sobol seeder, the in-memory fake); a GP 

8Bayesian-optimization brain does not, because its fit + acquisition are not 

9bit-reproducible across BLAS / threading / hardware / library versions even 

10with a fixed seed, and neither does an LLM brain, whose provider may resample 

11or move the model under an unpinned snapshot. 

12 

13This module makes that distinction EXPLICIT and machine-checkable rather than 

14leaving it as prose. `is_replay_safe(model_ref)` answers whether a run whose 

15iterations carry that `model_ref` can be faithfully replayed by re-asking the 

16brain. A consumer that replays or resumes a steered run consults it to refuse 

17(or flag) a run that a non-deterministic brain decided, instead of silently 

18re-deriving a divergent history. 

19 

20## Why a classifier, not a per-run event flag (yet) 

21 

22The deciding brain is already on the stream (`ProcedureIterationEnded. 

23model_ref`), so a steered run's replay-safety is derivable from data already 

24recorded; no new event field or loop change is needed to MARK a run. The 

25recorded-decision leg that makes a non-deterministic brain RESUMABLE (record 

26each pass's advised next_point + measured outcome, then re-seed the brain from 

27that record instead of re-asking) is now SHIPPED: `conduct_until_advised_from` 

28re-conditions the brain from the recorded (x, y) history and consults it live 

29only at the open frontier. That does NOT reclassify a GP run as replay-safe: 

30this classifier still judges the RE-ASK path (re-running the brain over the same 

31evidence), which stays non-reproducible for a GP. Resume side-steps the re-ask 

32entirely by replaying the recorded points, so "forward-only" (not 

33re-ask-reproducible) and "resumable" (re-seed-from-record) are now BOTH true of 

34a GP run at once. This classifier remains how a consumer that RE-ASKS tells the 

35two classes apart. 

36 

37## What the coverage guard ranges over, and why it is the factory's Literal 

38 

39`SUBSTRATE_REPLAYABILITY` below is keyed by `DecideSubstrate`, the Literal that 

40`decide_port_config` maintains as the set of substrates its factory can build. 

41That list is the INDEPENDENT side of the check: it is edited for a different 

42reason (making an adapter buildable) by whoever adds an adapter, and a 

43substrate that is not in it cannot be constructed at all. The fitness test 

44asserts the two sets are equal in BOTH directions, so adding a seventh 

45substrate fails CI until it is classified, and deleting one fails until its 

46classification goes too. 

47 

48The guard this replaces did not have an independent side. It asserted a 

49hand-written literal set of four refs against the classifier's own hand-written 

50sets, so it agreed by construction, and it never ranged over the adapters at 

51all. It reported nothing while the `llm` substrate shipped a `model_ref` that 

52no set could ever contain. 

53 

54## Substrate name is not the same thing as recorded ref 

55 

56Four substrates record their own name verbatim, so their recorded ref and their 

57substrate key coincide. Two do not: 

58 

59 - `staged` records NO ref of its own. It returns the child brain's advice 

60 unchanged, so what lands on the iteration is `sobol` or `botorch`. Its 

61 classification is `DELEGATED`, and seeing the literal string `"staged"` on 

62 an iteration means the composite grew a ref it should not have, which is 

63 why that input raises rather than classifying. 

64 - `llm` records `f"{provider}:{model}"`, so its recorded refs are an open set 

65 (one per model ever configured) rather than a single constant. A ref 

66 carrying a colon is read as this form; substrate names are bare 

67 identifiers and never carry one. 

68"""

81class Replayability(StrEnum): 

82 """How a decider substrate behaves when its advice is RE-ASKED.""" 

83 

84 REPLAY_SAFE = "replay_safe" 

85 """Advice is a pure function of the evidence, so a re-ask reproduces it.""" 

86 

87 FORWARD_ONLY = "forward_only" 

88 """Advice is not bit-reproducible on re-ask. 

89 

90 DISTINCT from "not recorded" AND from "not resumable": the iteration event 

91 records the brain's advised_next_point and the projection surfaces it, so a 

92 finished run IS reconstructable by READING the recorded trail, and 

93 `conduct_until_advised_from` RESUMES such a run by re-seeding the brain from 

94 the recorded (x, y) history. A substrate stays in this class regardless: the 

95 classifier judges the RE-ASK path. A run is not reclassified replay-safe 

96 because its decisions are recorded or because it can be resumed. Moving a 

97 substrate out of this class would require the RE-ASK itself to become 

98 bit-reproducible. 

99 """ 

100 

101 DELEGATED = "delegated" 

102 """Records no ref of its own; the child brain's ref is what lands. 

103 

104 A composite. Its runs classify per iteration by whichever child decided 

105 each one, so the composite's own name never reaches `is_replay_safe`. 

106 """ 

107 

108 

109SUBSTRATE_REPLAYABILITY: Final[Mapping[DecideSubstrate, Replayability]] = { 

110 "in_memory": Replayability.REPLAY_SAFE, 

111 "grid_walk": Replayability.REPLAY_SAFE, 

112 "sobol": Replayability.REPLAY_SAFE, 

113 "botorch": Replayability.FORWARD_ONLY, 

114 "staged": Replayability.DELEGATED, 

115 "llm": Replayability.FORWARD_ONLY, 

116} 

117"""Every substrate `build_decide_port` can materialise, with its replayability. 

118 

119`in_memory` is seeded by iteration index, `grid_walk` is a pure function of 

120space + observation count, and unscrambled `sobol` is a pure function of space 

121+ draw index, so all three reproduce on re-ask. `botorch` does not: GP fit + 

122acquisition are not bit-reproducible across BLAS / threading / hardware / 

123version. Neither does `llm`: the provider may sample, and an unpinned snapshot 

124may move the model under a caller who never changed a line. `staged` records no 

125ref of its own. 

126 

127Kept equal to `DecideSubstrate` in both directions by 

128`tests/unit/operation/test_decider_replayability.py`. 

129"""

131_LLM_REF_SEPARATOR = ":"

134def _is_llm_ref(model_ref: str) -> bool: 

135 """True if `model_ref` has the `llm` substrate's `provider:model` shape. 

136 

137 Partitions on the FIRST separator only: a provider's model identifier may 

138 itself carry one (`ollama:llama3:8b`), and everything after the provider is 

139 the model. A half-empty ref (`anthropic:` or `:claude-sonnet-4-6`) is NOT 

140 this shape, so it falls through to the unclassified branch and raises 

141 rather than being read as a nameless model. 

142 """ 

143 provider, _, model = model_ref.partition(_LLM_REF_SEPARATOR) 

144 return bool(provider) and bool(model) 

145 

146 

147def replayability_of(model_ref: str) -> Replayability: 

148 """The `Replayability` of the brain that recorded `model_ref`. 

149 

150 Raises `ValueError` for a ref this module cannot place, so an unknown brain 

151 is a loud failure and never a silent assume-safe. `DELEGATED` substrates 

152 raise too: a composite records its child's ref, so its own name appearing on 

153 an iteration is a defect in the composite rather than a classifiable run. 

154 """ 

155 if _is_llm_ref(model_ref): 

156 return SUBSTRATE_REPLAYABILITY["llm"] 

157 

158 replayability = SUBSTRATE_REPLAYABILITY.get(model_ref) # pyright: ignore[reportArgumentType] 

159 if replayability is None: 

160 raise ValueError( 

161 f"unclassified decider model_ref {model_ref!r}; add its substrate to " 

162 "SUBSTRATE_REPLAYABILITY" 

163 ) 

164 if replayability is Replayability.DELEGATED: 

165 raise ValueError( 

166 f"decider model_ref {model_ref!r} names a composite substrate, which " 

167 "records its child brain's ref rather than its own; an iteration " 

168 "carrying it means the composite grew a ref it should not have" 

169 ) 

170 return replayability 

171 

172 

173def is_replay_safe(model_ref: str) -> bool: 

174 """True if a run decided by `model_ref` replays faithfully by re-asking. 

175 

176 Raises `ValueError` for a ref `replayability_of` cannot place. 

177 """ 

178 return replayability_of(model_ref) is Replayability.REPLAY_SAFE 

179 

180 

181def run_is_replay_safe(model_refs: Iterable[str | None]) -> bool: 

182 """True if EVERY iteration's `model_ref` in a run is replay-safe. 

183 

184 `model_refs` is the collection of per-iteration `model_ref` values a run 

185 recorded (None entries, from non-steered or verdict-less iterations, are 

186 ignored). A run is replay-safe only if no iteration was decided by a 

187 forward-only brain, so a staged run that reached its BoTorch phase is 

188 correctly non-replayable while one that stopped during Sobol seeding is 

189 safe. 

190 """ 

191 return all(is_replay_safe(ref) for ref in model_refs if ref is not None)
