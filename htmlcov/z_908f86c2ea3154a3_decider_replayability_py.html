1"""Replayability classification of decider brains by their `model_ref`. 

2 

3The `conduct_until_advised` loop records, per iteration, the `model_ref` of the 

4brain that decided it (on `ProcedureIterationEnded`). The loop's replay- 

5determinism property holds only when that brain is a PURE FUNCTION of the 

6evidence: a replay re-asks the brain and must get the same answer. Some brains 

7satisfy this (the grid walker, the Sobol seeder, the in-memory fake); a GP 

8Bayesian-optimization brain does not, because its fit + acquisition are not 

9bit-reproducible across BLAS / threading / hardware / library versions even 

10with a fixed seed. 

11 

12This module makes that distinction EXPLICIT and machine-checkable rather than 

13leaving it as prose. `is_replay_safe(model_ref)` answers whether a run whose 

14iterations carry that `model_ref` can be faithfully replayed by re-asking the 

15brain. A consumer that replays or resumes a steered run consults it to refuse 

16(or flag) a run that a non-deterministic brain decided, instead of silently 

17re-deriving a divergent history. 

18 

19## Why a classifier, not a per-run event flag (yet) 

20 

21The deciding brain is already on the stream (`ProcedureIterationEnded. 

22model_ref`), so a steered run's replay-safety is derivable from data already 

23recorded; no new event field or loop change is needed to MARK a run. The 

24recorded-decision leg that makes a non-deterministic brain RESUMABLE (record 

25each pass's advised next_point + measured outcome, then re-seed the brain from 

26that record instead of re-asking) is now SHIPPED: `conduct_until_advised_from` 

27re-conditions the brain from the recorded (x, y) history and consults it live 

28only at the open frontier. That does NOT reclassify a GP run as replay-safe: 

29this classifier still judges the RE-ASK path (re-running the brain over the same 

30evidence), which stays non-reproducible for a GP. Resume side-steps the re-ask 

31entirely by replaying the recorded points, so "forward-only" (not 

32re-ask-reproducible) and "resumable" (re-seed-from-record) are now BOTH true of 

33a GP run at once. This classifier remains how a consumer that RE-ASKS tells the 

34two classes apart. 

35 

36## Keep this in lockstep with the deciders 

37 

38Every decider's `_MODEL_REF` constant must appear in exactly one of the two 

39sets below. A fitness test asserts the union covers every shipped decider's 

40`model_ref`, so adding a decider without classifying it fails CI rather than 

41defaulting to a silent (and possibly wrong) replay-safety assumption. 

42""" 

43 

44from __future__ import annotations 

45 

46from typing import TYPE_CHECKING 

47 

48if TYPE_CHECKING: 

49 from collections.abc import Iterable 

50 

51_REPLAY_SAFE_MODEL_REFS = frozenset( 

52 { 

53 "in_memory", # the deterministic fake: advice is seeded by iteration index 

54 "grid_walk", # pure function of space + observation count 

55 "sobol", # unscrambled Sobol: pure function of space + draw index 

56 } 

57) 

58"""`model_ref`s whose advice is a pure function of the evidence. 

59 

60A run decided entirely by these brains replays faithfully by re-asking the 

61brain, so it carries the conduct loop's replay-determinism property. 

62""" 

63 

64_FORWARD_ONLY_MODEL_REFS = frozenset( 

65 { 

66 "botorch", # GP fit + acquisition: not bit-reproducible across environments 

67 } 

68) 

69"""`model_ref`s whose advice is NOT bit-reproducible on RE-ASK. 

70 

71"forward-only" here means NOT re-ask-reproducible -- re-running the brain over 

72the same evidence may diverge (GP fit + acquisition are not bit-reproducible 

73across BLAS / threading / hardware / version). It is DISTINCT from "not 

74recorded" AND from "not resumable": TIER-1 replay records the brain's 

75advised_next_point on the iteration event + surfaces it in the iteration 

76projection, so a finished GP-steered run IS reconstructable by READING the 

77recorded trail; and `conduct_until_advised_from` now RESUMES such a run by 

78re-seeding the brain from the recorded (x, y) history (re-seed, not re-ask). 

79botorch STAYS in this set regardless: the classifier judges the RE-ASK path, 

80which is still non-reproducible. A run is not reclassified replay-safe because 

81its decisions are recorded or because it can be resumed; re-seed-from-record 

82side-steps the re-ask rather than making the re-ask reproducible. Flipping a 

83ref to replay-safe would require the RE-ASK itself to become bit-reproducible, 

84which a GP's fit + acquisition are not. 

85""" 

86 

87_CLASSIFIED_MODEL_REFS = _REPLAY_SAFE_MODEL_REFS | _FORWARD_ONLY_MODEL_REFS 

88 

89 

90def is_replay_safe(model_ref: str) -> bool: 

91 """True if a run decided by `model_ref` replays faithfully by re-asking. 

92 

93 Raises `ValueError` for an unclassified `model_ref` so an unknown brain is 

94 a loud failure, never a silent assume-safe. The staged composite never 

95 appears here: it records the CHILD brain's `model_ref` on each iteration 

96 (it adds no `model_ref` of its own), so a staged run's iterations classify 

97 individually (its Sobol passes are safe, its BoTorch passes are not). 

98 """ 

99 if model_ref not in _CLASSIFIED_MODEL_REFS: 

100 raise ValueError( 

101 f"unclassified decider model_ref {model_ref!r}; add it to " 

102 "_REPLAY_SAFE_MODEL_REFS or _FORWARD_ONLY_MODEL_REFS" 

103 ) 

104 return model_ref in _REPLAY_SAFE_MODEL_REFS 

105 

106 

107def run_is_replay_safe(model_refs: Iterable[str | None]) -> bool: 

108 """True if EVERY iteration's `model_ref` in a run is replay-safe. 

109 

110 `model_refs` is the collection of per-iteration `model_ref` values a run 

111 recorded (None entries, from non-steered or verdict-less iterations, are 

112 ignored). A run is replay-safe only if no iteration was decided by a 

113 forward-only brain, so a staged run that reached its BoTorch phase is 

114 correctly non-replayable while one that stopped during Sobol seeding is 

115 safe. 

116 """ 

117 return all(is_replay_safe(ref) for ref in model_refs if ref is not None) 

118 

119 

120__all__ = [ 

121 "is_replay_safe", 

122 "run_is_replay_safe", 

123]
