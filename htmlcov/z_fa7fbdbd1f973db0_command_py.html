1"""The `RotateSealOnlineKey` command: intent dataclass for this slice. 

2 

3`facility_id` selects the Seal singleton; `new_online_credential_id` is the 

4fresh Credential.id to install in the online (warm) slot. The principal 

5id of the invoker is supplied separately by the application handler at 

6call time and stamped onto `SealOnlineKeyRotated` as 

7`rotated_by_actor_id`. 

8 

9Rotation is a security-touching action (the offline root authorises a 

10warm-key swap, typically in response to suspected compromise or planned 

11rollover): the slice writes the domain event AND a paired 

12`DecisionRegistered` audit on the Decision BC stream in one transaction, 

13matching the `register_credential` / `revoke_credential` cross-BC 

14pattern. 

15 

16Strict-not-idempotent at the decider: rotating against a Republishing 

17Seal raises `SealCannotRotateError` (HTTP 409); rotating to the same 

18ref the slot already holds raises `SealCannotRotateError` (no-op 

19rotations are rejected so the audit gesture is always meaningful); 

20rotating to a ref equal to `offline_credential_id` raises 

21`SealKeyCollisionError` (HTTP 422) via the `_key_separation` helper. 

22""" 

23 

24from dataclasses import dataclass 

25from uuid import UUID 

26 

27 

28@dataclass(frozen=True) 

29class RotateSealOnlineKey: 

30 """Operator rotates the Seal singleton's online (warm) signing key. 

31 

32 Source state Live (Republishing is rejected). The new ref must 

33 differ from both the current online ref (no-op rotation rejected) 

34 and the current offline ref (key-separation invariant). The 

35 referenced Credential's purpose binding is checked at a future 

36 stage; today the slice accepts the ref opaquely per the eventual- 

37 consistency carve-out documented in 

38 [[project_federation_port_design]]. 

39 

40 `signed_by_offline_root` is the operator's affirmation that the 

41 offline (cold) root authorised this rotation. Required (no default) 

42 because the audit gesture is security-meaningful: the SOC must be 

43 able to scrub the Decision-BC stream and distinguish ceremonies 

44 where the offline root countersigned from those where it did not. 

45 """
