1"""Policy aggregate state, value objects, domain errors, and pure evaluation. 

2 

3Per ISA-99, a Policy is an authorization rule attached to a specific 

4Conduit: it answers "may principal P issue command C via this 

5Conduit". The Policy aggregate's `evaluate` function is the pure 

6domain-level Policy Decision Point; the `TrustAuthorize` infra 

7adapter wires it behind the cross-BC `Authorize` port. 

8 

9Policy is intentionally minimal: 

10 - `id` + `name` 

11 - `conduit_id` — the single Conduit this policy governs (one 

12 policy per conduit; cross-policy resolution is the 

13 `TrustAuthorize` adapter's problem) 

14 - `permitted_principal_ids: frozenset[UUID]` — explicit allow-list 

15 - `permitted_commands: frozenset[str]` — command-name allow-list 

16 (matches the discriminator string used by the Authorize port and 

17 the `event_type_name` everywhere else) 

18 

19Frozensets in domain state (deduplicated, hashable, set-membership 

20in O(1) for `evaluate`); plain lists in event payloads (JSON-friendly, 

21sorted for determinism). The evolver bridges the two. 

22 

23Status lifecycle (`Drafted → Approved → Active → Superseded`, per 

24BC-map) and modify/revoke slices defer to later sub-phases per the 

25same additive-state pattern as Zone and Conduit. 

26 

27**No referential integrity at command time.** `conduit_id` and 

28each entry in `permitted_principal_ids` are stored as bare UUIDs 

29without verifying the referenced Conduits / Actors exist. Same 

30event-sourcing posture as Conduit→Zone: typos produce 

31"dangling" policies; downstream evaluation just denies because 

32the conduit_id mismatch surfaces at evaluate-time. 

33 

34Empty `permitted_principal_ids` or empty `permitted_commands` is 

35allowed and produces a deny-all policy by construction (every 

36evaluation hits the "not in {empty}" branch). Useful for 

37temporarily revoking access without deleting the policy. 

38""" 

39

68class InvalidPolicySurfaceError(ValueError): 

69 """A new Policy must bind a real Surface; the nil sentinel is rejected. 

70 

71 The nil `surface_id` sentinel survives only on the immutable V1 

72 bootstrap seed stream (folded by `from_stored`). New policies must 

73 bind a concrete Surface so `evaluate` can strict-match the arrival 

74 surface; a nil-surface policy denies every real-surface call. 

75 """ 

76 

77 def __init__(self) -> None: 

78 super().__init__( 

79 "Policy surface_id must bind a real Surface " 

80 "(the nil sentinel is reserved for the retired V1 fold)" 

81 )

85@dataclass(frozen=True) 

86class PolicyName: 

87 """Display name for a policy. Trimmed; 1-200 chars. 

88 

89 Uses the shared `@bounded_name` decorator from 

90 `cora.shared.bounded_text`. 

91 """ 

92 

93 value: str 

94 

95 

96@dataclass(frozen=True) 

97class Policy: 

98 """Aggregate root: an authorization rule attached to a Conduit + Surface pair. 

99 

100 `surface_id`: the process-level arrival point this policy gates. 

101 `evaluate` strict-matches it against the call's arrival surface. 

102 The nil sentinel survives only on the immutable V1 bootstrap seed 

103 stream (folded by `from_stored`); such a policy strict-denies every 

104 real-surface call and is therefore operationally inert. The 

105 canonical bootstrap policy binds to the seeded HTTP Surface, and new 

106 policies must bind a concrete Surface (`define_policy` rejects nil). 

107 """ 

108 

109 id: UUID 

110 name: PolicyName 

111 conduit_id: UUID 

112 permitted_principal_ids: frozenset[UUID] 

113 permitted_commands: frozenset[str] 

114 surface_id: UUID = NIL_SENTINEL_ID 

115 

116 

117def evaluate( 

118 policy: Policy, 

119 *, 

120 principal_id: UUID, 

121 command_name: str, 

122 conduit_id: UUID, 

123 surface_id: UUID = NIL_SENTINEL_ID, 

124) -> AuthzResult: 

125 """Pure Policy Decision Point: does `policy` permit (principal, command, conduit, surface)? 

126 

127 Returns `Allow()` or `Deny(reason=...)`. The reason string is 

128 diagnostic — meant to flow into structlog / API responses for 

129 debugging, not for end-user display. Check order is cheapest- 

130 first: conduit mismatch → surface mismatch → principal not in 

131 set → command not in set. 

132 

133 Surface matching is strict equality. A policy that folded to a nil 

134 `surface_id` (the immutable V1 bootstrap seed is the only such 

135 stream) never matches a real arrival surface, so it strict-denies 

136 every live call and is operationally inert. The nil-as-wildcard 

137 legacy-fold shim was removed once the V1 bootstrap policy was 

138 retired in favor of the surface-bound bootstrap policy; new 

139 policies must bind a concrete Surface (`define_policy` rejects nil 

140 via `InvalidPolicySurfaceError`). 

141 

142 Living in `state.py` because it's a pure operation on Policy 

143 state (no I/O, no awaits, no mutation). 

144 """ 

145 if conduit_id != policy.conduit_id: 

146 return Deny( 

147 reason=(f"Policy {policy.id} governs conduit {policy.conduit_id}, not {conduit_id}") 

148 ) 

149 if surface_id != policy.surface_id: 

150 return Deny( 

151 reason=(f"Policy {policy.id} governs surface {policy.surface_id}, not {surface_id}") 

152 ) 

153 if principal_id not in policy.permitted_principal_ids: 

154 return Deny(reason=f"Principal {principal_id} not in policy {policy.id}'s permitted set") 

155 if command_name not in policy.permitted_commands: 

156 return Deny(reason=(f"Command {command_name!r} not in policy {policy.id}'s permitted set")) 

157 return Allow()
