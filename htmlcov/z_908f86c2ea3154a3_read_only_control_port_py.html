1"""Fail-closed write guards for a ControlPort a deployment declares unwritable. 

2 

3Two guards, one per surface, because #568 gave the `ControlPortRegistry` 

4two: `ReadOnlyControlPort` wraps a `str`-surfaced `ControlPort` (the 

5`InMemoryControlPort`, and the empty-routes bare port), and 

6`ReadOnlySubstratePort` wraps a typed `SubstrateControlPort[AddressT]` 

7(the real EPICS / Tango adapters, which #568 handed a parsed 

8`ControlAddress` rather than a raw string). Both refuse every write and 

9forward `read` / `subscribe` / `aclose` to the adapter underneath. 

10`build_control_port` is their only construction site: it wraps each 

11per-route adapter BEFORE handing it to the registry, so the guard sits 

12between the registry and the substrate. 

13 

14The two differ only in the address type their surface takes; every 

15argument on the docstrings below applies verbatim to both. 

16 

17## Why refuse rather than consult a flag 

18 

19The guard carries no routing table and asks no question at write time. 

20It refuses unconditionally, because the decision was already made when 

21`build_control_port` chose to construct it. A wrapped adapter cannot 

22be talked into a write; an unwrapped one was never guarded. There is 

23no third state, and so no arm to get wrong. 

24 

25That is the whole point. The sibling route fact `is_simulated` is a 

26runtime QUERY with a three-valued answer: the Conductor's 

27`_ActuationObserver` reaches it across the `ControlPort` Protocol via 

28`getattr(inner, "route_is_simulated", None)`, and absent silently 

29means "gate inactive". That fails OPEN, which `is_simulated` survives 

30only because a downstream guard refuses to promote a Dataset of 

31unknown provenance. A write gate has no such compensator, so it must 

32not be built that way. 

33 

34## Why below the registry, not around it 

35 

36Wrapping the whole registry would satisfy the same Protocol and be 

37simpler, and it would be wrong twice over: 

38 

39 - it would hide `route_is_simulated` from `_ActuationObserver`'s 

40 `getattr`, silently disabling the Dataset provenance gate; 

41 - it would hide `aclose` from the lifespan's teardown call. 

42 

43Wrapping per-adapter leaves the registry's own surface intact and 

44still intercepts every modeled write, because the registry hands the 

45naked adapter to nobody: `route()` is called only from the registry's 

46own `read` / `write` / `subscribe`. 

47 

48## The aclose delegation is load-bearing 

49 

50`ControlPortRegistry.aclose` fans out with 

51`getattr(port, "aclose", None)` and SKIPS any adapter that lacks the 

52method. A guard without `aclose` would therefore strand every EPICS 

53connection it wraps: a fail-open in the LIFECYCLE rather than in the 

54gate. `aclose` below is not boilerplate; deleting it leaks sockets. 

55 

56## Scope 

57 

58`scope` records WHICH declaration refused, so an operator reading a 

59traceback knows whether to change an env var or a route entry: 

60 

61 - `"deployment"`: `CONTROL_WRITES_ENABLED=false`, the observe-only 

62 safety switch, applied to every route with no exemption. 

63 - `"route"`: this one route carries `ControlPortRoute.read_only`. 

64"""

83class ReadOnlyControlPort: 

84 """A `ControlPort` that observes its inner adapter but never drives it. 

85 

86 Implements `ControlPort` structurally by delegating `read` and 

87 `subscribe`; `write` always raises `ControlWritesDisabledError`. 

88 """ 

89 

90 def __init__( 

91 self, 

92 inner: ControlPort, 

93 *, 

94 scope: Literal["deployment", "route"], 

95 prefix: str | None = None, 

96 ) -> None: 

97 self._inner = inner 

98 self._scope: Literal["deployment", "route"] = scope 

99 self._prefix = prefix 

100 

101 async def read(self, address: str) -> Measurement: 

102 return await self._inner.read(address) 

103 

104 async def write( 

105 self, 

106 address: str, 

107 value: int | float | bool | str | tuple[Any, ...], 

108 *, 

109 wait: bool = True, 

110 timeout_s: float = 30.0, 

111 ) -> None: 

112 """Refuse the write. No substrate is contacted. 

113 

114 Signature mirrors `ControlPort.write` so the guard substitutes 

115 for the adapter it wraps; every argument but `address` is 

116 deliberately unused, because nothing downstream of here runs. 

117 """ 

118 raise ControlWritesDisabledError(address, scope=self._scope, prefix=self._prefix) 

119 

120 def subscribe(self, address: str) -> AsyncIterator[Measurement]: 

121 return self._inner.subscribe(address) 

122 

123 async def aclose(self) -> None: 

124 """Close the wrapped adapter. See the module docstring: load-bearing.""" 

125 close = getattr(self._inner, "aclose", None) 

126 if close is None: 

127 return 

128 await close()

131class ReadOnlySubstratePort:
