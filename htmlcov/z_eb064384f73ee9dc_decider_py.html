1"""Pure decider for the ``RecordAttestation`` command. 

2 

3Pure function: given the (always None) Attestation state, a 

4``RecordAttestation`` command, and a pre-loaded 

5``AttestationRecordingContext``, returns the events to append. No I/O, 

6no awaits, no side effects. 

7 

8``now`` and ``new_id`` are injected by the application handler from the 

9Clock and IdGenerator ports. 

10 

11## Firing order 

12 

13Per [[project_data_attestation_design]] L15 (re-stated here so the 

14order is local-and-greppable on the decider source): 

15 

16 1. Pydantic 422 boundary parse-shape (off-decider). 

17 2. VO field validation: ``AttestationKind``, ``AttestationOutcome``, 

18 ``ChecksumVerifiedEvidence.__post_init__`` raise 

19 ``Invalid*Error``. 

20 3. Defensive kind/outcome closed-enum re-check (in-process callers 

21 bypassing the boundary). 

22 4. Authorize port -> ``UnauthorizedError`` (handler-tier; BEFORE 

23 event-store reads). 

24 5. ``AttestationKindNotYetSupportedError`` if kind is not 

25 ``ChecksumVerified`` (handler-tier). 

26 6. Pure-command kind/distribution_id gating -> 

27 ``AttestationKindRequiresDistributionError`` / 

28 ``AttestationKindRejectsDistributionError``. 

29 7. Pure-command evidence-shape vs kind (covered by VO validation 

30 today since only one concrete kind exists; the discriminator is 

31 the kind itself). 

32 8. Pure-command outcome-evidence cross-validation 

33 (``ChecksumVerifiedEvidence`` invariants: Match/Mismatch require 

34 computed_checksum non-None; Unreachable requires computed_checksum 

35 None and error_detail non-None). 

36 9. State-is-None genesis guard -> ``AttestationAlreadyExistsError``. 

37 10. (handler) Dataset pre-load -> ``DatasetNotFoundError``. 

38 11. (handler) Distribution pre-load (only if ``distribution_id`` set) 

39 -> ``AttestationDistributionNotFoundError``. 

40 12. Distribution.dataset_id equality vs command.dataset_id -> 

41 ``AttestationDistributionDatasetMismatchError``. 

42 12b. ``context.distribution.checksum.algorithm == 'sha256-tree'`` -> 

43 ``AttestationTreeChecksumNotYetSupportedError`` (the whole-file 

44 verifier cannot verify a directory digest; deferred). 

45 13. Belt-and-braces checksum comparison: ``kind=ChecksumVerified`` 

46 AND ``outcome=Match`` AND ``evidence.computed_checksum != 

47 context.distribution.checksum.value`` -> 

48 ``AttestationChecksumEvidenceMismatchError``. 

49 14. (handler) Scheme dispatch + ``ChecksumVerifier.verify()`` run in the 

50 handler, which assembles this ``AttestationRecordingInput`` from the 

51 computed result; the decider takes its evidence as authoritative 

52 (the cross-checks above are defense-in-depth for an in-process bypass). 

53 15. Emit ``AttestationRecorded``. 

54"""

83#: Closed set of kinds that require a non-None distribution_id (byte- 

84#: level kinds). ``ConformsToValidated`` is the only kind outside this 

85#: set and is gated by ``_KINDS_REJECTING_DISTRIBUTION``. 

86_KINDS_REQUIRING_DISTRIBUTION: frozenset[AttestationKind] = frozenset( 

87 { 

88 AttestationKind.CHECKSUM_VERIFIED, 

89 AttestationKind.FORMAT_VALIDATED, 

90 AttestationKind.BIT_ROT_CHECKED, 

91 } 

92) 

93 

94#: Closed set of kinds that forbid a distribution_id (profile claims 

95#: about logical Dataset content, scope-orthogonal to byte copies). 

96_KINDS_REJECTING_DISTRIBUTION: frozenset[AttestationKind] = frozenset( 

97 {AttestationKind.CONFORMS_TO_VALIDATED} 

98)

101def decide( 

102 state: Attestation | None, 

103 command: AttestationRecordingInput, 

104 *, 

105 context: AttestationRecordingContext, 

106 now: datetime, 

107 new_id: UUID, 

108 attested_by: ActorId, 

109) -> list[AttestationRecorded]: 

110 """Decide the events produced by recording a new Attestation fact. 

111 

112 Invariants: 

113 (Firing order per [[project_data_attestation_design]] L15.) 

114 - kind must be in the closed AttestationKind enum 

115 -> InvalidAttestationKindError 

116 - outcome must be in the closed AttestationOutcome enum 

117 -> InvalidAttestationOutcomeError 

118 - kind in {ChecksumVerified, FormatValidated, BitRotChecked} 

119 requires distribution_id 

120 -> AttestationKindRequiresDistributionError 

121 - kind=ConformsToValidated forbids distribution_id 

122 -> AttestationKindRejectsDistributionError 

123 - Today only kind=ChecksumVerified is implemented 

124 (handler-tier rejection re-checked defensively here) 

125 -> AttestationKindNotYetSupportedError 

126 - ChecksumVerifiedEvidence VO shape must validate 

127 -> InvalidAttestationEvidenceError 

128 - outcome=Match requires evidence.computed_checksum non-None 

129 -> InvalidAttestationEvidenceError 

130 - outcome=Mismatch requires evidence.computed_checksum non-None 

131 -> InvalidAttestationEvidenceError 

132 - outcome=Unreachable requires evidence.computed_checksum None 

133 AND evidence.error_detail non-None 

134 -> InvalidAttestationEvidenceError 

135 - state must be None (genesis-only) 

136 -> AttestationAlreadyExistsError 

137 - context.distribution.dataset_id must equal context.dataset.id 

138 when distribution_id is set 

139 -> AttestationDistributionDatasetMismatchError 

140 - context.distribution.checksum.algorithm must not be 'sha256-tree' 

141 (the directory verifier is deferred) 

142 -> AttestationTreeChecksumNotYetSupportedError 

143 - Belt-and-braces: outcome=Match AND evidence.computed_checksum 

144 != context.distribution.checksum.value 

145 -> AttestationChecksumEvidenceMismatchError 

146 """ 

147 # Step 2: VO field validation - kind / outcome closed enums. 

148 try: 

149 kind = AttestationKind(command.kind) 

150 except ValueError as exc: 

151 raise InvalidAttestationKindError(command.kind) from exc 

152 try: 

153 outcome = AttestationOutcome(command.outcome) 

154 except ValueError as exc: 

155 raise InvalidAttestationOutcomeError(command.outcome) from exc 

156 

157 # Step 6: Pure-command kind/distribution_id gating. Runs BEFORE 

158 # evidence VO construction so the operator-facing error names the 

159 # specific failure (missing/extra distribution_id) rather than a 

160 # downstream evidence-shape symptom. 

161 if kind in _KINDS_REQUIRING_DISTRIBUTION and command.distribution_id is None: 

162 raise AttestationKindRequiresDistributionError(kind.value) 

163 if kind in _KINDS_REJECTING_DISTRIBUTION and command.distribution_id is not None: 

164 raise AttestationKindRejectsDistributionError(kind.value) 

165 

166 # Step 2 (cont'd): construct the discriminated evidence VO. Today 

167 # only the ChecksumVerified arm is concrete; the 

168 # AttestationKindNotYetSupportedError check runs at the handler 

169 # tier before the decider sees the command, so we can assume 

170 # ChecksumVerified here. 

171 if kind is not AttestationKind.CHECKSUM_VERIFIED: 

172 # Defensive guard: the handler tier should have rejected 

173 # non-ChecksumVerified kinds before reaching the decider; if a 

174 # test bypasses the handler we raise the same NotYetSupported 

175 # error rather than fall through to a half-built evidence path. 

176 from cora.data.aggregates.attestation import ( 

177 AttestationKindNotYetSupportedError, 

178 ) 

179 

180 raise AttestationKindNotYetSupportedError(kind.value) 

181 

182 evidence = ChecksumVerifiedEvidence( 

183 expected_checksum=command.evidence_expected_checksum, 

184 computed_checksum=command.evidence_computed_checksum, 

185 algorithm=command.evidence_algorithm, 

186 verifier_supply_id=command.evidence_verifier_supply_id, 

187 verifier_kind=command.evidence_verifier_kind, 

188 error_detail=command.evidence_error_detail, 

189 ) 

190 

191 # Step 8: outcome-evidence cross-validation. The ChecksumVerified 

192 # arm requires computed_checksum non-None on Match/Mismatch and 

193 # None on Unreachable. The matching error_detail invariant is the 

194 # mirror (Unreachable MUST carry an error_detail; Match/Mismatch 

195 # SHOULD NOT but are not gated since a verifier may carry context 

196 # on either outcome for forensic purposes). 

197 if outcome is AttestationOutcome.MATCH and evidence.computed_checksum is None: 

198 raise InvalidAttestationEvidenceError( 

199 "outcome=Match requires evidence.computed_checksum to be non-None" 

200 ) 

201 if outcome is AttestationOutcome.MISMATCH and evidence.computed_checksum is None: 

202 raise InvalidAttestationEvidenceError( 

203 "outcome=Mismatch requires evidence.computed_checksum to be non-None" 

204 ) 

205 if outcome is AttestationOutcome.UNREACHABLE: 

206 if evidence.computed_checksum is not None: 

207 raise InvalidAttestationEvidenceError( 

208 "outcome=Unreachable requires evidence.computed_checksum to be None" 

209 ) 

210 if evidence.error_detail is None: 

211 raise InvalidAttestationEvidenceError( 

212 "outcome=Unreachable requires evidence.error_detail to be non-None" 

213 ) 

214 

215 # Step 9: State-is-None genesis guard. 

216 if state is not None: 

217 raise AttestationAlreadyExistsError(state.id) 

218 

219 # Step 12: Distribution.dataset_id equality (only when a Distribution 

220 # was loaded; the handler enforces the distribution_id-set -> 

221 # context.distribution-non-None contract). 

222 if context.distribution is not None: 222 ↛ 255line 222 didn't jump to line 255 because the condition on line 222 was always true

223 if context.distribution.dataset_id != context.dataset.id: 

224 raise AttestationDistributionDatasetMismatchError( 

225 distribution_id=context.distribution.id, 

226 expected_dataset_id=context.dataset.id, 

227 actual_dataset_id=context.distribution.dataset_id, 

228 ) 

229 # Step 12b: refuse to verify a directory (sha256-tree) Distribution. 

230 # The shipped verifier hashes a whole file; a tree digest is a 

231 # manifest hash, so whole-file evidence would Match-fail (caught 

232 # below) on Match but, worse, record a false Mismatch on 

233 # outcome=Mismatch, flipping the Distribution to Stale. Refuse 

234 # outright until the directory ChecksumVerifier ships (deferred). 

235 if context.distribution.checksum.algorithm == DATASET_CHECKSUM_ALGORITHM_SHA256_TREE: 

236 raise AttestationTreeChecksumNotYetSupportedError( 

237 distribution_id=context.distribution.id, 

238 algorithm=context.distribution.checksum.algorithm, 

239 ) 

240 # Step 13: belt-and-braces checksum comparison. Only meaningful 

241 # for ChecksumVerified Match (false-Match is the downstream- 

242 # visible failure mode; false-Mismatch is operator-visible but 

243 # does not silently flip Distribution.status to Verified). 

244 if ( 

245 outcome is AttestationOutcome.MATCH 

246 and evidence.computed_checksum != context.distribution.checksum.value 

247 ): 

248 raise AttestationChecksumEvidenceMismatchError( 

249 distribution_id=context.distribution.id, 

250 canonical_checksum=context.distribution.checksum.value, 

251 evidence_checksum=evidence.computed_checksum, 

252 ) 

253 

254 # Step 15: emit AttestationRecorded with primitives on the payload. 

255 return [ 

256 AttestationRecorded( 

257 attestation_id=new_id, 

258 dataset_id=command.dataset_id, 

259 distribution_id=command.distribution_id, 

260 kind=kind.value, 

261 outcome=outcome.value, 

262 evidence=build_checksum_verified_evidence_payload(evidence), 

263 occurred_at=now, 

264 attested_by=attested_by, 

265 ) 

266 ]
