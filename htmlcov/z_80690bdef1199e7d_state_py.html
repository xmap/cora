1"""Distribution aggregate state, value objects, status enum, and domain errors. 

2 

3A `Distribution` is a materialized byte-copy of a logical `Dataset` at a 

4storage `Supply`. Same scientific content as the Dataset, possibly 

5different format/location/access protocol. DCAT-3 `dcat:Distribution` 

6primitive imported directly. 

7 

8## What a Distribution is 

9 

10 - A specific byte-copy of a Dataset's content at a specific Supply 

11 - Has its own identity (`id`) distinct from the parent Dataset 

12 - Carries the same checksum + byte_size + encoding as the parent 

13 Dataset by invariant (byte-identical copy semantics; the decider 

14 enforces equality at registration per [[project-data-distribution-design]] 

15 L10 + L11) 

16 - Knows where the bytes live (uri + access_protocol) 

17 

18## What a Distribution is NOT 

19 

20 - Not the bytes (those live at the URI inside the Supply per 

21 [[project-data-territory-design]] L5) 

22 - Not the logical Dataset (Dataset is the content-identity tier; 

23 Distribution is the materialization tier; Fixture is to Assembly 

24 what Distribution is to Dataset) 

25 - Not an Edition (Edition is the publication-package tier; 

26 different aggregate per territory L1) 

27 - Not an Attestation (Attestation is the verify/format/bit-rot 

28 fact-chain; different aggregate per territory L7) 

29 

30## Reused VOs 

31 

32`DatasetChecksum` and `DatasetEncoding` are imported from the Dataset 

33aggregate and reused verbatim per [[project-data-distribution-design]] 

34L8. A Distribution's checksum/encoding are byte-identical to its 

35parent Dataset's; defining parallel VOs would duplicate identical 

36invariants and invite drift. 

37 

38## New VOs 

39 

40`DistributionUri` is a fresh class (per L7) with the same shape as 

41`DatasetUri` but distinct type identity: `Dataset.uri` is becoming 

42a denormalized convenience pointer to a canonical Distribution per 

43territory L5, while `Distribution.uri` carries the authoritative 

44value. Sharing a single VO type would obscure that asymmetry. 

45 

46`AccessProtocol` is a closed `StrEnum` carrying the transport family 

47of the URI (HTTPS, Globus, S3, POSIX, NFS, OAI_PMH). All six values 

48land day-one per L5 even though only HTTPS + POSIX are pilot-validated 

49today; closed-not-open because each transport needs an adapter 

50before bytes can be moved or verified at that protocol. 

51 

52`DistributionStatus` is a closed `StrEnum` carrying the 4-state 

53lifecycle (Registered, Verified, Stale, Discarded). All four land 

54day-one per L4 even though only Registered is reachable today 

55(genesis only); the Verified/Stale/Discarded transitions ship in 

56follow-on slices but the StrEnum and the nullable transition 

57attribution fields are present from the start (additive-state 

58pattern; matches `register_dataset` + Supply Slice 7B precedent). 

59 

60## Verified/Stale flip is a projection, not an aggregate event 

61 

62Per territory L7 + Distribution memo L7: `Distribution.status` flips 

63to `Verified` on `AttestationRecorded(kind=ChecksumVerified, 

64outcome=Match)` and to `Stale` on `outcome=Mismatch`. The flip is 

65projection-only (writer-side, no Distribution event emitted); the 

66Attestation aggregate carries the underlying fact. Distribution's 

67own state stream stays free of read-model feedback. 

68"""

397@dataclass(frozen=True) 

398class DistributionUri: 

399 """Opaque URI string pointing at the bulk content for this Distribution. 

400 

401 Trimmed; 1-2048 chars. Loose validation: `urllib.parse.urlparse` 

402 must return a non-empty scheme. XSS blocklist applied (shared 

403 with `DatasetUri.value` blocklist; same threat surface). 

404 

405 Distinct type identity from `DatasetUri` per L7: `Dataset.uri` is 

406 becoming a denormalized convenience pointer to a canonical 

407 Distribution per territory L5, while `Distribution.uri` carries 

408 the authoritative byte-location. Sharing a single VO type would 

409 obscure that asymmetry. 

410 

411 Bytes resolution / existence check is out of scope at the BC 

412 layer (mirrors `DatasetUri`); periodic re-checksum / verification 

413 is its own future workflow per the Attestation aggregate. 

414 """ 

415 

416 value: str 

417 

418 def __post_init__(self) -> None: 

419 trimmed = _validate_storage_uri( 

420 self.value, 

421 max_length=DISTRIBUTION_URI_MAX_LENGTH, 

422 error_factory=InvalidDistributionUriError, 

423 ) 

424 object.__setattr__(self, "value", trimmed)

446@dataclass(frozen=True) 

447class Distribution: 

448 """Aggregate root: one materialized byte-copy of a Dataset at a Supply. 

449 

450 Frozen dataclass. The 9 core intrinsic + binding fields are set 

451 at genesis and immutable thereafter. The 7 transition attribution 

452 fields default to None and are populated by future-slice evolver 

453 arms (additive-state pattern; matches Dataset + Asset + Supply 

454 precedent for forward-compat on legacy event streams). 

455 

456 Status FSM (per L4): 

457 Registered -> Verified -> Stale -> Discarded 

458 

459 All four StrEnum values declared day-one even though only 

460 Registered is reachable today. The Verified flip is 

461 projection-only (Attestation Slice C); the Stale and Discarded 

462 transitions ship in follow-on slices. 

463 

464 DatasetChecksum and DatasetEncoding reused verbatim from the 

465 Dataset aggregate per L8 (byte-identical copy semantics). 

466 """
