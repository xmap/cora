1"""Bind the arrival Surface identity to structlog contextvars. 

2 

3`BearerAuthMiddleware` resolves the arrival Surface UUID from the 

4request path (see `_resolve_expected_audience` in 

5`cora.infrastructure.auth.bearer_auth_middleware`) so the verifier can 

6audience-bind. The SAME identity is also a missing observability 

7dimension: every log line emitted inside the request body should carry 

8`surface_id` + `surface_kind` so operators can pivot from a single log 

9record to "which arrival surface produced this". 

10 

11The two-pass model is intentional: 

12 

13 - Domain pass (load-bearing): `surface_id` flows through handler 

14 function arguments and into `deps.authz.authorize(...)`. Authz 

15 reads from the function arg, NOT from structlog contextvars. 

16 - Observability pass (this module): structlog contextvars carry the 

17 same identity for every log line in the request. Pure-additive log 

18 dimension; does NOT replace the domain pass. 

19 

20## Binding seam 

21 

22The middleware calls `bind_surface_context` once per request (after 

23the unauthenticated-path skip, before any downstream work) and 

24`clear_surface_context` in a `finally` block. Same asyncio task = 

25same contextvars scope; the try/finally guarantees no leakage even 

26if a downstream handler raises. 

27 

28## MCP_STDIO is intentionally out of scope here 

29 

30stdio MCP servers do not flow through the HTTP middleware (separate 

31subprocess transport). Their observability binding would land at the 

32FastMCP server entrypoint, not here. The kind map below excludes 

33`SYSTEM_MCP_STDIO_SURFACE_ID` for that reason; an HTTP request that 

34somehow resolved to the stdio Surface is a deploy-time bug, not a 

35missing observability case. 

36 

37## Why the kind values are local string literals 

38 

39The authoritative `SurfaceKind` StrEnum lives in 

40`cora.trust.aggregates.surface.surface_kind`. Tach forbids 

41`cora.infrastructure` from importing `cora.trust.aggregates` (BC 

42isolation: infrastructure must stay BC-agnostic). The kind literals 

43below mirror the enum's `.value` strings; the architecture fitness 

44`test_surface_context_binding.py` cross-checks that the mirrored 

45values stay aligned with the StrEnum's values. 

46""" 

47

67SURFACE_KIND_HTTP = "http" 

68SURFACE_KIND_MCP_STREAMABLE_HTTP = "mcp_streamable_http"

71class UnknownSurfaceError(LookupError): 

72 """Raised when a Surface UUID has no kind mapping. 

73 

74 Loud-fail by design: a new Surface UUID seeded without an entry 

75 in `_SURFACE_KIND_BY_UUID` is a deploy-time bug. Silent fallback 

76 to a sentinel kind would let the observability dimension drift 

77 out of step with the seeded Surfaces. 

78 """ 

79 

80 

81_SURFACE_KIND_BY_UUID: dict[UUID, str] = { 

82 SYSTEM_HTTP_SURFACE_ID: SURFACE_KIND_HTTP, 

83 SYSTEM_MCP_STREAMABLE_HTTP_SURFACE_ID: SURFACE_KIND_MCP_STREAMABLE_HTTP, 

84} 

85"""HTTP-reachable Surface UUID to kind-string map. 

86 

87`SYSTEM_MCP_STDIO_SURFACE_ID` is intentionally absent: stdio MCP is a 

88subprocess transport, never reachable via the HTTP middleware. Any 

89future HTTP-reachable Surface (A2A, gRPC bridge, etc.) lands here 

90when its UUID is seeded. 

91""" 

92 

93 

94def surface_kind_for(surface_id: UUID) -> str: 

95 """Return the kind string for a known HTTP-reachable Surface UUID. 

96 

97 Raises `UnknownSurfaceError` when the UUID is not in the map. 

98 The middleware passes the resolved expected-audience UUID, which 

99 today is always one of the two HTTP-reachable system Surfaces; 

100 a mismatch indicates the seed migration and this map drifted. 

101 """ 

102 kind = _SURFACE_KIND_BY_UUID.get(surface_id) 

103 if kind is None: 

104 raise UnknownSurfaceError( 

105 f"No SurfaceKind mapping for surface_id={surface_id}. " 

106 "Add the UUID to _SURFACE_KIND_BY_UUID when a new Surface " 

107 "is seeded into HTTP-reachable routing." 

108 ) 

109 return kind

112def bind_surface_context(surface_id: UUID, surface_kind: str) -> None: 

113 """Bind `surface_id` + `surface_kind` to structlog contextvars. 

114 

115 Stringifies the UUID so the structlog `JSONRenderer` emits stable, 

116 log-aggregator-indexable shapes. Pairs with `clear_surface_context()` 

117 in a `try/finally` at the middleware seam. 

118 """ 

119 structlog.contextvars.bind_contextvars( 

120 surface_id=str(surface_id), 

121 surface_kind=surface_kind, 

122 ) 

123 

124 

125def clear_surface_context() -> None: 

126 """Unbind `surface_id` + `surface_kind` from structlog contextvars. 

127 

128 Called from the middleware's `finally` block so the binding never 

129 leaks across requests even when a downstream handler raises. Idempotent: 

130 safe to call when nothing was previously bound (structlog tolerates 

131 unbind of missing keys). 

132 """ 

133 structlog.contextvars.unbind_contextvars("surface_id", "surface_kind")
