1"""Read the routed request path from the ASGI scope. 

2 

3## Why this helper exists 

4 

5`request.url.path` is reconstructed by Starlette by concatenating 

6`http://{Host header}{path}` and re-parsing. CVE-2026-48710 (the 

7"badhost" advisory, published 2026-06-04, CVSS 6.5) shows that a 

8malformed `Host` header containing `/`, `?`, or `#` shifts the 

9path/query/fragment boundaries during re-parsing, so the parsed 

10`request.url.path` no longer matches the path the router actually 

11dispatched on. Middleware that reads `request.url.path` for security 

12decisions can be bypassed; the router still hands off to the original 

13endpoint because it reads the raw ASGI scope path. 

14 

15Affected Starlette versions: `<= 1.0.0`. We pin `0.52.1` transitively 

16via FastAPI `>=0.136.1,<0.137`, which does not yet accept Starlette 

17`1.0.1`. Upgrading the library is a separate, larger project. 

18 

19## What this fixes 

20 

21`request.scope["path"]` is the raw routed path Starlette extracted 

22from the ASGI scope before any URL reconstruction. It is the same 

23value the router itself uses, so middleware reading it cannot 

24disagree with the dispatched endpoint regardless of `Host` header 

25contents. 

26 

27All security-sensitive auth code in this package MUST call 

28`_routed_path(request)` instead of `request.url.path`. Forensic 

29logging in this package follows the same convention for 

30consistency: the logged path then always matches the routed path, 

31removing one source of post-incident confusion. 

32 

33`Request.url.scheme` / `Request.url.netloc` / `Request.url.query` 

34are still Host-reconstructed and remain at the call site's 

35discretion; the badhost class only desyncs the path component. 

36""" 

37 

38from typing import cast 

39 

40from starlette.requests import Request 

41 

42 

43def _routed_path(request: Request) -> str: 

44 """Return the routed request path from the ASGI scope. 

45 

46 See module docstring for the CVE-2026-48710 background. Use 

47 this instead of `request.url.path` for any decision the auth 

48 middleware makes; the two values diverge under a crafted 

49 `Host` header on vulnerable Starlette versions. 

50 """ 

51 return cast("str", request.scope["path"]) 

52 

53 

54__all__ = ["_routed_path"]
