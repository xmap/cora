1"""Frame aggregate state, status enum, and domain errors. 

2 

3`Frame` is a named coordinate system. The first frames in any 

4deployment are the beamline centerlines (e.g., APS 2-BM's standard 

51.35 mrad centerline, plus the alternate 5.1 mrad and 5.23 mrad 

6centerlines that engage when the mirror is in use). Mount placements 

7(and other Frame placements) reference a `parent_frame_id: UUID` field 

8that points at a Frame's `id`. 

9 

10Frames form a tree: every Frame has a `parent_id` that is 

11either `None` (root frame, e.g., the storage-ring centerline as 

12defined by the facility) or points at another Frame. Cycles are 

13defensively rejected at register time (depth-bounded BFS, max depth 

1416); since there is no `reparent_frame` slice in v1, cycles can only 

15arise from manual data manipulation, but the defensive check stays 

16to catch that case loudly. 

17 

18## Root frames versus child frames 

19 

20The invariant is "both together, or both None": 

21 - Root frame: `parent_id is None` AND 

22 `placement is None`. 

23 - Child frame: both non-None, and the embedded 

24 `Placement.parent_frame_id` field MUST equal the Frame's own 

25 `parent_id` (the Placement points at the same parent that 

26 the Frame declares). 

27 

28The decider enforces this invariant; `InvalidFrameRootError` carries 

29the offending combination for diagnostics. 

30 

31## Lifecycle 

32 

33`FrameStatus` is `Active | Decommissioned`, matching Supply's 

34lifecycle-terminal pattern (deregister_supply design). No operational 

35sub-states (no `Available`/`Degraded` analog for Frames): a frame 

36either exists in the coordinate hierarchy or it does not; runtime 

37"misalignment" is a property of the installed Asset, not of the slot 

38or frame. 

39 

40Transitions: 

41 - `register_frame` -> Active (genesis) 

42 - `decommission_frame` -> Decommissioned (terminal; guarded 

43 by FrameInUseError if any active 

44 Mount.placement.parent_frame_id or 

45 active child Frame.parent_id 

46 references this frame) 

47 

48`update_frame_placement` does NOT change status; it updates 

49`placement` and is a no-op when the new placement 

50equals the current one (idempotent contract via 

51`make_asset_update_handler`). 

52 

53## Bounded-name VO 

54 

55`FrameName` is the umpteenth trimmed-bounded-name VO; uses the 

56shared `validate_bounded_text` helper. The cap is 200 chars to 

57match `AssetName`; frame names tend to be much shorter 

58(`centerline_1p35_mrad`) but the cap protects the projection table 

59column without forcing a tighter discipline on operators. 

60"""

95class InvalidFrameRootError(ValueError): 

96 """A Frame's root-vs-child invariant was violated at register time. 

97 

98 The invariant is "both fields together, or both None": 

99 - Root frame: `parent_id is None` AND 

100 `placement is None`. 

101 - Child frame: both non-None, and the embedded 

102 `Placement.parent_frame_id` MUST equal the Frame's own 

103 `parent_id`. 

104 

105 Three failure modes folded into one error: 

106 1. `parent_id` is None but `placement` 

107 is not (or vice versa). 

108 2. Both are non-None but `placement.parent_frame_id` does not 

109 equal `parent_id`. 

110 

111 `reason` identifies which case fired for diagnostics. 

112 """ 

113 

114 def __init__(self, reason: str) -> None: 

115 super().__init__(f"Invalid Frame root configuration: {reason}") 

116 self.reason = reason

135class FrameCannotUpdateError(Exception):

137 

138 Two failure modes folded into one error (mirrors

177class FrameInUseError(Exception): 

178 """Attempted to decommission a frame still referenced by active consumers. 

179 

180 A frame is "in use" when any of the following hold: 

181 - Some active Mount's `Placement.parent_frame_id` points at this 

182 frame (lands once the Mount aggregate exists). 

183 - Some active child Frame's `parent_id` points at this 

184 frame. 

185 

186 The handler loads consumers via the `frame_consumers` projection 

187 before calling the decider. `consumer_ids` lists the offending 

188 references for diagnostics; the route surfaces a 409. 

189 """ 

190 

191 def __init__(self, frame_id: UUID, consumer_ids: tuple[UUID, ...]) -> None: 

192 super().__init__( 

193 f"Frame {frame_id} cannot be decommissioned: still referenced by " 

194 f"{len(consumer_ids)} active consumer(s) ({list(consumer_ids)!r})" 

195 ) 

196 self.frame_id = frame_id 

197 self.consumer_ids = consumer_ids

200class InvalidFrameRevisionError(ValueError): 

201 """A FrameRevisionLink VO failed its within-VO invariant. 

202 

203 The link carries a predecessor frame id plus a transform expressing 

204 where this frame's origin sits relative to the predecessor's. The 

205 transform's `parent_frame_id` field MUST equal `predecessor_frame_id` 

206 so the transform unambiguously names which frame it transforms 

207 from. Mirrors `Placement.__post_init__`'s within-VO validation 

208 precedent (finiteness, non-negative tolerance). 

209 

210 Cross-Frame invariants (self-supersession, predecessor existence) 

211 live in the decider, not here. 

212 """ 

213 

214 def __init__(self, reason: str) -> None: 

215 super().__init__(f"Invalid FrameRevisionLink: {reason}") 

216 self.reason = reason

219class FrameCannotSupersedeError(Exception): 

220 """Attempted to register a frame whose `supersedes` link is rejected 

221 by decider-layer cross-Frame rules. 

222 

223 Reason-bearing shape mirrors `FrameCannotUpdateError` / 

224 `FrameCannotDecommissionError`. v1 fires on one case: 

225 - Self-supersession: `supersedes.predecessor_frame_id` equals 

226 the frame's own `frame_id`. 

227 

228 Predecessor existence is NOT checked here. The codebase follows 

229 eventual-consistency for cross-Frame references (per the 

230 Mount.placement.parent_frame_id precedent), so a supersedes pointer 

231 at a non-existent predecessor frame is data-integrity, not write- 

232 time rejection. 

233 """ 

234 

235 def __init__(self, frame_id: UUID, reason: str) -> None: 

236 super().__init__(f"Frame {frame_id} cannot supersede: {reason}") 

237 self.frame_id = frame_id 

238 self.reason = reason

255@dataclass(frozen=True) 

256class FrameRevisionLink: 

257 """Links a Frame to the predecessor it revises. 

258 

259 The predecessor is an older revision of the same physical 

260 coordinate system. Concrete example: APSU shifted the storage-ring 

261 reference origin, so a new `F_2BM_apsu` root frame supersedes 

262 the prior `F_2BM_pre_apsu` root frame. Both stay as root frames 

263 (siblings under the facility origin); revision and spatial 

264 hierarchy are deliberately separated. 

265 

266 `transform_from_predecessor` is the Placement that maps a 

267 position expressed in the predecessor's coordinates to this 

268 frame's coordinates. The transform's `parent_frame_id` field MUST 

269 equal `predecessor_frame_id`; the within-VO invariant is enforced 

270 in `__post_init__` (mirror of `Placement.__post_init__`'s 

271 finiteness/tolerance checks). 

272 

273 Cross-Frame invariants (self-supersession, predecessor existence) 

274 are decider/handler concerns, not VO concerns. 

275 """ 

276 

277 predecessor_frame_id: UUID 

278 transform_from_predecessor: Placement 

279 

280 def __post_init__(self) -> None: 

281 if self.transform_from_predecessor.parent_frame_id != self.predecessor_frame_id: 

282 raise InvalidFrameRevisionError( 

283 f"transform.parent_frame_id ({self.transform_from_predecessor.parent_frame_id!s}) " 

284 f"must equal predecessor_frame_id ({self.predecessor_frame_id!s})" 

285 )

288@dataclass(frozen=True) 

289class Frame: 

290 """Aggregate root: a named coordinate frame in the placement tree. 

291 

292 `parent_id` is the immediate parent in the frame tree. 

293 `None` only for root frames (the storage-ring centerline at APS, 

294 for instance). Immutable across this aggregate's lifecycle (no 

295 `reparent_frame` slice in v1). 

296 

297 `placement` is the pose of THIS frame's origin 

298 relative to its parent. `None` for root frames; non-None for 

299 child frames. The invariant 

300 `placement.parent_frame_id == parent_id` is enforced at the 

301 decider. 

302 

303 `supersedes` marks this frame as a revision of an older frame 

304 (typically same physical coordinate system, e.g., post-upgrade 

305 re-survey of an origin). `None` for non-revision frames. Carries 

306 both the lineage pointer (predecessor_frame_id) and the geometric 

307 transform between the two coordinate systems. Set at registration 

308 only; immutable thereafter. 

309 

310 `status` is `Active` at registration and transitions only to 

311 `Decommissioned` (terminal). The `update_frame_placement` slice mutates 

312 `placement` but leaves status and supersedes 

313 unchanged. 

314 """ 

315 

316 id: UUID 

317 name: FrameName 

318 parent_id: UUID | None 

319 placement: Placement | None 

320 supersedes: FrameRevisionLink | None = None 

321 status: FrameStatus = FrameStatus.ACTIVE
