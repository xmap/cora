1"""SobolDecidePort: a deterministic, stateless Sobol initial-design seeder. 

2 

3A quasi-random seeder behind `DecidePort`, the low-discrepancy sibling of 

4`GridWalkDecidePort`. It advises the next point of a Sobol sequence over the 

5`SteeringSpace`, advancing one point per observation already recorded. Its 

6job is the INITIAL DESIGN: cover the space well enough that a downstream GP 

7brain has a meaningful first fit. A Sobol low-discrepancy sequence spreads 

8points more evenly than uniform random and is the conventional Bayesian- 

9optimization initialization. 

10 

11## Stateless and replay-deterministic by construction 

12 

13Like `GridWalkDecidePort`, the seeder holds no cursor: the sequence position 

14is `len(evidence.observations)`, re-derived every call, so a replay that 

15re-drives an earlier turn yields identical advice. The Sobol points are an 

16UNSCRAMBLED (`scramble=False`) sequence, which is a pure function of the 

17dimension and the draw index, with no random state: the same index always 

18maps to the same point on every platform and torch version. So the seeder is 

19a pure-function brain in the sense the conduct loop's replay property 

20requires, exactly like the grid walker, and unlike the GP brain it seeds. 

21 

22The seeder SKIPS the sequence's raw 0th point (the all-zeros corner, which 

23scales to every axis's lower bound: a degenerate, on-the-boundary seed): its 

24own position `k` maps to raw draw `k + 1`, so the first seed is interior. This 

25is still a pure function of position, so replay-stability is unchanged. 

26 

27## Continuous axes only 

28 

29Sobol generates points in the unit hypercube, scaled to each axis's 

30`[lower, upper]`. A discrete / categorical axis (one carrying `choices`) has 

31no continuous range to sample, so the seeder rejects a space that contains 

32one rather than guessing an encoding; discrete-axis seeding is deferred to a 

33smarter brain. An axis with neither bounds nor choices is likewise 

34un-samplable and rejected. 

35 

36## No objective use, never stops 

37 

38A seeder covers the space; it does not optimize and it does not converge, so 

39it ignores `objective.kind` entirely and never advises `Stop`. Deciding when 

40enough seed points exist is the caller's job (the staged decider hands off to 

41the GP brain on an observation-count threshold); a seeder consulted forever 

42keeps emitting Sobol points. 

43"""

70class SobolDecidePort: 

71 """A deterministic, stateless Sobol initial-design seeder over a SteeringSpace. 

72 

73 Satisfies the `DecidePort` Protocol structurally. Advises the 

74 `len(observations)`-th point of an unscrambled Sobol sequence scaled to 

75 the space's continuous axes; never advises `Stop`. Probes `torch` at 

76 construction so a missing `bo` extra fails as a `ValueError` at handler 

77 time, not deep in the loop. 

78 """ 

79 

80 def __init__(self) -> None: 

81 require_torch(_MODEL_REF) 

82 

83 async def advise_next(self, evidence: SteeringEvidence) -> SteeringAdvice: 

84 """Advise the next Sobol point for the current sequence position. 

85 

86 The position is `len(evidence.observations)` (failed acquisitions 

87 included: the walk advances past a failed point rather than retrying). 

88 Raises `DecideEvidenceRejectedError` if the space has no axes or 

89 carries an axis that is not a bounded continuous axis. 

90 """ 

91 names = _continuous_axis_names(evidence.space) 

92 position = len(evidence.observations) 

93 point = _sobol_point(evidence.space, position) 

94 return SteeringAdvice( 

95 verdict=SteeringVerdict.MEASURE, 

96 next_point=SteeringPoint(coordinates=dict(zip(names, point, strict=True))), 

97 rationale=f"sobol initial-design point {position + 1}", 

98 model_ref=_MODEL_REF, 

99 ) 

100 

101 async def aclose(self) -> None: 

102 """No-op: the seeder holds no resources.""" 

103 return None

106def _continuous_axis_names(space: SteeringSpace) -> list[str]: 

107 """The axis names, rejecting any non-continuous or unbounded axis.""" 

108 if not space.axes: 

109 raise DecideEvidenceRejectedError("steering space declares no axes to seed") 

110 for axis in space.axes: 

111 _require_continuous(axis) 

112 return [axis.name for axis in space.axes] 

113 

114 

115def _require_continuous(axis: SteeringAxis) -> None: 

116 """Reject a discrete/categorical or unbounded axis a Sobol seeder cannot sample.""" 

117 if axis.choices: 

118 raise DecideEvidenceRejectedError( 

119 f"axis {axis.name!r} carries choices; a Sobol seeder samples only " 

120 "bounded continuous axes" 

121 ) 

122 if axis.lower is None or axis.upper is None: 

123 raise DecideEvidenceRejectedError( 

124 f"axis {axis.name!r} has no [lower, upper] bound; a Sobol seeder cannot sample it" 

125 ) 

126

128def _sobol_point(space: SteeringSpace, index: int) -> list[float]: 

129 """The `index`-th seed point (skipping the origin), scaled to each axis's bounds. 

130 

131 The 0th point of an UNSCRAMBLED Sobol sequence is the all-zeros corner of 

132 the unit hypercube, which scales to every axis's lower bound: a degenerate, 

133 on-the-boundary seed that wastes the first (often expensive) acquisition and 

134 gives the GP a corner point rather than interior coverage. So the seeder 

135 skips raw index 0 and maps its own position `index` to raw draw `index + 1` 

136 (position 0 -> 0.5, 1 -> 0.75, 2 -> 0.25, ... in 1-D). It draws `index + 2` 

137 points from a fresh unscrambled engine and takes the last; an unscrambled 

138 Sobol sequence is a pure function of (dimension, draw index), so this stays 

139 deterministic and replay-stable without any RNG seed. 

140 """ 

141 import torch 

142 

143 dimension = len(space.axes) 

144 engine = torch.quasirandom.SobolEngine(dimension=dimension, scramble=False) 

145 drawn = engine.draw(index + 2, dtype=torch.double) 

146 unit = drawn[index + 1] 

147 point: list[float] = [] 

148 for axis_index, axis in enumerate(space.axes): 

149 assert axis.lower is not None # guarded by _require_continuous 

150 assert axis.upper is not None 

151 span = axis.upper - axis.lower 

152 point.append(axis.lower + float(unit[axis_index]) * span) 

153 return point
