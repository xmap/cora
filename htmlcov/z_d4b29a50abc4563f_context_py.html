1"""Cross-aggregate context the `adjust_run` decider validates against. 

2 

3`RunAdjustContext` is built by the `adjust_run` handler from 

4`load_run` + `load_plan` + `load_practice` + `load_method` before 

5reaching the pure decider. The decider treats these loaded entities 

6as opaque domain data and validates without performing any I/O. 

7 

8Mirrors `RunStartContext` (6f-1) shape. The Method's `parameters_schema` 

9is the only datum the decider needs from the upstream Recipe chain 

10(Run → Plan → Practice → Method); the schema is None when the 

11Method declares no contract (operator-responsibility territory per 

12the 6g-c schemaless semantic). 

13 

14Slice-local module by design: only `adjust_run` uses this today. 

15""" 

16 

17from dataclasses import dataclass 

18from typing import Any 

19 

20from cora.run.aggregates.run import Run 

21 

22 

23@dataclass(frozen=True) 

24class RunAdjustContext: 

25 """Snapshot of upstream aggregate state at Run-adjust time. 

26 

27 `run` is the source-state Run (the decider validates status 

28 and merges the patch against `run.effective_parameters`). 

29 `method_parameters_schema` is the Method's optional JSON Schema 

30 (None when the Method declares no contract; the decider then 

31 skips merged-result validation, mirroring 6g-c's schemaless 

32 semantic for steering of schemaless Methods). 

33 """ 

34 

35 run: Run 

36 method_parameters_schema: dict[str, Any] | None
