1"""Pure decider for the `RegisterAsset` command. 

2 

3Pure function: given the current Asset state (None for a fresh 

4stream) and a `RegisterAsset` command, returns the events to 

5append. No I/O, no awaits, no side effects. 

6 

7`now` and `new_id` are injected by the application handler from 

8the Clock and IdGenerator ports. 

9 

10## Anchoring rule 

11 

12An Asset is anchored exactly one way (XOR over {parent_id, facility_code}): 

13 - A root Asset binds `facility_code` (its owning Federation 

14 Facility) and MUST have `parent_id=None`. 

15 - A non-root Asset has a `parent_id` and MUST NOT bind 

16 `facility_code` (it inherits facility scope through the tree). 

17 

18Facility-envelope scope (institution / site / area) is owned by the 

19`Facility` aggregate (`FacilityKind{Site, Area}`), not by an Asset tier. 

20 

21Eventual-consistency stance: the decider does NOT verify the 

22referenced parent Asset exists in the event store. Cycle 

23detection (target's ancestors must not include this asset) 

24requires walking the parent chain and is deferred to projection- 

25worker era. The single-parent tree rule is enforced structurally 

26(one `parent_id` field, can't be a list). 

27 

28**Tiers are conventional, not enforced**: the decider does NOT 

29check that a Device's parent is a Component (etc). Device-in- 

30Device is allowed when reality demands it (smart instruments 

31with addressable sub-modules). 

32 

33## Model binding (Lock B) 

34 

35`command.model_id` flows through to the emitted AssetRegistered 

36event without inspection. The decider does NOT load the Model 

37snapshot: at registration the Asset's families set is empty, so 

38the cross-BC subset invariant 

39`Model.declared_family_ids subset-of Asset.family_ids` is vacuously 

40satisfied and there is nothing to validate against. The handler 

41enforces Model existence (raises `ModelNotFoundError` -> 404) 

42before invoking decide; the first meaningful subset enforcement 

43fires at the first `add_asset_family` call against the bound 

44Asset. 

45 

46## Alternate identifiers (Lock D + Lock F + Lock I) 

47 

48`command.alternate_identifiers` flows through to the emitted 

49AssetRegistered event verbatim. The decider does NOT validate 

50`(kind, value)` uniqueness across other Assets in v1 (Lock F): 

51PIDINST itself admits "should be unique", same-vendor serial 

52schemes legitimately reappear across facilities, and CORA stays 

53format-opaque about provenance of the string. Frozenset semantics 

54on the field structurally forbid duplicate `(kind, value)` pairs 

55on the same Asset. No cross-BC IO fires on this field's behalf 

56(Lock I); the handler does not load any external stream. 

57 

58## Owners (Lock 6 + Lock 11) 

59 

60`command.owners` flows through to the emitted AssetRegistered 

61event verbatim. The decider enforces name-uniqueness within the 

62payload (Lock 6): two owners sharing a `name` raise 

63`AssetOwnerAlreadyPresentError`. The pairing invariant on 

64(identifier, identifier_type) is enforced inside the `AssetOwner` 

65VO's `__post_init__`. No cross-BC IO fires on this field's 

66behalf; ROR / GRID / ISNI string values are opaque to the 

67aggregate. 

68 

69## Controller binding (Lock A precedent) 

70 

71`command.controller_id` flows through to the emitted 

72AssetRegistered event verbatim. Mirrors `model_id` and 

73`parent_id` precedents: the decider does NOT load the controller 

74Asset snapshot, does NOT verify it exists, and does NOT enforce 

75that the referenced Asset carries the MotionController Family. 

76Operators are trusted to register controllers before binding 

77stages to them; a dangling reference is operator error, not a 

78domain invariant violation. The handler does not load any external 

79stream on this field's behalf. 

80 

81## Enclosure location binding (Lock A precedent) 

82 

83`command.located_in_enclosure_id` flows through to the emitted 

84AssetRegistered event verbatim. Mirrors the `controller_id` 

85precedent exactly: the decider does NOT load the Enclosure 

86snapshot, does NOT verify it exists, and applies no validation. 

87The pointer stays a bare opaque UUID so the Equipment BC takes on 

88no module dependency on the Enclosure BC. The handler does not 

89load any external stream on this field's behalf. 

90 

91## Facility binding (Slice 8A) 

92 

93`command.facility_code` flows through to the emitted AssetRegistered 

94event via the typed `FacilityCode` VO loaded by the handler. The 

95handler resolves the slug via `FacilityLookup.lookup_by_code` and 

96threads `facility_lookup_result: FacilityLookupResult | None` into 

97the decider. When `command.facility_code` is non-None and the 

98lookup result is None, the decider raises 

99`AssetFacilityNotFoundError` (HTTP 404). When `command.facility_code` 

100is None, the decider skips this validation entirely (facility 

101binding is OPTIONAL on Asset; not every Asset has a Facility, e.g. 

102shared spare-parts pool). The lookup-result's `.code` field is folded 

103onto the event so the event's `facility_code` reflects the 

104projection's canonical typed VO, not a command-echo (mirrors the 

105Supply Slice 7A handler/decider split). 

106""" 

107 

108from datetime import datetime 

109from uuid import UUID 

110 

111from cora.equipment.aggregates.asset import ( 

112 Asset, 

113 AssetAlreadyExistsError, 

114 AssetFacilityNotFoundError, 

115 AssetName, 

116 AssetOwnerAlreadyPresentError, 

117 AssetRegistered, 

118 InvalidAssetParentError, 

119) 

120from cora.equipment.features.register_asset.command import RegisterAsset 

121from cora.infrastructure.ports.facility_lookup import FacilityLookupResult 

122from cora.shared.identity import ActorId 

123 

124 

125def decide( 

126 state: Asset | None, 

127 command: RegisterAsset, 

128 *, 

129 now: datetime, 

130 new_id: UUID, 

131 commissioned_by: ActorId, 

132 facility_lookup_result: FacilityLookupResult | None, 

133) -> list[AssetRegistered]: 

134 """Decide the events produced by registering a new asset. 

135 

136 Invariants: 

137 - State must be None (genesis-only) -> AssetAlreadyExistsError 

138 - Name must be valid -> InvalidAssetNameError 

139 (via AssetName VO) 

140 - Anchoring XOR: exactly one of {parent_id, facility_code}. 

141 A root Asset (parent_id=None) must bind facility_code; a 

142 non-root (with parent_id) must NOT bind facility_code 

143 -> InvalidAssetParentError 

144 - Owner names must be unique within the payload (Lock 6) 

145 -> AssetOwnerAlreadyPresentError 

146 - When command.facility_code is non-None, 

147 facility_lookup_result must be non-None 

148 -> AssetFacilityNotFoundError 

149 """ 

150 if state is not None: 

151 raise AssetAlreadyExistsError(state.id) 

152 

153 if command.facility_code is not None and facility_lookup_result is None: 

154 raise AssetFacilityNotFoundError(command.facility_code) 

155 

156 name = AssetName(command.name) # validates + trims; raises InvalidAssetNameError 

157 

158 # Anchoring rule: an Asset is either facility-rooted or parent-nested. 

159 # Exactly one of {parent_id, facility_code} is set. Facility-envelope 

160 # scope is owned by the Facility aggregate, not by an Asset tier. 

161 if command.parent_id is None and command.facility_code is None: 

162 msg = ( 

163 "Root Asset (parent_id=None) must bind a facility_code (its owning Federation Facility)" 

164 ) 

165 raise InvalidAssetParentError(msg) 

166 if command.parent_id is not None and command.facility_code is not None: 

167 msg = ( 

168 f"Non-root Asset (parent_id={command.parent_id}) must not also bind " 

169 "facility_code (children inherit facility scope through the tree)" 

170 ) 

171 raise InvalidAssetParentError(msg) 

172 

173 # Owner-name uniqueness within the payload (Lock 6). Frozenset 

174 # semantics already deduplicate full-VO equality but two distinct 

175 # AssetOwner VOs may share `name` while differing on optional 

176 # fields; the keying choice forbids that on a single Asset. 

177 seen_owner_names: set[str] = set() 

178 for owner in command.owners: 

179 if owner.name.value in seen_owner_names: 

180 raise AssetOwnerAlreadyPresentError(new_id, owner.name) 

181 seen_owner_names.add(owner.name.value) 

182 

183 return [ 

184 AssetRegistered( 

185 asset_id=new_id, 

186 name=name.value, 

187 tier=command.tier.value, 

188 parent_id=command.parent_id, 

189 occurred_at=now, 

190 commissioned_by=commissioned_by, 

191 drawing=command.drawing, 

192 model_id=command.model_id, 

193 alternate_identifiers=command.alternate_identifiers, 

194 owners=command.owners, 

195 controller_id=command.controller_id, 

196 located_in_enclosure_id=command.located_in_enclosure_id, 

197 facility_code=( 

198 facility_lookup_result.code if facility_lookup_result is not None else None 

199 ), 

200 ) 

201 ]
