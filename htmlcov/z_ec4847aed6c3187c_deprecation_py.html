1"""Why something stopped being recommended. 

2 

3Kept in `cora.shared` (neutral) because the eleven commands that carry it 

4span four BCs (Agent, Equipment, Recipe, Safety) and all answer the same 

5question with the same closed vocabulary. Ten are the versionable 

6templates; the eleventh is `LanguageModel`, a catalog entry the facility 

7withdraws approval for without ever being able to version it. Mirrors how 

8bounded-text limits live in `cora.shared.text_bounds` and the consequence 

9gate in `cora.shared.consequence`. 

10 

11## Why closed, not operator free text 

12 

13`<X>Deprecated` is the one terminal whose reason changes how a reader must 

14treat DATA THAT ALREADY EXISTS. A Method deprecated because a better one 

15landed leaves every prior Run standing; a Method deprecated because it was 

16subtly wrong makes every prior Run suspect. That distinction is a single bit, 

17it is the bit a scientist actually asks for months later, and free text 

18cannot be queried for it: "show me every Run whose Method was later found 

19defective" is a question a prose field can never answer. 

20 

21Free text also decays. A required prose field gets "old" / "n/a" / 

22"deprecated" by the third use, which leaves a column that looks like signal 

23and is not. The closed set costs one token at the call site and cannot rot. 

24 

25Same reasoning, same shape as `CautionRetireReason` (Caution BC), whose 

26docstring records the identical rejection: "Free-form `reason: str` 

27rejected: operators already pick from a small mental list." 

28 

29## The three values 

30 

31The axis is WHAT HAPPENED to the thing. Each value also states what that 

32means for data already produced under it, because that is what a reader 

33needs, but the consequence is the payload of the answer rather than the 

34question the set partitions on: 

35 

36 - `Superseded`: a newer version of the same thing replaces it. Prior use 

37 stands. The routine case and the expected default. 

38 - `Defective`: it was wrong. Prior use is suspect and may need review. 

39 The value the whole enum exists to make findable. 

40 - `Obsolete`: what it targeted no longer exists (the device class was 

41 retired, the facility stopped offering the technique). Prior use stands; 

42 there is simply nothing left to bind to. 

43 

44`Superseded` and `Obsolete` agree on the consequence and differ on the act, 

45which is exactly why the axis is the act. An earlier draft of this docstring 

46claimed the set partitioned on consequence and then listed two members with 

47the same one; the 2026-08-01 gate review caught the contradiction. If the 

48partition really were consequence, this would be a two-value enum and a 

49retired device class would have to be reported as `Superseded`, which is a 

50lie the operator would have to tell. 

51 

52Narrative detail beyond this belongs on a Caution or a Decision, both of 

53which are built to carry prose and neither of which is load-bearing for 

54replay. Extending this enum needs a new ACT that a reader would treat 

55differently, stated together with its consequence; a new shade of narrative 

56on an existing act is not a new value. 

57""" 

58 

59from enum import StrEnum 

60 

61 

62class DeprecationReason(StrEnum): 

63 """Closed reason for deprecating a versionable template.""" 

64 

65 SUPERSEDED = "Superseded" 

66 DEFECTIVE = "Defective" 

67 OBSOLETE = "Obsolete" 

68
