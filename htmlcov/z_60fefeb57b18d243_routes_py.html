1"""HTTP setup for the Run BC. 

2 

3`register_run_routes(app)` includes every slice's router and 

4registers exception handlers that translate the BC's domain / 

5application errors to HTTP status codes. Called once at app 

6construction. 

7 

8JSONResponse is used (not HTTPException) per FastAPI guidance to 

9avoid nested-exception pitfalls. 

10 

11`IdempotencyConflictError`, `IdempotencyClaimLostError`, 

12`CachedHandlerError`, and `ConcurrencyError` are infra-layer errors 

13registered by Access (the first BC that boots). They produce 

14the same JSON shape regardless of which BC raised them, so Run 

15does not re-register them. 

16 

17## Loop-collapse pattern 

18 

19Mirrors Recipe / Equipment / Subject. Generic error handlers per 

20family, tuple loops to register them. The truncate transition has 

21its own handler + guard errors (RunCannotTruncateError + two 

22validation errors: InvalidRunTruncateReasonError + 

23InvalidRunInterruptedAtError). 

24 

25 - 400 (validation): InvalidRunNameError, InvalidRunAbortReasonError, 

26 InvalidRunStopReasonError, InvalidRunTruncateReasonError, 

27 InvalidRunInterruptedAtError, InvalidRunParametersError, 

28 InvalidChannelNameError, InvalidObservationValueError, 

29 InvalidObservationShapeError, 

30 InvalidSamplingProcedureError, InvalidRunExternalRefError 

31 - 404 (load miss): RunNotFoundError 

32 - 409 (defensive guard for AlreadyExists): RunAlreadyExistsError 

33 - 409 (Run-start binding-state guards): RunBoundPlanDeprecatedError, 

34 RunSubjectNotMountableError, RunPlanAssetDecommissionedError,

142async def _handle_justification_required(request: Request, exc: Exception) -> JSONResponse: 

143 """422 handler for the obligation gate (Gate III). 

144 

145 A declared-class command (AbortRun) was issued without a valid justification. 

146 422 (unprocessable content) rather than 400: the request is well-formed but 

147 fails the admission precondition of accounting for the action, matching the 

148 422-for-unprocessable convention the Access / Federation / Operation BCs use. 

149 

150 Intra-BC distinction (deliberate, not drift): a bad `reason` on the same 

151 command maps to 400 via `_handle_validation_error` (a domain-invariant on a 

152 supplied value), while a missing/blank `justification` maps here to 422 (an 

153 unmet admission precondition). So on one abort call an over-length reason is 

154 400 but an over-length justification is 422; the two answer different questions 

155 (domain validity of a value vs. accountability for the act).""" 

156 _ = request 

157 return JSONResponse( 

158 status_code=status.HTTP_422_UNPROCESSABLE_CONTENT, 

159 content={"detail": str(exc)}, 

160 )
