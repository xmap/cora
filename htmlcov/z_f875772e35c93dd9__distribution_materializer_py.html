1"""DistributionMaterializer: leg B of stage-then-reconstruct. 

2 

3Sequences the three acts that turn "bytes copied to another tier" into a fact 

4CORA trusts: (1) move the bytes over a `TransferPort`, (2) on success record a 

5new `Distribution` of the SAME raw Dataset at the analysis-tier Storage Supply 

6(`register_distribution`), (3) record a checksum `Attestation` over the landed 

7bytes (`record_attestation`), whose Match flips the Distribution to Verified in 

8the Data BC projection. That Verified-at-tier fact is exactly what leg C's 

9start_run gate reads ([[project_run_input_dependency_design]]). 

10 

11This is an orchestration concern, so it lives in `cora.api` (the only module 

12that may reach both `cora.operation.ports` and the Data BC handlers). It is the 

13materialize edge job the EdgeConductor will drive; here it is a self-contained 

14unit with injected collaborators, exercised against fakes. 

15 

16## What it owns vs trusts 

17 

18It OWNS the sequence and the transfer gate: it begins the transfer, polls 

19`observe` to a terminal (a non-terminal `Suspended` just keeps polling; there is 

20no special Suspended path yet), and registers ONLY if the transfer Succeeded. It 

21TRUSTS the caller's `RegisterDistribution`: the 

22caller (which holds the parent Dataset) builds it with the byte-identical-copy 

23fields (checksum / byte_size / media_type equal to the parent Dataset); the 

24Data BC decider enforces that equality. The `RecordAttestation` is built here 

25from the registration's `dataset_id` plus the new Distribution id. 

26 

27## Eventual-consistency note 

28 

29`record_attestation` returns an attestation id for Match, Mismatch, AND 

30Unreachable; the Distribution's flip to Verified (Match) or Stale (Mismatch) is 

31a projection-only update the Data BC applies from `AttestationRecorded`. So a 

32successful `materialize` means "moved + registered + attested", not "Verified"; 

33the Verified status is the projection's eventual flip, which leg C's gate reads 

34later. This mirrors the safety-envelope eventual-consistency window. 

35 

36## Deferred 

37 

38A long-running continuous sync would complete via a later signal rather than a 

39synchronous observe-loop; this unit polls to a terminal with a runaway bound and 

40NO inter-poll backoff (a busy-spin that is fakes-only safe, see 

41`_observe_to_terminal`). Real-adapter poll backoff, a real `Suspended` 

42intervention path, and the signal-driven variant are deferred to the 

43first-real-adapter trigger; none may be skipped when this is wired to a live 

44substrate (Globus first). 

45"""

149 dataset_id=registration.dataset_id,

159 transfer_state=TransferState.SUCCEEDED,

165 async def _observe_to_terminal(self, handle: TransferHandle) -> TransferProgress: 

166 """Poll `observe` until a terminal; every non-terminal state just re-polls. 

167 

168 A non-terminal observation (`Pending` / `Active` / `Suspended`) falls 

169 through to the next poll: the loop does NOT fold on `Suspended`, but it 

170 also does NOT special-case it (no longer wait, no credential-renewal 

171 backoff). "Waiting through Suspended" here means "keeps polling," not 

172 "waits patiently"; a real Suspended handling path is deferred. 

173 

174 BUSY-SPIN, FAKES-ONLY: there is NO delay between polls. A test double 

175 returns a terminal on the first poll or two, so the spin never bites 

176 here. Against a REAL adapter this hammers `observe()` up to 

177 `_MAX_OBSERVATIONS` times with zero backoff, which either trips the 

178 substrate's rate limit or burns the whole budget in seconds and raises 

179 long before an hours-long transfer finishes. A real adapter MUST gain 

180 poll backoff (or the deferred signal-driven terminalization) BEFORE this 

181 is wired to one; see the module docstring "Deferred". `_MAX_OBSERVATIONS` 

182 is a runaway backstop only, not a substitute for backoff. 

183 """

185 progress = await self.transfer_port.observe(handle) 

186 if progress.state.is_terminal: 

187 return progress 

188 msg = (
