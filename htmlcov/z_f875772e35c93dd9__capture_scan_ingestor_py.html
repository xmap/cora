1"""CaptureScanIngestor: sweep terminated witnessed Runs into Datasets. 

2 

3Slice 17. The 2-BM pilot recorded 133 witnessed Runs and, before this 

4slice, zero Datasets: `ingest_scan` is a POST route and an MCP tool, and 

5by design a human invokes it (`run.aggregates.run.capture_path`'s 

6observed path stays unredacted specifically so an operator can locate 

7the file for it). That was tenable while scans were supervised one at a 

8time; it is not once a batch script runs 500+ scans unattended, which is 

9the trigger the design memo named and which has now fired at 2-BM. 

10 

11## A sweep, not a terminal hook 

12 

13Deliberately NOT wired onto `RunWitnessRecorder`'s own terminal, unlike 

14`CaptureBaselineReader` (invoked inline from `_promote`) and 

15`CaptureProgressFeeder` (fed observations as they arrive). A remote 

16scan-ingest probe measures tens of seconds (2026-08-18: ~26s to digest a 

1724 GB file even on the LOCAL disk holding it); `run_witness_loop` is a 

18single sequential `async for`, and missing a BEGUN observation while a 

1930-second-plus probe runs is not an acceptable trade for making this 

20one Run's ingest a few seconds faster. This module never imports 

21`_run_witness`, and `_run_witness.py` never imports this module. 

22 

23Instead: a periodic sweep against the read model. Its only candidate 

24signal is "a terminated witnessed Run's capture path resolved 

25(`run_capture_path` holds a row) and no Dataset names it as 

26`producing_run_id` yet" -- which is restart-safe with no in-memory 

27queue, backfills whatever the witness already wrote before this switch 

28existed, and self-limits during a batch (falls behind, catches up 

29after, which is correct, not a bug). 

30 

31## Bounded retry within a tick, not strict one-per-tick 

32 

33A single successful ingest per tick (throttling the sweep to what the 

34transport can sustain) is NOT the same as trying only the single oldest 

35candidate: an early version of this slice did the latter, and a gate 

36review caught that it lets ONE permanently-stuck candidate (a missing 

37per-code binding, a file with no parseable timestamp) block EVERY 

38newer run forever, since `ORDER BY created_at ASC LIMIT 1` always 

39re-selects the same oldest row. `tick()` instead excludes each 

40candidate it gives up on THIS tick and tries the next-oldest, up to 

41`_MAX_CANDIDATES_PER_TICK` attempts, stopping at the first real success 

42(or the first systemic failure -- see below). A persistently-failing 

43candidate is still retried every tick, forever, by design: the failure 

44is logged loudly each time rather than parked in a dead-letter table 

45this slice does not build, so fixing the root cause (adding the 

46binding, or supplying `captured_at` by hand through the ordinary POST 

47route) is what actually clears it. It just no longer starves its 

48siblings while it waits. 

49 

50## Never blocks, never raises past the tick 

51 

52Every `IngestScan` failure mode is caught and logged; the tick returns 

53either way. A `DatasetAlreadyIngestedError` means a human already 

54ingested these bytes by hand (the ordinary POST route uses the SAME 

55`scan_reader` / `checksum_computer` pair, so this is a real race, not a 

56bug) and is logged at `info`, not `warning`. `UnauthorizedError` is 

57treated as SYSTEMIC, not per-candidate: a missing grant denies every 

58candidate identically, so retrying the next-oldest would just burn 

59`_MAX_CANDIDATES_PER_TICK` queries for the same verdict; the tick stops 

60immediately instead, and the warning is edge-triggered (once per denial 

61episode, with a matching recovery log), mirroring 

62`cora.api._flag_watcher`'s identical posture for the same reason. 

63 

64## The producing-Asset cross-check reads a RECORDED fact, never a live poll 

65 

66`binding.producing_asset_id` is one fixed Asset per capture code; 2-BM has 

67two cameras behind two prefixes (`2bmSP1:`, `2bmSP2:`), so a camera switch 

68that this module does not notice would silently mint every subsequent 

69Dataset under the WRONG Camera Asset. When a binding declares 

70`camera_channel_name` + `expected_camera_label`, `_ingest_one` reads THAT 

71candidate's own `run_id`-scoped camera-selection observation 

72(`RunChannelLookup.read_run_channel_categorical_latest`) and SKIPs rather 

73than ingests on a mismatch or an absent observation. 

74 

75Deliberately NOT a live `control_port.read()` of the camera-selection PV at 

76tick time, unlike this module's every other correctness input: a candidate 

77can be backlogged ("falls behind, catches up after" above), so "what camera 

78is selected right now" answers the wrong question for an old candidate. 

79The fact has to be pinned to the SPECIFIC run being ingested, which is 

80exactly what a `capture_baseline_pvs` reading taken once at that run's own 

81promotion already gives us, for free, via already-shipped machinery 

82(`CaptureBaselineReader`). See `capture_scan_ingestor_binding.py`'s module 

83docstring for the config shape and 

84`capture_watch_preflight`'s "Camera-prefix cross-check" section for the 

85sibling MANUAL check this automates one layer down (that one guards 

86`full_file_name`'s PV prefix at preflight time; this one guards 

87`producing_asset_id` at ingest time, per run). 

88 

89Fails CLOSED on a missing observation, not open: an older backlog run 

90predating this config, or a dead camera-selection PV, must not read as 

91"assume it matched" ([[feedback-optional-role-disables-safety-check]] is 

92the exact lesson this session already paid for once, at 

93`CAPTURE_WATCH_PVS.full_file_name` itself). A stuck candidate is retried 

94forever and logged loudly every tick, same as `no_binding` / 

95`invalid_scan_file` below; an operator who wants it ingested anyway still 

96has the manual POST route. 

97 

98## Never logs the observed path, and never mints an event carrying it 

99 

100`observed_path` is personal data (2-BM's directory layout embeds 

101`{UserLastName}-{ProposalNumber}`; see 

102`run.aggregates.run.capture_path`'s module docstring) and this log sink 

103is not the vault: it cannot be erased. Every log line here carries 

104`run_id` and `capture_code` only, never the path and never an 

105exception's rendered message (`InvalidScanFileError`'s text embeds the 

106locator via `repr()`), mirroring `_run_witness.py`'s identical rule for 

107the same value. 

108 

109The same reasoning extends past logging to what this module hands 

110`IngestScan`: `_mint_locator` builds an INDIRECT `cora-capture-path://` 

111locator (`cora.data.adapters.capture_path_locator`), never a `file://` 

112URI built directly from `observed_path`. `DatasetRegistered.uri` / 

113`DistributionRegistered.uri` are immutable, INSERT-only fields with no 

114erasure path today; this is the difference between a human pasting a 

115real path into the ordinary POST route (always possible, always their 

116choice) and this sweep doing it automatically and unconditionally for 

117every run. 

118"""

167# Bounds how many candidates one tick will try before giving up for 

168# this pass: enough to walk past a small cluster of stuck runs, cheap 

169# enough (each excluded candidate costs one indexed query, no I/O to 

170# the substrate) that a pathological backlog cannot turn one tick into 

171# an unbounded loop. 

172_MAX_CANDIDATES_PER_TICK = 10 

173 

174_CANDIDATE_SQL = """ 

175SELECT rcp.capture_path_id, rcp.run_id, rcp.observed_path, rcp.host, rcp.root, 

176 prs.capture_code 

177FROM run_capture_path rcp 

178JOIN proj_run_summary prs ON prs.run_id = rcp.run_id 

179WHERE prs.capture_code IS NOT NULL 

180 AND prs.status IN ('Completed', 'Aborted') 

181 -- A row whose location was never recorded cannot produce a 

182 -- resolvable locator: `mint` declines, and `resolve` keys on 

183 -- (run_id, host, root) with no fallback. Excluding it here turns a 

184 -- candidate that would be re-selected and SKIPped on every tick, 

185 -- forever, into an explicit non-candidate. Rows predating the 

186 -- location columns are the population this covers. 

187 AND rcp.host IS NOT NULL 

188 AND rcp.root IS NOT NULL 

189 AND NOT (rcp.capture_path_id = ANY($1::uuid[])) 

190 AND NOT EXISTS ( 

191 SELECT 1 FROM proj_data_dataset_summary dds 

192 WHERE dds.producing_run_id = rcp.run_id 

193 ) 

194ORDER BY rcp.created_at ASC 

195LIMIT 1 

196"""

217class ScanIngestCandidateLookup(Protocol): 

218 """Composition-root-owned read: joins Run BC's own `run_capture_path` 

219 / `proj_run_summary` against Data BC's `proj_data_dataset_summary`. 

220 Neither BC owns this query alone, mirroring `main.py`'s own 

221 "only cora.api may depend on both" placement rule. 

222 

223 `exclude` holds `capture_path_id` values, not `run_id` values: a Run 

224 may hold more than one vault row (one per storage location it was 

225 observed under), and a tick that skips one location's row must still 

226 be free to try that SAME run's other location on the next attempt. 

227 Excluding by `run_id` would wrongly rule out every row for a run 

228 after just one of its locations proved unbound or unreadable. Lets 

229 one tick walk past candidates it already gave up on without 

230 re-selecting the same stuck head repeatedly; see 

231 `CaptureScanIngestor.tick`'s bounded-retry loop. 

232 """ 

233

235 self, *, exclude: frozenset[UUID] = frozenset() 

236 ) -> ScanIngestCandidate | None: ...

273def _mint_locator(candidate: ScanIngestCandidate, *, deps: Kernel) -> str | None: 

274 """`run_capture_path.observed_path` is a bare filesystem path (the 

275 raw PV value) and, at 2-BM, embeds a real person's surname 

276 (`{PIlastname}-{GUP#}`). `IngestScan.locator` gets an INDIRECT 

277 `cora-capture-path://` locator instead of a `file://` URI built directly 

278 from it: this is the one call in the whole automated sweep that 

279 would otherwise put personal data onto an immutable event, per 

280 `cora.data.adapters.capture_path_locator`'s module docstring. 

281 

282 The locator is built from the location the VAULT ROW recorded, not 

283 from a fresh match against current settings. `resolve` looks the row 

284 up by exactly that pair, so re-deriving it here would mean two reads 

285 of a mutable setting at two different times (the Run's terminal, and 

286 this tick, arbitrarily later); any change between them mints a 

287 locator that resolves to nothing, silently. 

288 

289 Current settings still get a say, as a REFUSAL rather than a 

290 re-match: a row whose recorded root is no longer in the active 

291 transport's allowlist is skipped, because the probe would decline to 

292 read it anyway (`resolve_confined_file_uri` gates the read on the 

293 same allowlist). Refusing here makes that an explicit SKIP instead of 

294 a failure several layers down. 

295 """ 

296 host, roots = active_scan_transport(deps) 

297 allowed = {normalize_storage_root(root) for root in roots} 

298 if candidate.host != host or candidate.root not in allowed: 

299 return None 

300 return mint_capture_path_locator( 

301 observed_path=candidate.observed_path, 

302 run_id=candidate.run_id, 

303 host=candidate.host, 

304 root=candidate.root, 

305 )

308class _Outcome(enum.Enum): 

309 """What one candidate's attempt means for the REST of this tick.""" 

310 

311 SUCCESS = enum.auto() 

312 """Ingested. The tick stops here (one success per tick).""" 

313 SKIP = enum.auto() 

314 """This candidate specifically is stuck; exclude it and try the

316 STOP_TICK = enum.auto()

321class CaptureScanIngestor: 

322 """Sweeps `ScanIngestCandidateLookup` and issues `IngestScan`, 

323 trying up to `_MAX_CANDIDATES_PER_TICK` candidates per tick and 

324 stopping at the first success.""" 

325 

326 def __init__( 

327 self, 

328 *, 

329 deps: Kernel, 

330 candidate_lookup: ScanIngestCandidateLookup, 

331 ingest_scan: IdempotentHandler, 

332 bindings: Mapping[str, CaptureScanIngestorBinding], 

333 run_channel_lookup: RunChannelLookup | None = None, 

334 ) -> None: 

335 self._deps = deps 

336 self._candidate_lookup = candidate_lookup 

337 self._ingest_scan = ingest_scan 

338 self._bindings = bindings 

339 # Optional, like `_run_witness.py`'s `capture_path_store`: every 

340 # existing caller's bindings leave `expected_camera_label` unset, 

341 # so the camera check in `_check_producing_camera` never consults 

342 # this collaborator for them, and defaulting it in rather than 

343 # threading it through every construction site (including test 

344 # call sites with no stake in this feature) costs nothing. A 

345 # caller that DOES configure the camera check should still pass a 

346 # real one -- the in-memory default always reports "unconfirmed", 

347 # which fails closed correctly but uselessly if relied on by 

348 # accident. 

349 self._run_channel_lookup = ( 

350 run_channel_lookup if run_channel_lookup is not None else InMemoryRunChannelLookup() 

351 ) 

352 self._authz_denied = False 

353 

354 async def tick(self) -> None: 

355 excluded: set[UUID] = set() 

356 for _ in range(_MAX_CANDIDATES_PER_TICK): 

357 candidate = await self._candidate_lookup.next_candidate(exclude=frozenset(excluded)) 

358 if candidate is None: 

359 return 

360 outcome = await self._ingest_one(candidate) 

361 if outcome is _Outcome.STOP_TICK: 

362 return 

363 if outcome is _Outcome.SUCCESS: 

364 return 

365 excluded.add(candidate.capture_path_id) 

366 _log.warning( 

367 "capture_scan_ingestor.tick_exhausted_attempts", 

368 attempts=_MAX_CANDIDATES_PER_TICK, 

369 ) 

370 

371 async def _ingest_one(self, candidate: ScanIngestCandidate) -> _Outcome: 

372 binding = self._bindings.get(candidate.capture_code) 

373 if binding is None: 

374 _log.info( 

375 "capture_scan_ingestor.no_binding", 

376 capture_code=candidate.capture_code, 

377 run_id=str(candidate.run_id), 

378 ) 

379 return _Outcome.SKIP 

380 

381 location = binding.locations.get(candidate.root) 

382 if location is None: 

383 _log.warning( 

384 "capture_scan_ingestor.no_location_for_root", 

385 capture_code=candidate.capture_code, 

386 run_id=str(candidate.run_id), 

387 root=candidate.root, 

388 ) 

389 return _Outcome.SKIP 

390 

391 if binding.expected_camera_label is not None: 

392 camera_outcome = await self._check_producing_camera(candidate, binding) 

393 if camera_outcome is not None: 

394 return camera_outcome 

395 

396 locator = _mint_locator(candidate, deps=self._deps) 

397 if locator is None: 

398 _log.warning( 

399 "capture_scan_ingestor.no_matching_root", 

400 capture_code=candidate.capture_code, 

401 run_id=str(candidate.run_id), 

402 ) 

403 return _Outcome.SKIP 

404 

405 command = IngestScan( 

406 locator=locator, 

407 producing_asset_id=binding.producing_asset_id, 

408 supply_id=location.supply_id, 

409 access_protocol=location.access_protocol, 

410 producing_run_id=candidate.run_id, 

411 ) 

412 try: 

413 dataset_id = await self._ingest_scan( 

414 command, 

415 principal_id=CAPTURE_SCAN_INGESTOR_AGENT_ID, 

416 correlation_id=self._deps.id_generator.new_id(), 

417 ) 

418 except asyncio.CancelledError: 

419 raise 

420 except UnauthorizedError: 

421 if not self._authz_denied: 

422 _log.warning( 

423 "capture_scan_ingestor.ingest_unauthorized", 

424 capture_code=candidate.capture_code, 

425 run_id=str(candidate.run_id), 

426 ) 

427 self._authz_denied = True 

428 return _Outcome.STOP_TICK 

429 except DatasetAlreadyIngestedError as exc: 

430 _log.info( 

431 "capture_scan_ingestor.already_ingested", 

432 capture_code=candidate.capture_code, 

433 run_id=str(candidate.run_id), 

434 existing_dataset_id=str(exc.existing_dataset_id), 

435 ) 

436 return _Outcome.SKIP 

437 except InvalidScanFileError: 

438 # Never `str(exc)`: the message embeds the locator via 

439 # `repr()` (see this module's own docstring). The class 

440 # alone already says "structurally incomplete", "unreadable", 

441 # or "no timestamp"; that's enough for an operator to act on 

442 # without the path. 

443 _log.warning( 

444 "capture_scan_ingestor.invalid_scan_file", 

445 capture_code=candidate.capture_code, 

446 run_id=str(candidate.run_id), 

447 ) 

448 return _Outcome.SKIP 

449 except ( 

450 ProducingRunNotFoundError, 

451 AcquisitionAssetNotFoundError, 

452 DistributionSupplyNotFoundError, 

453 ): 

454 _log.exception( 

455 "capture_scan_ingestor.cross_reference_missing", 

456 capture_code=candidate.capture_code, 

457 run_id=str(candidate.run_id), 

458 ) 

459 return _Outcome.SKIP 

460 except Exception: 

461 _log.exception( 

462 "capture_scan_ingestor.ingest_failed", 

463 capture_code=candidate.capture_code, 

464 run_id=str(candidate.run_id), 

465 ) 

466 return _Outcome.SKIP 

467 if self._authz_denied: 

468 _log.info("capture_scan_ingestor.ingest_authorized_recovered") 

469 self._authz_denied = False 

470 _log.info( 

471 "capture_scan_ingestor.ingested", 

472 capture_code=candidate.capture_code, 

473 run_id=str(candidate.run_id), 

474 dataset_id=str(dataset_id), 

475 ) 

476 return _Outcome.SUCCESS

478 async def _check_producing_camera( 

479 self, 

480 candidate: ScanIngestCandidate, 

481 binding: CaptureScanIngestorBinding, 

482 ) -> _Outcome | None: 

483 """The producing-Asset cross-check (see this module's docstring). 

484 

485 Returns `None` when the candidate's recorded camera-selection 

486 observation confirms `binding.producing_asset_id`'s assumption, so 

487 the caller proceeds to ingest; returns `_Outcome.SKIP` (having 

488 already logged why) on a mismatch or a missing observation. Never 

489 raises: a lookup failure is a candidate this tick cannot confirm, 

490 not a systemic problem for the whole tick. 

491 """ 

492 assert binding.camera_channel_name is not None 

493 assert binding.expected_camera_label is not None 

494 observation = await self._run_channel_lookup.read_run_channel_categorical_latest( 

495 run_id=candidate.run_id, channel_name=binding.camera_channel_name 

496 ) 

497 if observation is None: 

498 _log.warning( 

499 "capture_scan_ingestor.camera_unconfirmed", 

500 capture_code=candidate.capture_code, 

501 run_id=str(candidate.run_id), 

502 channel_name=binding.camera_channel_name, 

503 expected_camera_label=binding.expected_camera_label, 

504 ) 

505 return _Outcome.SKIP 

506 if observation.categorical_value != binding.expected_camera_label: 

507 _log.warning( 

508 "capture_scan_ingestor.camera_mismatch", 

509 capture_code=candidate.capture_code, 

510 run_id=str(candidate.run_id), 

511 expected_camera_label=binding.expected_camera_label, 

512 actual_camera_label=observation.categorical_value, 

513 ) 

514 return _Outcome.SKIP 

515 return None

518async def _sweep_loop(ingestor: CaptureScanIngestor, *, interval_seconds: float) -> None: 

519 """Periodic sweep. A failed tick is logged (inside `tick()` itself, 

520 which never raises); cancellation propagates.""" 

521 while True: 

522 try: 

523 await ingestor.tick() 

524 except asyncio.CancelledError: 

525 raise 

526 except Exception: 

527 _log.exception("capture_scan_ingestor.tick_failed") 

528 await asyncio.sleep(interval_seconds)

531@contextlib.asynccontextmanager 

532async def capture_scan_ingestor_lifespan( 

533 deps: Kernel, 

534 *, 

535 ingest_scan: IdempotentHandler, 

536 interval_seconds: float | None = None, 

537) -> AsyncGenerator[None]: 

538 """Spawn the CaptureScanIngestor sweep for the duration of the 

539 context. No-op unless `settings.capture_scan_ingestor_enabled` is 

540 True (default off, so a deployment opts in explicitly). When 

541 enabled, probes the `IngestScan` grant once at startup (or refuses 

542 boot in strict mode) so a missing grant is surfaced immediately 

543 rather than only at the first denied tick, mirroring every sibling 

544 watcher/writer runtime's `probe_read_grant` startup check.""" 

545 if not deps.settings.capture_scan_ingestor_enabled: 

546 _log.info("capture_scan_ingestor.skipped", reason="disabled") 

547 yield 

548 return 

549 

550 await probe_read_grant(
