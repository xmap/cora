1"""`FacilityCode` value object: cross-deployment convergent facility slug. 

2 

3The cross-deployment convergent identity for a facility per the locked 

4two-tier identity design (`Facility.id: UUID` internal-opaque PK + 

5`Facility.code: FacilityCode` cross-deployment slug). Appears at every 

6port surface that names a facility for cross-BC and cross-deployment 

7purposes: `CredentialLookupResult.facility_id`, `PermitLookupResult. 

8peer_facility_id`, the `PermitLookup.lookup_outbound / lookup_inbound` 

9keys, and the Calibration BC `publish_revision` call sites. 

10 

11Wire payloads (event payloads, command DTOs) keep bare `str` on disk; 

12the VO is in-memory only at the port surface. Handlers construct 

13`FacilityCode(command.peer_facility_id)` at the port edge and pass the 

14typed VO to the port; the projection-row adapter constructs the VO from 

15the raw `TEXT` column. 

16 

17## Shape 

18 

19`@dataclass(frozen=True, slots=True)` with a single `value: str` field 

20(matches the `bounded_name` shape). Validation runs in `__post_init__` 

21because the codepoint set is regex-bounded (lowercase ASCII alphanumeric 

22+ dash, 1-32 chars), which the `bounded_name` decorator does not express. 

23 

24## Validation 

25 

26 - `value` is trimmed (leading/trailing whitespace stripped before length 

27 + regex checks); the trimmed value is what gets installed on the 

28 instance. 

29 - Trimmed length MUST be 1-32 chars. 

30 - Trimmed value MUST match `^[a-z0-9-]{1,32}$` (lowercase ASCII letters, 

31 digits, dash). No uppercase, no underscore, no slash, no dot. 

32 

33The regex is deliberately strict: cross-deployment convergent identity 

34means two facilities that both call themselves "aps" must produce equal 

35`FacilityCode` values byte-for-byte across the wire. Allowing mixed 

36case ("APS" vs "aps") would silently fork identity. 

37 

38## Error class 

39 

40`InvalidFacilityCodeError(value)` carries the ORIGINAL untrimmed input 

41so callers can diagnose whitespace-only or wrong-case rejections without 

42losing the offending characters (mirrors the `bounded_name` / 

43`Identifier` precedent). 

44 

45## Why not `bounded_name` decorator 

46 

47The `bounded_name` decorator handles trim + length + empty-after-trim 

48rejection but does NOT express regex codepoint restrictions. Adding a 

49`pattern` knob to the decorator is a rule-of-three call; with only one 

50codepoint-restricted VO today (this one), a bespoke `__post_init__` 

51keeps the shared decorator surface minimal. Re-evaluate when a SECOND 

52codepoint-restricted VO lands. 

53 

54Cross-reference [[project-structural-scope-design]] for the locked 

55two-tier identity design and the per-site migration plan. 

56""" 

57 

58import re 

59from dataclasses import dataclass 

60 

61FACILITY_CODE_MAX_LENGTH = 32 

62"""Max length (inclusive) for `FacilityCode.value` after trim. 

63 

6432 chars matches the convergent-slug budget across known facility 

65identifier conventions (e.g. ROR-style 9-char short codes, ISA-95 

66Site identifiers, common synchrotron short names like `maxiv`, `esrf`, 

67`spring8`). Re-visit if a real facility code exceeds 32 chars. 

68""" 

69 

70_FACILITY_CODE_PATTERN = re.compile(r"^[a-z0-9-]{1,32}$") 

71"""Pre-compiled codepoint pattern: lowercase ASCII alphanumeric + dash, 

721-32 chars. The pattern is locked at module load so every construction 

73runs against the same compiled regex.""" 

74 

75 

76class InvalidFacilityCodeError(ValueError): 

77 """A `FacilityCode`'s value is empty, whitespace-only, too long, or 

78 contains disallowed codepoints (anything outside `[a-z0-9-]`). 

79 

80 The `value` attribute carries the ORIGINAL untrimmed input so callers 

81 can diagnose whitespace-only or wrong-case rejections without losing 

82 the offending characters. 

83 """ 

84 

85 def __init__(self, value: str) -> None: 

86 super().__init__( 

87 f"FacilityCode must be 1-{FACILITY_CODE_MAX_LENGTH} lowercase ASCII " 

88 f"alphanumeric or dash chars after trimming (got: {value!r})" 

89 ) 

90 self.value = value 

91 

92 

93@dataclass(frozen=True, slots=True) 

94class FacilityCode: 

95 """Cross-deployment convergent facility slug. 

96 

97 Single `value: str` field, trimmed and pattern-validated in 

98 `__post_init__`. Two `FacilityCode` instances with the same trimmed 

99 value compare equal and hash equal; substitutable everywhere a port 

100 surface names a facility for cross-BC or cross-deployment purposes. 

101 """ 

102 

103 value: str 

104 

105 def __post_init__(self) -> None: 

106 trimmed = self.value.strip() 

107 if not _FACILITY_CODE_PATTERN.fullmatch(trimmed): 

108 raise InvalidFacilityCodeError(self.value) 

109 object.__setattr__(self, "value", trimmed) 

110 

111 def __str__(self) -> str: 

112 return self.value 

113 

114

116 "FACILITY_CODE_MAX_LENGTH", 

117 "FacilityCode", 

118 "InvalidFacilityCodeError", 

119]
