1"""ControlPort-backed `BeamAvailabilityLookup` (BEAM-1 pre-flight read). 

2 

3Reads the configured beam PVs live via the Operation BC's `ControlPort` 

4at the run / procedure start instant and maps them to a 

5`BeamAvailabilityLookupResult`. Lives in `cora.operation.adapters` because the 

6Operation BC owns `ControlPort`; the consumer (Run / Operation start 

7handlers) depends only on the `BeamAvailabilityLookup` port in 

8`cora.infrastructure.ports`. 

9 

10Polarity (per PSS-1): 

11 - FES / SBS `BeamBlockingM`: INVERTED. `0` = not blocking = open. 

12 - ACIS `FesPermitM`: `1` = FES-open permitted. 

13 

14A PV that is not configured does not gate (treated as open / permitted). 

15Any read that fails (disconnect / timeout) or returns non-Good quality 

16sets `quality_ok=False` AND that flag to its fail-closed value, so a dead 

17gateway can never read as "beam open". 

18 

19All three PVs are `bi` records at 2-BM, so a real read arrives as 

20`kind="Categorical"` with `EpicsCaControlPort` having already resolved 

21the DBR_ENUM index to its label; the index never reaches this module. 

22`_binary_code` resolves that label (or a plain numeric reading) to 0 / 1 

23before `_read_open` / `_read_permit` apply the polarity above. See 

24`_binary_code` for the label set and `cora.api._enclosure_permit_observer` 

25for the sibling occurrence of this same mapping. 

26"""

47# Conventional EPICS binary state labels. A DBR_ENUM reading reaches 

48# this module as its resolved label, never as its index, so the label 

49# is the only thing left to compare against. Second occurrence of this 

50# mapping; see `cora.api._enclosure_permit_observer._binary_code` for

52_ONE_LABELS = frozenset({"1", "ON", "TRUE", "YES"}) 

53_ZERO_LABELS = frozenset({"0", "OFF", "FALSE", "NO"})

56def _binary_code(value: object) -> int | None: 

57 """Resolve a beam PV reading to 1 / 0, or None when it is neither. 

58 

59 Polarity is NOT decided here: this only turns a raw reading (an 

60 int, an integral float, or an EPICS enum label) into 0 / 1. The 

61 caller (`_read_open` / `_read_permit`) applies the per-PV meaning. 

62 

63 A numeric reading outside {0, 1} (e.g. a stray 2) also resolves to 

64 None, not to its raw value. The old `int(raw)` had no such floor, 

65 so a PV reading 2 used to come back trusted (`quality_ok=True`) 

66 and simply compare unequal to the open/permit code. These PVs are 

67 `bi` records with exactly two states, so a reading outside {0, 1} 

68 is not a third state to interpret, it is a signal that something 

69 upstream is wrong, and that should fail closed like any other 

70 unbelievable reading rather than be read with confidence. 

71 """ 

72 if isinstance(value, str): 

73 token = value.strip().upper() 

74 if token in _ONE_LABELS: 

75 return 1 

76 if token in _ZERO_LABELS: 

77 return 0 

78 return None 

79 try: 

80 code = int(value) # type: ignore[call-overload] 

81 except (TypeError, ValueError): 

82 return None 

83 return code if code in (0, 1) else None

124 async def _read_int(self, pv: str) -> tuple[int | None, bool]: 

125 try: 

126 reading = await self._control_port.read(pv) 

127 except (ControlNotConnectedError, ControlTimeoutError): 

128 return None, False 

129 if reading.quality != "Good": 

130 return None, False 

131 raw = reading.value 

132 # A fractional reading on a binary shutter / permit PV (e.g. a 

133 # 0.4 BeamBlockingM) is not trustworthy: int() would truncate it 

134 # to 0 and read it as "open", a fail-OPEN hole. Treat any 

135 # non-integral float the same as a bad read (fail closed). 

136 if isinstance(raw, float) and not raw.is_integer(): 

137 return None, False 

138 value = _binary_code(raw) 

139 if value is None: 

140 return None, False 

141 return value, True

144def build_beam_availability_lookup( 

145 control_port: ControlPort, beam_pvs: Mapping[str, str] 

146) -> BeamAvailabilityLookup: 

147 """Build the deployment's `BeamAvailabilityLookup` (BEAM-1). 

148 

149 Mirrors `build_control_port`'s empty-config default: with no beam 

150 PVs configured (`BEAM_AVAILABILITY_PVS` unset, generic / non-2BM 

151 deployments) returns the always-open `AllBeamOpenLookup` stub so the 

152 start gate passes trivially (beam-by-default); with PVs configured 

153 returns a `ControlPortBeamAvailabilityLookup` reading them live 

154 through the shared `ControlPort`. 

155 """ 

156 if not beam_pvs: 

157 return AllBeamOpenLookup() 

158 return ControlPortBeamAvailabilityLookup(control_port=control_port, beam_pvs=beam_pvs)
