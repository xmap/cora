1"""Federation port-tier value types: domain-shaped, substrate-neutral. 

2 

3These are the vocabulary the three federation ports (`PublishPort`, 

4`PullPort`, `SignaturePort`) speak in. None of the names here mention 

5DSSE, COSE, JWS, Sigstore, Fulcio, Rekor, SCITT, JWKS, or CBOR (per 

6anti-hooks #1 + #3): wire-tier vocabulary is owned by the adapters 

7under `cora/federation/adapters/*` and `cora/infrastructure/adapters/*`. 

8 

9`abi_tier` is typed `str` at this tier for now; the closed-enum 

10`AbiTier(Testing | Stable | Obsolete | Removed)` lives at BC-tier in 

11`cora.federation.aggregates.permit.state.AbiTier` and will hoist to 

12this module in a follow-up iteration once the BC-tier import sites 

13are refactored (~9 files). The string discipline is documented but 

14not enforced at the port boundary today. 

15"""

86SignatureEnvelope = DsseStaticJwksEnvelope | DsseSigstoreKeylessEnvelope | CoseSign1ScittEnvelope 

87"""Discriminated tagged union over `kind`. Consumers dispatch via 

88`isinstance` or by matching on `envelope.kind`. The three arms are 

89the locked v1 set per the memo; new arms expand the union and add a 

90new `kind` literal."""

93@dataclass(frozen=True, slots=True) 

94class SignedOffBy: 

95 """Human Signed-off-by attribution; the only DCO arm that closes the chain. 

96 

97 Per the Linux-kernel `coding-assistants.rst` invariant transplant, 

98 AI actors cannot Signed-off-by. 

99 

100 NOT ENFORCED TODAY. Nothing checks that `actor_id` resolves to 

101 `Actor.kind == human`: no decider reads the kind, and 

102 `DcoChainMissingHumanSignoffError` does not exist. `check_dco_chain` 

103 verifies only that the chain carries at least one `SignedOffBy` 

104 entry, not that its actor is human, so an agent actor_id passes 

105 today. The human-only rule is design intent per 

106 [[project_federation_port_design]], not a shipped check. Building it 

107 would add the first branch on `Actor.kind` outside the two carve-outs 

108 enumerated in `tests/architecture/test_actor_kind_blindness.py`, which 

109 is where the reason for it belongs. 

110 """ 

111 

112 actor_id: UUID 

113 signed_at: datetime

157@dataclass(frozen=True, slots=True) 

158class PublishedArtifact: 

159 """Domain-shaped artifact ready to publish or verify. 

160 

161 The port boundary carries everything a peer facility needs to 

162 verify the artifact end-to-end: the canonical bytes, the 

163 signature envelope, the canonicalization recipe identifier, 

164 the DCO chain, the ABI tier + lifecycle slots. No wire-tier 

165 vocabulary leaks through. 

166 

167 `abi_tier` is `str` at this tier (see module docstring). 

168 `canonicalization_version` is the recipe identifier per 

169 [[project_canonicalization_port_design]]; the verifier 

170 dispatches to the matching adapter via 

171 `CanonicalizationRegistry.resolve(version)`. 

172 """ 

173 

174 content_hash: bytes 

175 canonical_bytes: bytes 

176 payload_type: str 

177 signature_envelope: SignatureEnvelope 

178 source_facility_id: UUID 

179 published_at: datetime 

180 expires_at: datetime | None 

181 abi_tier: str 

182 dco_chain: tuple[DcoEntry, ...] 

183 schema_version: int 

184 canonicalization_version: str

245@dataclass(frozen=True, slots=True) 

246class FederationTrustContext: 

247 """Policy under which a federation verification runs. 

248 

249 Composed at verify time from the matching inbound-direction 

250 `Permit` (per arch-7, the aggregate's `InboundTerms` variant 

251 carries flat fields, not a `FederationTrustContext` field, to 

252 avoid Permit -> FederationTrustContext -> Permit circular 

253 containment). 

254 

255 `accept_yanked: Literal[False]` is structural: there is no 

256 `accept_expired` override, period (AH#19). The verifier never 

257 accepts a yanked publication; only an explicit `unyank` 

258 operator action restores it. 

259 

260 `required_receipt_kinds` is the consumer-side floor for 

261 transparency-log evidence per arm; default empty for backward 

262 compat. When non-empty, the verifier raises 

263 `FederationReceiptMissingError` if `envelope.receipts` does 

264 not contain at least one receipt matching each required kind. 

265 """ 

266 

267 permit_id: UUID 

268 allowed_credentials: frozenset[CredentialRef] 

269 allowed_payload_types: frozenset[str] 

270 abi_tier_floor: str 

271 accept_yanked: Literal[False] = False 

272 required_receipt_kinds: frozenset[Literal["scitt", "rekor_sct", "ts_authority"]] = field( 

273 default_factory=lambda: frozenset[Literal["scitt", "rekor_sct", "ts_authority"]]() 

274 )

296@dataclass(frozen=True, slots=True) 

297class StageResult: 

298 """Per-stage verification result.

359VerificationOutcome = Verified | Rejected | Unverifiable 

360"""Discriminated union over verifier outcome. Callers branch via 

361`isinstance`. The three arms map exactly to the SignatureVerification 

362verdict triple on the kernel-tier ByteSigner: 

363Verified ≅ Valid, Rejected ≅ Invalid, Unverifiable ≅ Unverifiable."""

373def is_envelope_kind(envelope: SignatureEnvelope, kind: str) -> bool: 

374 """Match an envelope against a `kind` literal without isinstance dispatch. 

375 

376 Helper for routing code that holds a `kind` string from a config 

377 or a wire payload and wants to verify it matches the envelope's 

378 own discriminator. Keeps the dispatch out of `if/elif` ladders. 

379 """ 

380 return envelope.kind == kind

393def stage_results_outcome_counts( 

394 stage_results: Sequence[StageResult], 

395) -> dict[str, int]: 

396 """Return a counts dict per outcome label for logging/diagnostics.""" 

397 counts = {"pass": 0, "fail": 0, "skip": 0} 

398 for r in stage_results: 

399 counts[r.outcome] = counts[r.outcome] + 1 

400 return counts
