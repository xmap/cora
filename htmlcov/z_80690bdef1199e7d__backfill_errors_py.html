1"""Lifespan-bootstrap error class for the Slice 2 Distribution backfill. 

2 

3Per [[project-data-distribution-design]] L23 + L23a: the Slice 2 backfill 

4runs as a runtime-Python lifespan step at app startup (NOT an Atlas SQL 

5migration, because Atlas CLI is a separate process and cannot read 

6session-local GUCs set by app lifespan). The bootstrap resolves the 

7``SELF_FACILITY_DEFAULT_STORAGE_SUPPLY_CODE`` env var to a Supply row via 

8the projection; any failure mode below causes the app to refuse to start 

9(fail-loud). 

10 

11These are not domain errors raised by the decider; they are lifespan-tier 

12errors raised by ``bootstrap_default_storage_supply`` before any HTTP 

13route opens. Operator remediation is described in the per-kind message. 

14 

15## One class, one kind enum 

16 

17The four failure modes (env-var-unset-with-legacy-data, missing Supply, 

18wrong kind, non-Available status) all carry the same conceptual shape: 

19"lifespan failed to resolve the default storage Supply". Per the 

20altitude-correction in PR #60 code review, they collapse to a single 

21``DefaultStorageSupplyBootstrapError`` carrying a 

22``DefaultStorageSupplyBootstrapFailure`` enum discriminator plus 

23per-kind context fields, instead of four near-identical subclasses. 

24""" 

25 

26from enum import StrEnum 

27 

28 

29class DefaultStorageSupplyBootstrapFailure(StrEnum): 

30 """Discriminator for the four lifespan-bootstrap failure modes.""" 

31 

32 CODE_UNSET = "CodeUnset" 

33 NOT_FOUND = "NotFound" 

34 KIND_MISMATCH = "KindMismatch" 

35 NOT_AVAILABLE = "NotAvailable" 

36 

37 

38class DefaultStorageSupplyBootstrapError(Exception): 

39 """Lifespan boot failed to resolve the default storage Supply. 

40 

41 Carries a ``kind`` discriminator and per-kind context fields. Use 

42 the ``kind`` attribute (a :class:`DefaultStorageSupplyBootstrapFailure` 

43 member) to branch on the specific failure mode. 

44 

45 Operator remediation depends on ``kind``: 

46 

47 - ``CODE_UNSET``: set ``SELF_FACILITY_DEFAULT_STORAGE_SUPPLY_CODE`` in 

48 the app environment to the ``code`` of an existing storage-kind 

49 Available Supply, then restart. 

50 - ``NOT_FOUND``: register the Supply first via ``register_supply`` 

51 REST/MCP, or fix the env var to point at an already-registered 

52 storage-kind Supply. 

53 - ``KIND_MISMATCH``: point the env var at a different Supply whose 

54 kind is ``"Storage"``, or register a new storage-kind Supply. 

55 - ``NOT_AVAILABLE``: mark the Supply Available via 

56 ``mark_supply_available`` (or operator equivalent), or point the 

57 env var at a different Available storage Supply. 

58 """ 

59
