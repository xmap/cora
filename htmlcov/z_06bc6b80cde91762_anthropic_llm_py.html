1"""Anthropic implementation of `LLM`. 

2 

3Lives under `cora.agent.adapters` per the cross-BC 

4adapter-ownership convention (Safety BC owns 

5`PostgresClearanceLookup`, Caution BC owns `PostgresCautionLookup`, 

6Agent BC owns this). 

7 

8## Structured output via tool-use 

9 

10The Anthropic API exposes structured output through the 

11tool-use-as-structured-output convention: define a single tool 

12whose `input_schema` IS the desired output schema, set 

13`tool_choice` to force that tool, then parse the resulting 

14`tool_use` block's `input` field as the output. 

15 

16This convention has been stable since Claude 3.5 Sonnet (mid-2024) 

17and survives across model upgrades. The adapter generates the 

18synthetic tool name `cora_structured_output` (a single name across 

19all calls so the cache layer for the tools block remains stable; 

20the `input_schema` differs per call but the tool definition's 

21position in the request is identical). 

22 

23## Cache breakpoints 

24 

25`LLMContentBlock.cache` markers are translated to 

26`cache_control={"type": "ephemeral", "ttl": ...}` on the 

27corresponding `TextBlockParam`. Anthropic accepts at most 4 

28cache-marked blocks per request across system + tools + messages; 

29the adapter raises `LLMInvalidRequestError` BEFORE the API call 

30when this is exceeded so misconfigured prompts fail loudly. 

31 

32When any breakpoint requests the `"1h"` TTL, the adapter sets the 

33`anthropic-beta: extended-cache-ttl-2025-04-11` header (the 1h tier 

34is gated behind this beta flag). 

35 

36## Retries 

37 

38The Anthropic SDK ships with `max_retries=2` exponential backoff 

39out of the box (0.5s to 8s on 408/409/429/5xx + connection 

40errors). The adapter uses this default unchanged per the design 

41memo lock; setting `max_retries=2` explicitly here makes the value 

42auditable from the adapter without grepping SDK source. The 

4310-minute request timeout is a defensive ceiling: RunDebriefer 

44generation typically completes in 5-15 seconds; 600s catches 

45catastrophic provider stalls without paying for a forever-hung 

46subscriber call. 

47 

48## Error translation 

49 

50After the SDK exhausts inner retries, any remaining SDK error is 

51translated to the `LLM` taxonomy so consumers depend only on 

52the port-level error classes. Mapping: 

53 

54 - `AuthenticationError` (401 / 403) -> `LLMAuthenticationError` 

55 - `RateLimitError` (429) -> `LLMRateLimitError` 

56 - `APITimeoutError` -> `LLMTimeoutError` 

57 - `BadRequestError` (400) -> `LLMInvalidRequestError` 

58 - `InternalServerError` (5xx) -> `LLMServerError` 

59 - `APIConnectionError` -> `LLMServerError` (network-flavored) 

60 - Any other `APIStatusError` -> `LLMServerError` (defensive default) 

61 - Tool-use missing / schema mismatch on response -> `LLMSchemaValidationError` 

62 

63## Serving the same protocol through a gateway 

64 

65Two constructor arguments, `provider_name` and `resolve_model_id`, 

66exist so a gateway that speaks the Anthropic Messages protocol can 

67reuse this adapter's mechanics without a second copy of them. 

68`ArgoLLM` is the caller: Argonne's gateway serves `/v1/messages` 

69unchanged (forced tool-use and 1h-TTL cache breakpoints both 

70measured working through it) but wants bespoke model identifiers on 

71the wire and its own name in telemetry. 

72 

73A third, `inspect_response`, exists because a gateway can return 

74something that is shaped like a response but is not one. Argo answers 

75an unrecognized username with HTTP 200 and a synthetic assistant 

76message, so the hook runs before structured-output extraction and lets 

77the gateway's adapter classify that as the authentication failure it 

78is. Without it the missing tool-use block would surface as a schema 

79error and send an operator to debug a prompt over a credential. 

80 

81`chat` refuses a request whose `model_ref.provider` disagrees with 

82`provider_name`, and the guard lives here rather than in each gateway's 

83adapter so both directions are covered by construction. The asymmetric 

84version was worse than no guard in one respect: it made the gateway 

85path fail loudly while the direct path stayed silent, which is the 

86opposite of where a reader would expect the risk. 

87 

88None of the three make this a config-switched multi-provider 

89adapter. Gateway-specific concerns (the identifier map, the refusal 

90to accept a snapshot pin the gateway cannot honor) live in the 

91gateway's own adapter class, so the direct-Anthropic path stays free 

92of them. 

93"""

128# Reported as `gen_ai.provider.name` when no gateway overrides it. 

129_DIRECT_PROVIDER_NAME = "anthropic" 

130 

131# Single stable tool name across every call so the tools-layer 

132# cache breakpoint stays warm. The schema differs per call (lives 

133# in `input_schema`); the name does not. 

134_STRUCTURED_OUTPUT_TOOL_NAME = "cora_structured_output" 

135 

136# Anthropic's per-request limit on cache_control markers. Exceeding 

137# it is rejected by the API; we validate client-side so adapters 

138# fail loudly with a useful message instead of cryptic 400. 

139_MAX_CACHE_BREAKPOINTS = 4 

140 

141# Default request-level timeout for one LLM call (seconds). Catches 

142# catastrophic stalls without exceeding the design's 10-minute 

143# ceiling. Adjustable via constructor for tests / future tuning. 

144_DEFAULT_REQUEST_TIMEOUT_SECONDS = 600.0 

145 

146# Anthropic SDK default retries; pinned here for auditability per 

147# the design memo (max_retries=2, exponential 0.5s-8s). 

148_DEFAULT_MAX_RETRIES = 2 

149 

150# Beta header required when any cache breakpoint requests the 1h 

151# TTL. The 5m TTL is the default tier and doesn't need a header. 

152_EXTENDED_CACHE_TTL_BETA = "extended-cache-ttl-2025-04-11"

157def _or_omit(value: float | None) -> float | anthropic.Omit: 

158 """Pass a dial through, or the SDK's own "not sent" sentinel. 

159 

160 `anthropic.omit` rather than a `**kwargs` splat: splatting defeats 

161 pyright's overload matching on `messages.create`, which then reports 

162 the float against every unrelated keyword the method accepts. 

163 

164 Omitting is not the same as sending the provider's documented 

165 default: the SDK's default may differ from the docs, and a value we 

166 guessed would be recorded as provenance we never chose. A caller 

167 that sets nothing gets the provider's behaviour and makes no claim 

168 about it. 

169 

170 There is no `seed` here because the Anthropic Messages API has none. 

171 That is the ceiling on replaying a vendor call however the dials are 

172 set, and it is why the catalog can promise an invocable identity but 

173 never an identical answer. 

174 """ 

175 return anthropic.omit if value is None else value

178class AnthropicLLM: 

179 """Production `LLM` implementation backed by `anthropic.AsyncAnthropic`. 

180 

181 Constructor accepts `api_key` directly (read from `Settings.anthropic_api_key` 

182 by the Kernel factory) rather than implicitly via the SDK's env-var 

183 lookup. Centralising the credential at the composition root keeps 

184 sensitive material off the global environment for the rest of the 

185 process and gives tests a clean injection point. 

186 

187 Optionally accepts an explicit `client: AsyncAnthropic` for tests 

188 that want to wire a mock or a recorded fixture; production wiring 

189 leaves it `None` and the adapter constructs its own. 

190 """ 

191 

192 def __init__( 

193 self, 

194 *, 

195 api_key: str, 

196 max_retries: int = _DEFAULT_MAX_RETRIES, 

197 request_timeout_seconds: float = _DEFAULT_REQUEST_TIMEOUT_SECONDS, 

198 client: anthropic.AsyncAnthropic | None = None, 

199 provider_name: str = _DIRECT_PROVIDER_NAME, 

200 resolve_model_id: Callable[[ModelRef], str] | None = None, 

201 inspect_response: Callable[[anthropic.types.Message], None] | None = None, 

202 ) -> None: 

203 self._client = client or anthropic.AsyncAnthropic( 

204 api_key=api_key, 

205 max_retries=max_retries, 

206 timeout=request_timeout_seconds, 

207 ) 

208 self._provider_name = provider_name 

209 self._resolve_model_id = resolve_model_id or _resolve_model_id 

210 self._inspect_response = inspect_response

212 async def aclose(self) -> None: 

213 """Release the underlying httpx connection pool. 

214 

215 Wired into `Kernel.Teardown` from `cora.api.main` so the 

216 FastAPI lifespan closes the SDK client at shutdown. Without 

217 this the underlying `httpx.AsyncClient` leaks its connection 

218 pool on every process exit (a watch item flagged at gate 

219 review). 

220 """ 

221 await self._client.close()

223 async def chat(self, request: LLMChatRequest) -> LLMResponse: 

224 if request.model_ref.provider != self._provider_name: 

225 msg = ( 

226 f"model_ref names provider {request.model_ref.provider!r} but this " 

227 f"adapter serves {self._provider_name!r}. Cost resolves from the " 

228 "model_ref while the serving route comes from configuration, so a " 

229 "call served by one and priced as the other misattributes spend " 

230 "with nothing to show for it. Price the catalog entry as " 

231 f"{self._provider_name!r}, or select the adapter that matches it." 

232 ) 

233 raise LLMInvalidRequestError(msg) 

234 

235 cache_count = _count_cache_breakpoints(request) 

236 if cache_count > _MAX_CACHE_BREAKPOINTS: 

237 msg = ( 

238 f"LLMChatRequest has {cache_count} cache breakpoints; " 

239 f"Anthropic accepts at most {_MAX_CACHE_BREAKPOINTS}. " 

240 "Merge layers or drop a breakpoint." 

241 ) 

242 raise LLMInvalidRequestError(msg) 

243 

244 system_blocks: list[TextBlockParam] = [ 

245 _to_text_block_param(block.text, block.cache) for block in request.system.blocks 

246 ] 

247 user_blocks: list[TextBlockParam] = [ 

248 _to_text_block_param(request.user_message.text, request.user_message.cache) 

249 ] 

250 

251 synthetic_tool = ToolParam( 

252 name=_STRUCTURED_OUTPUT_TOOL_NAME, 

253 description=( 

254 "Emit the structured Decision payload. Always call this tool exactly " 

255 "once; do not return free-form prose. Every field in the input_schema " 

256 "is required unless marked optional." 

257 ), 

258 input_schema=cast("dict[str, object]", dict(request.structured_output_schema)), 

259 ) 

260 tool_choice: ToolChoiceToolParam = { 

261 "type": "tool", 

262 "name": _STRUCTURED_OUTPUT_TOOL_NAME, 

263 } 

264 

265 extra_headers = _maybe_extended_cache_header(request) 

266 model_id = self._resolve_model_id(request.model_ref) 

267 

268 with ( 

269 track_in_flight_call(request.model_ref), 

270 _tracer.start_as_current_span("llm.chat") as span, 

271 ): 

272 try: 

273 message = await self._client.messages.create( 

274 model=model_id, 

275 max_tokens=request.max_output_tokens, 

276 system=system_blocks, 

277 messages=[{"role": "user", "content": user_blocks}], 

278 tools=[synthetic_tool], 

279 tool_choice=tool_choice, 

280 extra_headers=extra_headers, 

281 temperature=_or_omit(request.temperature), 

282 top_p=_or_omit(request.top_p), 

283 ) 

284 except anthropic.AuthenticationError as exc: 

285 raise LLMAuthenticationError(str(exc)) from exc 

286 except anthropic.RateLimitError as exc: 

287 raise LLMRateLimitError(str(exc)) from exc 

288 except anthropic.APITimeoutError as exc: 

289 raise LLMTimeoutError(str(exc)) from exc 

290 except anthropic.BadRequestError as exc: 

291 raise LLMInvalidRequestError(str(exc)) from exc 

292 except anthropic.InternalServerError as exc: 

293 raise LLMServerError(str(exc)) from exc 

294 except anthropic.APIConnectionError as exc: 

295 raise LLMServerError(f"network error: {exc}") from exc 

296 except anthropic.APIStatusError as exc: 

297 # Defensive default for any APIStatusError subclass not 

298 # named above. Mapping to LLMServerError treats it as 

299 # retryable; the alternative (silently surfacing the SDK 

300 # exception) would skip the retry layer. 

301 raise LLMServerError(str(exc)) from exc 

302 

303 if self._inspect_response is not None: 

304 self._inspect_response(message) 

305 

306 tool_use_block = _find_structured_output_block(message) 

307 parsed = tool_use_block.input 

308 raw_text = _extract_raw_text(message) 

309 usage = _to_llm_usage(message.usage) 

310 response_model_id = message.model 

311 stop_reason = message.stop_reason or "end_turn" 

312 

313 # `record_llm_call` returns the computed USD cost; the 

314 # adapter intentionally discards it here. The cost is 

315 # persisted on the `cora.agent.llm.cost.usd` histogram 

316 # (where dashboards consume it), and durably by the LLM 

317 # producers, which recompute it via `compute_cost_usd` 

318 # (same pure function, same inputs) onto the inference 

319 # entry's cost_usd. Surfacing it on `LLMResponse` would 

320 # force every consumer to think about pricing semantics; 

321 # consumers that want the value compute it from usage. 

322 record_llm_call( 

323 span, 

324 provider_name=self._provider_name, 

325 request_model_ref=request.model_ref, 

326 response_model_id=response_model_id, 

327 usage=usage, 

328 stop_reason=stop_reason, 

329 max_tokens=request.max_output_tokens, 

330 ) 

331 

332 return LLMResponse( 

333 parsed=parsed, 

334 raw_text=raw_text, 

335 usage=usage, 

336 stop_reason=stop_reason, 

337 model_id=response_model_id, 

338 response_id=message.id, 

339 tool_call_id=tool_use_block.id, 

340 tool_name=tool_use_block.name, 

341 )

344def _count_cache_breakpoints(request: LLMChatRequest) -> int: 

345 """Sum cache markers across system + user blocks. 

346 

347 The adapter does NOT include the synthetic structured-output 

348 tool in the count because it never carries `cache_control` here 

349 (the schema differs per call so caching the tool definition 

350 would be meaningless). Tools-layer caching for stable tools 

351 (such as a future RecipeScreener) lands when an additive `tools` 

352 field appears on `LLMChatRequest`. 

353 """ 

354 count = 0 

355 for block in request.system.blocks: 

356 if block.cache is not None: 

357 count += 1 

358 if request.user_message.cache is not None: 

359 count += 1 

360 return count

363def _to_text_block_param( 

364 text: str, 

365 cache: CacheBreakpoint | None, 

366) -> TextBlockParam: 

367 if cache is None: 

368 return {"type": "text", "text": text} 

369 cache_control = CacheControlEphemeralParam(type="ephemeral", ttl=cache.ttl) 

370 return {"type": "text", "text": text, "cache_control": cache_control}

373def _maybe_extended_cache_header(request: LLMChatRequest) -> dict[str, str]: 

374 """Return the beta header dict when any breakpoint asks for 1h TTL. 

375 

376 Empty dict otherwise (`AsyncAnthropic.messages.create(extra_headers={})` 

377 is a no-op; we always pass the kwarg so the SDK doesn't trip on 

378 `None` in some edge path). 

379 """ 

380 needs_1h = any( 

381 block.cache is not None and block.cache.ttl == "1h" for block in request.system.blocks 

382 ) or (request.user_message.cache is not None and request.user_message.cache.ttl == "1h") 

383 if needs_1h: 

384 return {"anthropic-beta": _EXTENDED_CACHE_TTL_BETA} 

385 return {}

388def _resolve_model_id(model_ref: ModelRef) -> str: 

389 """Resolve `ModelRef` to the API-level model identifier. 

390 

391 Anthropic accepts either `claude-opus-4-7` (latest stable) or 

392 a pinned snapshot like `claude-opus-4-7-20260301`. We compose 

393 `<model>-<snapshot_pin>` when a pin is set; otherwise the bare 

394 model name selects "latest stable for this model family" per 

395 Anthropic's convention. 

396 """ 

397 if model_ref.snapshot_pin is None: 

398 return model_ref.model 

399 return f"{model_ref.model}-{model_ref.snapshot_pin}"

402def _find_structured_output_block(message: anthropic.types.Message) -> ToolUseBlock: 

403 """Find the synthetic-tool block; raise if absent or wrong-named. 

404 

405 Returns the whole block, not just `.input`: `.id` and `.name` are the 

406 call's `tool_call_id` / `tool_name` provenance, discarded until the 

407 inference ledger gained columns for them. The SDK's typing guarantees 

408 `ToolUseBlock.input` is `dict[str, object]` (Anthropic JSON-decodes 

409 server-side). We trust the type at the structural level and validate 

410 presence-by-name, not shape. 

411 """ 

412 for block in message.content: 

413 if isinstance(block, ToolUseBlock) and block.name == _STRUCTURED_OUTPUT_TOOL_NAME: 

414 return block 

415 msg = ( 

416 f"response had no tool_use block named {_STRUCTURED_OUTPUT_TOOL_NAME!r}; " 

417 f"stop_reason={message.stop_reason}, content_block_types=" 

418 f"{[b.type for b in message.content]}" 

419 ) 

420 raise LLMSchemaValidationError(msg)

423def _extract_raw_text(message: anthropic.types.Message) -> str: 

424 """Concatenate every TextBlock in the response into a single string. 

425 

426 Tool-use-structured-output responses often have zero TextBlocks 

427 (the model went straight to the tool call). Returning `""` in 

428 that case is intentional: the structured output is in `parsed`, 

429 not in raw_text. 

430 """ 

431 parts: list[str] = [] 

432 for block in message.content: 

433 if block.type == "text": 

434 parts.append(block.text) 

435 return "".join(parts)
