1"""Deterministic stream-id derivation for Shortfall. 

2 

3A Shortfall is keyed on the capture observation it judges, one stream 

4per `capture_path_id`, and the id is derived rather than minted so the 

5EVENT STORE is what enforces "at most one Shortfall per observation". 

6 

7## Why derived, when Acquisition and Attestation mint a fresh UUIDv7 

8 

9Those two are reached once, by a caller who has already decided to 

10record. This one is reached by a sweep that retries the same candidate 

11every tick. `_CANDIDATE_SQL` does drop a candidate once its Shortfall 

12lands, but that read goes through `proj_data_shortfall_summary`, and a 

13projection lags: between the append and the projection catching up, the 

14next tick re-selects the same candidate and tries again. With a fresh 

15id per attempt each of those retries would mint ANOTHER Shortfall 

16stream, and the record would accumulate one duplicate per tick of 

17projection lag. 

18 

19Deriving the id makes the second append a version conflict against a 

20stream that already exists, so uniqueness is guaranteed by 

21`expected_version=0` inside the same transaction rather than by a read 

22that can be stale. Idempotency is not a projection read. 

23 

24## Derived from the surrogate, never from the path 

25 

26The input is `capture_path_id`, the opaque surrogate key of the 

27`run_capture_path` vault row. Never the observed path and never the 

28filename: both embed `{UserLastName}-{ProposalNumber}` at 2-BM, and a 

29path-seeded uuid5 would be a confirmation oracle, letting anyone who 

30could guess a path test that guess against the derived stream id. 

31 

32`_DATA_SHORTFALL_NAMESPACE` is a fixed sentinel chosen once and frozen; 

33it MUST NOT change, or existing Shortfall streams become unreachable. 

34Mirrors `_FEDERATION_SEAL_NAMESPACE` and the 

35`_DATA_DISTRIBUTION_BACKFILL_NAMESPACE` precedent in this same BC. 

36""" 

37 

38from uuid import UUID, uuid5 

39 

40_DATA_SHORTFALL_NAMESPACE = UUID("01900000-0000-7000-8000-0000da5f0001") 

41 

42 

43def shortfall_stream_id(capture_path_id: UUID) -> UUID: 

44 """Derive the deterministic Shortfall stream UUID from the vault 

45 row's surrogate key. 

46 

47 The result is used as BOTH the stream id and the `shortfall_id` on 

48 the payload, same as every other aggregate whose stream id is its 

49 own identity; the difference here is only that the value is derived 

50 instead of minted. 

51 """ 

52 return uuid5(_DATA_SHORTFALL_NAMESPACE, str(capture_path_id)) 

53 

54 

55__all__ = ["shortfall_stream_id"]
