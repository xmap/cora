1"""Composition-root edge conductor: terminalize ANY aggregate FSM over a port. 

2 

3`EdgeConductor` is the ONE L2 edge-runtime shell the composition root 

4hosts. It conducts an aggregate (a Run, or a Procedure phase) to its 

5terminal across a substrate port, generalising what the Procedure 

6`Conductor` (over `ControlPort`) and the now-dissolved Reckoner (over 

7`ComputePort`) each did with their own near-identical `conduct()` spine. 

8 

9## What it unifies 

10 

11The two spines reduced to ONE shape modulo (a) the inner work primitive 

12and (b) whether the engine owns the start transition. `EdgeConductor` 

13captures the shared shell: 

14 

15 optional start -> inner work (yields a ConductOutcome) -> terminal 

16 

17and drives EITHER FSM by INJECTING the parts that genuinely diverge, 

18never hardcoding one aggregate: 

19 

20- **`start`** (`Optional`): a Procedure phase issues `start_procedure` 

21 inside the conduct; a Run passes NONE (`start_run` is the heavy gated 

22 entry that must not fold in, so the caller starts the Run upstream). 

23- **`complete` / `abort`** (the terminalize pair): each is an injected 

24 builder that, given the inner `ConductOutcome`, issues its FSM's 

25 terminal command. The complete arm carries the success provenance; the 

26 abort arm is best-effort. The `artifact_uri` asymmetry lives in the 

27 injected builders: a Run's complete arm carries it, its abort arm does 

28 not, so the two arms build DIFFERENT commands, not one shared bag. 

29- **`reraise`** (a per-FSM exception set): the Procedure path re-raises a 

30 closed lifecycle set (`UnauthorizedError` / `ProcedureNotFoundError` / 

31 `ConcurrencyError` -> 403/404/409 route mappers); the Run path catches 

32 broadly (an EMPTY set), matching the dissolved Reckoner. The engine 

33 carries BOTH as injected sets, never hardcoding one. 

34 

35## The two kind-sources are preserved 

36 

37The actuation kind the engine threads onto the terminal comes from the 

38INNER work, never from the engine: a control-step conduct derives it 

39through the Procedure Conductor's `_ActuationObserver`; a compute conduct 

40derives it from `ComputePort.provide_result(...).actuation_kind`. The 

41engine is agnostic; the inner work hands it a `ConductOutcome` already 

42carrying the observed kind, and the injected terminalize builders read it 

43back off the concrete outcome. 

44 

45## Why it lives at `cora.api` 

46 

47It needs both `ComputePort` (`cora.operation`-owned) and the Run FSM 

48handlers (`cora.run.features`). tach forbids `cora.run -> cora.operation`, 

49and Operation imports only `cora.run.aggregates`, so no BC can host a 

50runtime that needs both. `cora.api` is the one module that depends on 

51both, exactly as the dissolved Reckoner did. The merge is a code 

52consolidation, not a layering move and not a BC merge: the Run and 

53Procedure AGGREGATES stay separate. 

54 

55## Single-blocking, cancel-orphan-safe 

56 

57The inner work completes within one `conduct()` call (no intermediate 

58FSM state). A cancelled conduct best-effort aborts the aggregate via the 

59shared `abort_orphan_on_cancel`, then re-raises, so a cancelled conduct 

60never strands the FSM in `Running`. The guard wraps the WHOLE inner work 

61(submit + await + fetch), not only the await: a DELIBERATE strengthening 

62over the dissolved Reckoner, which guarded `await_terminal_state` alone. 

63So a cancel during submit, or during the post-success artifact fetch, also 

64terminalizes the aggregate (Aborted) instead of leaving a Run `Running`; 

65the trade is that a job that succeeded just before a mid-fetch cancel is 

66aborted rather than left recoverable (the stronger never-strand invariant 

67wins). Behaviour is otherwise byte-for-byte the dissolved Reckoner's. The 

68fire-and-reconcile split (submit returns immediately; a reconciler 

69completes later) is the second-substrate (Slurm) trigger, deferred. 

70"""

112class EdgeConductor[OutcomeT: ConductOutcome]: 

113 """The composition-root edge-runtime shell: optional-start -> work -> terminal. 

114 

115 Construct once per driven FSM with the injected handlers; call 

116 `conduct` per episode. It drives EITHER FSM: 

117 

118 - a Run (`start=None`, empty `reraise`, `complete`/`abort` build the 

119 Run terminals carrying the `artifact_uri` asymmetry); 

120 - a Procedure phase (`start` issues `start_procedure`, `reraise` is the 

121 lifecycle set, `complete`/`abort` build the Procedure terminals). 

122 

123 The shell owns ONLY the cross-FSM control flow: the optional start, the 

124 cancel-orphan-safe inner await, the success/failure terminalize branch, 

125 and the per-FSM reraise policy. Everything FSM-specific is injected. 

126 """ 

127 

128 def __init__( 

129 self, 

130 *, 

131 start: Callable[[], Awaitable[object]] | None, 

132 complete: Callable[[OutcomeT], Awaitable[OutcomeT]], 

133 abort: Callable[[OutcomeT], Awaitable[OutcomeT]], 

134 cancel_abort: Callable[[], Awaitable[object]], 

135 reraise: tuple[type[Exception], ...], 

136 ) -> None: 

137 self._start = start 

138 self._complete = complete 

139 self._abort = abort 

140 self._cancel_abort = cancel_abort 

141 self._reraise = reraise

143 async def conduct(self, inner: Callable[[], Awaitable[OutcomeT]]) -> OutcomeT: 

144 """Conduct one episode: optional start -> `inner` -> terminalize. 

145 

146 `inner` performs the FSM-specific work (submit/await/fetch for a 

147 compute Run; the Conductor's step walk for a Procedure phase) and 

148 returns its concrete `ConductOutcome`. The shell then completes on 

149 success or best-effort aborts on failure, returning the terminalize 

150 builder's (possibly amended) outcome - a complete-terminal rejection 

151 becomes a failure on the returned outcome. 

152 

153 The injected `start` re-raises its FSM's lifecycle set 

154 (`UnauthorizedError` / not-found / concurrency) so the route layer 

155 maps them to 403/404/409; a non-lifecycle start rejection is the 

156 builder's concern. A `CancelledError` while `inner` runs best-effort 

157 aborts via the injected `cancel_abort` and re-raises, so the FSM is 

158 never stranded in `Running` by a cancellation. 

159 """ 

160 if self._start is not None: 160 ↛ 161line 160 didn't jump to line 161 because the condition on line 160 was never true

161 try: 

162 await self._start() 

163 except self._reraise: 

164 raise 

165 async with abort_orphan_on_cancel(self._cancel_abort): 

166 outcome = await inner() 

167 if outcome.succeeded: 

168 return await self._complete(outcome) 

169 # Best-effort abort: a failed conduct's diagnostic must survive even 

170 # if the FSM cannot be transitioned (already terminal); the injected 

171 # abort suppresses its own rejection. The lifecycle reraise set lets a 

172 # Procedure surface 403/404/409 mappers while a Run (empty set) 

173 # catches broadly. 

174 return await self._abort(outcome)

177@dataclass(frozen=True) 

178class RunConductOutcome: 

179 """Outcome of conducting a single compute Run via `EdgeConductor`. 

180 

181 `status` is the job's terminal `ComputeStatus`, or None when the job 

182 never started (submit was rejected / the substrate was unavailable). 

183 `job_id` / `artifact_ref` / `actuation_kind` carry the captured 

184 provenance (artifact only on success). `failure` is the abort reason 

185 recorded on the Run when the conduct did not succeed, or a 

186 lifecycle-handler error message when the terminal transition itself 

187 was rejected; None on a clean success. 

188 

189 Structurally satisfies the `ConductOutcome` Protocol 

190 (`succeeded` + `actuation_kind`) so the shell treats it uniformly. 

191 """ 

192 

193 run_id: UUID 

194 status: ComputeStatus | None 

195 job_id: JobId | None = None 

196 artifact_ref: ArtifactRef | None = None 

197 actuation_kind: ActuationKind | None = None 

198 failure: str | None = None 

199 

200 @property 

201 def succeeded(self) -> bool: 

202 # Key on is_success (the single source of truth shared with the fetch 

203 # gate in _run_compute) rather than `is SUCCEEDED`, so a future 

204 # non-SUCCEEDED success status cannot route a fetched artifact to abort. 

205 return self.status is not None and self.status.is_success and self.failure is None

208class ComputeRunDriver: 

209 """Conduct a compute Run to its terminal over `ComputePort`. 

210 

211 The compute inner-work + Run terminalizers the `EdgeConductor` shell 

212 drives for a Run: submit -> await -> fetch, then `complete_run` 

213 (carrying the captured provenance + artifact uri) on success, or 

214 best-effort `abort_run` on failure. The Run carries NO start seam 

215 (start_run is the gated entry upstream) and an EMPTY reraise set 

216 (catch broadly), matching the dissolved Reckoner. 

217 

218 This is the dual-reader (REST + MCP) Run-conduct entry. A multi-step 

219 compute Run is conducted as a Procedure PHASE of the Run instead, 

220 via the `conduct_phase_then_complete_run` glue; a single-job Run is 

221 the degenerate case this driver keeps inline (one submit/await/fetch), 

222 so the floor does not force a Procedure phase onto the bare endpoint. 

223 """ 

224 

225 def __init__( 

226 self, 

227 *, 

228 compute_port: ComputePort, 

229 complete_run: CompleteRunHandler, 

230 abort_run: AbortRunHandler, 

231 ) -> None: 

232 self._compute_port = compute_port 

233 self._complete_run = complete_run 

234 self._abort_run = abort_run

236 async def conduct( 

237 self, 

238 *, 

239 run_id: UUID, 

240 job_spec: JobSpec, 

241 principal_id: UUID, 

242 correlation_id: UUID, 

243 causation_id: UUID | None = None, 

244 surface_id: UUID = NIL_SENTINEL_ID, 

245 ) -> RunConductOutcome: 

246 """Conduct an already-`Running` compute Run to its terminal. 

247 

248 Submits `job_spec`, awaits the terminal state, and transitions the 

249 Run via the `EdgeConductor` shell: `complete_run` (provenance + 

250 artifact uri) on `Succeeded`, else best-effort `abort_run`. A 

251 `CancelledError` mid-conduct best-effort aborts the Run and 

252 re-raises. 

253 """ 

254 envelope: dict[str, Any] = { 

255 "principal_id": principal_id, 

256 "correlation_id": correlation_id, 

257 "causation_id": causation_id, 

258 "surface_id": surface_id, 

259 } 

260 # Holds the in-flight job id once submit returns, so the 

261 # cancel-orphan abort (built before the job is known) can record it 

262 # as a breadcrumb. None until submit succeeds (a cancellation during 

263 # submit thus records no job id). 

264 in_flight: list[JobId] = [] 

265 engine: EdgeConductor[RunConductOutcome] = EdgeConductor( 

266 # No start seam for a Run (start_run is the gated entry upstream). 

267 start=None, 

268 complete=lambda outcome: self._issue_complete(run_id, outcome, envelope), 

269 abort=lambda outcome: self._issue_abort(run_id, outcome, envelope), 

270 # Cancel-orphan abort: a conduct cancelled mid-flight leaves the 

271 # Run `Running` with a job in an unknown state. The observed kind 

272 # is unrecoverable on cancellation, so this records None. 

273 cancel_abort=lambda: self._abort_run( 

274 AbortRun( 

275 run_id=run_id, 

276 reason="cancelled mid-compute", 

277 # Obligation gate (Gate III): AbortRun requires a justification 

278 # even for machine-initiated aborts (kind-blind). The conductor 

279 # accounts for itself with the mechanical cause. 

280 justification="edge-conductor: compute conduct cancelled mid-flight", 

281 actuation_kind=None, 

282 producing_job_id=str(in_flight[0]) if in_flight else None, 

283 ), 

284 **envelope, 

285 ), 

286 # Run catches broadly (empty set), exactly as the Reckoner did. 

287 reraise=(), 

288 ) 

289 return await engine.conduct(lambda: self._run_compute(run_id, job_spec, in_flight))

291 async def _run_compute( 

292 self, run_id: UUID, job_spec: JobSpec, in_flight: list[JobId] 

293 ) -> RunConductOutcome: 

294 """Inner work: submit -> await -> fetch, mapping failures to an outcome. 

295 

296 Returns a non-succeeded `RunConductOutcome` (the shell then 

297 best-effort aborts) for any compute failure family, or a succeeded 

298 outcome carrying the artifact + provenance the shell completes with. 

299 Job-id provenance rides the outcome so the shell's abort builder 

300 records it; the cancel path records the in-flight id (kind 

301 unrecoverable, so None there). 

302 """ 

303 try: 

304 job_id = await self._compute_port.submit(job_spec) 

305 except (ComputeSubmitRejectedError, ComputeNotAvailableError) as exc: 

306 return RunConductOutcome( 

307 run_id=run_id, 

308 status=None, 

309 failure=_bounded(f"compute submit failed: {exc}"), 

310 ) 

311 in_flight.append(job_id) 

312 try: 

313 status = await self._compute_port.await_terminal_state(job_id) 

314 except ComputeTimeoutError as exc: 

315 return self._failure_outcome(run_id, job_id, ComputeStatus.TIMED_OUT, str(exc)) 

316 except ComputeJobFailedError as exc: 

317 return self._failure_outcome(run_id, job_id, ComputeStatus.FAILED, str(exc)) 

318 if not status.is_success: 

319 return self._failure_outcome(run_id, job_id, status, _status_reason(status)) 

320 try: 

321 artifact_ref = await self._compute_port.fetch_artifact_ref(job_id) 

322 except ArtifactNotFoundError as exc: 

323 return self._failure_outcome(run_id, job_id, status, str(exc)) 

324 result = self._compute_port.provide_result(job_id, status, (artifact_ref,)) 

325 return RunConductOutcome( 

326 run_id=run_id, 

327 status=status, 

328 job_id=job_id, 

329 artifact_ref=artifact_ref, 

330 actuation_kind=result.actuation_kind, 

331 ) 

332 

333 def _failure_outcome( 

334 self, run_id: UUID, job_id: JobId, status: ComputeStatus, detail: str 

335 ) -> RunConductOutcome: 

336 """A non-success outcome carrying the captured kind + bounded reason.""" 

337 result = self._compute_port.provide_result(job_id, status, ()) 

338 return RunConductOutcome( 

339 run_id=run_id, 

340 status=status, 

341 job_id=job_id, 

342 actuation_kind=result.actuation_kind, 

343 failure=_bounded(detail), 

344 )

346 async def _issue_complete( 

347 self, run_id: UUID, outcome: RunConductOutcome, envelope: dict[str, Any] 

348 ) -> RunConductOutcome: 

349 """The Run complete arm: CompleteRun carries the artifact_uri (asymmetry). 

350 

351 A complete-terminal rejection is NOT swallowed: it is recorded on 

352 the returned outcome's `failure` so the caller sees "the conduct 

353 succeeded but the Run could not be completed." 

354 """ 

355 assert outcome.artifact_ref is not None # success implies an artifact 

356 try: 

357 await self._complete_run( 

358 CompleteRun( 

359 run_id=run_id, 

360 actuation_kind=( 

361 outcome.actuation_kind.value if outcome.actuation_kind is not None else None 

362 ), 

363 producing_job_id=str(outcome.job_id) if outcome.job_id is not None else None, 

364 artifact_uri=outcome.artifact_ref.uri, 

365 ), 

366 **envelope, 

367 ) 

368 except Exception as exc: # lifecycle handler rejected the complete 

369 return replace(outcome, failure=_bounded(f"complete_run rejected: {exc}")) 

370 return outcome 

371 

372 async def _issue_abort( 

373 self, run_id: UUID, outcome: RunConductOutcome, envelope: dict[str, Any] 

374 ) -> RunConductOutcome: 

375 """The Run abort arm: AbortRun, swallowing a lifecycle rejection. 

376 

377 AbortRun carries NO `artifact_uri` (a failed job's partial output is 

378 not registered) - the artifact_uri asymmetry. Best-effort: if the 

379 abort ALSO fails (the Run was already terminal), the original 

380 conduct failure is what the caller sees on the returned outcome. The 

381 Run path's empty reraise set means even a lifecycle-mapped exception 

382 is suppressed here, matching the dissolved Reckoner's broad catch. 

383 """ 

384 with contextlib.suppress(Exception): 

385 await self._abort_run( 

386 AbortRun( 

387 run_id=run_id, 

388 reason=outcome.failure or "compute conduct failed", 

389 # Obligation gate (Gate III): kind-blind, so the conductor 

390 # justifies its own abort with the mechanical failure cause. 

391 justification=f"edge-conductor: {outcome.failure or 'compute conduct failed'}", 

392 actuation_kind=( 

393 outcome.actuation_kind.value if outcome.actuation_kind is not None else None 

394 ), 

395 producing_job_id=str(outcome.job_id) if outcome.job_id is not None else None, 

396 ), 

397 **envelope, 

398 ) 

399 return outcome

409def _status_reason(status: ComputeStatus) -> str: 

410 """Abort reason for a non-success terminal status.""" 

411 return _STATUS_REASON.get(status, f"compute job ended {status.value}")

414def _bounded(text: str) -> str: 

415 """Trim a derived abort reason to fit RunAbortReason's 1-500 bound.""" 

416 trimmed = text.strip() 

417 if len(trimmed) <= _REASON_MAX: 

418 return trimmed 

419 return trimmed[: _REASON_MAX - 3] + "..."
