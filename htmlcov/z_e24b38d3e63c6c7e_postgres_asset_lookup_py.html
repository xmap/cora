1"""Postgres adapter implementing `AssetLookup` over `proj_equipment_asset_summary`. 

2 

3Consumed by cross-BC handlers via the `Kernel.asset_lookup` port to 

4validate cross-aggregate Asset references at command time. First 

5consumer is Supply BC's `register_supply` handler (Session 5 Slice 

67B): it resolves `command.containing_asset_id` to an 

7`AssetLookupResult` and threads the result into the decider. 

8 

9## Why query the projection (not the event store) 

10 

11Per modern DDD guidance (Khononov 2021, Herberto Graca 2017, 

12Dudycz 2024): cross-aggregate integration at command time should 

13go through a replicated read model, NOT a synchronous replay of 

14the upstream aggregate. `proj_equipment_asset_summary` is exactly 

15that: a denormalized cross-stream view maintained by the Asset 

16projection worker. The lookup adapter reads it directly via the 

17shared asyncpg pool. 

18 

19## Query shape 

20 

21Single SELECT keyed by the `asset_id` primary key, LEFT JOINing 

22`proj_equipment_asset_family_membership` and 

23`proj_equipment_family_summary` so the Asset's Family affordances 

24aggregate into one set in the same round-trip. `LEFT JOIN` + 

25`array_agg(... FILTER ...)` keeps an Asset with no Family (or whose 

26Families declare no affordance) resolvable with an empty affordance 

27set, rather than returning no row. `GROUP BY` collapses the 

28one-row-per-Family-membership fan-out back to one row per Asset. 

29 

30Returns `None` when no Asset row matches. Assets in every lifecycle 

31(`Commissioned`, `Active`, `Maintenance`, `Decommissioned`) are 

32returned; consumer deciders partition on `lifecycle` if needed. 

33Slice 7B Supply consumer does NOT filter on lifecycle (mirrors 

34slice 6A `FacilityLookup` precedent: bind anyway, the operator 

35chose to keep the lineage visible). 

36 

37## Enum coercion 

38 

39`tier` and `lifecycle` are stored as `TEXT` columns and typed as 

40`str` on the port's `AssetLookupResult` (to keep 

41`cora.infrastructure.ports.asset_lookup` import-free of Equipment 

42BC types). The adapter still constructs `AssetTier(row["tier"])` 

43/ `AssetLifecycle(row["lifecycle"])` as a validation step: a 

44corrupted row whose `tier` or `lifecycle` is not a known enum 

45value surfaces as `ValueError` from the adapter rather than as a 

46silent wrong-tier match downstream. The validated `StrEnum` value 

47IS-A `str`, so the assignment into the dataclass's `str`-typed 

48fields is exact. 

49""" 

50 

51# pyright: reportUnknownMemberType=false, reportUnknownVariableType=false, reportUnknownArgumentType=false 

52 

53from typing import Any 

54from uuid import UUID 

55 

56import asyncpg 

57 

58from cora.equipment.aggregates.asset import AssetLifecycle, AssetTier 

59from cora.infrastructure.ports.asset_lookup import AssetLookupResult 

60 

61_LOOKUP_SQL = """ 

62SELECT 

63 a.asset_id, 

64 a.name, 

65 a.tier, 

66 a.lifecycle, 

67 COALESCE( 

68 array_agg(DISTINCT aff.affordance) FILTER (WHERE aff.affordance IS NOT NULL), 

69 ARRAY[]::text[] 

70 ) AS family_affordances 

71FROM proj_equipment_asset_summary a 

72LEFT JOIN proj_equipment_asset_family_membership m 

73 ON m.asset_id = a.asset_id 

74LEFT JOIN proj_equipment_family_summary f 

75 ON f.family_id = m.family_id 

76LEFT JOIN LATERAL unnest(f.affordances) AS aff(affordance) ON TRUE 

77WHERE a.asset_id = $1 

78GROUP BY a.asset_id, a.name, a.tier, a.lifecycle 

79""" 

80 

81 

82class PostgresAssetLookup: 

83 """asyncpg-backed `AssetLookup` implementation.""" 

84 

85 def __init__(self, pool: asyncpg.Pool) -> None: 

86 self._pool = pool 

87 

88 async def lookup(self, asset_id: UUID) -> AssetLookupResult | None: 

89 async with self._pool.acquire() as conn: 

90 row = await conn.fetchrow(_LOOKUP_SQL, asset_id) 

91 if row is None: 

92 return None 

93 return _row_to_result(row) 

94 

95 

96def _row_to_result(row: Any) -> AssetLookupResult: 

97 return AssetLookupResult( 

98 id=row["asset_id"], 

99 name=str(row["name"]), 

100 tier=AssetTier(row["tier"]), 

101 lifecycle=AssetLifecycle(row["lifecycle"]), 

102 family_affordances=frozenset(str(a) for a in row["family_affordances"]), 

103 ) 

104 

105 

106__all__ = ["PostgresAssetLookup"]
