1"""Acquisition aggregate state, status enum, and domain errors. 

2 

3An `Acquisition` is the birth-certificate fact that a producing Asset 

4captured bytes into a Dataset under an optional Run context. It is a 

5slim recorded-fact-chain: one stream per Acquisition, exactly one 

6event ever (`AcquisitionRecorded`), terminal at genesis. State IS the 

7event-folded value (slim-aggregate rule). 

8 

9## What an Acquisition is NOT 

10 

11 - Not the bytes (those live wherever the produced Dataset's URI 

12 points) 

13 - Not the Dataset (the Dataset is the logical product; the 

14 Acquisition records the act of capturing it) 

15 - Not an editable record: a flawed Acquisition is corrected by 

16 recording a NEW Acquisition, not by mutating the old one 

17 (fact-chain semantic) 

18 

19## Dual-time pattern 

20 

21`captured_at` and `recorded_at` are BOTH first-class state fields 

22with distinct semantic: 

23 

24 - `captured_at`: caller-asserted provenance about when the physical 

25 capture happened at the instrument (instrument wall-clock). 

26 - `recorded_at`: CORA-side wall-clock when `record_acquisition` ran 

27 (the in-memory state field maps to the event's `occurred_at` 

28 payload key per the CORA transversal-time convention). 

29 

30`captured_at` MAY legitimately precede `recorded_at` by hours or days 

31(operator backfills from an offline acquisition host, post-hoc 

32reprocessor registration, EPICS replay). The decider does NOT enforce 

33`captured_at <= recorded_at`; it only rejects a `captured_at` that is 

34in the future relative to `recorded_at + skew_tolerance`. 

35 

36## Cross-aggregate bindings 

37 

38 - `producing_asset_id` REQUIRED: the capturing Asset. Its Family 

39 MUST declare the Capturing affordance (gate at decider time). 

40 - `dataset_id` REQUIRED: the logical Dataset this capture produced. 

41 - `producing_run_id` OPTIONAL (None for calibration / dark-field / 

42 autonomous-agent standalone captures with no Run context). 

43 

44## Attribution 

45 

46A single `recorded_by: ActorId` carries the every-fact-has-an-actor 

47obligation. The PHYSICAL capturing entity is the `producing_asset_id` 

48(a device, not an actor); only the act of RECORDING the fact into 

49CORA needs an ActorId. Capture-port-driven recordings carry the 

50system principal; operator-initiated registrations carry the 

51operator's ActorId. 

52 

53## Settings and evidence 

54 

55`settings` is a carrier dict validated for primitive-leaf shape 

56today; per-Family schema validation against the producing Asset's 

57Family.settings_schema is deferred. `evidence` is a freeform 

58placeholder dict (primitive-leaf shape only); per-Family evidence 

59schemas are deferred until operator demand surfaces a distinct shape. 

60"""

77class AcquisitionStatus(StrEnum): 

78 """The Acquisition's lifecycle state. 

79 

80 Ships day-one with exactly one value (`RECORDED`). Kept as a 

81 StrEnum (not a constant) for symmetry with every other CORA 

82 aggregate and the BC-status-vocabulary fitness test. Member name 

83 is SCREAMING_SNAKE per Python StrEnum convention; the string value 

84 is PascalCase per the BC-status-vocabulary fitness expectation. 

85 

86 An Acquisition is terminal at genesis: there is no further 

87 transition. A flawed capture is corrected by recording a new 

88 Acquisition, not by mutating this one. 

89 """

271@dataclass(frozen=True, slots=True) 

272class Acquisition: 

273 """Aggregate root: one recorded capture fact. 

274 

275 All fields are set-once at genesis and immutable. Per-Acquisition 

276 streams are exactly one event long; state IS the event-folded 

277 value (slim-aggregate rule). 

278 

279 `recorded_at` is the CORA-side wall-clock (maps to the event's 

280 `occurred_at` payload key); `captured_at` is the instrument 

281 wall-clock carried as a separate first-class field. 

282 """
