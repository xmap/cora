1"""The `DefineMethod` command — intent dataclass for this slice. 

2 

3Carries the caller-controlled inputs: 

4 - `name` — display name for the new Method (the technique class) 

5 - `needed_family_ids` — frozenset of Family ids the Method 

6 requires (eventual-consistency stance: existence not verified 

7 at decide time, mismatch surfaces at Plan binding) 

8 

9Server-side concerns (new aggregate id, wall-clock timestamp, 

10correlation id, per-event ids) are injected by the handler from 

11infrastructure ports, matching the cross-BC create-style command 

12shape locked in Access / Trust / Subject / Equipment. 

13 

14Status is implicit at definition (`Defined`) and not part of the 

15command — see Method aggregate's `state.py` docstring for the 

16enum-in-state, derived-from-event-type-in-evolver convention. 

17 

18`needed_family_ids` is `frozenset[UUID]` (not `list`) so the 

19command itself is hashable for `with_idempotency`'s SHA256 hash; 

20the cross-BC `_normalize_for_hash` helper sorts frozensets for 

21deterministic hashing across worker processes. 

22""" 

23 

24from dataclasses import dataclass, field 

25from uuid import UUID 

26 

27from cora.recipe.aggregates.method import ExecutionPattern 

28 

29 

30@dataclass(frozen=True) 

31class DefineMethod: 

32 """Define a new abstract technique-class recipe (Method). 

33 

34 `needed_supplies` is a frozenset of Supply.kind STRINGS 

35 the Method requires (NOT Supply instance UUIDs). Methods are 

36 facility-portable; the kind label resolves to a per-facility 

37 Supply instance at Plan-bind time. Default empty frozenset 

38 (sample-cleaning Methods need no supplies). Same hashability + 

39 `_normalize_for_hash` story as needed_family_ids. 

40 

41 `needed_input_kinds` is a frozenset of input-Dataset kind STRINGS 

42 the Method consumes (for example "raw-projections", "flat-field", 

43 "prior-reconstruction"), NOT Dataset instance UUIDs. 

44 Eventual-consistency: resolved to concrete input Datasets at 

45 Plan-bind / start_run. Default empty frozenset (a Method that 

46 consumes no prior Datasets). Same hashability + `_normalize_for_hash` 

47 story as needed_supplies. 

48 

49 `capability_id` points to the universal 

50 Capability template (Recipe BC) this Method realizes as a 

51 Method-shaped executor. REQUIRED per Pattern P from 

52 [[project-capability-aggregate-design]] (was optional 

53 during the additive transition window). The handler loads 

54 the Capability via the cross-BC port + the decider validates 

55 that `Capability.executor_shapes` contains Method, raising 

56 `MethodCapabilityExecutorMismatchError` (409) otherwise. A 

57 missing Capability stream raises `CapabilityNotFoundError` 

58 (404) — eventual-consistency: existence is verified at handler 

59 time, not API-boundary time. 

60 

61 Field order keeps `capability_id` before the default-factory 

62 collections (kwargs-only at most callsites; positional callers 

63 in code review get pyright-flagged on the type). 

64 """ 

65

80 # Plan binding. Same hashability + `_normalize_for_hash` story as 

81 # needed_family_ids.

83 # monotone_quality (anytime-algorithm claim) + resumable_from_checkpoint
