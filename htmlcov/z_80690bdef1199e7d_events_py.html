1"""Domain events emitted by the Distribution aggregate plus the discriminated union. 

2 

3Mirrors the locked event-module shape: event classes, discriminated union, 

4``event_type_name``, ``to_payload``, ``from_stored``. The persistence-envelope 

5construction (``NewEvent``) lives at ``cora.infrastructure.event_envelope.to_new_event``. 

6 

7## This module ships three events today 

8 

9 - ``DistributionRegistered`` (genesis): identity + same-BC ref + cross-BC ref + 

10 integrity + size + encoding + transport + attribution. The status is implicit 

11 (``Registered``); the evolver sets it. 

12 - ``DistributionMarkedStale`` (transition, non-terminal): records that the 

13 bytes for this copy are known to be gone or no longer trusted (a storage 

14 failure, a checksum mismatch found out-of-band, or any other grounds an 

15 operator has). Unlike ``DistributionDiscarded``, this RECORDS A FACT ABOUT 

16 THE WORLD rather than a deliberate act CORA is entitled to refuse; the 

17 mark_distribution_stale decider's only guard is structural (the target 

18 must exist and must not already be Discarded). The status is implicit 

19 (``Stale``); the evolver sets it. 

20 - ``DistributionDiscarded`` (transition, terminal): the metadata-only 

21 reclaim-decision record. Bytes are reclaimed out-of-band (same shape as 

22 ``DatasetDiscarded``); this event keeps the reclaim reason + attribution 

23 for audit. The status is implicit (``Discarded``); the evolver sets it. 

24 

25## Future events NAMED but not locked here 

26 

27Per [[project-data-distribution-design]] L18: 

28 

29 - ``DistributionVerified`` (Registered/Verified -> Verified) 

30 

31This will land additively in a follow-on slice. The discriminated union and 

32``from_stored`` switch land its case at that time. The Verified flip stays 

33projection-only today (per state.py "Verified/Stale flip is a projection") 

34and is NOT retro-converted to a stream event by this slice. The Stale flip 

35now has BOTH a projection-only path (AttestationRecorded Mismatch, unchanged) 

36AND a Distribution-stream event (``DistributionMarkedStale``, this slice); see 

37``cora.data.projections.distribution_summary`` for how the two independently 

38reach the same read-model status. 

39 

40## Payload conventions 

41 

42- UUIDs serialize as strings; set-semantic fields (none today on Distribution) 

43 would sort deterministically per the existing convention. 

44- ``checksum`` serializes as a nested object: ``{"algorithm": str, "value": str}`` 

45 matching ``DatasetRegistered.checksum``. 

46- ``encoding`` serializes as a nested object: 

47 ``{"media_type": str, "conforms_to": list[str]}`` with ``conforms_to`` sorted. 

48- ``access_protocol`` serializes as the ``AccessProtocol.value`` bare string per 

49 [[project-facility-aggregate-design]] cryptographic-chain immutability 

50 discipline (no typed-VO wrapping on disk). 

51- Status is NOT carried in the payload; the event type encodes it 

52 (``DistributionRegistered -> REGISTERED``), same precedent as Dataset. 

53"""

67@dataclass(frozen=True) 

68class DistributionRegistered: 

69 """A new Distribution was registered as a materialized byte-copy of a Dataset. 

70 

71 Status is implicit (``Registered``); the evolver sets it. The 

72 cross-aggregate references (``dataset_id``, ``supply_id``) are 

73 eventual-consistency primitives; the handler pre-loads each on the 

74 write path, the evolver does NOT re-verify on fold. 

75 

76 ``checksum: DatasetChecksum`` and ``access_protocol: AccessProtocol`` 

77 are declared as their real value object / enum, not unwrapped to 

78 primitives, for the same closed-vocabulary carve-out as 

79 ``DatasetRegistered`` (see that event's docstring): the record 

80 exporter's generated redaction table resolves a field's disposition 

81 from its DECLARED TYPE, and ``DatasetChecksum`` marks itself 

82 ``ClosedValueObject`` so the exporter keeps it whole, digest 

83 included. 

84 

85 ``encoding: DatasetEncoding`` moved onto the event alongside 

86 ``checksum`` for shape symmetry with ``DatasetRegistered``, not 

87 because it independently qualifies for the carve-out: it is NOT a 

88 ``ClosedValueObject`` and the exporter still recurses into it and 

89 still drops ``media_type``/``conforms_to`` exactly as before. Do not 

90 cite this field as carve-out precedent. 

91 

92 ``to_payload`` / ``from_stored`` still serialize the SAME on-disk 

93 shapes as before this change (``checksum``/``encoding`` as nested 

94 objects, ``access_protocol`` as ``AccessProtocol.value``'s bare 

95 string, per [[project-facility-aggregate-design]] cryptographic-chain 

96 immutability discipline); only the dataclass's declared shape moved 

97 to match what was already on disk. 

98 

99 Fold-symmetry attribution per [[project-fold-symmetry-design]]: 

100 ``registered_by: ActorId`` carries the envelope ``principal_id`` of 

101 the register-slice caller. Carried on the event payload so a future 

102 slice that opts into folding attribution onto Distribution state 

103 already has the data. 

104 """ 

105 

106 distribution_id: UUID 

107 dataset_id: UUID 

108 supply_id: UUID 

109 uri: str 

110 checksum: DatasetChecksum 

111 byte_size: int 

112 encoding: DatasetEncoding 

113 access_protocol: AccessProtocol 

114 occurred_at: datetime 

115 registered_by: ActorId

118@dataclass(frozen=True) 

119class DistributionMarkedStale: 

120 """A Distribution copy's bytes are known to be gone or no longer trusted. 

121 

122 Non-terminal transition (any non-Discarded status -> Stale). Unlike 

123 ``DistributionDiscarded``, this event RECORDS A FACT ABOUT THE WORLD 

124 THAT ALREADY HAPPENED (a storage array failure, a bit-rot finding, or 

125 any other grounds an operator has to no longer trust this copy's 

126 bytes); it is not a deliberate act CORA is entitled to refuse. The 

127 only guard enforced upstream in the decider is structural: the target 

128 must exist and must not already be Discarded (terminal). There is no 

129 redundancy guard and no parent-Dataset guard. ``reason`` is a 

130 free-form string (1-500 chars after trimming), captured verbatim. 

131 

132 ``trigger`` is the locked 3-value ``TriggerSource`` vocabulary, 

133 serialized as its bare ``.value`` string (Supply's identical 

134 treatment, not this module's typed-enum ``access_protocol`` 

135 carve-out): it names WHAT concluded this copy is stale, which 

136 ``reason`` alone cannot, since an operator's storage-failure report 

137 and a sweep's re-probe both produce free text. Only ``Operator`` is 

138 emitted today; the decider hardcodes it rather than accepting it 

139 from the caller, so a principal cannot claim its assertion came 

140 from a monitor. 

141 

142 Fold-symmetry attribution per [[project-fold-symmetry-design]]: 

143 ``marked_stale_by: ActorId`` carries the envelope ``principal_id`` of 

144 the mark_distribution_stale-slice caller. There is deliberately NO 

145 trigger-to-identity pairing check of the kind Supply's events run: 

146 Supply pairs three trigger values against three distinct identity 

147 NewTypes, whereas this event's attribution is ``ActorId`` for every 

148 value the slice can emit, so the check would compare a constant 

149 against a constant. 

150 """ 

151 

152 distribution_id: UUID 

153 reason: str 

154 trigger: str 

155 occurred_at: datetime 

156 marked_stale_by: ActorId

159@dataclass(frozen=True) 

160class DistributionDiscarded: 

161 """A Distribution copy was discarded (any prior status -> Discarded terminal). 

162 

163 Metadata-only, same posture as ``DatasetDiscarded``: the bytes for 

164 this storage-tier copy are reclaimed out-of-band (an operator 

165 workflow against S3 / Globus / POSIX); this event records the 

166 reclaim decision + reason for audit. ``reason`` is a free-form 

167 string (1-500 chars after trimming), captured verbatim. 

168 

169 The guard is enforced upstream in the decider: a copy may be 

170 discarded only when a sibling copy of the same Dataset is Verified 

171 on a different storage tier, and the parent Dataset is not itself 

172 Discarded. The event itself carries no sibling reference; the 

173 redundancy invariant lives at decide-time. 

174 

175 Fold-symmetry attribution per [[project-fold-symmetry-design]]: 

176 ``discarded_by: ActorId`` carries the envelope ``principal_id`` of 

177 the discard-slice caller. 

178 """ 

179 

180 distribution_id: UUID 

181 reason: str 

182 occurred_at: datetime 

183 discarded_by: ActorId

186#: Discriminated union over Distribution events. ``DistributionRegistered`` 

187#: is the genesis arm; ``DistributionMarkedStale`` is a non-terminal 

188#: transition; ``DistributionDiscarded`` is the terminal transition. 

189#: Future slices extend additively (Verified). 

190DistributionEvent = DistributionRegistered | DistributionMarkedStale | DistributionDiscarded

198def to_payload(event: DistributionEvent) -> dict[str, Any]: 

199 """Serialize a Distribution event to a JSON-friendly dict for jsonb storage. 

200 

201 Set-semantic fields (``encoding.conforms_to``) sort deterministically 

202 so two registrations of the same logical Distribution produce 

203 byte-identical jsonb. 

204 """ 

205 match event: 

206 case DistributionRegistered( 

207 distribution_id=distribution_id, 

208 dataset_id=dataset_id, 

209 supply_id=supply_id, 

210 uri=uri, 

211 checksum=checksum, 

212 byte_size=byte_size, 

213 encoding=encoding, 

214 access_protocol=access_protocol, 

215 occurred_at=occurred_at, 

216 registered_by=registered_by, 

217 ): 

218 return { 

219 "distribution_id": str(distribution_id), 

220 "dataset_id": str(dataset_id), 

221 "supply_id": str(supply_id), 

222 "uri": uri, 

223 "checksum": { 

224 "algorithm": checksum.algorithm, 

225 "value": checksum.value, 

226 }, 

227 "byte_size": byte_size, 

228 "encoding": { 

229 "media_type": encoding.media_type, 

230 "conforms_to": sorted(encoding.conforms_to), 

231 }, 

232 "access_protocol": access_protocol.value, 

233 "occurred_at": occurred_at.isoformat(), 

234 "registered_by": str(registered_by), 

235 } 

236 case DistributionMarkedStale( 

237 distribution_id=distribution_id, 

238 reason=reason, 

239 trigger=trigger, 

240 occurred_at=occurred_at, 

241 marked_stale_by=marked_stale_by, 

242 ): 

243 return { 

244 "distribution_id": str(distribution_id), 

245 "reason": reason, 

246 "trigger": trigger, 

247 "occurred_at": occurred_at.isoformat(), 

248 "marked_stale_by": str(marked_stale_by), 

249 } 

250 case DistributionDiscarded( 

251 distribution_id=distribution_id, 

252 reason=reason, 

253 occurred_at=occurred_at, 

254 discarded_by=discarded_by, 

255 ): 

256 return { 

257 "distribution_id": str(distribution_id), 

258 "reason": reason, 

259 "occurred_at": occurred_at.isoformat(), 

260 "discarded_by": str(discarded_by), 

261 } 

262 case _: # pragma: no cover # exhaustiveness guard for future arms 

263 assert_never(event)

266def from_stored(stored: StoredEvent) -> DistributionEvent: 

267 """Rebuild a Distribution event from a ``StoredEvent`` loaded from the event store. 

268 

269 Dispatches on ``stored.event_type``; raises ``ValueError`` on unknown 

270 discriminators so a stream contaminated with foreign event types fails 

271 loud rather than silently being dropped by the evolver. Each per-event 

272 builder is wrapped in ``deserialize_or_raise`` to surface malformed 

273 payloads as ``MalformedDistributionRegistered`` / 

274 ``MalformedDistributionDiscarded`` per 

275 [[project-from-stored-wrap-convention]]. 

276 """ 

277 payload = stored.payload 

278 match stored.event_type: 

279 case "DistributionRegistered": 

280 

281 def _build_registered() -> DistributionRegistered: 

282 raw_checksum = payload["checksum"] 

283 raw_encoding = payload["encoding"] 

284 return DistributionRegistered( 

285 distribution_id=UUID(payload["distribution_id"]), 

286 dataset_id=UUID(payload["dataset_id"]), 

287 supply_id=UUID(payload["supply_id"]), 

288 uri=payload["uri"], 

289 checksum=DatasetChecksum( 

290 algorithm=raw_checksum["algorithm"], value=raw_checksum["value"] 

291 ), 

292 byte_size=int(payload["byte_size"]), 

293 encoding=DatasetEncoding( 

294 media_type=raw_encoding["media_type"], 

295 conforms_to=frozenset(raw_encoding["conforms_to"]), 

296 ), 

297 access_protocol=AccessProtocol(payload["access_protocol"]), 

298 occurred_at=datetime.fromisoformat(payload["occurred_at"]), 

299 registered_by=ActorId(UUID(payload["registered_by"])), 

300 ) 

301 

302 return deserialize_or_raise( 

303 "DistributionRegistered", _build_registered, extra=(ValueError,) 

304 ) 

305 case "DistributionMarkedStale": 

306 return deserialize_or_raise( 

307 "DistributionMarkedStale", 

308 lambda: DistributionMarkedStale( 

309 distribution_id=UUID(payload["distribution_id"]), 

310 reason=payload["reason"], 

311 trigger=payload["trigger"], 

312 occurred_at=datetime.fromisoformat(payload["occurred_at"]), 

313 marked_stale_by=ActorId(UUID(payload["marked_stale_by"])), 

314 ), 

315 ) 

316 case "DistributionDiscarded": 316 ↛ 326line 316 didn't jump to line 326 because the pattern on line 316 always matched

317 return deserialize_or_raise( 

318 "DistributionDiscarded", 

319 lambda: DistributionDiscarded( 

320 distribution_id=UUID(payload["distribution_id"]), 

321 reason=payload["reason"], 

322 occurred_at=datetime.fromisoformat(payload["occurred_at"]), 

323 discarded_by=ActorId(UUID(payload["discarded_by"])), 

324 ), 

325 ) 

326 case _: 

327 msg = f"Unknown DistributionEvent event_type: {stored.event_type!r}" 

328 raise ValueError(msg)
