94 # Authorization — Trust BC wiring 

95 # When None, `build_kernel` wires `AllowAllAuthorize` and every 

96 # command is permitted (legacy default; matches dev/test). When 

97 # set to a UUID, `TrustAuthorize` is wired and gates every command 

98 # through that single Policy aggregate. Multi-policy resolution 

99 # via projections lands in a later phase; until then this is one 

100 # policy per deployment. 

101 # 

102 # The bootstrap migration seeded the System Bootstrap Policy at a 

103 # fixed UUID so production deployments can enable real authz with 

104 # a single env var instead of the old 3-step dance: 

105 # 

106 # TRUST_POLICY_ID=00000000-0000-0000-0000-000000000002 

107 # 

108 # The seed permits SYSTEM_PRINCIPAL_ID to call DefinePolicy + 

109 # RegisterActor on the nil conduit, bound to the seeded HTTP 

110 # Surface — the minimum needed to register a real admin Actor and 

111 # promote a real admin Policy. 

112 # The default stays None (AllowAllAuthorize) for now because 

113 # ~2400 tests pass arbitrary principal_ids; flipping the default 

114 # is gated on a test-fixture audit (memory: 

115 # project_bootstrap_policy_design.md, WI8).

199 # `llm_enabled` is the SWITCH; `anthropic_api_key` below is the 

200 # CREDENTIAL. Both are required before CORA calls an external model, 

201 # and this one defaults OFF. 

202 # 

203 # Why a switch at all, when a key is already needed: the key is often 

204 # present in an environment for an unrelated reason, and its mere 

205 # presence used to be enough to auto-register RunDebriefer + 

206 # CautionDrafter, which call an external API on EVERY terminal Run. 

207 # That is experiment metadata leaving the facility (EGRESS) and money 

208 # being spent (SPEND), switched on by a side effect. Every one of the 

209 # ~13 sibling subscribers carries its own `*_enabled` default-off 

210 # flag; this seam was the outlier. 

211 # 

212 # Egress and spend are a DIFFERENT axis from actuation (the 

213 # ControlPort write gate and the ComputePort exec allowlist, see 

214 # `control_writes_enabled`). A facility told "read-only, CORA cannot

216 # be unhappy to discover CORA phoned its data out. Both promises 

217 # belong to the observe-only posture; neither subsumes the other.
