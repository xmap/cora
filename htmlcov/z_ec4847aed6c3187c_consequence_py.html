1"""Consequence gate (Gate IV): the declared class of commands that require a 

2second, independent principal's co-signature (a Granted Ratification) before they 

3are admitted. 

4 

5Kept in `cora.shared` (neutral) so the Run-side decider can consult it without a 

6Trust import, mirroring how bounded-text limits live in `cora.shared.text_bounds`. 

7The membership test is the gate's TRIGGER; the `ConsequenceLookup` port answers 

8the orthogonal COVERAGE question ("is there a Granted Ratification for this 

9action?"). Keeping the two separate is what keeps the gate's marginal cost a pure 

10fold + decider arm. 

11 

12## Allowlist-first (rule-of-three deferred) 

13 

14The declared class is a static frozenset of command names, mirroring the 

15obligation gate's allowlist and the required-role sets. A Capability-declared 

16`consequence_class` (per-action, data-driven) is the richer version; it is 

17deferred until a second in-scope command appears (rule of three). A log-folded 

18first-of-kind refinement of the trigger (co-sign only the FIRST time a command is 

19run against a scope) is a documented follow-up and does not change this module's 

20contract. 

21 

22## v1 membership 

23 

24`StopRun` only: a deliberate, non-emergency, irreversible early termination of a 

25running experiment. NOT `AbortRun` (emergency exit; holding an emergency for a 

26co-signature inverts the safety posture). 

27""" 

28 

29from typing import Final 

30 

31COMMANDS_REQUIRING_RATIFICATION: Final[frozenset[str]] = frozenset({"StopRun"}) 

32 

33 

34def requires_ratification(command_name: str) -> bool: 

35 """Return True iff `command_name` is in the declared consequence class.""" 

36 return command_name in COMMANDS_REQUIRING_RATIFICATION 

37 

38 

39__all__ = ["COMMANDS_REQUIRING_RATIFICATION", "requires_ratification"]
